# Infraction Quick Reference

[[General Index|General index]] · [[Tournament Rules Index|Tournament index]] · [[Quick Reference/Infraction Quick Reference.pdf|Print-ready A4 PDF]]

**NOP = No Penalty; W = Warning; GL = Game Loss; ML = Match Loss; DQ = Disqualification.**

Names are shortened; each links to its full rule. Use the PDF for the verified one-page A4 layout.

## Gameplay errors

**Upgrades:** 3rd W in the same category -> GL. Competitive: 6th gameplay W -> GL; Professional: 5th -> GL. Exclude Failure to Maintain Game State from automatic upgrades. See [[Game Play Errors]].

| Name | Penalty | Remedy / situational upgrade |
| --- | :---: | --- |
| [[Missed Trigger|Missed trigger]] <span title="Tournament rule 702.2 · PDF page 36" aria-label="Source rule">ⓘ</span> | NOP / W | W only for a missed mandatory trigger that benefits its accountable player. Previous turn: leave missed. Same turn: opp chooses resolve now or miss. |
| [[Forgetting to Score a Point|Missed point]] <span title="Tournament rule 702.3 · PDF page 37" aria-label="Source rule">ⓘ</span> | NOP | Correct hold/conquer score if determinable and <=1 cycle; otherwise continue. Card-trigger points use Missed Trigger. |
| [[Forgetting to Draw Cards|Missed draw]] <span title="Tournament rule 702.4 · PDF page 37" aria-label="Source rule">ⓘ</span> | NOP* | Draw missing cards if determinable and <=1 cycle; otherwise continue. |
| [[Looking at Extra Cards|Looked at extra cards]] <span title="Tournament rule 702.5 · PDF page 37" aria-label="Source rule">ⓘ</span> | W | While still looking: opp chooses extras to shuffle back. If moved to a new group, opp first returns cards to the looked-at group. Caught later: continue. |
| [[Channeling Too Many Runes|Channeled too many]] <span title="Tournament rule 702.6 · PDF page 38" aria-label="Source rule">ⓘ</span> | W | Used for payment: rewind if possible; else General Error. Within <=1 cycle: shuffle extras into Rune Deck (random runes if unidentified); later: continue. |
| [[Channeling Too Few Runes|Channeled too few]] <span title="Tournament rule 702.7 · PDF page 38" aria-label="Source rule">ⓘ</span> | NOP* | Channel missing runes within <=1 cycle; otherwise continue. |
| [[Overpayment for Cost|Overpaid cost]] <span title="Tournament rule 702.8 · PDF page 38" aria-label="Source rule">ⓘ</span> | NOP* | Simple rewind before card/ability entered Chain; otherwise continue. If overpay caused a result that would not otherwise happen: General Error. |
| [[Mispayment for Cost|Mispaid cost]] <span title="Tournament rule 702.9 · PDF page 39" aria-label="Source rule">ⓘ</span> | W | Simple rewind; else correct payment if possible; else continue. Incorrectly recycled runes: rewind if possible. |
| [[Looking at Secret Information|Saw secret info]] <span title="Tournament rule 702.10 · PDF page 39" aria-label="Source rule">ⓘ</span> | W | Re-randomize exposed cards with original random source; if impossible, reveal info to all and continue. |
| [[Looking at Opponent Private Information|Saw opponent private info]] <span title="Tournament rule 702.11 · PDF page 39" aria-label="Source rule">ⓘ</span> | W | Affected opponent may re-randomize exposed cards with original random source; if declined, continue. |
| [[Drawing Extra Cards|Drew extra cards]] <span title="Tournament rule 702.12 · PDF page 40" aria-label="Source rule">ⓘ</span> | W | Before joining a private set, or opening hand before mulligan: shuffle extras back. After joining a private set, within cycle: opp sees hand and chooses extras to shuffle back. Later excess hand: apply remedy then. |
| [[Facedown Card Error|Facedown error]] <span title="Tournament rule 702.13 · PDF page 40" aria-label="Source rule">ⓘ</span> | W / GL | Added: immediate self-catch, no further actions -> return; later, before new unknown cards join origin -> return and replace with random legal card. No replacement/new unknown cards -> GL. Removed: return if same turn and identifiable/recoverable; else GL. |
| [[Mulligan Procedure Error|Mulligan error]] <span title="Tournament rule 702.14 · PDF page 41" aria-label="Source rule">ⓘ</span> | W | Mulliganed >2: opp sees hand and may choose up to the excess number to recycle/replace. Gameplay already begun: continue. |
| [[Forgetting to Ready During the Awaken Phase|Missed Awaken ready]] <span title="Tournament rule 702.15 · PDF page 41" aria-label="Source rule">ⓘ</span> | NOP* | Same turn: ready objects that should have readied; suppress resulting triggers. Later turn: leave unchanged. |
| [[General Error|General error]] <span title="Tournament rule 702.16 · PDF page 41" aria-label="Source rule">ⓘ</span> | W | Rewind if possible; otherwise continue. |
| [[Failure to Maintain Game State|Failure to maintain state]] <span title="Tournament rule 702.17 · PDF page 42" aria-label="Source rule">ⓘ</span> | W | Tracking warning; fix underlying error under its own remedy. No automatic upgrade; HJ may specifically instruct one. |

## Tournament errors

**Upgrades:** 3rd W in the same category -> GL. Competitive: 6th tournament W -> GL; Professional: 5th -> GL. Count separately from gameplay warnings. See [[Tournament Errors]].

| Name | Penalty | Remedy / situational upgrade |
| --- | :---: | --- |
| [[Slow Play|Slow play]] <span title="Tournament rule 703.2 · PDF page 42" aria-label="Source rule">ⓘ</span> | W | Require timely play; no specific game-state repair prescribed. Intentional stalling for advantage -> Cheating (DQ). |
| [[Decklist Error|Decklist error]] <span title="Tournament rule 703.3 · PDF page 42" aria-label="Source rule">ⓘ</span> | GL | Illegal list: minimal changes to legalize, then match deck to list. Legal presented deck differs: update list to deck. HJ may proxy unavailable correction cards. |
| [[Deck Presentation Error|Deck presentation]] <span title="Tournament rule 703.4 · PDF page 43" aria-label="Source rule">ⓘ</span> | W / GL | Before hands: restore. After hands: self-caught + easily restorable -> fix; caught by others or cannot restore -> GL. Pro extra deck-box cards -> GL. Forgotten champion: before first turn, restore; later Casual player searches deck/hand/SB, Competitive judge finds registered G1 champion in deck/hand, Pro leaves zone empty. If from hand, draw replacement; shuffle random deck; no champion found -> leave empty. HJ may proxy. |
| [[Communication Violation|Communication]] <span title="Tournament rule 703.5 · PDF page 45" aria-label="Source rule">ⓘ</span> | W | Supply correct information; rewind decisions based on incorrect communication if possible. |
| [[Marked Cards (Penalty)|Marked cards]] <span title="Tournament rule 703.6 · PDF page 45" aria-label="Source rule">ⓘ</span> | W | Judge may require sleeve removal or sleeve/card replacement now or before next round. HJ may proxy unavailable cards. |
| [[Insufficient Randomization|Insufficient randomization]] <span title="Tournament rule 703.7 · PDF page 45" aria-label="Source rule">ⓘ</span> | W | Player re-randomizes, or judge randomizes deck. Pile shuffling alone is insufficient. |
| [[Late to Match|Late to match]] <span title="Tournament rule 703.8 · PDF page 46" aria-label="Source rule">ⓘ</span> | W / GL / ML | <=2 min: W + extension. >2 to <=10 min: W + extension; Competitive/Pro -> GL. >10 min: ML. No-show: ML + drop unless reporting before next match. Judge may approve <=10-min extension instead, if requested before clock starts or between games. |
| [[Outside Assistance|Outside assistance]] <span title="Tournament rule 703.9 · PDF page 46" aria-label="Source rule">ⓘ</span> | NOP / W / ML / DQ | Refuses advice + calls judge: W; otherwise ML. HJ deems advice malicious: NOP for recipient. Solicited advice -> Cheating (DQ). Same penalty for adviser if also a player; malicious/knowing spectators may be barred. Electronic-device violation: W. |
| [[Improperly Determining a Winner|Improper winner]] <span title="Tournament rule 703.10 · PDF page 46" aria-label="Source rule">ⓘ</span> | ML / DQ | Pro: DQ. Knowingly attempting or baiting -> Cheating (DQ). Apply loss; no other remedy prescribed. |

## Quick reminders

NOP* becomes W if the error was obviously advantageous. Opp = next opponent in turn order (except the affected opponent for private info). One cycle ends when the player whose turn contained the error starts their next turn. Shuffle only the randomized portion; preserve known positions. Simple rewinds: any judge; complex: HJ/authorized appeals judge. Casual: generally softer; opponent-choice fixes may be random/judge-made. Report GL or higher to HJ. Every DQ starts an investigation.
