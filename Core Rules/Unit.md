<details class="rule-ref"><summary title="Core rule 141.1.a · PDF page 17" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 141.1.a · PDF page 17</div></details>

Units are at one of several [[Location|Locations]] while on [[Board|the Board]]: a [[Battlefield]] or their [[Base]]. ^cr-141-1-a-1

<details class="rule-ref"><summary title="Core rule 141.1.a.1 · PDF page 17" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 141.1.a.1 · PDF page 17</div></details>

<details class="rule-ref"><summary title="Core rule 141.1.a.2 · PDF page 17" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 141.1.a.2 · PDF page 17</div></details>

Units can be chosen, affected, or manipulated by [[Spell|spells]], affects, or [[Game Action|game actions]] that specify Units. ^cr-141-1-a-3

<details class="rule-ref"><summary title="Core rule 141.1.a.3 · PDF page 17" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 141.1.a.3 · PDF page 17</div></details>

See [[Kill#^cr-429|Kill]] for more information.

<details class="rule-ref"><summary title="Core rule 141.1.a.4 · PDF page 17" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 141.1.a.4 · PDF page 17</div></details>

While in the [[Trash]]: ^cr-141-1-b

<details class="rule-ref"><summary title="Core rule 141.1.b · PDF page 17" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 141.1.b · PDF page 17</div></details>

Units are treated as [[Card|Cards]], similar to when in the [[Hand]]. ^cr-141-1-b-1

<details class="rule-ref"><summary title="Core rule 141.1.b.1 · PDF page 17" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 141.1.b.1 · PDF page 17</div></details>

They retain the properties of being a Unit, but are not on [[Board|the Board]] and thus cannot take actions or be affected by [[Spell|spells]], [[Ability|abilities]], or [[Game Action|game actions]] that target Units on the Board. ^cr-141-1-b-2

<details class="rule-ref"><summary title="Core rule 141.1.b.2 · PDF page 17" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 141.1.b.2 · PDF page 17</div></details>

<details class="rule-ref"><summary title="Core rule 141.1.b.3 · PDF page 17" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 141.1.b.3 · PDF page 17</div></details>

[[Damage]] is a marked value that is applied to Units. ^cr-142

<details class="rule-ref"><summary title="Core rule 142 · PDF page 18" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 142 · PDF page 18</div></details>

[[Damage]] is not a [[Game Object]]. ^cr-142-1

<details class="rule-ref"><summary title="Core rule 142.1 · PDF page 18" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 142.1 · PDF page 18</div></details>

[[Damage]] is a value tracked per-Unit. ^cr-142-2

<details class="rule-ref"><summary title="Core rule 142.2 · PDF page 18" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 142.2 · PDF page 18</div></details>

[[Damage]] is marked on Units by players. ^cr-142-3

<details class="rule-ref"><summary title="Core rule 142.3 · PDF page 18" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 142.3 · PDF page 18</div></details>

The player responsible for the [[Deal]] action that caused the [[Damage]] to be marked is the player who marked that Damage. ^cr-142-3-a

<details class="rule-ref"><summary title="Core rule 142.3.a · PDF page 18" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 142.3.a · PDF page 18</div></details>

[[Game Effect|Game Effects]] may refer to that player’s [[Damage]]. This means the Damage marked by that player. ^cr-142-3-b

**Example:** A unit reads in part “Your [[Damage|damage]] can’t be prevented.” This refers to the damage marked by that player.

<details class="rule-ref"><summary title="Core rule 142.3.b · PDF page 18" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 142.3.b · PDF page 18</div></details>

[[Damage]] tracks how close a Unit is to being [[Kill|Killed]]. ^cr-142-4

See [[Kill#^cr-429|Kill]] for more information.

<details class="rule-ref"><summary title="Core rule 142.4 · PDF page 18" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 142.4 · PDF page 18</div></details>

[[Lethal Damage]] is the amount of marked [[Damage]] that will cause a unit to die in a [[Cleanups|cleanup]]. ^cr-142-4-a

<details class="rule-ref"><summary title="Core rule 142.4.a · PDF page 18" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 142.4.a · PDF page 18</div></details>

[[Lethal Damage]] for a Unit is a non-zero amount greater than or equal to that Unit’s [[Might]]. ^cr-142-4-b

**Example:** A unit has 5 &#91;M&#93; and 3 [[Damage|damage]] marked on it. Frigid Touch is played [[Targeting|targeting]] that unit. When it resolves, the unit’s [[Might]] becomes 3, and it will have [[Lethal Damage|lethal damage]] marked on it.

**Example:** A unit has 0 &#91;M&#93;. In order to have [[Lethal Damage|lethal damage]] marked on it, it must have at least 1 [[Damage|damage]] marked on it.

<details class="rule-ref"><summary title="Core rule 142.4.b · PDF page 18" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 142.4.b · PDF page 18</div></details>

Some effects may alter this amount. These effects will refer to the amount of [[Damage|damage]] needed to [[Kill|kill]] a unit. ^cr-142-4-c

**Example:** Elder Dragon’s [[Passive Ability|passive ability]] reads “Any amount of your [[Damage|damage]] is enough to [[Kill|kill]] [[Enemy|enemy]] units.” This alters the [[Lethal Damage]] value for enemy units that have damage marked by you.

<details class="rule-ref"><summary title="Core rule 142.4.c · PDF page 18" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 142.4.c · PDF page 18</div></details>

[[Damage]] can be Healed. ^cr-142-5

See [[Heal#^cr-419|Heal]] for more information.

<details class="rule-ref"><summary title="Core rule 142.5 · PDF page 18" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 142.5 · PDF page 18</div></details>

Units have multiple Intrinsic Properties [[Unique|unique]] to them: ^cr-143

<details class="rule-ref"><summary title="Core rule 143 · PDF page 18" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 143 · PDF page 18</div></details>

[[Tag]]: A Unit has zero or more Tags representing one or more [[Champion|champions]], regions, factions, or species it belongs to. ^cr-143-1

<details class="rule-ref"><summary title="Core rule 143.1 · PDF page 18" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 143.1 · PDF page 18</div></details>

These have no intrinsic rules or behaviors by themselves. ^cr-143-1-a

<details class="rule-ref"><summary title="Core rule 143.1.a · PDF page 18" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 143.1.a · PDF page 18</div></details>

[[Spell|Spells]], [[Ability|abilities]], and [[Game Action|game actions]] can reference these types as part of their execution. ^cr-143-1-b

<details class="rule-ref"><summary title="Core rule 143.1.b · PDF page 18" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 143.1.b · PDF page 18</div></details>

[[Might]]: The [[Combat|combat]] statistic of a Unit. Used to determine a Unit's contribution to Combat, as well as when it is [[Kill|Killed]] by damaging effects. ^cr-143-2

<details class="rule-ref"><summary title="Core rule 143.2 · PDF page 19" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 143.2 · PDF page 19</div></details>

A Unit’s [[Might]] can be referenced by [[Card|cards]] and effects in one of three forms: A Unit has a [[Printed Might]], that is the value in the top right corner of the unit card/[[Token|token]]; a [[Base Might]], that is a trait that is alterable by effects in the Trait-Altering layer; and an [[Effective Might]], that is the value calculated in the arithmetic layer including all Might altering [[Game Effect|Game Effects]]. ^cr-143-2-a

See [[Layers#^cr-475|Layers]] for more information.

<details class="rule-ref"><summary title="Core rule 143.2.a · PDF page 19" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 143.2.a · PDF page 19</div></details>

[[Card]] text may refer to the latter two of these three forms. When cards or these rules refer to a Unit’s [[Effective Might]], they will do so by simply referring to that unit’s “[[Might]].” ^cr-143-2-a-1

**Example:** A [[Card|card]] reads in part “Choose a unit. Its [[Base Might|base Might]] becomes 5 this [[Turn|turn]].” This applies an effect in the trait-altering layer.

**Example:** A [[Card|card]] reads in part “Choose a unit. Increase its [[Might]] to 5 this [[Turn|turn]].” This applies an effect in the arithmetic layer.

<details class="rule-ref"><summary title="Core rule 143.2.a.1 · PDF page 19" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 143.2.a.1 · PDF page 19</div></details>

If a Unit ever has nonzero [[Damage|damage]] marked on it equalling or exceeding its [[Might]], it is [[Kill|Killed]]. ^cr-143-2-b

<details class="rule-ref"><summary title="Core rule 143.2.b · PDF page 19" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 143.2.b · PDF page 19</div></details>

If a unit's [[Might]] is ever less than 0, it is treated as 0 when referenced by [[Spell|spells]] and [[Ability|abilities]], and when summing Might to be assigned as [[Damage|damage]] in the [[Combat]] Damage Step. ^cr-143-2-c

See [[Combat Procedure#^cr-467|The Combat Damage Step]] for more information.

<details class="rule-ref"><summary title="Core rule 143.2.c · PDF page 19" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 143.2.c · PDF page 19</div></details>

Although the unit’s [[Might]] is treated as 0, it is not 0. Effects that calculate Might increases and decreases use the actual value of the unit’s Might. ^cr-143-2-c-1

<details class="rule-ref"><summary title="Core rule 143.2.c.1 · PDF page 19" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 143.2.c.1 · PDF page 19</div></details>

Units can have [[Damage|damage]] marked on them. ^cr-143-3

<details class="rule-ref"><summary title="Core rule 143.3 · PDF page 19" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 143.3 · PDF page 19</div></details>

When [[Spell|spells]], [[Ability|abilities]], or other [[Game Effect|game effects]] [[Deal|deal]] [[Damage|damage]], Units mark that damage on them temporarily. This can be tracked with coins, dice, or other markers, or by memory. ^cr-143-3-a

<details class="rule-ref"><summary title="Core rule 143.3.a · PDF page 19" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 143.3.a · PDF page 19</div></details>

[[Damage]] is Healed from Units at two specific times: ^cr-143-3-b

<details class="rule-ref"><summary title="Core rule 143.3.b · PDF page 19" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 143.3.b · PDF page 19</div></details>

At the end of each player's [[Turn|turn]]. ^cr-143-3-b-1

See [[Ending Phase#^cr-317-2|Ending Phase]] for more information.

<details class="rule-ref"><summary title="Core rule 143.3.b.1 · PDF page 19" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 143.3.b.1 · PDF page 19</div></details>

During a [[Combat]] [[Cleanups|Cleanup]]. ^cr-143-3-b-2

See [[Combat Procedure#^cr-468-1|Combat Procedure]] for more information about [[Combat]] [[Cleanups]].

<details class="rule-ref"><summary title="Core rule 143.3.b.2 · PDF page 19" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 143.3.b.2 · PDF page 19</div></details>

Units enter [[Board|the Board]] [[Exhaust|exhausted]]. ^cr-143-4

<details class="rule-ref"><summary title="Core rule 143.4 · PDF page 19" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 143.4 · PDF page 19</div></details>

This can be altered by [[Accelerate]] or similar [[Game Effect|game effects]]. ^cr-143-4-a

See [[Accelerate#^cr-805|Accelerate]] for more information.

<details class="rule-ref"><summary title="Core rule 143.4.a · PDF page 19" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 143.4.a · PDF page 19</div></details>

Units cannot be [[Attached]] to other [[Permanent|permanents]]. ^cr-143-5

See [[Attach#^cr-435|Attach]] for more information on the [[Attach|attach]] [[Game Action|game action]].

See [[Attachment#^cr-716|Attachment]] for more information on [[Attachment|attachment]].

<details class="rule-ref"><summary title="Core rule 143.5 · PDF page 19" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 143.5 · PDF page 19</div></details>

If a Unit would be [[Attached]] to a [[Permanent|permanent]], nothing happens. ^cr-143-5-a

<details class="rule-ref"><summary title="Core rule 143.5.a · PDF page 19" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 143.5.a · PDF page 19</div></details>

If a non-Unit [[Game Object]] that is [[Attached]] becomes a Unit through any means, it [[Detach|detaches]] as it becomes a Unit. ^cr-143-5-b

<details class="rule-ref"><summary title="Core rule 143.5.b · PDF page 19" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 143.5.b · PDF page 19</div></details>

Units have the Inherent [[Ability]] to perform a [[Standard Move]]. ^cr-144

<details class="rule-ref"><summary title="Core rule 144 · PDF page 19" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 144 · PDF page 19</div></details>

This action is limited in when it can be performed. ^cr-144-1

<details class="rule-ref"><summary title="Core rule 144.1 · PDF page 20" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 144.1 · PDF page 20</div></details>

This action can be done any time during a player's [[Main Phase]]. ^cr-144-1-a

<details class="rule-ref"><summary title="Core rule 144.1.a · PDF page 20" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 144.1.a · PDF page 20</div></details>

This action cannot be performed during a [[Closed State]]. ^cr-144-1-b

<details class="rule-ref"><summary title="Core rule 144.1.b · PDF page 20" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 144.1.b · PDF page 20</div></details>

This action cannot be performed during a [[Showdowns|Showdown]] or [[Combat]]. ^cr-144-1-c

<details class="rule-ref"><summary title="Core rule 144.1.c · PDF page 20" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 144.1.c · PDF page 20</div></details>

[[Exhaust|Exhausting]] the Unit is the [[Costs|Cost]] for this action. ^cr-144-2

<details class="rule-ref"><summary title="Core rule 144.2 · PDF page 20" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 144.2 · PDF page 20</div></details>

Players may perform multiple Units' [[Standard Move|standard move]] simultaneously. This is treated as one [[Game Action|game action]] performed on multiple Units. ^cr-144-3

<details class="rule-ref"><summary title="Core rule 144.3 · PDF page 20" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 144.3 · PDF page 20</div></details>

When a [[Move]] like this is declared by a player, the units' Destination must be the same. ^cr-144-3-a

<details class="rule-ref"><summary title="Core rule 144.3.a · PDF page 20" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 144.3.a · PDF page 20</div></details>

When a [[Move]] like this is declared by a player, the Origins do not need to be the same. ^cr-144-3-b

<details class="rule-ref"><summary title="Core rule 144.3.b · PDF page 20" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 144.3.b · PDF page 20</div></details>

The [[Costs]] of [[Exhaust|Exhausting]] the Units are also paid Simultaneously. ^cr-144-3-c

<details class="rule-ref"><summary title="Core rule 144.3.c · PDF page 20" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 144.3.c · PDF page 20</div></details>

The Destinations where Units can [[Move]] to with their [[Standard Move]] are restricted: ^cr-144-4

<details class="rule-ref"><summary title="Core rule 144.4 · PDF page 20" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 144.4 · PDF page 20</div></details>

<details class="rule-ref"><summary title="Core rule 144.4.a · PDF page 20" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 144.4.a · PDF page 20</div></details>

Units cannot [[Move]] to a [[Battlefield]] that already has units from 2 other players present, or where a [[Combat]] is ongoing that has 2 other players as participants. ^cr-144-4-a-1

See [[Movement#^cr-449-2|Movement]] for more information on valid destinations for [[Movement|movement]].

<details class="rule-ref"><summary title="Core rule 144.4.a.1 · PDF page 20" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 144.4.a.1 · PDF page 20</div></details>

See [[Activated Ability#^cr-376|Activated Abilities]] for more information.

<details class="rule-ref"><summary title="Core rule 145.1 · PDF page 20" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 145.1 · PDF page 20</div></details>
