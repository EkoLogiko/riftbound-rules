# Mighty

[[Start Here|Home]] · [[Concept Index|Find a concept]] · [[Core Rules Index|Core rules]]

<span title="Core rule 706"></span> ^cr-706

<details class="rule-ref"><summary title="Core rule 706 · PDF page 116" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 706 · PDF page 116</div></details>

Mighty is a description that applies to some [[Unit|units]]. Other [[Game Effect|game effects]] can check whether a unit is Mighty. ^cr-707

<details class="rule-ref"><summary title="Core rule 707 · PDF page 116" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 707 · PDF page 116</div></details>

A [[Unit]] "is Mighty" as long as its [[Might]] is 5 or greater. ^cr-708

<details class="rule-ref"><summary title="Core rule 708 · PDF page 116" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 708 · PDF page 116</div></details>

A [[Unit]] "becomes Mighty" at the moment its [[Might]] changes from being less than 5 to being 5 or greater. ^cr-709

**Example:** A [[Unit]] with [[Might]] 4 that gets +1 &#91;M&#93; becomes Mighty.

**Example:** A [[Unit]] with [[Might]] 5 that gets +1 &#91;M&#93; does not become Mighty, because it was already Mighty.

<details class="rule-ref"><summary title="Core rule 709 · PDF page 116" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 709 · PDF page 116</div></details>

[[Unit|Units]] on [[Board|the board]] are evaluated according to their current [[Might]]. ^cr-710

**Example:** A [[Unit|unit]] with a [[Base Might|base Might]] of 3 is targeted by a [[Spell|spell]] that reads "A unit gets +3 &#91;M&#93; this [[Turn|turn]]." As that spell resolves, its [[Might]] changes from 3 to 6, and it becomes Mighty. When that effect expires at the end of the turn, it will no longer be Mighty.

<details class="rule-ref"><summary title="Core rule 710 · PDF page 116" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 710 · PDF page 116</div></details>

[[Unit|Units]] in [[Non-Board Zones]] are evaluated according to their [[Printed Might|printed Might]]. ^cr-711

**Example:** A [[Unit|unit]] in the [[Trash|trash]] is Mighty if its [[Printed Might|printed Might]] is 5 or greater. It doesn't matter if there were effects raising or lowering its [[Might|might]] while it was on [[Board|the board]].
