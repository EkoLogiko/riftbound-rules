# Counter

[[Start Here|Home]] · [[Concept Index|Find a concept]] · [[Core Rules Index|Core rules]]

<span title="Core rule 426"></span> ^cr-426

<details class="rule-ref"><summary title="Core rule 426 · PDF page 85" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 426 · PDF page 85</div></details>

Countering is the act of negating the execution, activation, or otherwise playing of a [[Card|card]] or [[Ability|ability]] by a player. ^cr-426-1

<details class="rule-ref"><summary title="Core rule 426.1 · PDF page 85" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 426.1 · PDF page 85</div></details>

A [[Card|card]] or [[Ability|ability]] that is Countered does nothing and is cleared from the [[Chain|chain]]. ^cr-426-1-a

<details class="rule-ref"><summary title="Core rule 426.1.a · PDF page 85" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 426.1.a · PDF page 85</div></details>

[[Card|Cards]] that are cleared from the [[Chain|chain]] in this way are placed in the [[Trash|trash]]. ^cr-426-1-a-1

<details class="rule-ref"><summary title="Core rule 426.1.a.1 · PDF page 85" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 426.1.a.1 · PDF page 85</div></details>

A [[Card|card]] that is Countered is not considered to have been played for [[Ability|abilities]] that trigger on cards being played. ^cr-426-1-b

<details class="rule-ref"><summary title="Core rule 426.1.b · PDF page 85" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 426.1.b · PDF page 85</div></details>

Countering does not refund any [[Costs|costs]] paid to [[Play|play]] a [[Card|card]], activate an [[Ability|ability]], or trigger an ability. ^cr-426-1-c

<details class="rule-ref"><summary title="Core rule 426.1.c · PDF page 85" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 426.1.c · PDF page 85</div></details>

This includes additional [[Costs|costs]]. ^cr-426-1-c-1

<details class="rule-ref"><summary title="Core rule 426.1.c.1 · PDF page 85" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 426.1.c.1 · PDF page 85</div></details>

Countering is a [[Limited Action]]. ^cr-426-2

<details class="rule-ref"><summary title="Core rule 426.2 · PDF page 86" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 426.2 · PDF page 86</div></details>

Players may only Counter [[Card|cards]] and [[Ability|abilities]] when directed to by [[Game Effect|Game Effects]]. ^cr-426-2-a

<details class="rule-ref"><summary title="Core rule 426.2.a · PDF page 86" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 426.2.a · PDF page 86</div></details>

This action is formatted as "Counter &#91;a [[Card|card]] or [[Ability|ability]] on the [[Chain|chain]]&#93;." ^cr-426-3
