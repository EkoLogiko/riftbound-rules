# Showdowns

[[Start Here|Home]] · [[Concept Index|Find a concept]] · [[Core Rules Index|Core rules]]

<!-- flowchart-links:start -->

<!-- flowchart-links:end -->

<span title="Core rule 341"></span> ^cr-341

<details class="rule-ref"><summary title="Core rule 341 · PDF page 45" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 341 · PDF page 45</div></details>

A Showdown is a Window of Opportunity in which Players have an [[Open State]] in which they may [[Play|play]] [[Spell|Spells]] in an alternating fashion. ^cr-342

<details class="rule-ref"><summary title="Core rule 342 · PDF page 45" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 342 · PDF page 45</div></details>

Each [[Spell|spell]] played this way creates a [[Chain]] as normal. ^cr-342-1

<details class="rule-ref"><summary title="Core rule 342.1 · PDF page 45" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 342.1 · PDF page 45</div></details>

The State of [[Turn|the turn]] is partially determined by whether or not a Showdown or [[Combat]] is in progress. ^cr-343

<details class="rule-ref"><summary title="Core rule 343 · PDF page 45" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 343 · PDF page 45</div></details>

[[Turn|The turn]] is said to be in a [[Showdown State]] if a Showdown or [[Combat]] is in progress. ^cr-343-1

<details class="rule-ref"><summary title="Core rule 343.1 · PDF page 45" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 343.1 · PDF page 45</div></details>

[[Card|Cards]] of all Categories, by default, cannot be played during a [[Showdown State]]. ^cr-343-1-a

<details class="rule-ref"><summary title="Core rule 343.1.a · PDF page 45" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 343.1.a · PDF page 45</div></details>

[[Card]] [[Ability|abilities]], by default, cannot be played during a [[Showdown State]]. ^cr-343-1-b

<details class="rule-ref"><summary title="Core rule 343.1.b · PDF page 45" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 343.1.b · PDF page 45</div></details>

[[Turn|The turn]] is said to be in a [[Neutral State]] if no Showdown or [[Combat]] is in progress. ^cr-343-2

<details class="rule-ref"><summary title="Core rule 343.2 · PDF page 45" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 343.2 · PDF page 45</div></details>

A Showdown begins when [[Control]] of a [[Battlefield]] is [[Contested]] during a [[Cleanups|Cleanup]] and [[Turn|the turn]] is in a [[Neutral Open State]]. ^cr-344

<details class="rule-ref"><summary title="Core rule 344 · PDF page 45" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 344 · PDF page 45</div></details>

If [[Control]] of a [[Battlefield]] is [[Contested]] between two players, then a Showdown will be opened as the first step of [[Combat]]. If a Showdown is already ongoing at that Battlefield, it will become a Combat Showdown and a Combat will initiate there. ^cr-344-1

See [[Combat#^cr-461|Combat]] for more information.

<details class="rule-ref"><summary title="Core rule 344.1 · PDF page 45" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 344.1 · PDF page 45</div></details>

If [[Control]] of a [[Battlefield]] is [[Contested]], there aren’t [[Unit|units]] controlled by different players there, and [[Turn|the turn]] is in a [[Neutral Open State]], a Showdown is opened during the next [[Cleanups|Cleanup]]. ^cr-344-2

See [[Cleanups#^cr-318|Cleanups]] for more information.

<details class="rule-ref"><summary title="Core rule 344.2 · PDF page 45" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 344.2 · PDF page 45</div></details>

As a Showdown begins, the player who applied [[Contested]] status to the [[Battlefield]] gains [[Focus]]. ^cr-345

<details class="rule-ref"><summary title="Core rule 345 · PDF page 45" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 345 · PDF page 45</div></details>

When the last item on the [[Chain|chain]] resolves and [[Turn|the turn]] returns to an [[Open State]] during a Showdown, [[Focus]] passes, and the next Player gains both Focus and [[Priority]]. ^cr-346

<details class="rule-ref"><summary title="Core rule 346 · PDF page 45" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 346 · PDF page 45</div></details>

[[Focus]] will not pass in this way if the [[Chain|chain]] opened as a result of a [[Triggered Ability|triggered ability]] being added to the chain, nor if it opened as a result of an Add [[Ability|ability]] being added to the chain. ^cr-346-1

**Example:** the [[Combat]] [[Chain]] opens as a result of [[Triggered Ability|triggered abilities]] being added to the chain, so when the last item on the Combat Chain resolves and [[Turn|the turn]] returns to an [[Open State]], [[Focus]] will not pass.

<details class="rule-ref"><summary title="Core rule 346.1 · PDF page 45" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 346.1 · PDF page 45</div></details>

During a Showdown, the player with [[Focus]] may do one of the following: ^cr-347

<details class="rule-ref"><summary title="Core rule 347 · PDF page 45" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 347 · PDF page 45</div></details>

[[Play]] a [[Card]] or [[Activated Ability]] that is legally timed. ^cr-347-1

<details class="rule-ref"><summary title="Core rule 347.1 · PDF page 45" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 347.1 · PDF page 45</div></details>

The [[Card|card]] or [[Activated Ability|activated ability]] will start a [[Chain]] as normal. ^cr-347-1-a

<details class="rule-ref"><summary title="Core rule 347.1.a · PDF page 46" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 347.1.a · PDF page 46</div></details>

When that [[Chain]] closes, the next Player in [[Turn]] Order gains [[Focus]]. ^cr-347-1-b

<details class="rule-ref"><summary title="Core rule 347.1.b · PDF page 46" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 347.1.b · PDF page 46</div></details>

Pass. ^cr-347-2

<details class="rule-ref"><summary title="Core rule 347.2 · PDF page 46" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 347.2 · PDF page 46</div></details>

If all Players have passed once in sequence, the Showdown ends. ^cr-347-2-a

<details class="rule-ref"><summary title="Core rule 347.2.a · PDF page 46" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 347.2.a · PDF page 46</div></details>

Otherwise, the next Player in [[Turn]] Order gains [[Focus]]. ^cr-347-2-b

<details class="rule-ref"><summary title="Core rule 347.2.b · PDF page 46" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 347.2.b · PDF page 46</div></details>

If all players pass [[Focus]] without playing a [[Card|card]] or activating an [[Ability|ability]], then the Showdown Closes. ^cr-348

<details class="rule-ref"><summary title="Core rule 348 · PDF page 46" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 348 · PDF page 46</div></details>

If it is a [[Combat]] Showdown, proceed with the remaining steps of Combat to resolve the phase. ^cr-348-1

See [[Combat Procedure#^cr-465|The Steps of Combat]] for more information.

<details class="rule-ref"><summary title="Core rule 348.1 · PDF page 46" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 348.1 · PDF page 46</div></details>

If it is a Non-Combat Showdown, do the following: ^cr-348-2

<details class="rule-ref"><summary title="Core rule 348.2 · PDF page 46" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 348.2 · PDF page 46</div></details>

If only one player’s [[Unit|Units]] remain at the [[Battlefield]], and if that player does not already [[Control]] the Battlefield, that player establishes Control over the Battlefield. ^cr-348-2-a

See [[Control#^cr-188|Control]] for more information on [[Control]].

See [[Scoring#^cr-471-1|Scoring]] for more information on [[Conquer|Conquering]].

<details class="rule-ref"><summary title="Core rule 348.2.a · PDF page 46" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 348.2.a · PDF page 46</div></details>

This results in a [[Conquer]] if that player has not yet scored that [[Battlefield]] this [[Turn|turn]]. ^cr-348-2-a-1

<details class="rule-ref"><summary title="Core rule 348.2.a.1 · PDF page 46" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 348.2.a.1 · PDF page 46</div></details>
