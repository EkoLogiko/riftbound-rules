# Repeat

[[Start Here|Home]] · [[Concept Index|Find a concept]] · [[Core Rules Index|Core rules]]

<span title="Core rule 820"></span> ^cr-820

<details class="rule-ref"><summary title="Core rule 820 · PDF page 135" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 820 · PDF page 135</div></details>

Repeat is an Optional [[Additional Cost]] [[Keywords|keyword]]. ^cr-820-1

<details class="rule-ref"><summary title="Core rule 820.1 · PDF page 135" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 820.1 · PDF page 135</div></details>

Repeat is present on [[Spell|Spells]] and [[Ability|Abilities]]. ^cr-820-1-a

<details class="rule-ref"><summary title="Core rule 820.1.a · PDF page 135" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 820.1.a · PDF page 135</div></details>

Repeat is an optional [[Costs|cost]] that a player may pay to execute the effect of their [[Spell|spells]] and [[Ability|abilities]] a second time. ^cr-820-1-b

<details class="rule-ref"><summary title="Core rule 820.1.b · PDF page 135" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 820.1.b · PDF page 135</div></details>

Repeat is formatted as “Repeat &#91;[[Costs|Cost]]&#93;” ^cr-820-1-c

<details class="rule-ref"><summary title="Core rule 820.1.c · PDF page 135" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 820.1.c · PDF page 135</div></details>

The [[Costs|Cost]] is an [[Additional Cost]] to be paid during the steps of playing the [[Spell|spell]] or [[Ability|ability]]. ^cr-820-1-c-1

<details class="rule-ref"><summary title="Core rule 820.1.c.1 · PDF page 135" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 820.1.c.1 · PDF page 135</div></details>

If a [[Spell|spell]] or [[Ability|ability]] has more than one instance of Repeat, each [[Costs|Cost]] may be paid or not paid individually. ^cr-820-1-c-2

<details class="rule-ref"><summary title="Core rule 820.1.c.2 · PDF page 135" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 820.1.c.2 · PDF page 135</div></details>

Each Repeat [[Costs|Cost]] can be paid only a single time. ^cr-820-1-c-3

<details class="rule-ref"><summary title="Core rule 820.1.c.3 · PDF page 135" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 820.1.c.3 · PDF page 135</div></details>

Repeat is functionally short for “You may pay &#91;[[Costs|Cost]]&#93; as an [[Additional Cost|additional cost]] as you [[Play|play]] this. If you do, execute the [[Instructions|instructions]] of this [[Chain|chain]] item one additional time during resolution.” ^cr-820-1-d

<details class="rule-ref"><summary title="Core rule 820.1.d · PDF page 135" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 820.1.d · PDF page 135</div></details>

When the [[Additional Cost|additional cost]] is paid, the effect of the [[Spell|spell]] or [[Ability|ability]], upon resolution, will be performed an additional time. ^cr-820-1-d-1

**Example:** Desert’s Call is a [[Spell|spell]] with &#91;Repeat&#93; &#91;2&#93; and “[[Play]] a 2 &#91;M&#93; Sand Soldier [[Unit|unit]] [[Token|token]].” If its controller pays its Repeat [[Costs|cost]] as they play it, the [[Card|card]]’s instruction to play a Sand Soldier is executed twice, as though the card says “Play a 2 &#91;M&#93; Sand Soldier unit token. Play a 2 &#91;M&#93; Sand Soldier unit token.”

**Example:** A [[Unit|unit]] reads in part “When I attack or defend, you may [[Deal|deal]] [[Damage|damage]] equal to my [[Might]] to an [[Enemy|enemy]] unit here,” and “My [[Ability|abilities]] have &#91;Repeat&#93; — [[Discard]] 1.” When its ability triggers, if its controller pays the Repeat [[Costs|cost]] as they [[Play|play]] it, the ability’s instruction to deal damage equal to the unit’s Might is executed twice, as though the ability says “Deal damage equal to my Might to an enemy unit here. Deal damage equal to my Might to an enemy unit here.”

<details class="rule-ref"><summary title="Core rule 820.1.d.1 · PDF page 135" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 820.1.d.1 · PDF page 135</div></details>

Any [[Instructions|instructions]] not performed on resolution of the [[Spell|spell]] or [[Ability|ability]] are ignored. ^cr-820-1-d-2

<details class="rule-ref"><summary title="Core rule 820.1.d.2 · PDF page 135" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 820.1.d.2 · PDF page 135</div></details>

When a [[Spell|spell]] or [[Ability|ability]]’s effect is performed an additional time with Repeat, choices must be made at the usual time during the Make Relevant Choices step of Playing a [[Card]]. ^cr-820-2

See [[Playing Cards#^cr-349|Playing Cards]] for more information.

<details class="rule-ref"><summary title="Core rule 820.2 · PDF page 135" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 820.2 · PDF page 135</div></details>

Choices made for the additional execution do not have to be the same as the choices made for the initial execution. ^cr-820-2-a

**Example:** Rocket Barrage is a [[Spell|spell]] with &#91;Repeat&#93; &#91;4&#93;&#91;C&#93; and “Choose one — [[Deal]] 4 to a [[Unit|unit]] in a [[Base|base]]. &#91;or&#93; [[Kill]] a [[Gear|gear]].” If Rocket Barrage’s controller pays its Repeat [[Costs|cost]] as they [[Play|play]] it, they may choose the same mode or a different one, and if they choose the same mode, may choose the same target or a different one. If they choose “Kill a gear” twice and choose two different gear, they must specify which gear is the first target and which is the second. As the spell resolves, those two gear will be killed in the chosen order.

<details class="rule-ref"><summary title="Core rule 820.2.a · PDF page 135" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 820.2.a · PDF page 135</div></details>

Multiple instances of Repeat can be paid for separately. The [[Spell|spell]] or [[Ability|ability]]’s [[Instructions|instructions]] will be executed an additional time on resolution for each instance of Repeat that is paid for. ^cr-820-3

<details class="rule-ref"><summary title="Core rule 820.3 · PDF page 136" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 820.3 · PDF page 136</div></details>

Regardless of the number of times a [[Spell|spell]] or [[Ability|ability]]'s [[Instructions|instructions]] are executed with this [[Keywords|keyword]], it is only Played once. ^cr-820-3-a

<details class="rule-ref"><summary title="Core rule 820.3.a · PDF page 136" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 820.3.a · PDF page 136</div></details>

Repeat, and whether or not a [[Spell|spell]] or [[Ability|ability]] has Repeat, is a characteristic of the spell or ability and may be checked or referenced by other [[Game Effect|Game Effects]]. ^cr-820-4

<details class="rule-ref"><summary title="Core rule 820.4 · PDF page 136" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 820.4 · PDF page 136</div></details>
