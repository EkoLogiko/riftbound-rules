# Rune Pool

[[Start Here|Home]] · [[Concept Index|Find a concept]] · [[Core Rules Index|Core rules]]

<span title="Core rule 165"></span> ^cr-165

<details class="rule-ref"><summary title="Core rule 165 · PDF page 24" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 165 · PDF page 24</div></details>

The Rune Pool is a conceptual collection of a player's available [[Energy]] and [[Power]] available to pay [[Costs]]. ^cr-166

<details class="rule-ref"><summary title="Core rule 166 · PDF page 24" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 166 · PDF page 24</div></details>

When a [[Card|card]] adds [[Energy]] or [[Power]], it is added to the controlling player's Rune Pool. ^cr-166-1

<details class="rule-ref"><summary title="Core rule 166.1 · PDF page 24" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 166.1 · PDF page 24</div></details>

Players must add [[Energy]] and [[Power]] to their Rune Pool in order to be able to spend it to [[Play|play]] [[Card|cards]] or pay for [[Ability|Abilities]] with [[Costs|costs]]. ^cr-166-2

<details class="rule-ref"><summary title="Core rule 166.2 · PDF page 24" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 166.2 · PDF page 24</div></details>

[[Energy]] and [[Power]] do not have a physical marker or tracker, although players may wish to use a physical tracker if they are retaining unspent Energy and Power over the course of their [[Turn|turn]]. ^cr-166-3

<details class="rule-ref"><summary title="Core rule 166.3 · PDF page 25" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 166.3 · PDF page 25</div></details>

Every player's Rune Pool empties at the start of each player's [[Main Phase]] and the end of each player's [[Turn|turn]]. ^cr-167

<details class="rule-ref"><summary title="Core rule 167 · PDF page 25" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 167 · PDF page 25</div></details>

Any unspent [[Energy]] or [[Power]] are lost. ^cr-167-1

<details class="rule-ref"><summary title="Core rule 167.1 · PDF page 25" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 167.1 · PDF page 25</div></details>

All [[Ability|Abilities]] that include the action "Add" are abilities that are adding [[Energy]] or [[Power]] to the Rune Pool. ^cr-168

See [[Add#^cr-430|Add]] for more information.

<details class="rule-ref"><summary title="Core rule 168 · PDF page 25" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 168 · PDF page 25</div></details>
