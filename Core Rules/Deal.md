# Deal

[[Start Here|Home]] · [[Concept Index|Find a concept]] · [[Core Rules Index|Core rules]]

<span title="Core rule 418"></span> ^cr-418

<details class="rule-ref"><summary title="Core rule 418 · PDF page 80" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 418 · PDF page 80</div></details>

[[Spell|Spells]], [[Unit|Units]], [[Ability|Abilities]], and other [[Game Effect|game effects]] may Deal [[Damage]] to units. ^cr-418-1

<details class="rule-ref"><summary title="Core rule 418.1 · PDF page 80" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 418.1 · PDF page 80</div></details>

Assigning [[Damage]] during the [[Combat]] Damage Step is not Dealing Damage, but will cause Damage to be Dealt when assignment is complete. ^cr-418-1-a

<details class="rule-ref"><summary title="Core rule 418.1.a · PDF page 80" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 418.1.a · PDF page 80</div></details>

To Deal [[Damage]] to [[Unit|Units]], mark the specified amount of Damage on the Unit. ^cr-418-1-b

<details class="rule-ref"><summary title="Core rule 418.1.b · PDF page 80" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 418.1.b · PDF page 80</div></details>

[[Damage]] is marked on each [[Unit|unit]] separately. ^cr-418-1-c

<details class="rule-ref"><summary title="Core rule 418.1.c · PDF page 80" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 418.1.c · PDF page 80</div></details>

[[Damage]] can be Dealt to more than one [[Unit]] at the same time. ^cr-418-1-d

<details class="rule-ref"><summary title="Core rule 418.1.d · PDF page 80" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 418.1.d · PDF page 80</div></details>

Valid [[Damage]] is a positive integer amount, greater than or equal to 1 Damage. ^cr-418-1-e

<details class="rule-ref"><summary title="Core rule 418.1.e · PDF page 80" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 418.1.e · PDF page 80</div></details>

Only Valid [[Damage]] is Dealt. ^cr-418-1-e-1

**Example:** A [[Unit|unit]] reads “when I take [[Damage|damage]], give me +2 &#91;M&#93; this [[Turn|turn]].” A [[Spell|spell]] is played that Prevents the next 3 damage the unit would take. If a player plays Hextech Ray [[Targeting|targeting]] the unit, it will take no damage and its [[Triggered Ability|triggered ability]] will not trigger. If that player had played Void Seeker instead, it would be Dealt 1 and trigger its [[Ability|ability]].

<details class="rule-ref"><summary title="Core rule 418.1.e.1 · PDF page 80" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 418.1.e.1 · PDF page 80</div></details>

Only [[Damage]] can be Dealt. ^cr-418-2

<details class="rule-ref"><summary title="Core rule 418.2 · PDF page 80" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 418.2 · PDF page 80</div></details>

Dealing [[Damage]] is a [[Limited Action]]. ^cr-418-3

<details class="rule-ref"><summary title="Core rule 418.3 · PDF page 80" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 418.3 · PDF page 80</div></details>

Assigning [[Damage]] causes Damage to be dealt outside of being directed to Deal Damage. ^cr-418-3-a

See [[Combat#^cr-461|Combat]] for more information.

<details class="rule-ref"><summary title="Core rule 418.3.a · PDF page 80" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 418.3.a · PDF page 80</div></details>

Dealing can have the intrinsic property of [[Bonus Damage]]. ^cr-418-4

<details class="rule-ref"><summary title="Core rule 418.4 · PDF page 80" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 418.4 · PDF page 80</div></details>

[[Bonus Damage]] is a property granted to the action of Dealing and alters the amount of [[Damage]] distributed by this action. ^cr-418-5

See [[Bonus Damage#^cr-712|Bonus Damage]] for more information.

<details class="rule-ref"><summary title="Core rule 418.5 · PDF page 80" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 418.5 · PDF page 80</div></details>

Deal actions can originate from one or more sources. ^cr-418-6

<details class="rule-ref"><summary title="Core rule 418.6 · PDF page 81" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 418.6 · PDF page 81</div></details>

If a [[Game Effect|game effect]] does not specify a source, the game effect describing the Deal action is the source. ^cr-418-6-a

**Example:** Void Seeker is a [[Spell|spell]] that reads “Deal 4 to a [[Unit|unit]] at a [[Battlefield|battlefield]]. [[Draw]] 1.” The [[Damage|damage]] that Void Seeker instructs you to deal is dealt by Void Seeker.

<details class="rule-ref"><summary title="Core rule 418.6.a · PDF page 81" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 418.6.a · PDF page 81</div></details>

If a [[Game Effect|game effect]] does specify a source, then that source is what is considered the origin of the [[Damage]] for this Deal action. ^cr-418-6-b

<details class="rule-ref"><summary title="Core rule 418.6.b · PDF page 81" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 418.6.b · PDF page 81</div></details>

[[Unit|Units]] and [[Spell|Spells]] can be the source of [[Damage]] for Deal actions. ^cr-418-6-b-1

<details class="rule-ref"><summary title="Core rule 418.6.b.1 · PDF page 81" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 418.6.b.1 · PDF page 81</div></details>

[[Ability|Abilities]] can be the source of [[Damage]] for Deal actions. ^cr-418-6-b-2

<details class="rule-ref"><summary title="Core rule 418.6.b.2 · PDF page 81" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 418.6.b.2 · PDF page 81</div></details>

When an [[Ability]] is the source of [[Damage]] for a Deal action, it is in addition to the [[Spell]] or [[Unit]] that created that Ability. ^cr-418-6-b-2-a

**Example:** Iron Ballista is a [[Gear|gear]] that says “&#91;E&#93;: Deal 2 to a [[Unit|unit]] at a [[Battlefield|battlefield]].” This [[Damage|damage]] is dealt both by a gear and by an [[Ability|ability]].

<details class="rule-ref"><summary title="Core rule 418.6.b.2.a · PDF page 81" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 418.6.b.2.a · PDF page 81</div></details>

When a [[Spell|spell]] or [[Ability|ability]] specifies a [[Unit]] as the source of the [[Damage]] for the Deal action, it is not in addition to the spell or ability that instructed it. ^cr-418-6-b-3

**Example:** Challenge is a [[Spell|spell]] that reads “Choose a [[Friendly|friendly]] [[Unit|unit]] and an [[Enemy|enemy]] unit. They deal [[Damage|damage]] equal to their Mights to each other.” The damage that Challenge causes to be dealt is dealt by the chosen units, not by Challenge.

<details class="rule-ref"><summary title="Core rule 418.6.b.3 · PDF page 81" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 418.6.b.3 · PDF page 81</div></details>

The controller of the source of a Deal action is responsible for that Deal action unless the player performing the Deal action is otherwise specified. ^cr-418-6-b-4

**Example:** If a player plays Challenge [[Targeting|targeting]] a [[Friendly|friendly]] [[Unit|unit]] and an [[Enemy|enemy]] unit, the controller of the enemy unit is responsible for the [[Damage|damage]] dealt by their unit. Any effects that trigger “when you deal damage” that that player controls will trigger.

<details class="rule-ref"><summary title="Core rule 418.6.b.4 · PDF page 81" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 418.6.b.4 · PDF page 81</div></details>

[[Damage]] Dealt as a result of being assigned during [[Combat]] has the [[Unit|Units]] as its source. ^cr-418-6-c

<details class="rule-ref"><summary title="Core rule 418.6.c · PDF page 81" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 418.6.c · PDF page 81</div></details>

The [[Damage]] assigned, and subsequently Dealt, to attackers has the defenders as the source and vice versa. ^cr-418-6-c-1

<details class="rule-ref"><summary title="Core rule 418.6.c.1 · PDF page 81" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 418.6.c.1 · PDF page 81</div></details>

Deal actions can distribute [[Damage]] as part of [[Combat|combat]] actions or non-combat actions. ^cr-418-7

<details class="rule-ref"><summary title="Core rule 418.7 · PDF page 81" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 418.7 · PDF page 81</div></details>

Some Deal actions may be written as “Deal X … for each …” Such actions Deal one instance of [[Damage]]. ^cr-418-8

**Example:** Riven, Shattered reads in part “When I attack, choose an [[Enemy|enemy]] [[Unit|unit]] here. Deal 2 to it for each [[Equipment]] [[Attached|attached]] to me.” If Riven has three Equipment attached to her, she will deal one instance of 6 [[Damage|damage]], not three instances of 2 damage.

<details class="rule-ref"><summary title="Core rule 418.8 · PDF page 81" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 418.8 · PDF page 81</div></details>
