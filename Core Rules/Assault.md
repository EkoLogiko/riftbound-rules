Assault is a [[Passive Ability]] [[Keywords|keyword]]. ^cr-807-1

<details class="rule-ref"><summary title="Core rule 807.1 · PDF page 127" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 807.1 · PDF page 127</div></details>

It is present on [[Unit|Units]]. ^cr-807-1-a

<details class="rule-ref"><summary title="Core rule 807.1.a · PDF page 127" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 807.1.a · PDF page 127</div></details>

Assault is formatted as "Assault &#91;X&#93;". ^cr-807-1-b

<details class="rule-ref"><summary title="Core rule 807.1.b · PDF page 127" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 807.1.b · PDF page 127</div></details>

The X is referenced in the functional text of the [[Ability|ability]]. ^cr-807-1-b-1

<details class="rule-ref"><summary title="Core rule 807.1.b.1 · PDF page 127" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 807.1.b.1 · PDF page 127</div></details>

The X is referred to as the Assault Value. ^cr-807-1-b-2

<details class="rule-ref"><summary title="Core rule 807.1.b.2 · PDF page 127" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 807.1.b.2 · PDF page 127</div></details>

If X is omitted, it is presumed to be 1. ^cr-807-1-b-3

<details class="rule-ref"><summary title="Core rule 807.1.b.3 · PDF page 127" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 807.1.b.3 · PDF page 127</div></details>

It is functionally short for "While I am an [[Attacker|attacker]], I have +X &#91;M&#93;." ^cr-807-1-c

<details class="rule-ref"><summary title="Core rule 807.1.c · PDF page 127" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 807.1.c · PDF page 127</div></details>

Being an [[Attacker|attacker]] means the [[Unit]] has gained the Attacker designation during [[Combat]]. ^cr-807-1-d

See [[Combat#^cr-461|Combat]] for more information.

<details class="rule-ref"><summary title="Core rule 807.1.d · PDF page 127" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 807.1.d · PDF page 127</div></details>

Assault remains in effect as long as the [[Unit]] maintains the [[Attacker]] designation. ^cr-807-1-d-1

<details class="rule-ref"><summary title="Core rule 807.1.d.1 · PDF page 127" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 807.1.d.1 · PDF page 127</div></details>

If a [[Unit]] has Assault or has been granted Assault and is granted Assault by an additional source, the Assault Value of all granted Assault [[Keywords|keywords]] is summed. ^cr-807-2

**Example:** Petty Officer has Assault. It is chosen as the target of Cleave, which says "Give a [[Unit|unit]] &#91;Assault 3&#93; this [[Turn|turn]]." After Cleave resolves, Petty Officer has Assault 4 this turn.

<details class="rule-ref"><summary title="Core rule 807.2 · PDF page 127" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 807.2 · PDF page 127</div></details>

Assault, and whether or not a [[Unit|unit]] has Assault, is a characteristic of the Unit and may be checked or referenced by other [[Game Effect|Game Effects]]. ^cr-807-3
