<span title="Core rule 445"></span> ^cr-445

<details class="rule-ref"><summary title="Core rule 445 · PDF page 98" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 445 · PDF page 98</div></details>

Paying a resource is the act of removing that resource from your [[Rune Pool]]. ^cr-445-1

<details class="rule-ref"><summary title="Core rule 445.1 · PDF page 98" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 445.1 · PDF page 98</div></details>

Pay is an action that interacts with [[Energy]] and [[Power]]. ^cr-445-1-a

<details class="rule-ref"><summary title="Core rule 445.1.a · PDF page 98" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 445.1.a · PDF page 98</div></details>

In order to qualify as a resource to be removed from the [[Rune Pool]], the resource must be &#91;1&#93; or greater, or &#91;C&#93; or &#91;A&#93; or greater. ^cr-445-1-b

**Example:** &#91;0&#93; is not a resource that can be removed from the [[Rune Pool]]. As a [[Costs|cost]], it is paid without performing the pay [[Game Action|game action]]. This cannot be declined.

<details class="rule-ref"><summary title="Core rule 445.1.b · PDF page 98" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 445.1.b · PDF page 98</div></details>

When a player is instructed to Pay a resource, that player may remove that resource from their [[Rune Pool]] if it exists there. If they choose not to, the instruction is negated. ^cr-445-2

<details class="rule-ref"><summary title="Core rule 445.2 · PDF page 98" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 445.2 · PDF page 98</div></details>

If the instruction to Pay resources is part of paying [[Costs|costs]] for a [[Card|card]] or [[Ability|ability]], choosing not to pay those resources will cause the act of playing the card or ability to be undone. ^cr-445-2-a

See [[Process of Playing a Card#^cr-358|Check Legality]] for more information.

<details class="rule-ref"><summary title="Core rule 445.2.a · PDF page 98" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 445.2.a · PDF page 98</div></details>

If the instruction to Pay resources is part of paying any other [[Costs|cost]], choosing not to pay those resources will [[Prevent|prevent]] the execution of the associated effect. ^cr-445-2-b

See [[Costs#^cr-201|Costs]] for more information.

<details class="rule-ref"><summary title="Core rule 445.2.b · PDF page 98" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 445.2.b · PDF page 98</div></details>

Players may activate [[Ability|abilities]] that Add resources with the [[Reaction (Keyword)|Reaction keyword]] at any time that they are instructed to Pay resources. Those abilities finalize and resolve immediately, ignoring normal restrictions. ^cr-445-2-c

See [[Add#^cr-430|Add]] for more information.

<details class="rule-ref"><summary title="Core rule 445.2.c · PDF page 98" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 445.2.c · PDF page 98</div></details>

Pay is a [[Limited Action]]. ^cr-445-3

<details class="rule-ref"><summary title="Core rule 445.3 · PDF page 98" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 445.3 · PDF page 98</div></details>

Players may only Pay resources when directed to by [[Game Effect|Game Effects]]. ^cr-445-3-a

<details class="rule-ref"><summary title="Core rule 445.3.a · PDF page 98" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 445.3.a · PDF page 98</div></details>
