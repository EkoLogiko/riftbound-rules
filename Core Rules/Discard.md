# Discard

[[Start Here|Home]] · [[Concept Index|Find a concept]] · [[Core Rules Index|Core rules]]

<span title="Core rule 423"></span> ^cr-423

<details class="rule-ref"><summary title="Core rule 423 · PDF page 83" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 423 · PDF page 83</div></details>

Discarding a [[Card|card]] is [[Movement|moving]] it from a player's [[Hand|hand]] directly into their [[Trash|trash]] without activating or executing its normal [[Rules Text|rules text]]. ^cr-423-1

<details class="rule-ref"><summary title="Core rule 423.1 · PDF page 83" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 423.1 · PDF page 83</div></details>

The player who is performing the action chooses which [[Card|cards]] to send to their [[Trash]], and may use [[Private Information]] to do so. ^cr-423-1-a

<details class="rule-ref"><summary title="Core rule 423.1.a · PDF page 83" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 423.1.a · PDF page 83</div></details>

“When I am discarded” [[Ability|abilities]] or other [[Triggered Ability|Triggered Abilities]] that trigger on discarding are executed after discarding has occurred. ^cr-423-1-b

<details class="rule-ref"><summary title="Core rule 423.1.b · PDF page 83" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 423.1.b · PDF page 83</div></details>

Discarding is a [[Limited Action]]. ^cr-423-2

<details class="rule-ref"><summary title="Core rule 423.2 · PDF page 84" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 423.2 · PDF page 84</div></details>

A player must Discard [[Card|cards]] when instructed to do so by [[Game Effect|game effects]] or [[Costs|costs]]. ^cr-423-2-a

<details class="rule-ref"><summary title="Core rule 423.2.a · PDF page 84" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 423.2.a · PDF page 84</div></details>

When Discarding is listed as a [[Costs|Cost]], then the Action must be able to be completed for the cost to be paid. ^cr-423-3

**Example:** A [[Card|card]] has the [[Ability|ability]] "Discard 2: [[Deal]] 2 [[Damage|damage]] to a [[Unit|unit]] at a [[Battlefield|battlefield]]." To activate the ability, the card's controller must have at least 2 cards in [[Hand|hand]] and must be able to discard them.

<details class="rule-ref"><summary title="Core rule 423.3 · PDF page 84" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 423.3 · PDF page 84</div></details>

When Discarding is part of an effect, then a player must Discard as many [[Card|cards]] as possible from their [[Hand|hand]]. If instructed to discard more cards than they have in their hand, further discard [[Instructions|instructions]] are negated. ^cr-423-4

**Example:** Undercover Agent has the [[Ability|ability]] "&#91;[[Deathknell]]&#93;&#91;>&#93; Discard 2, then [[Draw|draw]] 2. (When I die, get the effect.)" If Undercover Agent's controller has 2 or more [[Card|cards]] in [[Hand|hand]], they must discard 2. If they have 1 card in hand, they discard 1, and the rest of the discard instruction is negated. If they have no cards in hand, the entire discard instruction is negated. Regardless of how many cards they discard, they then draw 2.

<details class="rule-ref"><summary title="Core rule 423.4 · PDF page 84" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 423.4 · PDF page 84</div></details>

This action is formatted as "Discard X." ^cr-423-5
