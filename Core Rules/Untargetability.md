# Untargetability

[[Start Here|Home]] · [[Concept Index|Find a concept]] · [[Core Rules Index|Core rules]]

<span title="Core rule 756"></span> ^cr-756

<details class="rule-ref"><summary title="Core rule 756 · PDF page 123" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 756 · PDF page 123</div></details>

Some [[Game Effect|Game Effects]] declare that a [[Game Object]] can’t be chosen by a certain set of [[Spell|spells]] and [[Ability|abilities]]. Those effects designate the Game Object as Untargetable. ^cr-757

<details class="rule-ref"><summary title="Core rule 757 · PDF page 123" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 757 · PDF page 123</div></details>

These [[Passive Ability|passive abilities]] will usually take the form “&#91;[[Game Object]]&#93; can’t be chosen by &#91;[[Card Category|Category]]&#93; [[Spell|spells]] and [[Ability|abilities]].” ^cr-757-1

**Example:** Ruin Runner’s [[Passive Ability|passive ability]] reads “I can’t be chosen by [[Enemy|enemy]] [[Spell|spells]] and [[Ability|abilities]].”

<details class="rule-ref"><summary title="Core rule 757.1 · PDF page 123" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 757.1 · PDF page 123</div></details>

Untargetable [[Game Object|Game Objects]] are not legal targets for the indicated [[Spell|spells]] and [[Ability|abilities]]. ^cr-758

See [[Process of Playing a Card#^cr-355-6|Targeting]] for more information.

<details class="rule-ref"><summary title="Core rule 758 · PDF page 123" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 758 · PDF page 123</div></details>

If a [[Game Object]] becomes untargetable for a [[Spell|spell]] or [[Ability|ability]] after becoming its target and before it resolves, the spell or ability will mistarget on resolution. Any [[Instructions|instructions]] related to that Game Object will be ignored as the spell resolves. ^cr-758-1

<details class="rule-ref"><summary title="Core rule 758.1 · PDF page 123" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 758.1 · PDF page 123</div></details>

If the [[Spell|spell]] or [[Ability|ability]] changes for any reason such that it will no longer fall under the [[Card Category|category]] of spells or abilities for which a [[Game Object]] is untargetable, the Game Object will become a legal target for that spell or ability. ^cr-758-2

**Example:** A 1 &#91;M&#93; [[Unit|unit]] reads “I can’t be chosen by [[Enemy|enemy]] [[Spell|spells]] or [[Ability|abilities]] with [[Energy Cost|Energy cost]] less than my [[Might]].” That unit is targeted by an enemy Falling Star; in reaction to the Falling Star, the unit’s controller plays Discipline [[Targeting|targeting]] that unit, bringing its Might to 3 &#91;M&#93;. If Falling Star resolved at that point, the unit would be unaffected by it as it resolves. Falling Star’s controller plays Eclipse before Falling Star resolves, bringing the unit’s Might to -1 &#91;M&#93;. When Falling Star resolves now, the unit is affected by the spell and has 6 [[Damage|damage]] marked. It dies in the following [[Cleanups|cleanup]].

<details class="rule-ref"><summary title="Core rule 758.2 · PDF page 123" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 758.2 · PDF page 123</div></details>

This will also occur if the [[Game Object]] is no longer among the set of objects that are made untargetable by a [[Game Effect]]. ^cr-758-2-a

**Example:** Alpha Wildclaw and Vilemaw are controlled by the same player and located at a [[Battlefield|battlefield]]. An opponent targets Vilemaw with Rebuke. Before Rebuke resolves, Vilemaw’s controller plays Discipline [[Targeting|targeting]] Alpha Wildclaw, making Vilemaw no longer a legal target. Rebuke’s controller then targets Alpha Wildclaw with Star-Crossed. When Star-Crossed resolves, Alpha Wildclaw’s [[Passive Ability|passive ability]] no longer applies to Vilemaw, making it a legal target for Rebuke. After all [[Spell|spells]] and [[Ability|abilities]] have resolved, both Vilemaw and Alpha Wildclaw will be returned to [[Hand|hand]].
