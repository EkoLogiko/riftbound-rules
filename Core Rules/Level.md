# Level

[[Start Here|Home]] · [[Concept Index|Find a concept]] · [[Core Rules Index|Core rules]]

<span title="Core rule 824"></span> ^cr-824

<details class="rule-ref"><summary title="Core rule 824 · PDF page 138" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 824 · PDF page 138</div></details>

Level is a [[Dependent Keyword]]. ^cr-824-1

<details class="rule-ref"><summary title="Core rule 824.1 · PDF page 138" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 824.1 · PDF page 138</div></details>

It is formatted as "&#91;Level &#91;N&#93;&#91;>&#93; &#91;Text&#93;". ^cr-824-1-a

<details class="rule-ref"><summary title="Core rule 824.1.a · PDF page 138" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 824.1.a · PDF page 138</div></details>

Starting from the [[Keywords|Keyword]] to the end of the clause, the entire statement is the Level [[Ability]]. ^cr-824-1-b

<details class="rule-ref"><summary title="Core rule 824.1.b · PDF page 138" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 824.1.b · PDF page 138</div></details>

It is functionally short for “While you have &#91;N&#93; or more XP, this [[Card|card]] gains ‘&#91;Text&#93;’.” ^cr-824-1-b-1

<details class="rule-ref"><summary title="Core rule 824.1.b.1 · PDF page 138" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 824.1.b.1 · PDF page 138</div></details>

The &#91;Text&#93; here is the Dependent [[Ability]] ^cr-824-1-b-2

<details class="rule-ref"><summary title="Core rule 824.1.b.2 · PDF page 138" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 824.1.b.2 · PDF page 138</div></details>

As long as the controlling player has &#91;N&#93; XP, then the Dependent [[Ability]] will be be Active on the [[Card|card]] with Level ^cr-824-1-c

<details class="rule-ref"><summary title="Core rule 824.1.c · PDF page 138" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 824.1.c · PDF page 138</div></details>

If the controller of the [[Card|card]] with Level changes, then the Dependent [[Ability]] will be rendered Active or [[Inactive]] based on the new controller’s XP. ^cr-824-1-c-1

<details class="rule-ref"><summary title="Core rule 824.1.c.1 · PDF page 138" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 824.1.c.1 · PDF page 138</div></details>

The Dependent [[Ability]] will be [[Inactive]] as soon as the controlling player has less than &#91;N&#93; XP. ^cr-824-1-d

<details class="rule-ref"><summary title="Core rule 824.1.d · PDF page 138" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 824.1.d · PDF page 138</div></details>

Level, and whether or not a [[Card|card]] has Level is a characteristic of the card and may be checked or referenced by other [[Game Effect|Game Effects]]. ^cr-824-2

<details class="rule-ref"><summary title="Core rule 824.2 · PDF page 138" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 824.2 · PDF page 138</div></details>
