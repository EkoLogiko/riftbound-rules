# Making New Choices

[[Start Here|Home]] · [[Concept Index|Find a concept]] · [[Core Rules Index|Core rules]]

<span title="Core rule 750"></span> ^cr-750

<details class="rule-ref"><summary title="Core rule 750 · PDF page 122" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 750 · PDF page 122</div></details>

Some [[Game Effect|Game Effects]] will instruct a player to make new choices for a [[Finalized Chain Item|finalized item]] on the [[Chain|chain]]. ^cr-751

<details class="rule-ref"><summary title="Core rule 751 · PDF page 122" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 751 · PDF page 122</div></details>

This refers to the choices normally made during finalization, with some exclusions. ^cr-752

See [[Process of Playing a Card#^cr-355|Make Relevant Choices]] for more information.

<details class="rule-ref"><summary title="Core rule 752 · PDF page 122" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 752 · PDF page 122</div></details>

The relevant choices that can be remade for these [[Game Effect|Game Effects]] are [[Location|locations]] to be played to, modes, destinations, and targets. ^cr-752-1

<details class="rule-ref"><summary title="Core rule 752.1 · PDF page 122" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 752.1 · PDF page 122</div></details>

This does not refer to any choices made “as you [[Play|play]] this” or “as I am played,” or any choices made for [[Optional Additional Costs]]. ^cr-752-2

<details class="rule-ref"><summary title="Core rule 752.2 · PDF page 122" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 752.2 · PDF page 122</div></details>

When making new choices in this way, a player must choose to remake all choices made for a [[Chain|chain]] item, even if they choose to make the same choice that was previously made. ^cr-753

<details class="rule-ref"><summary title="Core rule 753 · PDF page 123" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 753 · PDF page 123</div></details>

A player may not make choices this way that would be illegal or that would lead to an illegal state, even if there are no other options. ^cr-753-1

<details class="rule-ref"><summary title="Core rule 753.1 · PDF page 123" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 753.1 · PDF page 123</div></details>

A player may not choose to make new choices for a [[Chain|chain]] item if there aren’t legal choices that they could make in this way. In such a case, the instruction to make new choices is negated. ^cr-753-2

<details class="rule-ref"><summary title="Core rule 753.2 · PDF page 123" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 753.2 · PDF page 123</div></details>

Restrictions and requirements applied to a [[Chain|chain]] item will also apply to new choices made for that chain item in this way. ^cr-753-3

**Example:** If a [[Card|card]] is played from facedown, it gains the restriction that it can only target [[Game Object|game objects]] at the [[Battlefield|battlefield]] it was played from unless its [[Targeting|targeting]] is restricted in such a way that choosing a [[Unit|unit]] at that battlefield is impossible. If a player makes new choices for such a card, they must still choose from among objects at that battlefield.

<details class="rule-ref"><summary title="Core rule 753.3 · PDF page 123" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 753.3 · PDF page 123</div></details>

If, as a result of new choices, the [[Chain|chain]] item targets a [[Game Object]], even if it previously targeted the same Game Object, any [[Targeting Effect|Targeting Effects]] of that Game Object will trigger as appropriate. ^cr-754

<details class="rule-ref"><summary title="Core rule 754 · PDF page 123" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 754 · PDF page 123</div></details>

Any [[Costs|costs]] “to [[Play|play]]” the [[Chain|chain]] item that are incurred as a result of new choices made in this way are ignored. ^cr-755

<details class="rule-ref"><summary title="Core rule 755 · PDF page 123" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 755 · PDF page 123</div></details>

The [[Chain|chain]] item is already played and its [[Costs|costs]] paid. Any further costs incurred have no effect on the [[Finalized Chain Item|finalized chain item]]. ^cr-755-1

<details class="rule-ref"><summary title="Core rule 755.1 · PDF page 123" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 755.1 · PDF page 123</div></details>
