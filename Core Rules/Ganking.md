# Ganking

[[Start Here|Home]] · [[Concept Index|Find a concept]] · [[Core Rules Index|Core rules]]

<span title="Core rule 810"></span> ^cr-810

<details class="rule-ref"><summary title="Core rule 810 · PDF page 128" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 810 · PDF page 128</div></details>

Ganking is a [[Passive Ability]] [[Keywords|keyword]]. ^cr-810-1

<details class="rule-ref"><summary title="Core rule 810.1 · PDF page 129" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 810.1 · PDF page 129</div></details>

It is present on [[Unit|Units]]. ^cr-810-1-a

<details class="rule-ref"><summary title="Core rule 810.1.a · PDF page 129" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 810.1.a · PDF page 129</div></details>

It is functionally short for "I may [[Move|move]] to a [[Battlefield|battlefield]] from another battlefield with a [[Standard Move|standard move]]." ^cr-810-1-b

<details class="rule-ref"><summary title="Core rule 810.1.b · PDF page 129" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 810.1.b · PDF page 129</div></details>

It is a [[Passive Ability|passive ability]] that adds permissions to the [[Unit]]'s [[Standard Move]]. ^cr-810-1-c

<details class="rule-ref"><summary title="Core rule 810.1.c · PDF page 129" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 810.1.c · PDF page 129</div></details>

It does not restrict or remove options from the [[Unit]]'s [[Standard Move]]. ^cr-810-1-c-1

<details class="rule-ref"><summary title="Core rule 810.1.c.1 · PDF page 129" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 810.1.c.1 · PDF page 129</div></details>

It does not have an activation [[Costs|cost]]. ^cr-810-1-c-2

<details class="rule-ref"><summary title="Core rule 810.1.c.2 · PDF page 129" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 810.1.c.2 · PDF page 129</div></details>

It does not give additional [[Ability|abilities]] or activations of [[Movement]], only new options for the [[Standard Move]]. ^cr-810-1-c-3

<details class="rule-ref"><summary title="Core rule 810.1.c.3 · PDF page 129" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 810.1.c.3 · PDF page 129</div></details>

Multiple instances of Ganking are redundant. ^cr-810-2

<details class="rule-ref"><summary title="Core rule 810.2 · PDF page 129" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 810.2 · PDF page 129</div></details>

Ganking, and whether or not a [[Unit|unit]] has Ganking, is a characteristic of the Unit and may be checked or referenced by other [[Game Effect|Game Effects]]. ^cr-810-3
