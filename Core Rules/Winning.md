# Winning

[[Start Here|Home]] · [[Concept Index|Find a concept]] · [[Core Rules Index|Core rules]]

<span title="Core rule 193"></span> ^cr-193

<details class="rule-ref"><summary title="Core rule 193 · PDF page 32" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 193 · PDF page 32</div></details>

Players win Riftbound games primarily through gaining [[Points|points]]. ^cr-194

<details class="rule-ref"><summary title="Core rule 194 · PDF page 32" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 194 · PDF page 32</div></details>

Players can gain [[Points|points]] a number of ways: ^cr-194-1

<details class="rule-ref"><summary title="Core rule 194.1 · PDF page 32" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 194.1 · PDF page 32</div></details>

[[Hold|Holding]] a [[Battlefield]]. ^cr-194-1-a

See [[Scoring#^cr-469|Scoring]] for more information.

<details class="rule-ref"><summary title="Core rule 194.1.a · PDF page 32" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 194.1.a · PDF page 32</div></details>

[[Conquer|Conquering]] a [[Battlefield]]. ^cr-194-1-b

See [[Scoring#^cr-469|Scoring]] for more information.

<details class="rule-ref"><summary title="Core rule 194.1.b · PDF page 32" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 194.1.b · PDF page 32</div></details>

[[Spell|Spells]], [[Triggered Ability|Triggered Abilities]] and [[Activated Ability|Activated Abilities]] that instruct them to gain one or more [[Points|points]]. ^cr-194-1-c

<details class="rule-ref"><summary title="Core rule 194.1.c · PDF page 32" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 194.1.c · PDF page 32</div></details>

When an opponent Burns Out and picks that player to gain 1 point. ^cr-194-1-d

See [[Burn Out#^cr-432|Burn Out]] for more information.

<details class="rule-ref"><summary title="Core rule 194.1.d · PDF page 32" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 194.1.d · PDF page 32</div></details>

A player wins the game if, in a [[Cleanups|cleanup]], they have [[Points|points]] greater than or equal to the [[Victory Score]] and more points than any other player. ^cr-194-2

See [[Cleanups#^cr-318|Cleanups]] for more information.

<details class="rule-ref"><summary title="Core rule 194.2 · PDF page 32" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 194.2 · PDF page 32</div></details>

If more than one player has [[Points|points]] greater than or equal to the [[Victory Score]], whichever player has more points wins. ^cr-194-2-a

<details class="rule-ref"><summary title="Core rule 194.2.a · PDF page 32" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 194.2.a · PDF page 32</div></details>

If those players have the same number of [[Points|points]], [[Play|play]] continues until one player has more points in a [[Cleanups|cleanup]]. ^cr-194-2-b

<details class="rule-ref"><summary title="Core rule 194.2.b · PDF page 32" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 194.2.b · PDF page 32</div></details>

The [[Victory Score]] is 8 [[Points|points]] by default. ^cr-194-3

<details class="rule-ref"><summary title="Core rule 194.3 · PDF page 32" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 194.3 · PDF page 32</div></details>

Some game modes or [[Card|card]] effects may alter the [[Victory Score]]. ^cr-194-3-a

See [[Modes of Play#^cr-483|Modes of Play]] for more information.

<details class="rule-ref"><summary title="Core rule 194.3.a · PDF page 32" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 194.3.a · PDF page 32</div></details>

Players cannot have less than 0 [[Points|points]]. ^cr-194-4

<details class="rule-ref"><summary title="Core rule 194.4 · PDF page 33" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 194.4 · PDF page 33</div></details>

If a player would lose 1 or more [[Points|points]] while they have 0 points, nothing occurs. ^cr-194-4-a

<details class="rule-ref"><summary title="Core rule 194.4.a · PDF page 33" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 194.4.a · PDF page 33</div></details>

Any effects that trigger on a player losing [[Points|points]] do not trigger. ^cr-194-4-b

<details class="rule-ref"><summary title="Core rule 194.4.b · PDF page 33" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 194.4.b · PDF page 33</div></details>

A player also wins the game if an effect instructs them to do so, or if they are the only player remaining in the game. ^cr-195

<details class="rule-ref"><summary title="Core rule 195 · PDF page 33" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 195 · PDF page 33</div></details>

If an effect instructs a player to lose the game, that player is immediately removed from the game. ^cr-195-1

See [[Conceding#^cr-649|Conceding]] for more information about being removed from the game.

<details class="rule-ref"><summary title="Core rule 195.1 · PDF page 33" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 195.1 · PDF page 33</div></details>

When a player wins the game, the game ends. ^cr-196
