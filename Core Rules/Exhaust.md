# Exhaust

[[Start Here|Home]] · [[Concept Index|Find a concept]] · [[Core Rules Index|Core rules]]

<span title="Core rule 415"></span> ^cr-415

<details class="rule-ref"><summary title="Core rule 415 · PDF page 78" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 415 · PDF page 78</div></details>

Exhausting is an action that marks a non-spell [[Game Object]] on [[Board|the board]] as "spent." ^cr-415-1

<details class="rule-ref"><summary title="Core rule 415.1 · PDF page 78" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 415.1 · PDF page 78</div></details>

To mark it, rotate the [[Card|card]] 90 degrees opposite of [[Ready|Readying]], so that the orientation of the card is lengthwise in front of you. ^cr-415-1-a

<details class="rule-ref"><summary title="Core rule 415.1.a · PDF page 78" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 415.1.a · PDF page 78</div></details>

A [[Game Object]] that is already Exhausted cannot be Exhausted again. ^cr-415-1-b

<details class="rule-ref"><summary title="Core rule 415.1.b · PDF page 79" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 415.1.b · PDF page 79</div></details>

If a [[Game Object]] is instructed to be Exhausted while it is already Exhausted, nothing additional happens. ^cr-415-1-c

<details class="rule-ref"><summary title="Core rule 415.1.c · PDF page 79" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 415.1.c · PDF page 79</div></details>

"Exhausted" is a state for [[Game Object|Game Objects]] on [[Board|the board]] that other [[Game Effect|game effects]] and rules can reference. ^cr-415-2

<details class="rule-ref"><summary title="Core rule 415.2 · PDF page 79" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 415.2 · PDF page 79</div></details>

This is a [[Limited Action]]. ^cr-415-3

<details class="rule-ref"><summary title="Core rule 415.3 · PDF page 79" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 415.3 · PDF page 79</div></details>

Most Exhaust actions will be [[Costs|costs]] for [[Activated Ability|Activated Abilities]] or [[Discretionary Action|Discretionary Actions]]. ^cr-415-3-a

**Example:** A [[Unit|unit]]'s [[Standard Move]] exhausts the unit as a [[Costs|cost]].

<details class="rule-ref"><summary title="Core rule 415.3.a · PDF page 79" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 415.3.a · PDF page 79</div></details>

When Exhausting is listed as a [[Costs|Cost]], then the Action must be able to be completed for the cost to be paid. ^cr-415-4

**Example:** A [[Spell|spell]] says "As an [[Additional Cost|additional cost]] to [[Play|play]] this, you may exhaust a [[Friendly|friendly]] [[Unit|unit]]." An exhausted friendly unit may not be exhausted again as the additional cost for the spell, and the additional cost has not been paid.

<details class="rule-ref"><summary title="Core rule 415.4 · PDF page 79" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 415.4 · PDF page 79</div></details>

In [[Ability|abilities]], the Exhaust symbol represents the [[Costs|cost]] "Exhaust this" or "Exhaust me." It resembles a [[Card|card]] turning sideways. ^cr-415-5

<details class="rule-ref"><summary title="Core rule 415.5 · PDF page 79" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 415.5 · PDF page 79</div></details>
