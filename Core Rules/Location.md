# Location

[[Start Here|Home]] · [[Concept Index|Find a concept]] · [[Core Rules Index|Core rules]]

<span title="Core rule 197"></span> ^cr-197

<details class="rule-ref"><summary title="Core rule 197 · PDF page 33" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 197 · PDF page 33</div></details>

Locations are the [[Game Object|Game Objects]] and [[Zone|Zones]] where [[Permanent|permanents]] and [[Rune|runes]] may be located. ^cr-198

<details class="rule-ref"><summary title="Core rule 198 · PDF page 33" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 198 · PDF page 33</div></details>

Locations include the [[Battlefield|Battlefields]] and the [[Base|Bases]]. ^cr-198-1

<details class="rule-ref"><summary title="Core rule 198.1 · PDF page 33" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 198.1 · PDF page 33</div></details>

A [[Permanent|permanent]]’s Location is a characteristic of that permanent that may be referenced by [[Game Effect|Game Effects]]. ^cr-198-2

<details class="rule-ref"><summary title="Core rule 198.2 · PDF page 33" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 198.2 · PDF page 33</div></details>

A [[Game Object]] that comprises a Location is also a Game Object at that location. ^cr-199

<details class="rule-ref"><summary title="Core rule 199 · PDF page 33" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 199 · PDF page 33</div></details>

A [[Battlefield]] is both a location and also a [[Game Object]] at that location. ^cr-199-1

<details class="rule-ref"><summary title="Core rule 199.1 · PDF page 33" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 199.1 · PDF page 33</div></details>

Locations can be Destinations and Origins for [[Movement|movement]]. ^cr-200

See [[Movement#^cr-447|Movement]] for more information.
