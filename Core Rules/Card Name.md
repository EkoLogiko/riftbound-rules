# Card Name

[[Start Here|Home]] · [[Concept Index|Find a concept]] · [[Core Rules Index|Core rules]]

<span title="Core rule 132"></span> ^cr-132

<details class="rule-ref"><summary title="Core rule 132 · PDF page 10" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 132 · PDF page 10</div></details>

Each [[Card|card]] has a name that identifies it uniquely. ^cr-132-1

<details class="rule-ref"><summary title="Core rule 132.1 · PDF page 10" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 132.1 · PDF page 10</div></details>

This is usually located in the middle of the [[Card|card]]. ^cr-132-2

<details class="rule-ref"><summary title="Core rule 132.2 · PDF page 10" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 132.2 · PDF page 10</div></details>

[[Card|Cards]] that are printed in different languages but represent the same card are considered to have the same name for the purposes of deckbuilding and gameplay. ^cr-132-3

**Example:** Chemtech Enforcer in English and its counterpart in Chinese are considered the same [[Card|card]], despite the Name element on the card reading differently.

<details class="rule-ref"><summary title="Core rule 132.3 · PDF page 10" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 132.3 · PDF page 10</div></details>

Some [[Card|cards]] have both a short name and a subtitle. For all purposes, including rules and deckbuilding, such a card’s name is “&#91;Short Name&#93;, &#91;Subtitle&#93;”. ^cr-132-4

**Example:** Kai’Sa, Evolutionary and Kai’Sa, Survivor both have the short name Kai’Sa, but they have different names. You can include 3 of each in your deck under normal deckbuilding rules. If one of them is your [[Chosen Champion]], the other is not.

<details class="rule-ref"><summary title="Core rule 132.4 · PDF page 10-11" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 132.4 · PDF page 10-11</div></details>
