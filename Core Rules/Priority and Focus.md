<details class="rule-ref"><summary title="Core rule 311 · PDF page 36" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 311 · PDF page 36</div></details>

At any given time, up to one player has [[Priority]]. ^cr-312

<details class="rule-ref"><summary title="Core rule 312 · PDF page 36" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 312 · PDF page 36</div></details>

[[Priority]] is the singular exclusive right to take [[Discretionary Action|Discretionary Actions]]. ^cr-312-1

See [[Game Action#^cr-411-1|Discretionary Actions]] for more information.

<details class="rule-ref"><summary title="Core rule 312.1 · PDF page 36" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 312.1 · PDF page 36</div></details>

The player with [[Priority]] can take appropriately timed [[Discretionary Action|Discretionary Actions]]. ^cr-312-1-a

<details class="rule-ref"><summary title="Core rule 312.1.a · PDF page 36" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 312.1.a · PDF page 36</div></details>

If no player has [[Priority]], no player can take [[Discretionary Action|Discretionary Actions]]. ^cr-312-1-b

<details class="rule-ref"><summary title="Core rule 312.1.b · PDF page 36" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 312.1.b · PDF page 36</div></details>

Players can always take and make choices for [[Limited Action|Limited Actions]] when instructed, regardless of [[Priority]]. ^cr-312-1-b-1

<details class="rule-ref"><summary title="Core rule 312.1.b.1 · PDF page 36" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 312.1.b.1 · PDF page 36</div></details>

A player receives [[Priority]] at the following times: ^cr-312-2

<details class="rule-ref"><summary title="Core rule 312.2 · PDF page 36" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 312.2 · PDF page 36</div></details>

When [[Turn|the turn]] is in a [[Neutral Open State]] during their [[Main Phase]]. ^cr-312-2-a

<details class="rule-ref"><summary title="Core rule 312.2.a · PDF page 37" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 312.2.a · PDF page 37</div></details>

When [[Turn|the turn]] is in a [[Showdown State]] and they gain [[Focus]]. ^cr-312-2-b

<details class="rule-ref"><summary title="Core rule 312.2.b · PDF page 37" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 312.2.b · PDF page 37</div></details>

When [[Turn|the turn]] is in a [[Closed State]], all [[Pending Chain Item|pending chain items]] finish being finalized, and they [[Control|control]] the next item on the [[Chain]]. ^cr-312-2-c

<details class="rule-ref"><summary title="Core rule 312.2.c · PDF page 37" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 312.2.c · PDF page 37</div></details>

When [[Turn|the turn]] is in a [[Closed State]], they are the next Player in Turn Order, and the player with [[Priority]] passes. ^cr-312-2-d

<details class="rule-ref"><summary title="Core rule 312.2.d · PDF page 37" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 312.2.d · PDF page 37</div></details>

When a player is granted [[Priority]], it is either created if no player has it or taken from the player with Priority. ^cr-312-3

<details class="rule-ref"><summary title="Core rule 312.3 · PDF page 37" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 312.3 · PDF page 37</div></details>

At any given time, up to one player has [[Focus]]. ^cr-313

<details class="rule-ref"><summary title="Core rule 313 · PDF page 37" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 313 · PDF page 37</div></details>

[[Focus]] is the permission to take appropriately timed [[Discretionary Action|Discretionary Actions]] when [[Turn|the turn]] is in a [[Showdown Open State]]. ^cr-313-1

See [[Turn States#^cr-307|States of the Turn]] for more information.

<details class="rule-ref"><summary title="Core rule 313.1 · PDF page 37" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 313.1 · PDF page 37</div></details>

The player with [[Focus]] must obey any additional restrictions on which [[Discretionary Action|Discretionary Actions]] may be performed. ^cr-313-1-a

**Example:** A player with [[Focus]] may not [[Play|play]] [[Spell|spells]] or activate [[Ability|abilities]] that don't have the Action or Reaction [[Keywords|keywords]].

<details class="rule-ref"><summary title="Core rule 313.1.a · PDF page 37" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 313.1.a · PDF page 37</div></details>

A player who gains [[Focus]] also gains [[Priority]]. ^cr-313-2

<details class="rule-ref"><summary title="Core rule 313.2 · PDF page 37" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 313.2 · PDF page 37</div></details>

A player who passes [[Priority]] retains [[Focus]]. ^cr-313-3

<details class="rule-ref"><summary title="Core rule 313.3 · PDF page 37" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 313.3 · PDF page 37</div></details>

A player may not make [[Discretionary Action|discretionary actions]] with [[Focus]] unless they also possess [[Priority]]. ^cr-313-4

<details class="rule-ref"><summary title="Core rule 313.4 · PDF page 37" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 313.4 · PDF page 37</div></details>

If [[Turn|the turn]] is in a [[Neutral State]], no player has [[Focus]]. ^cr-313-5
