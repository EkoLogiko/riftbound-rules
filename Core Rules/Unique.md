# Unique

[[Start Here|Home]] · [[Concept Index|Find a concept]] · [[Core Rules Index|Core rules]]

<span title="Core rule 825"></span> ^cr-825

<details class="rule-ref"><summary title="Core rule 825 · PDF page 138" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 825 · PDF page 138</div></details>

Unique is a Deck Constraint Permission. ^cr-825-1

<details class="rule-ref"><summary title="Core rule 825.1 · PDF page 138" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 825.1 · PDF page 138</div></details>

It is normally present on [[Main Deck|main deck]] [[Card|cards]]. ^cr-825-2

<details class="rule-ref"><summary title="Core rule 825.2 · PDF page 138" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 825.2 · PDF page 138</div></details>

Unique is not functionally short for any [[Rules Text|rules text]], and instead provides a restriction to players during [[Deck Construction]]. ^cr-825-3

<details class="rule-ref"><summary title="Core rule 825.3 · PDF page 138" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 825.3 · PDF page 138</div></details>

A deck can contain only one [[Card|card]] of a given [[Card Name|name]] if the card has Unique ^cr-825-3-a

<details class="rule-ref"><summary title="Core rule 825.3.a · PDF page 138" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 825.3.a · PDF page 138</div></details>

If a [[Card|card]] is a [[Signature|Signature card]] and is also Unique, then that deck can contain any combination of three Signature cards, but still only one of each named Unique card. ^cr-825-3-b

<details class="rule-ref"><summary title="Core rule 825.3.b · PDF page 138" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 825.3.b · PDF page 138</div></details>

[[Card|Cards]] with Unique have no additional effects during gameplay. ^cr-825-4

<details class="rule-ref"><summary title="Core rule 825.4 · PDF page 138" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 825.4 · PDF page 138</div></details>

Unique, and whether or not a [[Card]] has Unique, is a characteristic of the [[Unit]] and may be checked or referenced by other [[Game Effect|Game Effects]]. ^cr-825-5

<details class="rule-ref"><summary title="Core rule 825.5 · PDF page 138" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 825.5 · PDF page 138</div></details>
