# Empower (Game Action)

[[Start Here|Home]] · [[Concept Index|Find a concept]] · [[Core Rules Index|Core rules]]

<span title="Core rule 442"></span> ^cr-442

<details class="rule-ref"><summary title="Core rule 442 · PDF page 96" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 442 · PDF page 96</div></details>

Empowering is the act of rendering one or more [[Game Object|Game Objects]] Empowered. ^cr-442-1

<details class="rule-ref"><summary title="Core rule 442.1 · PDF page 96" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 442.1 · PDF page 96</div></details>

Empowered is a binary state. A [[Game Object]] is Empowered or it isn’t. ^cr-442-1-a

<details class="rule-ref"><summary title="Core rule 442.1.a · PDF page 96" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 442.1.a · PDF page 96</div></details>

An Empowered [[Game Object]] can not be Empowered. ^cr-442-1-b

<details class="rule-ref"><summary title="Core rule 442.1.b · PDF page 96" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 442.1.b · PDF page 96</div></details>

If a [[Game Object]] is instructed to be Empowered when it is already Empowered, nothing additional happens. ^cr-442-1-c

<details class="rule-ref"><summary title="Core rule 442.1.c · PDF page 96" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 442.1.c · PDF page 96</div></details>

Some effects may grant a [[Game Object]] permission to be Empowered multiple times. Such an effect ignores this restriction. For these Game Objects, Empowered is not a binary state but a stacking status. ^cr-442-1-c-1

<details class="rule-ref"><summary title="Core rule 442.1.c.1 · PDF page 96" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 442.1.c.1 · PDF page 96</div></details>

“Empowered” is a state for [[Game Object|Game Objects]] on [[Board|the board]] that other [[Game Effect|game effects]] and [[Ability|abilities]] can reference. ^cr-442-2

<details class="rule-ref"><summary title="Core rule 442.2 · PDF page 97" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 442.2 · PDF page 97</div></details>

When a [[Game Object]] becomes Empowered as a result of the Empower [[Game Action|game action]], that is an event that can similarly be referenced by [[Game Effect|game effects]] and [[Ability|abilities]]. ^cr-442-2-a

<details class="rule-ref"><summary title="Core rule 442.2.a · PDF page 97" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 442.2.a · PDF page 97</div></details>

Empowering is a [[Limited Action]]. ^cr-442-3

<details class="rule-ref"><summary title="Core rule 442.3 · PDF page 97" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 442.3 · PDF page 97</div></details>

Players may only Empower [[Game Object|Game Objects]] when directed to by [[Game Effect|Game Effects]]. ^cr-442-3-a

<details class="rule-ref"><summary title="Core rule 442.3.a · PDF page 97" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 442.3.a · PDF page 97</div></details>
