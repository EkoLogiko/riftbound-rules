# Front Side

[[Start Here|Home]] · [[Concept Index|Find a concept]] · [[Core Rules Index|Core rules]]

<span title="Core rule 130"></span> ^cr-130

<details class="rule-ref"><summary title="Core rule 130 · PDF page 10" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 130 · PDF page 10</div></details>

The front side of a [[Card|card]] is the opposite of its back. ^cr-130-1

<details class="rule-ref"><summary title="Core rule 130.1 · PDF page 10" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 130.1 · PDF page 10</div></details>

This is also referred to as a front face. ^cr-130-2

<details class="rule-ref"><summary title="Core rule 130.2 · PDF page 10" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 130.2 · PDF page 10</div></details>

This can be identified in situations where the back is not easily discernible by the presence of the [[Play]] [[Costs|Cost]] in the upper left corner of the [[Card|card]]. ^cr-130-3

<details class="rule-ref"><summary title="Core rule 130.3 · PDF page 10" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 130.3 · PDF page 10</div></details>

[[Card|Cards]], when played, are played with their front face presented. ^cr-130-4

<details class="rule-ref"><summary title="Core rule 130.4 · PDF page 10" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 130.4 · PDF page 10</div></details>

The term face up is used to describe the state during regular [[Play|play]] of having a [[Card|card]]'s front face presented ^cr-130-5

<details class="rule-ref"><summary title="Core rule 130.5 · PDF page 10" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 130.5 · PDF page 10</div></details>

[[Card|Cards]] are considered to be [[Public Information]] while in this state, even if obscured by other cards in a pile. Example: The [[Trash]] is Public Information because all cards there have their front face presented even while stacked. ^cr-130-6

<details class="rule-ref"><summary title="Core rule 130.6 · PDF page 10" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 130.6 · PDF page 10</div></details>
