[[Battlefield]] Count: 3 ^cr-491-4

<details class="rule-ref"><summary title="Core rule 491.4 · PDF page 113" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 491.4 · PDF page 113</div></details>

Each player provides three (3) [[Battlefield|Battlefields]], included in their deck during deck building. ^cr-491-4-a

<details class="rule-ref"><summary title="Core rule 491.4.a · PDF page 113" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 491.4.a · PDF page 113</div></details>

[[Setup]]: ^cr-491-5

<details class="rule-ref"><summary title="Core rule 491.5 · PDF page 113" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 491.5 · PDF page 113</div></details>

Each player who is not going first randomly selects one (1) of their three (3) [[Battlefield|Battlefields]]. The other two are removed and will not be used for this game. The selected Battlefields are placed simultaneously between the players before [[Play|play]] and will be used for this game. ^cr-491-5-a

<details class="rule-ref"><summary title="Core rule 491.5.a · PDF page 113" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 491.5.a · PDF page 113</div></details>

The player who is taking the first [[Turn|turn]] removes their [[Battlefield|Battlefields]]. They will not be used. ^cr-491-5-b

<details class="rule-ref"><summary title="Core rule 491.5.b · PDF page 113" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 491.5.b · PDF page 113</div></details>

[[Turn]] order alternates teams. ^cr-491-5-c

<details class="rule-ref"><summary title="Core rule 491.5.c · PDF page 113" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 491.5.c · PDF page 113</div></details>

The first player will be followed by an opponent, then the first player's teammate, then the first opponent's teammate, and so on. ^cr-491-5-c-1

<details class="rule-ref"><summary title="Core rule 491.5.c.1 · PDF page 113" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 491.5.c.1 · PDF page 113</div></details>

If allies are sitting across from each other, [[Turn|turn]] order proceeds clockwise as normal. ^cr-491-5-c-2

<details class="rule-ref"><summary title="Core rule 491.5.c.2 · PDF page 113" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 491.5.c.2 · PDF page 113</div></details>

If allies are sitting next to each other, [[Turn|turn]] order is passed across the table. ^cr-491-5-c-3

<details class="rule-ref"><summary title="Core rule 491.5.c.3 · PDF page 113" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 491.5.c.3 · PDF page 113</div></details>

Format: Best of 1. The first team to reach the [[Victory Score]] in [[Points]] wins the Match. ^cr-491-6

<details class="rule-ref"><summary title="Core rule 491.6 · PDF page 113" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 491.6 · PDF page 113</div></details>

Teammates win or lose together. ^cr-491-6-a

<details class="rule-ref"><summary title="Core rule 491.6.a · PDF page 113" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 491.6.a · PDF page 113</div></details>

If one player Concedes, then the entire team loses. ^cr-491-6-a-1

<details class="rule-ref"><summary title="Core rule 491.6.a.1 · PDF page 113" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 491.6.a.1 · PDF page 113</div></details>

If one player Loses, then the entire team loses. ^cr-491-6-a-2

<details class="rule-ref"><summary title="Core rule 491.6.a.2 · PDF page 113" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 491.6.a.2 · PDF page 113</div></details>

If one player Wins, then the entire team wins. ^cr-491-6-a-3

<details class="rule-ref"><summary title="Core rule 491.6.a.3 · PDF page 113" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 491.6.a.3 · PDF page 113</div></details>

First [[Turn]] Process: The player going first does not [[Draw|draw]] a [[Card|card]] during their first [[Draw Phase]] of the game. The player going last channels an extra [[Rune]] from their [[Rune Deck]] during their first [[Channel Phase]] of the game. ^cr-491-7

<details class="rule-ref"><summary title="Core rule 491.7 · PDF page 113" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 491.7 · PDF page 113</div></details>

[[Unique]] Rules ^cr-491-8

<details class="rule-ref"><summary title="Core rule 491.8 · PDF page 113" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 491.8 · PDF page 113</div></details>

Players may [[Play|play]] [[Spell|spells]] or activate [[Ability|abilities]] during their Teammate's [[Turn]]. In order to do so, their Teammate will invite them to play a spell or activate an ability using their own [[Priority]]. ^cr-491-8-a

<details class="rule-ref"><summary title="Core rule 491.8.a · PDF page 113" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 491.8.a · PDF page 113</div></details>

A [[Battlefield]] can only be Scored, via [[Conquer|Conquering]] or [[Hold|Holding]], once per team per [[Turn|turn]]. ^cr-491-8-b

<details class="rule-ref"><summary title="Core rule 491.8.b · PDF page 114" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 491.8.b · PDF page 114</div></details>

[[Battlefield|Battlefields]] controlled during the [[Scoring Step]] in the [[Beginning Phase]] of a player's [[Turn|turn]] by that player's teammate are disqualified from being scored by that Team, that turn. ^cr-491-8-b-1

**Example:** A player may not induce their partner to retreat, and then [[Conquer|conquer]] a [[Battlefield]] their teammate was controlling.

<details class="rule-ref"><summary title="Core rule 491.8.b.1 · PDF page 114" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 491.8.b.1 · PDF page 114</div></details>

[[Control]] is not shared. ^cr-491-8-c

<details class="rule-ref"><summary title="Core rule 491.8.c · PDF page 114" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 491.8.c · PDF page 114</div></details>

Players may not [[Hide]] [[Card|cards]] at [[Battlefield|Battlefields]] controlled by their Teammate. ^cr-491-8-c-1

<details class="rule-ref"><summary title="Core rule 491.8.c.1 · PDF page 114" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 491.8.c.1 · PDF page 114</div></details>

Players may not issue Standard [[Movement]] to their Teammate's [[Unit|Units]]. ^cr-491-8-c-2

<details class="rule-ref"><summary title="Core rule 491.8.c.2 · PDF page 114" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 491.8.c.2 · PDF page 114</div></details>

[[Points]] are shared by a team. ^cr-491-8-d

<details class="rule-ref"><summary title="Core rule 491.8.d · PDF page 114" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 491.8.d · PDF page 114</div></details>

Both players on a team have the same number of Victory [[Points]]. ^cr-491-8-d-1

<details class="rule-ref"><summary title="Core rule 491.8.d.1 · PDF page 114" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 491.8.d.1 · PDF page 114</div></details>

If a player gains or loses [[Points|points]], their team gains or loses those points. ^cr-491-8-d-2

<details class="rule-ref"><summary title="Core rule 491.8.d.2 · PDF page 114" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 491.8.d.2 · PDF page 114</div></details>

If a [[Spell|spell]] or [[Ability|ability]] references or checks a player gaining or losing [[Points|points]], that ability checks whether that player’s team gains or loses points. ^cr-491-8-d-3

<details class="rule-ref"><summary title="Core rule 491.8.d.3 · PDF page 114" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 491.8.d.3 · PDF page 114</div></details>

[[Friendly]] describes controlled [[Game Object|Game Objects]] by a player or their Teammate. ^cr-491-8-e

**Example:** "When you [[Play|play]] me, [[Ready|ready]] a [[Friendly|friendly]] [[Unit|unit]]" could target a player's own Units or their teammate's Units.

<details class="rule-ref"><summary title="Core rule 491.8.e · PDF page 114" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 491.8.e · PDF page 114</div></details>

Hands are [[Private Information]]. Players may show their Private Information to one or more players at any time during [[Play|play]], including their teammate. ^cr-491-8-f

<details class="rule-ref"><summary title="Core rule 491.8.f · PDF page 114" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 491.8.f · PDF page 114</div></details>

Revealing [[Card|Cards]] is still a [[Game Action|game action]] and cannot be done unless instructed. ^cr-491-8-f-1

See [[Reveal#^cr-425|Reveal]] for more information.

<details class="rule-ref"><summary title="Core rule 491.8.f.1 · PDF page 114" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 491.8.f.1 · PDF page 114</div></details>

The Final Point has an adjustment to the criteria when [[Scoring|scoring]]. ^cr-491-8-g

<details class="rule-ref"><summary title="Core rule 491.8.g · PDF page 114" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 491.8.g · PDF page 114</div></details>

When [[Scoring|scoring]] the Final Point from [[Conquer]] during their or a teammate’s [[Turn|turn]], a player must Score each [[Battlefield]] in the same turn, excepting any that were occupied by their ally during the [[Scoring Step|scoring step]] of that turn’s [[Beginning Phase]]. ^cr-491-8-g-1

See [[Scoring#^cr-469|Scoring]] for more information.

<details class="rule-ref"><summary title="Core rule 491.8.g.1 · PDF page 114" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 491.8.g.1 · PDF page 114</div></details>

No other changes to Final Point restrictions. ^cr-491-8-g-2

<details class="rule-ref"><summary title="Core rule 491.8.g.2 · PDF page 114" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 491.8.g.2 · PDF page 114</div></details>

Teammates may not utilize the same [[Champion Legend]]. ^cr-491-8-h

<details class="rule-ref"><summary title="Core rule 491.8.h · PDF page 114" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 491.8.h · PDF page 114</div></details>

Teammates may not utilize the same [[Battlefield|Battlefields]]. ^cr-491-8-i
