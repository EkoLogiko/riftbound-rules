# Might Bonus

[[Start Here|Home]] · [[Concept Index|Find a concept]] · [[Core Rules Index|Core rules]]

<span title="Core rule 137"></span> ^cr-137

<details class="rule-ref"><summary title="Core rule 137 · PDF page 16" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 137 · PDF page 16</div></details>

Some [[Card|cards]] have a Might Bonus in their lower right corner, expressed as an operator plus an integer. ^cr-137-1

<details class="rule-ref"><summary title="Core rule 137.1 · PDF page 16" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 137.1 · PDF page 16</div></details>

A [[Card|card]]’s Might Bonus can be +0. ^cr-137-2

<details class="rule-ref"><summary title="Core rule 137.2 · PDF page 16" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 137.2 · PDF page 16</div></details>

A [[Card|card]]’s Might Bonus modulates the [[Might]] of the card to which the card that has the Might Bonus is [[Attached]]. ^cr-137-3

See [[Attachment#^cr-716|Attachment]] for more information.

<details class="rule-ref"><summary title="Core rule 137.3 · PDF page 16-17" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 137.3 · PDF page 16-17</div></details>

The Might Bonus is applied while [[Attached]] and stops applying as soon as the [[Card|card]] with the Might Bonus is no longer Attached. ^cr-137-3-a

<details class="rule-ref"><summary title="Core rule 137.3.a · PDF page 17" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 137.3.a · PDF page 17</div></details>

If the [[Card|card]] to which a card with a Might Bonus is [[Attached]] has no [[Might]] value, the Might Bonus is ignored. ^cr-137-3-b

<details class="rule-ref"><summary title="Core rule 137.3.b · PDF page 17" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 137.3.b · PDF page 17</div></details>
