# Special Terms

[[Card]] text and this rules document use certain terms in specific ways that are different from their common usage. ^cr-740

<details class="rule-ref"><summary title="Core rule 740 · PDF page 121" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 740 · PDF page 121</div></details>

Some [[Card|card]] text refers to [[Game Object|Game Objects]] in particular ways: ^cr-740-1

<details class="rule-ref"><summary title="Core rule 740.1 · PDF page 121" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 740.1 · PDF page 121</div></details>

Two [[Game Object|Game Objects]] are [[Friendly|friendly]] if they share a controller, or if one’s controller is teammates with the other’s. ^cr-740-1-a

<details class="rule-ref"><summary title="Core rule 740.1.a · PDF page 121" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 740.1.a · PDF page 121</div></details>

Two [[Game Object|Game Objects]] are [[Enemy|enemies]] if one’s controller is an opponent of the other’s. ^cr-740-1-b

<details class="rule-ref"><summary title="Core rule 740.1.b · PDF page 121" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 740.1.b · PDF page 121</div></details>

Some [[Card|card]] text refers to [[Unit|Units]] in particular ways: ^cr-740-2

<details class="rule-ref"><summary title="Core rule 740.2 · PDF page 121" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 740.2 · PDF page 121</div></details>

A [[Unit|unit]] is [[Alone|alone]] when there are no other [[Friendly|friendly]] units at the same [[Location|location]]. ^cr-740-2-a

<details class="rule-ref"><summary title="Core rule 740.2.a · PDF page 121" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 740.2.a · PDF page 121</div></details>

A [[Unit|unit]] is [[One on One|one on one]] when it and the [[Enemy|enemy]] unit at the same [[Location|location]] are both [[Alone|alone]]. ^cr-740-2-b

<details class="rule-ref"><summary title="Core rule 740.2.b · PDF page 121" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 740.2.b · PDF page 121</div></details>

A [[Unit|unit]] is [[In Combat|in combat]] if it is occupying a [[Battlefield|battlefield]] where [[Combat|combat]] is ongoing and has a combat designation. ^cr-740-2-c

<details class="rule-ref"><summary title="Core rule 740.2.c · PDF page 121" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 740.2.c · PDF page 121</div></details>

Some [[Card|card]] text refers to specific terminology: ^cr-740-3

<details class="rule-ref"><summary title="Core rule 740.3 · PDF page 121" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 740.3 · PDF page 121</div></details>

A [[Tie|tie]] occurs when there are [[Unit|units]] controlled by different players located at a [[Battlefield|battlefield]] where [[Combat|combat]] is taking place during the step 3d of the combat [[Cleanups|cleanup]]. ^cr-740-3-a

<details class="rule-ref"><summary title="Core rule 740.3.a · PDF page 121" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 740.3.a · PDF page 121</div></details>

Some terms in this document are used in particular ways: ^cr-740-4

<details class="rule-ref"><summary title="Core rule 740.4 · PDF page 121" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 740.4 · PDF page 121</div></details>

[[Costs within Instructions|Costs within instructions]] are [[Instructions|instructions]] that take a particular form (“&#91;do X&#93; to &#91;do Y&#93;”). &#91;Do X&#93; is the [[Costs|cost]] associated with the instruction, and &#91;do Y&#93; is the effect. ^cr-740-4-a

<details class="rule-ref"><summary title="Core rule 740.4.a · PDF page 122" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 740.4.a · PDF page 122</div></details>

For [[Spell|spells]], [[Costs within Instructions|costs within instructions]] are paid on resolution of the spell. In order to get the effect, the [[Costs|cost]] must be paid. ^cr-740-4-a-1

<details class="rule-ref"><summary title="Core rule 740.4.a.1 · PDF page 122" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 740.4.a.1 · PDF page 122</div></details>

For [[Triggered Ability|triggered abilities]], [[Costs within Instructions|costs within instructions]] that appear in the first part of the trigger effect are paid on finalization of the triggered ability. In order to place the triggered ability on the [[Chain|chain]], the [[Costs|cost]] must be paid. ^cr-740-4-a-2

<details class="rule-ref"><summary title="Core rule 740.4.a.2 · PDF page 122" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 740.4.a.2 · PDF page 122</div></details>

[[Costs within Instructions|Costs within instructions]] that appear in any later part of the trigger effect are paid on resolution. ^cr-740-4-a-2-a

<details class="rule-ref"><summary title="Core rule 740.4.a.2.a · PDF page 122" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 740.4.a.2.a · PDF page 122</div></details>
