<span title="Core rule 301"></span> ^cr-301

<details class="rule-ref"><summary title="Core rule 301 · PDF page 35" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 301 · PDF page 35</div></details>

[[Play]] continues cyclically until one player wins. ^cr-302

<details class="rule-ref"><summary title="Core rule 302 · PDF page 35" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 302 · PDF page 35</div></details>

The phases of a turn are rigid, but the actions taken during those steps can be done in any order, unless otherwise specified. ^cr-303

<details class="rule-ref"><summary title="Core rule 303 · PDF page 35" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 303 · PDF page 35</div></details>

[[Game Action|Game Actions]] of any nature are performed one at a time and are executed completely. ^cr-303-1

<details class="rule-ref"><summary title="Core rule 303.1 · PDF page 35" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 303.1 · PDF page 35</div></details>

[[Game Action|Game Actions]] cannot be performed simultaneously for any reason. ^cr-303-2

<details class="rule-ref"><summary title="Core rule 303.2 · PDF page 35" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 303.2 · PDF page 35</div></details>

If one or more [[Game Action|game actions]], [[Game Effect|game effects]], or [[Triggered Ability|Triggered Abilities]] are activated simultaneously, then Turn Order is referenced to organize the sequence of actions, starting with the current [[Turn Player]]. ^cr-303-2-a

See [[Triggered Ability#^cr-382|Triggered Abilities]] for more information.

<details class="rule-ref"><summary title="Core rule 303.2.a · PDF page 35" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 303.2.a · PDF page 35</div></details>

The Turn Player is the player taking the current turn. ^cr-304

<details class="rule-ref"><summary title="Core rule 304 · PDF page 35" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 304 · PDF page 35</div></details>

When there are no items on the [[Chain]] and the Turn Player cannot or chooses not to perform any [[Discretionary Action|Discretionary Actions]], the current phase or step of the turn ends and the next phase, step, or turn begins. ^cr-305

<details class="rule-ref"><summary title="Core rule 305 · PDF page 35" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 305 · PDF page 35</div></details>

The Turn Player changes when the current [[Turn Player]] reaches the End of all of the Phases of their Turn. ^cr-306
