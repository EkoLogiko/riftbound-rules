<details class="rule-ref"><summary title="Core rule 826 · PDF page 138" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 826 · PDF page 138</div></details>

Backline is a [[Passive Ability]] [[Keywords|keyword]]. ^cr-826-1

<details class="rule-ref"><summary title="Core rule 826.1 · PDF page 138" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 826.1 · PDF page 138</div></details>

It is present on [[Unit|Units]]. ^cr-826-2

<details class="rule-ref"><summary title="Core rule 826.2 · PDF page 138" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 826.2 · PDF page 138</div></details>

It is functionally short for “I must be assigned [[Lethal Damage|lethal damage]] after any other [[Unit|unit]] with the same controller as me that does not have &#91;Backline&#93; during the [[Combat]] [[Damage]] step.” ^cr-826-3

<details class="rule-ref"><summary title="Core rule 826.3 · PDF page 138" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 826.3 · PDF page 138</div></details>

It alters how players can elect to assign [[Combat|combat]] [[Damage|damage]] during combat. ^cr-826-4

<details class="rule-ref"><summary title="Core rule 826.4 · PDF page 138" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 826.4 · PDF page 138</div></details>

Players must still assign [[Lethal Damage|lethal damage]] to a [[Unit|unit]] before [[Movement|moving]] to the next when assigning their [[Damage|damage]]. ^cr-826-4-a

<details class="rule-ref"><summary title="Core rule 826.4.a · PDF page 138-139" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 826.4.a · PDF page 138-139</div></details>

If more than one [[Unit|unit]] with Backline is present with the same controller [[In Combat|in Combat]], [[Damage|damage]] may be assigned to any of them. Units with Backline are invalid assignments until all units without Backline have [[Lethal Damage|lethal damage]] assigned to them. ^cr-826-4-b

<details class="rule-ref"><summary title="Core rule 826.4.b · PDF page 139" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 826.4.b · PDF page 139</div></details>

Multiple Instances of Backline are redundant. ^cr-826-5

<details class="rule-ref"><summary title="Core rule 826.5 · PDF page 139" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 826.5 · PDF page 139</div></details>

Backline, and whether or not a [[Unit|unit]] has Backline, is a characteristic of the Unit and may be checked or referenced by other [[Game Effect|Game Effects]]. ^cr-826-6

<details class="rule-ref"><summary title="Core rule 826.6 · PDF page 139" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 826.6 · PDF page 139</div></details>
