Disarm is a [[Triggered Ability]] [[Keywords|keyword]]. ^cr-831-1

<details class="rule-ref"><summary title="Core rule 831.1 · PDF page 141" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 831.1 · PDF page 141</div></details>

Disarm is present on [[Unit|Units]]. ^cr-831-1-a

<details class="rule-ref"><summary title="Core rule 831.1.a · PDF page 141" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 831.1.a · PDF page 141</div></details>

Disarm is an [[Attack Trigger]]. ^cr-831-1-b

<details class="rule-ref"><summary title="Core rule 831.1.b · PDF page 141" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 831.1.b · PDF page 141</div></details>

Disarm is formatted as “Disarm X.” ^cr-831-1-c

<details class="rule-ref"><summary title="Core rule 831.1.c · PDF page 141" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 831.1.c · PDF page 141</div></details>

The X is referenced in the functional text of the [[Ability|ability]]. ^cr-831-1-c-1

<details class="rule-ref"><summary title="Core rule 831.1.c.1 · PDF page 141" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 831.1.c.1 · PDF page 141</div></details>

The X is referred to as the Disarm Value. ^cr-831-1-c-2

<details class="rule-ref"><summary title="Core rule 831.1.c.2 · PDF page 141" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 831.1.c.2 · PDF page 141</div></details>

If X is omitted, it is presumed to be 1. ^cr-831-1-c-3

<details class="rule-ref"><summary title="Core rule 831.1.c.3 · PDF page 141" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 831.1.c.3 · PDF page 141</div></details>

Disarm is functionally short for “When I attack, give an [[Enemy|enemy]] [[Unit|unit]] here -X &#91;M&#93; this [[Turn|turn]].” ^cr-831-1-d

<details class="rule-ref"><summary title="Core rule 831.1.d · PDF page 141" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 831.1.d · PDF page 141</div></details>

Regardless of how many instances of the Disarm [[Keywords|keyword]] a [[Unit|unit]] has, it will only trigger once using the total Disarm Value. ^cr-831-1-d-1

<details class="rule-ref"><summary title="Core rule 831.1.d.1 · PDF page 141" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 831.1.d.1 · PDF page 141</div></details>

If a [[Unit]] has Disarm, or has been granted Disarm, and is granted Disarm by an additional source, the Disarm Value of all granted Disarm [[Keywords|keywords]] is summed. ^cr-831-2

**Example:** Clanging Sentry reads “Your Mechs have &#91;Disarm&#93;.” If you [[Play|play]] a second Clanging Sentry, both of them will have Disarm 2.

<details class="rule-ref"><summary title="Core rule 831.2 · PDF page 141" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 831.2 · PDF page 141</div></details>

Disarm, and whether or not a [[Unit|unit]] has Disarm, is a characteristic of the Unit and may be checked or referenced by other [[Game Effect|Game Effects]]. ^cr-831-3
