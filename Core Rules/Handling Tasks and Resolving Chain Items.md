# Handling Tasks and Resolving Chain Items

<span title="Core rule 332"></span> ^cr-332

<details class="rule-ref"><summary title="Core rule 332 · PDF page 43" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 332 · PDF page 43</div></details>

A [[Task]] is one or more steps or processes that one or more Players must perform before continuing with any other actions. ^cr-333

<details class="rule-ref"><summary title="Core rule 333 · PDF page 43" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 333 · PDF page 43</div></details>

[[Task|Tasks]] include, but are not limited to: [[Cleanups]], the actions performed during the [[Start of Turn]] Process, throughout [[Combat]] in its various steps, and the actions performed during the End of [[Turn]] Process. ^cr-333-1

See [[Cleanups#^cr-318|Cleanups]] for more information on [[Cleanups]].

See [[Start of Turn#^cr-315|Start of Turn]] for more information on the [[Start of Turn]] process.

See [[Combat#^cr-461|Combat]] for more information on the steps of [[Combat]].

See [[Ending Phase#^cr-317|Ending Phase]] for more information.

<details class="rule-ref"><summary title="Core rule 333.1 · PDF page 43" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 333.1 · PDF page 43</div></details>

Whenever a Player takes one or more actions that incur [[Task|Tasks]] they should refer to the process of [[HOT FEPR]]: Handle [[Outstanding Task|Outstanding Tasks]]; then Finalize, Execute, Pass, Resolve. ^cr-334

<details class="rule-ref"><summary title="Core rule 334 · PDF page 43" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 334 · PDF page 43</div></details>

In the course of Handling [[Outstanding Task|Outstanding Tasks]], [[Chain]] Items may be added to the Chain. They will remain there until the [[Task|Tasks]] are complete. ^cr-334-1

<details class="rule-ref"><summary title="Core rule 334.1 · PDF page 43" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 334.1 · PDF page 43</div></details>

When all [[Outstanding Task|Outstanding Tasks]] are completed, all [[Pending Chain Item|pending Chain Items]] will subsequently be processed by the FEPR process. ^cr-334-2

<details class="rule-ref"><summary title="Core rule 334.2 · PDF page 43" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 334.2 · PDF page 43</div></details>

During the FEPR process, new [[Task|Tasks]] may be incurred. Complete the current step of the process and then pause and complete the necessary Tasks before continuing. ^cr-334-2-a

<details class="rule-ref"><summary title="Core rule 334.2.a · PDF page 43" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 334.2.a · PDF page 43</div></details>

If there are no [[Outstanding Task|Outstanding Tasks]], no [[Pending Chain Item|pending Chain Items]], no ongoing [[Showdowns|Showdown]] or [[Combat]], and it is the [[Main Phase]], [[Turn|the Turn]] Player receives [[Priority|priority]]. If there are no Outstanding Tasks, no pending Chain Items, no ongoing Showdown, and it is any other phase of the turn, proceed to the next substep, step, phase, or turn. ^cr-335

<details class="rule-ref"><summary title="Core rule 335 · PDF page 43" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 335 · PDF page 43</div></details>

If there are no [[Outstanding Task|Outstanding Tasks]], no [[Pending Chain Item|pending Chain Items]], and there is an ongoing [[Showdowns|Showdown]], the player with [[Focus]] receives [[Priority|priority]]. ^cr-335-1

<details class="rule-ref"><summary title="Core rule 335.1 · PDF page 43" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 335.1 · PDF page 43</div></details>

When there are no [[Outstanding Task|outstanding Tasks]] and there are [[Pending Chain Item|pending Chain Items]] on the [[Chain]], players should refer to the FEPR process to proceed. ^cr-336

<details class="rule-ref"><summary title="Core rule 336 · PDF page 43" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 336 · PDF page 43</div></details>

In the sequence of resolving FEPR more [[Chain]] Items may become [[Pending Chain Item|Pending Chain Items]]. These will be processed by the same FEPR process that produced them. ^cr-336-1

<details class="rule-ref"><summary title="Core rule 336.1 · PDF page 43" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 336.1 · PDF page 43</div></details>

### Step 1: Finalize

^cr-337

<details class="rule-ref"><summary title="Core rule 337 · PDF page 43" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 337 · PDF page 43</div></details>

If there is at least one [[Chain]] Item Pending, the controller of the oldest [[Pending Chain Item]] must complete the steps of Playing that Pending Item until it is a [[Finalized Chain Item|Finalized Item]] or leaves the Chain. ^cr-337-1

See [[Playing Cards#^cr-349|Playing Cards]] for more information on finalizing [[Chain|chain]] items.

<details class="rule-ref"><summary title="Core rule 337.1 · PDF page 44" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 337.1 · PDF page 44</div></details>

Finalizing an item to the [[Chain|chain]] does not pass [[Priority]]. ^cr-337-1-a

<details class="rule-ref"><summary title="Core rule 337.1.a · PDF page 44" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 337.1.a · PDF page 44</div></details>

[[Chain]] Items are Finalized in the order they were appended to the Chain. ^cr-337-1-b

<details class="rule-ref"><summary title="Core rule 337.1.b · PDF page 44" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 337.1.b · PDF page 44</div></details>

If, after finalizing the [[Chain]] Item, that item is a [[Unit]], [[Gear]], or an [[Ability|ability]] that Adds resources, it resolves immediately—[[Move]] to Step 4: Resolve. ^cr-337-2

See [[Playing Cards#^cr-349|Playing Cards]] for more information.

<details class="rule-ref"><summary title="Core rule 337.2 · PDF page 44" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 337.2 · PDF page 44</div></details>

If, after finalizing the [[Chain]] Item, there are still [[Pending Chain Item|Pending Chain Items]], return to Step 1. Finalize. ^cr-337-3

<details class="rule-ref"><summary title="Core rule 337.3 · PDF page 44" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 337.3 · PDF page 44</div></details>

If, after finalizing the [[Chain]] Item, there are no more items on the chain to be Finalized, the controller of the next item on the chain gains [[Priority]]. [[Move]] to Step 2: Execute. ^cr-337-4

<details class="rule-ref"><summary title="Core rule 337.4 · PDF page 44" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 337.4 · PDF page 44</div></details>

### Step 2: Execute

^cr-338

<details class="rule-ref"><summary title="Core rule 338 · PDF page 44" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 338 · PDF page 44</div></details>

The player with [[Priority]] may do any the following: ^cr-338-1

<details class="rule-ref"><summary title="Core rule 338.1 · PDF page 44" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 338.1 · PDF page 44</div></details>

[[Play]] a [[Card]] or [[Activated Ability]] that is legally timed. ^cr-338-1-a

<details class="rule-ref"><summary title="Core rule 338.1.a · PDF page 44" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 338.1.a · PDF page 44</div></details>

[[Card|Cards]] and [[Activated Ability|Activated Abilities]], by default, cannot be played during a [[Closed State]]. ^cr-338-1-a-1

<details class="rule-ref"><summary title="Core rule 338.1.a.1 · PDF page 44" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 338.1.a.1 · PDF page 44</div></details>

A Legally Timed [[Card]] or [[Activated Ability]] would be one with Reaction or one that will have Reaction when played under appropriate circumstances. ^cr-338-1-a-2

<details class="rule-ref"><summary title="Core rule 338.1.a.2 · PDF page 44" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 338.1.a.2 · PDF page 44</div></details>

Other exceptions may be created during regular [[Play|play]]. ^cr-338-1-a-3

<details class="rule-ref"><summary title="Core rule 338.1.a.3 · PDF page 44" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 338.1.a.3 · PDF page 44</div></details>

The [[Card]] or [[Activated Ability]] will be added to the [[Chain|chain]] as a [[Pending Chain Item|Pending Item]], following the steps of playing a card. ^cr-338-1-a-4

<details class="rule-ref"><summary title="Core rule 338.1.a.4 · PDF page 44" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 338.1.a.4 · PDF page 44</div></details>

This can be an additional item to the item that Started the [[Chain]] in the case of the first player with [[Priority]] after creating the Chain. ^cr-338-1-a-5

<details class="rule-ref"><summary title="Core rule 338.1.a.5 · PDF page 44" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 338.1.a.5 · PDF page 44</div></details>

Whether a [[Card]] or [[Activated Ability]] is legally timed is evaluated during the “Check Legality” step of Playing a Card. ^cr-338-1-a-6

See [[Playing Cards#^cr-349|Playing Cards]] for more information.

See [[Playing or Activating an Ability#^cr-399|Playing or Activating Abilities]] for more information.

<details class="rule-ref"><summary title="Core rule 338.1.a.6 · PDF page 44" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 338.1.a.6 · PDF page 44</div></details>

Playing a [[Card]] or [[Activated Ability]] will create one or more [[Pending Chain Item|Pending Items]]. Return to Step 1: Finalize. ^cr-338-1-a-7

<details class="rule-ref"><summary title="Core rule 338.1.a.7 · PDF page 44" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 338.1.a.7 · PDF page 44</div></details>

Pass [[Priority]] ^cr-338-1-b

<details class="rule-ref"><summary title="Core rule 338.1.b · PDF page 44" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 338.1.b · PDF page 44</div></details>

The player with [[Priority]] passes Priority to the next Player in [[Turn]] Order. Proceed to Step 3: Pass. ^cr-338-1-b-1

<details class="rule-ref"><summary title="Core rule 338.1.b.1 · PDF page 44" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 338.1.b.1 · PDF page 44</div></details>

### Step 3: Pass

^cr-339

<details class="rule-ref"><summary title="Core rule 339 · PDF page 44" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 339 · PDF page 44</div></details>

If all players have passed [[Priority]] in sequence without adding any items to the [[Chain]], proceed to Step 4: Resolve. ^cr-339-1

<details class="rule-ref"><summary title="Core rule 339.1 · PDF page 44" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 339.1 · PDF page 44</div></details>

Otherwise, the player with [[Priority]] passes Priority to the next Player in [[Turn]] Order. Return to Step 2: Execute. ^cr-339-2

<details class="rule-ref"><summary title="Core rule 339.2 · PDF page 44" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 339.2 · PDF page 44</div></details>

### Step 4: Resolve

^cr-340

<details class="rule-ref"><summary title="Core rule 340 · PDF page 44" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 340 · PDF page 44</div></details>

The newest [[Finalized Chain Item]] resolves. Execute its [[Game Effect|game effects]] in their entirety. ^cr-340-1

See [[Playing Cards#^cr-349|Playing Cards]] for more information on resolving [[Spell|spells]].

See [[Playing or Activating an Ability#^cr-399|Playing or Activating Abilities]] for more information on resolving [[Ability|abilities]].

<details class="rule-ref"><summary title="Core rule 340.1 · PDF page 45" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 340.1 · PDF page 45</div></details>

If the [[Chain]] is empty, [[Play|play]] proceeds in an [[Open State]]. ^cr-340-2

<details class="rule-ref"><summary title="Core rule 340.2 · PDF page 45" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 340.2 · PDF page 45</div></details>

If this occurs during a [[Showdowns|Showdown]] and the [[Chain|chain]] wasn’t initiated by a [[Triggered Ability|triggered ability]] or an [[Ability|ability]] that Adds resources, [[Focus|focus]] passes to the next player in [[Turn|turn]] order. ^cr-340-2-a

<details class="rule-ref"><summary title="Core rule 340.2.a · PDF page 45" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 340.2.a · PDF page 45</div></details>

If the [[Chain]] is not empty and there are one or more [[Pending Chain Item|Pending Items]], return to Step 1: Finalize. ^cr-340-3

<details class="rule-ref"><summary title="Core rule 340.3 · PDF page 45" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 340.3 · PDF page 45</div></details>

If the [[Chain]] is not empty and there are no [[Pending Chain Item|Pending Items]], the controller of the newest item on the chain gains [[Priority]]. Return to Step 2: Execute. ^cr-340-4

<details class="rule-ref"><summary title="Core rule 340.4 · PDF page 45" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 340.4 · PDF page 45</div></details>
