# Keywords

[[Start Here|Home]] · [[Concept Index|Find a concept]] · [[Core Rules Index|Core rules]]

<span title="Core rule 800"></span> ^cr-800

<details class="rule-ref"><summary title="Core rule 800 · PDF page 125" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 800 · PDF page 125</div></details>

A Keyword is a specific term that appears on [[Card|Cards]] that acts as a shorthand for a specific [[Game Effect|game effect]], or [[Ability|ability]] of any variety. ^cr-801

<details class="rule-ref"><summary title="Core rule 801 · PDF page 125" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 801 · PDF page 125</div></details>

A Keyword can be an [[Ability|ability]]. ^cr-801-1

<details class="rule-ref"><summary title="Core rule 801.1 · PDF page 125" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 801.1 · PDF page 125</div></details>

Keywords can be identified by having a colored highlight behind them. ^cr-801-2

<details class="rule-ref"><summary title="Core rule 801.2 · PDF page 125" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 801.2 · PDF page 125</div></details>

The color of the highlight has no effect on gameplay. ^cr-801-2-a

<details class="rule-ref"><summary title="Core rule 801.2.a · PDF page 125" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 801.2.a · PDF page 125</div></details>

Keywords can be referenced or specified by other [[Game Effect|Game Effects]]. ^cr-801-3

<details class="rule-ref"><summary title="Core rule 801.3 · PDF page 125" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 801.3 · PDF page 125</div></details>

Other effects may grant Keywords. ^cr-801-3-a

<details class="rule-ref"><summary title="Core rule 801.3.a · PDF page 125" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 801.3.a · PDF page 125</div></details>

The definition and rules of the specific Keyword will determine the behavior if a Keyword is granted while it is already present. ^cr-801-3-a-1

<details class="rule-ref"><summary title="Core rule 801.3.a.1 · PDF page 125" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 801.3.a.1 · PDF page 125</div></details>

The effect that granted the Keyword will specify the duration for which it is granted. ^cr-801-3-a-2

<details class="rule-ref"><summary title="Core rule 801.3.a.2 · PDF page 125" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 801.3.a.2 · PDF page 125</div></details>

If an effect that grants a Keyword does not specify a duration, the duration is as long as that [[Game Object]] remains on [[Board|the Board]] or in its current Non-Board [[Zone]]. ^cr-801-3-a-3

<details class="rule-ref"><summary title="Core rule 801.3.a.3 · PDF page 125" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 801.3.a.3 · PDF page 125</div></details>

Other effects may remove Keywords. ^cr-801-3-b

<details class="rule-ref"><summary title="Core rule 801.3.b · PDF page 125" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 801.3.b · PDF page 125</div></details>

The effect that removed the Keyword will specify the duration it is removed. ^cr-801-3-b-1

<details class="rule-ref"><summary title="Core rule 801.3.b.1 · PDF page 125" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 801.3.b.1 · PDF page 125</div></details>

If an effect that removes a Keyword does not specify a duration, the duration is as long as that [[Game Object]] remains on [[Board|the Board]] or in its current Non-Board [[Zone]]. ^cr-801-3-b-2

<details class="rule-ref"><summary title="Core rule 801.3.b.2 · PDF page 125" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 801.3.b.2 · PDF page 125</div></details>

A [[Card|card]] can have any number of Keywords. ^cr-802

<details class="rule-ref"><summary title="Core rule 802 · PDF page 125" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 802 · PDF page 125</div></details>

Similar to other [[Rules Text|rules text]], execute any effects of Keywords in the order listed when reading the [[Card|card]] from top to bottom of the rules text. ^cr-803
