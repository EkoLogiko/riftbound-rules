# Legion

[[Start Here|Home]] · [[Concept Index|Find a concept]] · [[Core Rules Index|Core rules]]

<span title="Core rule 812"></span> ^cr-812

<details class="rule-ref"><summary title="Core rule 812 · PDF page 131" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 812 · PDF page 131</div></details>

Legion is a [[Dependent Keyword]]. ^cr-812-1

<details class="rule-ref"><summary title="Core rule 812.1 · PDF page 131" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 812.1 · PDF page 131</div></details>

It is formatted as "&#91;Legion&#93;&#91;>&#93; &#91;Text&#93;". ^cr-812-1-a

<details class="rule-ref"><summary title="Core rule 812.1.a · PDF page 131" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 812.1.a · PDF page 131</div></details>

Starting from the [[Keywords|Keyword]] to the end of the clause, the entire statement is the Legion [[Ability]]. ^cr-812-1-b

<details class="rule-ref"><summary title="Core rule 812.1.b · PDF page 131" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 812.1.b · PDF page 131</div></details>

Legion is functionally short for “If you have played another [[Card|card]] this [[Turn|turn]], this card gains &#91;Text&#93;.” ^cr-812-1-b-1

<details class="rule-ref"><summary title="Core rule 812.1.b.1 · PDF page 131" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 812.1.b.1 · PDF page 131</div></details>

The &#91;Text&#93; is the Dependent [[Ability]]. ^cr-812-1-b-2

<details class="rule-ref"><summary title="Core rule 812.1.b.2 · PDF page 131" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 812.1.b.2 · PDF page 131</div></details>

As long as a [[Card|card]] different than the one with the Legion [[Ability|ability]] has been Finalized by you on the same [[Turn|turn]] then the Dependent Ability is Active on the card with Legion. ^cr-812-1-c

<details class="rule-ref"><summary title="Core rule 812.1.c · PDF page 131" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 812.1.c · PDF page 131</div></details>

All instances of Legion on [[Card|cards]] a player controls are satisfied by that player playing a single card. ^cr-812-2

**Example:** One [[Card|card]] has three different Legion [[Ability|Abilities]]. The Legion Text of all three abilities will be active as long as one card has been finalized by the card's controller earlier in the same [[Turn|turn]].

<details class="rule-ref"><summary title="Core rule 812.2 · PDF page 131" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 812.2 · PDF page 131</div></details>

Legion, and whether or not a [[Card|card]] has Legion, is a characteristic of the card and may be checked or referenced by other [[Game Effect|Game Effects]]. ^cr-812-3

<details class="rule-ref"><summary title="Core rule 812.3 · PDF page 131" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 812.3 · PDF page 131</div></details>
