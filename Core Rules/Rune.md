A Rune is not a [[Main Deck]] [[Card|card]]. ^cr-161-1

<details class="rule-ref"><summary title="Core rule 161.1 · PDF page 23" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 161.1 · PDF page 23</div></details>

This means, despite remaining on [[Board|the Board]] until Recycled or otherwise removed from the board, it is not a [[Permanent]]. ^cr-161-1-a

<details class="rule-ref"><summary title="Core rule 161.1.a · PDF page 23" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 161.1.a · PDF page 23</div></details>

Runes are kept in the [[Rune Deck]]. ^cr-161-2

<details class="rule-ref"><summary title="Core rule 161.2 · PDF page 23" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 161.2 · PDF page 23</div></details>

Exactly 12 Rune [[Card|cards]] chosen during [[Deck Construction]]. ^cr-161-2-a

See [[Deck Construction#^cr-103-4|Rune Deck]] for more information.

<details class="rule-ref"><summary title="Core rule 161.2.a · PDF page 23" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 161.2.a · PDF page 23</div></details>

When a Rune is Recycled it is returned to the [[Rune Deck]], not the [[Main Deck]]. ^cr-161-2-b

See [[Recycle#^cr-417|Recycle]] for more information.

<details class="rule-ref"><summary title="Core rule 161.2.b · PDF page 24" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 161.2.b · PDF page 24</div></details>

Runes produce the resources needed to pay [[Costs|costs]]. ^cr-162

<details class="rule-ref"><summary title="Core rule 162 · PDF page 24" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 162 · PDF page 24</div></details>

<details class="rule-ref"><summary title="Core rule 163 · PDF page 24" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 163 · PDF page 24</div></details>

[[Energy]] is used to pay numeric Energy [[Costs|costs]]. ^cr-163-1

<details class="rule-ref"><summary title="Core rule 163.1 · PDF page 24" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 163.1 · PDF page 24</div></details>

[[Energy]] has no [[Domain]]. ^cr-163-1-a

<details class="rule-ref"><summary title="Core rule 163.1.a · PDF page 24" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 163.1.a · PDF page 24</div></details>

[[Energy]] has no type. ^cr-163-1-b

<details class="rule-ref"><summary title="Core rule 163.1.b · PDF page 24" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 163.1.b · PDF page 24</div></details>

[[Power]] is used to pay Domain-associated Power [[Costs]]. ^cr-163-2

[[Power]]'s [[Domain]] usually corresponds to the Domain of the Rune that produced it. ^cr-163-2-a-1
