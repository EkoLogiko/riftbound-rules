# Swap

[[Start Here|Home]] · [[Concept Index|Find a concept]] · [[Core Rules Index|Core rules]]

<span title="Core rule 434"></span> ^cr-434

<details class="rule-ref"><summary title="Core rule 434 · PDF page 91" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 434 · PDF page 91</div></details>

Swapping is the act of increasing one numeric value and decreasing another numeric value on some number of [[Game Object|Game Objects]] such that their values are reversed. ^cr-434-1

<details class="rule-ref"><summary title="Core rule 434.1 · PDF page 91" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 434.1 · PDF page 91</div></details>

Swapping creates two different effects that apply to each attribute. One that Increases one value and one that Decreases the other. These effects last for the duration specified by the effect that instructed the Swap. ^cr-434-1-a

<details class="rule-ref"><summary title="Core rule 434.1.a · PDF page 91" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 434.1.a · PDF page 91</div></details>

To accomplish this, determine the difference between these values and then apply an Increase for that amount to the lower value of the two attributes, and a Decrease of that amount to the higher value of the two attributes. ^cr-434-1-b

<details class="rule-ref"><summary title="Core rule 434.1.b · PDF page 91" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 434.1.b · PDF page 91</div></details>

If both attributes are the same numeric value, Swapping has no effect. ^cr-434-1-c

<details class="rule-ref"><summary title="Core rule 434.1.c · PDF page 91" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 434.1.c · PDF page 91</div></details>

If the attributes being swapped are [[Unit|Units]]’ Mights, this effect is the equivalent to giving those units a [[Might]] increasing effect and a Might decreasing effect respectively. ^cr-434-1-d

<details class="rule-ref"><summary title="Core rule 434.1.d · PDF page 91" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 434.1.d · PDF page 91</div></details>

Swapping is a [[Limited Action]]. ^cr-434-2

<details class="rule-ref"><summary title="Core rule 434.2 · PDF page 91" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 434.2 · PDF page 91</div></details>

Players may only swap when [[Game Effect|Game Effects]] direct them to do so. ^cr-434-2-a

<details class="rule-ref"><summary title="Core rule 434.2.a · PDF page 91" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 434.2.a · PDF page 91</div></details>
