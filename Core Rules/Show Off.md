# Show Off

[[Start Here|Home]] · [[Concept Index|Find a concept]] · [[Core Rules Index|Core rules]]

<span title="Core rule 832"></span> ^cr-832

<details class="rule-ref"><summary title="Core rule 832 · PDF page 141" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 832 · PDF page 141</div></details>

Show Off is a [[Passive Ability]] [[Keywords|keyword]]. ^cr-832-1

<details class="rule-ref"><summary title="Core rule 832.1 · PDF page 141" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 832.1 · PDF page 141</div></details>

Show Off is normally present on [[Card|Cards]]. ^cr-832-1-a

<details class="rule-ref"><summary title="Core rule 832.1.a · PDF page 141" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 832.1.a · PDF page 141</div></details>

Show Off is formatted as “&#91;Show Off&#93; &#91;Object&#93;.” ^cr-832-1-b

<details class="rule-ref"><summary title="Core rule 832.1.b · PDF page 141" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 832.1.b · PDF page 141</div></details>

The “&#91;Object&#93;” in this [[Ability|ability]] could be one object or multiple; object/s of a given type; or it could have further specifications on qualities of the object/s. The object in question could be [[Game Object|Game Objects]] on [[Board|the board]] or [[Card|cards]] in [[Hand|hand]]. ^cr-832-1-b-1

Examples: A [[Card|card]] reads “&#91;Show Off&#93; a [[Unit|unit]].” A card reads “&#91;Show Off&#93; a card with [[Energy Cost|Energy cost]] &#91;7&#93; or more.” A card reads “&#91;Show Off&#93; five units with different names.”

<details class="rule-ref"><summary title="Core rule 832.1.b.1 · PDF page 141" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 832.1.b.1 · PDF page 141</div></details>

Show Off is functionally short for “As you [[Play|play]] &#91;me/this&#93;, you may [[Reveal|reveal]] &#91;Object&#93; from your [[Hand|hand]] and/or pick &#91;Object&#93; from among [[Friendly|friendly]] [[Game Object|game objects]] on [[Board|the board]].” ^cr-832-1-c

<details class="rule-ref"><summary title="Core rule 832.1.c · PDF page 141" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 832.1.c · PDF page 141</div></details>

Showing Off one or more [[Card|Cards]] or [[Game Object|Game Objects]] in this way can be referenced by [[Linked Ability|linked abilities]] and [[Instructions|instructions]]. ^cr-832-1-c-1

**Example:** A [[Unit|unit]] reads in part “&#91;Show Off&#93; five units with different names,” and “When you [[Play|play]] me, [[Kill|kill]] all other units. If you showed off, the next unit you play this [[Turn|turn]] [[Costs|costs]] &#91;1&#93; less for each killed unit.”

<details class="rule-ref"><summary title="Core rule 832.1.c.1 · PDF page 142" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 832.1.c.1 · PDF page 142</div></details>

The decision of whether or not to Show Off is made by the controller of the [[Chain|chain]] item with Show Off during the process of finalizing it. ^cr-832-1-c-2

See [[Process of Playing a Card#^cr-355|Make Relevant Choices]] for more information.

<details class="rule-ref"><summary title="Core rule 832.1.c.2 · PDF page 142" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 832.1.c.2 · PDF page 142</div></details>

If &#91;Object&#93; is a set of [[Card|Cards]] or [[Game Object|Game Objects]], that set can be composed of Game Objects on [[Board|the board]] as well as Cards in [[Hand|hand]], as long as the composed set satisfies the Show Off condition. ^cr-832-1-c-3

**Example:** A [[Unit|unit]] reads in part “&#91;Show Off&#93; five units with different names.” When showing off as part of playing that unit, units may be [[Reveal|revealed]] from [[Hand|hand]] or picked from among [[Friendly|friendly]] units on [[Board|the board]], as long as the group of units picked and revealed satisfies the specified quality.

<details class="rule-ref"><summary title="Core rule 832.1.c.3 · PDF page 142" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 832.1.c.3 · PDF page 142</div></details>

If some or all of the &#91;Object&#93; set leave the appropriate [[Zone|zones]] during the finalization process after being shown off, it will not [[Prevent|prevent]] the source of the Show Off [[Ability|ability]] from becoming a [[Finalized Chain Item]]. ^cr-832-1-c-4

**Example:** A [[Spell|spell]] reads “&#91;Show Off&#93; a Mech” and “As an [[Additional Cost|additional cost]] to [[Play|play]] this, [[Discard|discard]] 1.” When finalizing the spell, the same Mech being shown off can be discarded to the mandatory additional cost without preventing the spell from being finalized.

<details class="rule-ref"><summary title="Core rule 832.1.c.4 · PDF page 142" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 832.1.c.4 · PDF page 142</div></details>

[[Linked Ability|Linked abilities]] and [[Instructions|instructions]] can reference information about the shown off object/s. ^cr-832-1-d

**Example:** Primordial Roar is a [[Spell|spell]] that reads “&#91;Show Off&#93; a [[Unit|unit]],” and “If you showed off a unit, [[Deal|deal]] [[Damage|damage]] equal to that unit's [[Might]] to a unit.”

<details class="rule-ref"><summary title="Core rule 832.1.d · PDF page 142" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 832.1.d · PDF page 142</div></details>

The information referenced in this way is checked when the [[Card|card]]/s in question are shown off during finalization. Any later changes to the shown off objects will not be considered. ^cr-832-1-d-1

**Example:** Primordial Roar is played showing off a [[Friendly|friendly]] [[Unit|unit]] with 4 &#91;M&#93; and an [[Enemy|enemy]] unit with 3 &#91;M&#93;. In reaction to Primordial Roar, an opponent plays Frigid Touch, giving the friendly unit -2 &#91;M&#93; this [[Turn|turn]]. Because the information was checked when the friendly unit was shown off, the [[Spell|spell]] still deals 4 [[Damage|damage]] to the enemy unit, [[Kill|killing]] it.

<details class="rule-ref"><summary title="Core rule 832.1.d.1 · PDF page 142" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 832.1.d.1 · PDF page 142</div></details>

Multiple instances of Show Off are treated separately. ^cr-832-2

<details class="rule-ref"><summary title="Core rule 832.2 · PDF page 142" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 832.2 · PDF page 142</div></details>

If a linked effect or instruction refers to an instance of Show Off, it refers to the [[Keywords|keyword]] granted by the same source unless specified otherwise or there is no keyword granted by the same source. If the linked effect or instruction specifies information about the shown off [[Card|card]], it is linked to only that instance of the Show Off keyword. If there is no linked keyword, an [[Ability|ability]] that references showing off is linked to all Show Off keywords on the appropriate card. ^cr-832-2-a

**Example:** A [[Card|card]] reads in part “[[Spell|Spells]] you [[Play|play]] have ‘&#91;Show Off&#93; a [[Mighty]] [[Unit|unit]].’ and ‘If you showed off, this [[Costs|costs]] &#91;A&#93; less.” If a spell that reads in part “&#91;Show Off&#93; a spell with [[Energy Cost|Energy cost]] &#91;7&#93; or more,” and “If you showed off, this can’t be countered.” is played by the same controller, showing off a Mighty unit will not be sufficient to satisfy both [[Ability|abilities]] that reference showing off because they refer to instances of the show off [[Keywords|keyword]] granted by different sources.

<details class="rule-ref"><summary title="Core rule 832.2.a · PDF page 142" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 832.2.a · PDF page 142</div></details>

Show Off, and whether or not a [[Card|card]] has Show Off, is a characteristic of the card and may be checked or referenced by other [[Game Effect|Game Effects]]. ^cr-832-3
