# Accelerate

[[Start Here|Home]] · [[Concept Index|Find a concept]] · [[Core Rules Index|Core rules]]

<span title="Core rule 805"></span> ^cr-805

<details class="rule-ref"><summary title="Core rule 805 · PDF page 125" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 805 · PDF page 125</div></details>

Accelerate is an Optional [[Additional Cost]] [[Keywords|keyword]]. ^cr-805-1

<details class="rule-ref"><summary title="Core rule 805.1 · PDF page 125" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 805.1 · PDF page 125</div></details>

Accelerate is present on [[Unit|Units]]. ^cr-805-1-a

<details class="rule-ref"><summary title="Core rule 805.1.a · PDF page 125" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 805.1.a · PDF page 125</div></details>

Accelerate is functionally short for "As you [[Play|play]] me, you may pay &#91;1&#93;&#91;C&#93; as an [[Additional Cost|additional cost]]. If you do, I enter [[Ready|ready]]." ^cr-805-1-b

<details class="rule-ref"><summary title="Core rule 805.1.b · PDF page 125" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 805.1.b · PDF page 125</div></details>

If the [[Unit|unit]] has one or more domains, the [[Power]] portion of the Accelerate [[Costs|cost]] can be paid only with a Power that matches one of the domains of the unit. ^cr-805-1-b-1

<details class="rule-ref"><summary title="Core rule 805.1.b.1 · PDF page 125" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 805.1.b.1 · PDF page 125</div></details>

If the [[Unit|unit]] has no [[Domain|domain]], the [[Power]] portion of the Accelerate [[Costs|cost]] can be paid with &#91;A&#93; (a Power of any domain). ^cr-805-1-b-2

<details class="rule-ref"><summary title="Core rule 805.1.b.2 · PDF page 125" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 805.1.b.2 · PDF page 125</div></details>

Accelerate is an Optional [[Additional Cost]] to be paid as a player plays the [[Unit|unit]] with the [[Ability|ability]]. ^cr-805-2

<details class="rule-ref"><summary title="Core rule 805.2 · PDF page 125" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 805.2 · PDF page 125</div></details>

Accelerate [[Costs|costs]] cannot be paid while the [[Unit|unit]] is on [[Board|the board]], only as part of the steps of playing a [[Card|card]]. ^cr-805-2-a

<details class="rule-ref"><summary title="Core rule 805.2.a · PDF page 125-126" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 805.2.a · PDF page 125-126</div></details>

Paying the [[Costs|cost]] generates a [[Delayed Replacement]] Effect. Even if the [[Unit|unit]] loses the Accelerate [[Keywords|keyword]] during the finalization process, as long as the cost was paid, that unit will still enter [[Ready|ready]]. ^cr-805-2-b

<details class="rule-ref"><summary title="Core rule 805.2.b · PDF page 126" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 805.2.b · PDF page 126</div></details>

Accelerate has no function while on [[Board|the board]]. ^cr-805-3

<details class="rule-ref"><summary title="Core rule 805.3 · PDF page 126" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 805.3 · PDF page 126</div></details>

Multiple instances of Accelerate are redundant. ^cr-805-4

<details class="rule-ref"><summary title="Core rule 805.4 · PDF page 126" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 805.4 · PDF page 126</div></details>

Accelerate, and whether or not a [[Unit|unit]] has Accelerate, is a characteristic of the Unit and may be checked or referenced by other [[Game Effect|Game Effects]]. ^cr-805-5

<details class="rule-ref"><summary title="Core rule 805.5 · PDF page 126" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 805.5 · PDF page 126</div></details>

Accelerate generates a [[Delayed Replacement|delayed replacement]] effect that replaces a [[Unit|unit]] entering [[Board|the board]] [[Exhaust|exhausted]] with it entering [[Ready|ready]]. It does not enter exhausted and then become ready. ^cr-805-6

<details class="rule-ref"><summary title="Core rule 805.6 · PDF page 126" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 805.6 · PDF page 126</div></details>

Accelerate will not interact with, or trigger, [[Ability|abilities]] that are affected by [[Unit|units]] becoming [[Ready|ready]]. ^cr-805-6-a

<details class="rule-ref"><summary title="Core rule 805.6.a · PDF page 126" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 805.6.a · PDF page 126</div></details>
