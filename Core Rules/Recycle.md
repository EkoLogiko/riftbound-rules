# Recycle

[[Start Here|Home]] · [[Concept Index|Find a concept]] · [[Core Rules Index|Core rules]]

<span title="Core rule 417"></span> ^cr-417

<details class="rule-ref"><summary title="Core rule 417 · PDF page 79" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 417 · PDF page 79</div></details>

Recycling [[Card|cards]] is the action in which a player takes one or more cards from a specific [[Zone|zone]] and then puts it on the bottom of the corresponding deck. ^cr-417-1

<details class="rule-ref"><summary title="Core rule 417.1 · PDF page 79" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 417.1 · PDF page 79</div></details>

[[Main Deck]] [[Card|cards]] are Recycled to the Main Deck. ^cr-417-1-a

<details class="rule-ref"><summary title="Core rule 417.1.a · PDF page 79" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 417.1.a · PDF page 79</div></details>

[[Rune|Runes]] are Recycled to the [[Rune Deck]]. ^cr-417-1-b

<details class="rule-ref"><summary title="Core rule 417.1.b · PDF page 79" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 417.1.b · PDF page 79</div></details>

Each player Recycles [[Card|cards]] to their own [[Main Deck]] and [[Rune Deck]], regardless of which player is instructed to perform the Recycle action. ^cr-417-1-c

<details class="rule-ref"><summary title="Core rule 417.1.c · PDF page 79" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 417.1.c · PDF page 79</div></details>

This is a [[Limited Action]]. ^cr-417-2

<details class="rule-ref"><summary title="Core rule 417.2 · PDF page 79" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 417.2 · PDF page 79</div></details>

The player must Recycle [[Card|cards]] from the specified [[Zone|zones]] when instructed to do so by [[Game Effect|game effects]] or [[Costs|costs]]. ^cr-417-2-a

<details class="rule-ref"><summary title="Core rule 417.2.a · PDF page 79" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 417.2.a · PDF page 79</div></details>

When Recycling is listed as a [[Costs|Cost]], the action must be able to be completed for the cost to be paid. ^cr-417-3

**Example:** Vi, Destructive has the [[Ability|ability]] "Recycle 1 from your [[Trash|trash]]: Give me +1 &#91;M&#93; this [[Turn|turn]]." Each time a player activates the ability, they must recycle 1 [[Card|card]] from their trash to pay its [[Costs|cost]]. If they have no cards in their trash, they can't activate the ability, because they can't pay its cost.

<details class="rule-ref"><summary title="Core rule 417.3 · PDF page 80" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 417.3 · PDF page 80</div></details>

When Recycling is part of an effect, a player must Recycle as many [[Card|cards]] as possible from the specified [[Zone|zone]] or zones. ^cr-417-4

<details class="rule-ref"><summary title="Core rule 417.4 · PDF page 80" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 417.4 · PDF page 80</div></details>

If 2 or more [[Card|cards]] are Recycled to the [[Main Deck]] simultaneously, they are placed on the bottom of that deck in a random order. ^cr-417-5

**Example:** Garbage Grabber has the [[Ability|ability]] "Recycle 3 from your [[Trash|trash]], &#91;1&#93;, &#91;E&#93;: [[Draw]] " To pay the [[Costs|cost]] of activating this ability, its controller chooses 3 [[Card|cards]] from their trash and places them on the bottom of their [[Main Deck]] in a random order.

<details class="rule-ref"><summary title="Core rule 417.5 · PDF page 80" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 417.5 · PDF page 80</div></details>

If 2 or more [[Card|cards]] are Recycled to the [[Rune Deck]] simultaneously, they are placed on the bottom of that deck in the order of their owner's choosing. ^cr-417-5-a

<details class="rule-ref"><summary title="Core rule 417.5.a · PDF page 80" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 417.5.a · PDF page 80</div></details>

This action, when instructed, is sometimes formatted as "Recycle X from &#91;[[Zone]]&#93;." That means to take X [[Card|cards]] of the instructed player's choice from the relevant zone and recycle them. Such an instruction does not target the recycled cards. ^cr-417-6

**Example:** Dr. Mundo, Expert has the [[Ability|ability]] "At the start of your [[Beginning Phase]], recycle 3 from your [[Trash|trash]]." As that ability resolves, its controller recycles 3 [[Card|cards]] from their trash. If there are fewer than 3 cards in that player's trash, they recycle as many as they can.

<details class="rule-ref"><summary title="Core rule 417.6 · PDF page 80" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 417.6 · PDF page 80</div></details>
