# Flow

[[Start Here|Home]] · [[Concept Index|Find a concept]] · [[Core Rules Index|Core rules]]

<span title="Core rule 829"></span> ^cr-829

<details class="rule-ref"><summary title="Core rule 829 · PDF page 140" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 829 · PDF page 140</div></details>

Flow is a [[Passive Ability]] [[Keywords|keyword]]. ^cr-829-1

<details class="rule-ref"><summary title="Core rule 829.1 · PDF page 140" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 829.1 · PDF page 140</div></details>

Flow is present on [[Spell|Spells]]. ^cr-829-1-a

<details class="rule-ref"><summary title="Core rule 829.1.a · PDF page 140" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 829.1.a · PDF page 140</div></details>

It is functionally short for “You may [[Play|play]] this from your [[Trash|trash]] for its flow [[Costs|cost]]. Then [[Banish|banish]] it.” ^cr-829-1-b

<details class="rule-ref"><summary title="Core rule 829.1.b · PDF page 140" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 829.1.b · PDF page 140</div></details>

Banishing the [[Spell|spell]] in this way is a [[Delayed Replacement|delayed replacement]] effect. If the spell would leave the [[Chain|chain]] after becoming a [[Finalized Chain Item|finalized chain item]], and leaving the chain wasn’t instructed by its own execution, [[Banish|banish]] it instead. ^cr-829-1-b-1

See [[Replacement Effect#^cr-367|Replacement Effects]] for more information.

See [[Delayed Ability#^cr-390|Delayed Abilities]] for more information.

<details class="rule-ref"><summary title="Core rule 829.1.b.1 · PDF page 140" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 829.1.b.1 · PDF page 140</div></details>

Playing a [[Spell|spell]] for its Flow [[Costs|cost]] does not change the timing at which it can be played, nor any permissions for the spell aside from the [[Zone|zone]] from which it can be played. ^cr-829-1-b-2

<details class="rule-ref"><summary title="Core rule 829.1.b.2 · PDF page 140" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 829.1.b.2 · PDF page 140</div></details>

Flow is formatted as “Flow &#91;[[Costs|Cost]]&#93;” ^cr-829-1-c

<details class="rule-ref"><summary title="Core rule 829.1.c · PDF page 140" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 829.1.c · PDF page 140</div></details>

The [[Costs|cost]] is an alternate cost that replaces the [[Base Cost|base cost]] of the [[Spell|spell]] to be paid during finalization. ^cr-829-1-c-1

<details class="rule-ref"><summary title="Core rule 829.1.c.1 · PDF page 140" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 829.1.c.1 · PDF page 140</div></details>

Flow [[Costs|costs]] may include both resource costs and non-resource costs. ^cr-829-1-c-2

<details class="rule-ref"><summary title="Core rule 829.1.c.2 · PDF page 140" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 829.1.c.2 · PDF page 140</div></details>

If a [[Spell|spell]] has multiple instances of the Flow [[Keywords|keyword]] with different [[Costs|costs]], its controller may choose which cost to apply as they [[Play|play]] it. ^cr-829-1-c-3

<details class="rule-ref"><summary title="Core rule 829.1.c.3 · PDF page 140" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 829.1.c.3 · PDF page 140</div></details>

Flow, and whether or not a [[Spell|spell]] has Flow, is a characteristic of the Spell and may be checked or referenced by other [[Game Effect|Game Effects]]. ^cr-829-2
