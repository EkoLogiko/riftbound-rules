<span title="Core rule 327"></span> ^cr-327

<details class="rule-ref"><summary title="Core rule 327 · PDF page 42" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 327 · PDF page 42</div></details>

The Chain is a Non-Board [[Zone]] that temporarily exists whenever a [[Card|card]] or [[Ability|ability]] is played. ^cr-328

<details class="rule-ref"><summary title="Core rule 328 · PDF page 42" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 328 · PDF page 42</div></details>

[[Card|Cards]], [[Ability|abilities]], and [[Token|tokens]] are placed here as part of the process of being played. ^cr-328-1

See [[Playing Cards#^cr-349|The Process of Play]] for more information.

See [[Ability#^cr-360|Abilities]] for more information on [[Ability|Abilities]].

<details class="rule-ref"><summary title="Core rule 328.1 · PDF page 42" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 328.1 · PDF page 42</div></details>

[[Card|Cards]], [[Token|tokens]], and [[Ability|abilities]] added to the chain are added as [[Pending Chain Item|Pending Chain Items]] that become [[Finalized Chain Item|Finalized Chain Items]]. ^cr-329

<details class="rule-ref"><summary title="Core rule 329 · PDF page 42" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 329 · PDF page 42</div></details>

[[Pending Chain Item|Pending Items]] are on the Chain. ^cr-329-1

<details class="rule-ref"><summary title="Core rule 329.1 · PDF page 42" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 329.1 · PDF page 42</div></details>

Chain Items are Pending until the “Check Legality” step of playing a [[Card|card]]. ^cr-329-2

See [[Playing Cards#^cr-349|Playing Cards]] for more information.

<details class="rule-ref"><summary title="Core rule 329.2 · PDF page 42" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 329.2 · PDF page 42</div></details>

When a [[Pending Chain Item]] is no longer Pending it is finalized and becomes a [[Finalized Chain Item]]. ^cr-329-3

<details class="rule-ref"><summary title="Core rule 329.3 · PDF page 43" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 329.3 · PDF page 43</div></details>

The Chain exists as long as a Chain Item is on it. ^cr-330

<details class="rule-ref"><summary title="Core rule 330 · PDF page 43" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 330 · PDF page 43</div></details>

Only one Chain can exist at a time. ^cr-330-1

<details class="rule-ref"><summary title="Core rule 330.1 · PDF page 43" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 330.1 · PDF page 43</div></details>

If a [[Card|card]], [[Token|token]], or [[Ability|ability]] would begin to be played while a Chain already exists, it is placed on the existing Chain. ^cr-330-2

<details class="rule-ref"><summary title="Core rule 330.2 · PDF page 43" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 330.2 · PDF page 43</div></details>

The State of [[Turn|the Turn]] is partially determined by whether or not the Chain currently exists. ^cr-331

<details class="rule-ref"><summary title="Core rule 331 · PDF page 43" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 331 · PDF page 43</div></details>

[[Turn|The turn]] is said to be in a [[Closed State]] if a Chain exists. ^cr-331-1

<details class="rule-ref"><summary title="Core rule 331.1 · PDF page 43" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 331.1 · PDF page 43</div></details>

[[Card|Cards]] of all Categories, by default, cannot be played during a [[Closed State]]. ^cr-331-1-a

<details class="rule-ref"><summary title="Core rule 331.1.a · PDF page 43" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 331.1.a · PDF page 43</div></details>

[[Card]] [[Ability|abilities]], by default, cannot be played during a [[Closed State]]. ^cr-331-1-b

<details class="rule-ref"><summary title="Core rule 331.1.b · PDF page 43" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 331.1.b · PDF page 43</div></details>

[[Turn|The turn]] is said to be in an [[Open State]] if no Chain exists. ^cr-331-2

<details class="rule-ref"><summary title="Core rule 331.2 · PDF page 43" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 331.2 · PDF page 43</div></details>
