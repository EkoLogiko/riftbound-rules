# Move

[[Start Here|Home]] · [[Concept Index|Find a concept]] · [[Core Rules Index|Core rules]]

<span title="Core rule 421"></span> ^cr-421

<details class="rule-ref"><summary title="Core rule 421 · PDF page 83" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 421 · PDF page 83</div></details>

[[Movement|Moving]] is the act of a [[Game Object]] moving between two [[Location|Locations]] on [[Board|The Board]]. ^cr-421-1

See [[Movement#^cr-447|Movement]] for more information on [[Movement|movement]].

<details class="rule-ref"><summary title="Core rule 421.1 · PDF page 83" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 421.1 · PDF page 83</div></details>

[[Movement|Moving]] is a [[Limited Action]]. ^cr-421-2

<details class="rule-ref"><summary title="Core rule 421.2 · PDF page 83" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 421.2 · PDF page 83</div></details>

Players may only move [[Game Object|Game Objects]] when instructed to do so by [[Game Effect|Game Effects]] or [[Costs|costs]]. ^cr-421-2-a

<details class="rule-ref"><summary title="Core rule 421.2.a · PDF page 83" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 421.2.a · PDF page 83</div></details>

The [[Standard Move]] inherent to [[Unit|Units]] may also cause [[Movement]]. ^cr-421-2-b

See [[Unit#^cr-144|Unit]] for more information on the [[Standard Move]].

<details class="rule-ref"><summary title="Core rule 421.2.b · PDF page 83" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 421.2.b · PDF page 83</div></details>

The [[Standard Move]] inherent to [[Unit|Units]] is a [[Discretionary Action]]. ^cr-421-3

<details class="rule-ref"><summary title="Core rule 421.3 · PDF page 83" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 421.3 · PDF page 83</div></details>

The [[Costs|Cost]] is [[Exhaust|Exhausting]] one or more [[Unit|Units]]. ^cr-421-3-a

<details class="rule-ref"><summary title="Core rule 421.3.a · PDF page 83" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 421.3.a · PDF page 83</div></details>

The Effect is [[Movement|Moving]] those [[Unit|Units]]. ^cr-421-3-b
