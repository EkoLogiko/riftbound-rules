# Rules Text

[[Start Here|Home]] · [[Concept Index|Find a concept]] · [[Core Rules Index|Core rules]]

<span title="Core rule 135"></span> ^cr-135

<details class="rule-ref"><summary title="Core rule 135 · PDF page 13" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 135 · PDF page 13</div></details>

All [[Card|cards]] have a section that describes how they affect the game. This section is known as the Rules Text of the card. ^cr-135-1

[[Ability|Abilities]] ^cr-135-2-a

<details class="rule-ref"><summary title="Core rule 135.2.a · PDF page 13" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 135.2.a · PDF page 13</div></details>

[[Ability|Abilities]] are discrete pieces of text that describe what a [[Card|card]] may or must do. ^cr-135-2-a-1

See [[Ability#^cr-360|Abilities]] for more information.

<details class="rule-ref"><summary title="Core rule 135.2.a.1 · PDF page 13" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 135.2.a.1 · PDF page 13</div></details>

They may appear on any [[Card|card]]. ^cr-135-2-a-2

<details class="rule-ref"><summary title="Core rule 135.2.a.2 · PDF page 13" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 135.2.a.2 · PDF page 13</div></details>

[[Instructions]] ^cr-135-2-b

<details class="rule-ref"><summary title="Core rule 135.2.b · PDF page 13" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 135.2.b · PDF page 13</div></details>

[[Instructions]] are a type of text that appears on [[Spell|spells]] and within [[Ability|abilities]]. ^cr-135-2-b-1

<details class="rule-ref"><summary title="Core rule 135.2.b.1 · PDF page 13" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 135.2.b.1 · PDF page 13</div></details>

They describe actions to be performed by one or more players. ^cr-135-2-b-2

<details class="rule-ref"><summary title="Core rule 135.2.b.2 · PDF page 13" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 135.2.b.2 · PDF page 13</div></details>

[[Instructions]] will self-describe when they are to be executed. If there is no timing described, they will execute during resolution. ^cr-135-2-b-3

**Example:** An instruction says “as you [[Play|play]] me, [[Kill|kill]] a [[Unit|unit]] as an [[Additional Cost|additional cost]].” That instruction will execute as the [[Card|card]] is being played. If the card is given [[Repeat]] and the Repeat [[Costs|cost]] is paid, this instruction will not execute because the Repeat execution does not happen until resolution of the [[Spell|spell]], after this instruction has executed.

<details class="rule-ref"><summary title="Core rule 135.2.b.3 · PDF page 13" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 135.2.b.3 · PDF page 13</div></details>

[[Instructions]] can usually be recognized by the way they are written. An instruction is written in the imperative mood, using the [[Base|base]] form of a verb and omitting the subject unless necessary. ^cr-135-2-b-4

<details class="rule-ref"><summary title="Core rule 135.2.b.4 · PDF page 13" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 135.2.b.4 · PDF page 13</div></details>

A single instruction is made up of a [[Game Action|game action]] and its complement. ^cr-135-2-b-5

<details class="rule-ref"><summary title="Core rule 135.2.b.5 · PDF page 13" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 135.2.b.5 · PDF page 13</div></details>

The complement of a [[Game Action|game action]] is made up of the players or [[Game Object|Game Objects]] that perform that game action, that that game action is performed on, the condition under which it is performed, and the duration for its effect to last. Some game actions omit a complement entirely. ^cr-135-2-b-5-a

**Example:** Void Seeker is made up of two [[Instructions|instructions]]. The first is “[[Deal|deal]] 4 to a [[Unit|unit]] at a [[Battlefield|battlefield]].” Here “deal 4” is the [[Game Action|game action]], while “a unit at a battlefield,” is its complement. The second instruction, “[[Draw|draw]] 1,” has no complement.

**Example:** Teemo, Strategist’s [[Defend Trigger|defend trigger]] reads “When I defend, choose an [[Enemy|enemy]] [[Unit|unit]] here and [[Reveal|reveal]] the top 5 [[Card|cards]] of your [[Main Deck]]. [[Deal]] 1 to that unit for each card with [[Hidden]] revealed this way, then [[Recycle|recycle]] the revealed cards.” There are four [[Instructions|instructions]] here: “choose an enemy unit here,” “reveal the top 5 cards of your Main Deck,” “deal 1 to that unit for each card with Hidden revealed this way,” and “recycle the revealed cards.”

<details class="rule-ref"><summary title="Core rule 135.2.b.5.a · PDF page 13-14" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 135.2.b.5.a · PDF page 13-14</div></details>

If a conditional clause appears in [[Instructions|instructions]] prior to one or more clauses with multiple instructions, that condition applies to all instructions in subsequent clauses in the same sentence. ^cr-135-2-b-5-b

**Example:** A [[Spell|spell]] reads in part “If you’ve gained a point this [[Turn|turn]], [[Draw|draw]] 1, then [[Discard|discard]] 1.” In order for either of the [[Instructions|instructions]] that follow the “If you’ve gained a point this turn,” conditional clause to execute, the condition must be true.

**Example:** Rogue Assassin is a [[Legend|legend]] that reads in part “&#91;[[Action (Keyword)|Action]]&#93;&#91;>&#93; &#91;E&#93;: If it's your [[Turn|turn]], [[Move|move]] a [[Friendly|friendly]] [[Unit|unit]] in a [[Showdowns|showdown]] to [[Base|base]] and if I'm &#91;[[Empowered (Keyword)|Empowered]]&#93;, [[Ready|ready]] it.” The first conditional clause in the [[Activated Ability|activated ability]] applies to all subsequent [[Instructions|instructions]] in the same sentence. The second conditional clause, “if I’m &#91;[[Empowered (Keyword)|Empowered]]&#93;,” only applies to the instruction that immediately follows it.

<details class="rule-ref"><summary title="Core rule 135.2.b.5.b · PDF page 14" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 135.2.b.5.b · PDF page 14</div></details>

[[Instructions]] do not include trigger conditions or the events or actions that a [[Replacement Effect|replacement effect]] defines as being eligible to be replaced. ^cr-135-2-b-6

**Example:** An [[Ability|ability]] reads “When you [[Play|play]] me, [[Draw|draw]] 1.” The trigger condition for this ability is not an instruction. “Draw 1,” is the only instruction included in the ability.

**Example:** An [[Ability|ability]] reads “If a [[Unit|unit]] would die, [[Banish|banish]] it instead.” The text “If a unit would die,” is not an instruction of the ability.

**Example:** An [[Ability|ability]] reads “As I’m [[Reveal|revealed]] from your [[Main Deck]], Add &#91;2&#93;.” The text “As I’m revealed from your Main Deck,” is not an instruction of the ability.

<details class="rule-ref"><summary title="Core rule 135.2.b.6 · PDF page 14" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 135.2.b.6 · PDF page 14</div></details>

[[Instructions]] of a [[Spell|spell]] or [[Ability|ability]] may reference actions taken during Finalization. They will do so by checking whether “you” performed those [[Game Action|game actions]]. These instructions check whether the game action was performed, not by whom. If another player gains [[Control|control]] of the spell or ability after the game action was performed during finalization, it will still be considered true for the purposes of these instructions. ^cr-135-2-b-7

**Example:** Rampage is a [[Spell|spell]] that reads “As you [[Play|play]] this, you may pay &#91;C&#93; as an [[Additional Cost|additional cost]].” and “Choose a [[Friendly|friendly]] [[Unit|unit]] and an [[Enemy|enemy]] unit. If you paid the additional cost, give the friendly unit +2 &#91;[[Might]]&#93; this [[Turn|turn]]. They [[Deal|deal]] [[Damage|damage]] equal to their Mights to each other.” If another player gains [[Control|control]] of Rampage, although they are not the one who paid the [[Costs|cost]], the “if you paid the additional cost,” condition will still be fulfilled.

**Example:** Back Off is a [[Spell|spell]] that reads in part “If you played this from your [[Hand|hand]], [[Draw|draw]] 1.” On resolution, Back Off checks if it was played from hand. If another player gained [[Control|control]] of Back Off, as long as the [[Card|card]] was played from hand, the condition will be true and the controller of the spell will draw 1.

<details class="rule-ref"><summary title="Core rule 135.2.b.7 · PDF page 14" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 135.2.b.7 · PDF page 14</div></details>

See [[Keywords#^cr-800|Keywords]] for more information.

<details class="rule-ref"><summary title="Core rule 135.2.c.1 · PDF page 14" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 135.2.c.1 · PDF page 14</div></details>

[[Reminder Text]] ^cr-135-2-d

<details class="rule-ref"><summary title="Core rule 135.2.d · PDF page 15" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 135.2.d · PDF page 15</div></details>

<details class="rule-ref"><summary title="Core rule 135.2.d.1 · PDF page 15" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 135.2.d.1 · PDF page 15</div></details>

<details class="rule-ref"><summary title="Core rule 135.2.d.3 · PDF page 15" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 135.2.d.3 · PDF page 15</div></details>

[[Symbols]] ^cr-135-2-e

<details class="rule-ref"><summary title="Core rule 135.2.e · PDF page 15" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 135.2.e · PDF page 15</div></details>

Rules text sometimes contains [[Symbols|symbols]] that express [[Game Concepts|game concepts]]. Each symbol also has a shorthand used to represent it in written text. ^cr-135-2-e-1

<details class="rule-ref"><summary title="Core rule 135.2.e.1 · PDF page 15" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 135.2.e.1 · PDF page 15</div></details>

The [[Costs|cost]] of [[Exhaust|Exhausting]] a [[Permanent]] is represented by the “exhaust symbol,” which resembles a [[Card|card]] turning sideways. Its shorthand is &#91;E&#93;. (Some previous rules information has given its shorthand as &#91;T&#93;.) ^cr-135-2-e-2

<details class="rule-ref"><summary title="Core rule 135.2.e.2 · PDF page 15" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 135.2.e.2 · PDF page 15</div></details>

[[Might]] is represented by the “Might symbol,” which resembles a sword and [[Shield|shield]]. Its shorthand is &#91;M&#93;. (Some previous rules information has given its shorthand as &#91;S&#93;.) ^cr-135-2-e-3

<details class="rule-ref"><summary title="Core rule 135.2.e.3 · PDF page 15" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 135.2.e.3 · PDF page 15</div></details>

[[Power]] of a specific [[Domain]] is represented by its domain symbol and the corresponding shorthand. ^cr-135-2-e-4

See [[Domain#^cr-134|Domain]] for more information.

<details class="rule-ref"><summary title="Core rule 135.2.e.4 · PDF page 15" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 135.2.e.4 · PDF page 15</div></details>

[[Power]] of any [[Domain]] is represented by a swirling rainbow symbol. Its shorthand is &#91;A&#93;. ^cr-135-2-e-5

<details class="rule-ref"><summary title="Core rule 135.2.e.5 · PDF page 15" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 135.2.e.5 · PDF page 15</div></details>

When required as a [[Costs|cost]], &#91;A&#93; can be paid by [[Power]] of any [[Domain]]. ^cr-135-2-e-5-a

<details class="rule-ref"><summary title="Core rule 135.2.e.5.a · PDF page 15" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 135.2.e.5.a · PDF page 15</div></details>

When Added to a player’s [[Rune Pool]], &#91;A&#93; can be spent to pay a [[Power Cost|Power cost]] of any [[Domain]]. ^cr-135-2-e-5-b

<details class="rule-ref"><summary title="Core rule 135.2.e.5.b · PDF page 15" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 135.2.e.5.b · PDF page 15</div></details>

[[Power]] of a [[Domain|domain]] corresponding to a [[Card|card]]’s own Domain is not represented by a symbol, but appears in these rules similarly to other [[Symbols|symbols]]. Its shorthand is &#91;C&#93;. ^cr-135-2-e-6

<details class="rule-ref"><summary title="Core rule 135.2.e.6 · PDF page 15" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 135.2.e.6 · PDF page 15</div></details>

When a &#91;C&#93; shorthand is printed on a [[Card|card]] as [[Reminder Text|reminder text]], it assumes that card’s usual [[Domain]], but it still means “one [[Power]] of this card’s Domain.” ^cr-135-2-e-6-a

<details class="rule-ref"><summary title="Core rule 135.2.e.6.a · PDF page 15" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 135.2.e.6.a · PDF page 15</div></details>

A &#91;C&#93; shorthand on a [[Card|card]] with no [[Domain]] is processed as &#91;A&#93; instead. ^cr-135-2-e-6-b

<details class="rule-ref"><summary title="Core rule 135.2.e.6.b · PDF page 15" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 135.2.e.6.b · PDF page 15</div></details>

A &#91;C&#93; shorthand on a [[Card|card]] with multiple Domains is processed as any [[Power|power]] of that card’s Domains. ^cr-135-2-e-6-c

**Example:** Defiant Dance is a Calm and Chaos [[Spell|spell]]. Its [[Costs|cost]] is &#91;1&#93;&#91;C&#93;. The [[Power|power]] component of that cost can be paid with either &#91;G&#93; or &#91;P&#93;.

**Example:** Tibbers is a Fury and Chaos [[Unit]]. If Tibbers is granted the [[Accelerate]] [[Keywords|keyword]], the [[Power|power]] component of the optional [[Additional Cost|additional cost]] can be paid with either &#91;R&#93; or &#91;P&#93;.

<details class="rule-ref"><summary title="Core rule 135.2.e.6.c · PDF page 15" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 135.2.e.6.c · PDF page 15</div></details>

A [[Keywords|keyword]] associated with an [[Ability|ability]] is indicated by the &#91;>&#93; symbol. ^cr-135-2-e-7

<details class="rule-ref"><summary title="Core rule 135.2.e.7 · PDF page 15" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 135.2.e.7 · PDF page 15</div></details>

This could be a [[Dependent Keyword|dependent keyword]] like &#91;[[Legion]]&#93;&#91;>&#93; or &#91;[[Level]]&#93;&#91;>&#93;, a [[Triggered Ability|triggered ability]] with a keyworded trigger condition like &#91;[[Deathknell]]&#93; or it could be a permissive [[Keywords|keyword]] associated with an [[Ability|ability]] like &#91;[[Action (Keyword)|Action]]&#93;&#91;>&#93; or &#91;[[Reaction (Keyword)|Reaction]]&#93;&#91;>&#93;. ^cr-135-2-e-7-a

<details class="rule-ref"><summary title="Core rule 135.2.e.7.a · PDF page 16" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 135.2.e.7.a · PDF page 16</div></details>

Whatever instruction or [[Ability|ability]] comes after the &#91;>&#93; is modified by the [[Keywords|keyword]] that comes before the &#91;>&#93;. It will either be [[Inactive|inactive]], in the case of a [[Dependent Keyword|dependent keyword]]; the trigger effect, in the case of a keyword [[Triggered Ability|triggered ability]]; or it will receive the permission granted by the keyword in the case of a permissive keyword. ^cr-135-2-e-7-b

<details class="rule-ref"><summary title="Core rule 135.2.e.7.b · PDF page 16" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 135.2.e.7.b · PDF page 16</div></details>

Rules text can be blank. ^cr-135-3

<details class="rule-ref"><summary title="Core rule 135.3 · PDF page 16" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 135.3 · PDF page 16</div></details>

A [[Card|card]]’s printed Rules Text is [[Inactive]] while that card is [[Attached]] to another card. ^cr-135-4

See [[Attachment#^cr-716|Attachment]] for more information.

See [[Inactive#^cr-720|Inactive]] for more information.

<details class="rule-ref"><summary title="Core rule 135.4 · PDF page 16" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 135.4 · PDF page 16</div></details>

The presence of text, rules, [[Keywords]], and other effects can still be referenced and detected by other [[Game Effect|game effects]], even while Rules Text is [[Inactive]]. ^cr-135-4-a

<details class="rule-ref"><summary title="Core rule 135.4.a · PDF page 16" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 135.4.a · PDF page 16</div></details>

Any granted or appended Rules Text on a [[Card|card]] is still Active even if that card is [[Attached]] to another card. ^cr-135-4-b
