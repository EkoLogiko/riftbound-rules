# Copy

[[Start Here|Home]] · [[Concept Index|Find a concept]] · [[Core Rules Index|Core rules]]

<span title="Core rule 446"></span> ^cr-446

<details class="rule-ref"><summary title="Core rule 446 · PDF page 98" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 446 · PDF page 98</div></details>

Copying a [[Game Object]] is the act of adding or replacing some or all of the copyable traits of another Game Object with those of the Copied Game Object. ^cr-446-1

<details class="rule-ref"><summary title="Core rule 446.1 · PDF page 98" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 446.1 · PDF page 98</div></details>

[[Copy Effects]] are rendered in the Copy Effects layer. ^cr-446-2

See [[Layers#^cr-475|Layers]] for more information.

<details class="rule-ref"><summary title="Core rule 446.2 · PDF page 98" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 446.2 · PDF page 98</div></details>

Some [[Game Object|Game Objects]] may be created as a Copy of another Game Object. This is not a Copy Effect. The Copy in such a case is rendered with the same copyable traits as those of the Game Object it is a Copy of. It has no printed traits of its own that are subsequently replaced. ^cr-446-3

**Example:** Zilean, Time Mage is a [[Unit|unit]] that reads “Once each [[Turn|turn]], if you would [[Play|play]] a [[Token|token]] unit while I'm at a [[Battlefield|battlefield]], you may play that token and an additional copy of it instead.” The additional copy played by Zilean’s [[Replacement Effect|replacement effect]] has no printed traits of its own. Its printed traits are those of the token it is a copy of.

<details class="rule-ref"><summary title="Core rule 446.3 · PDF page 98" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 446.3 · PDF page 98</div></details>

Copy is a [[Limited Action]]. ^cr-446-4

<details class="rule-ref"><summary title="Core rule 446.4 · PDF page 98" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 446.4 · PDF page 98</div></details>

Players may only Copy [[Game Object|Game Objects]] when directed to by [[Game Effect|Game Effects]]. ^cr-446-4-a

<details class="rule-ref"><summary title="Core rule 446.4.a · PDF page 98" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 446.4.a · PDF page 98</div></details>
