[[Battlefield]] Count: 2 ^cr-488-4

<details class="rule-ref"><summary title="Core rule 488.4 · PDF page 111" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 488.4 · PDF page 111</div></details>

Each player provides three (3) [[Battlefield|Battlefields]], included in their deck during deck building. Only 1 will be used, chosen during [[Setup|setup]]. ^cr-488-4-a

<details class="rule-ref"><summary title="Core rule 488.4.a · PDF page 111" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 488.4.a · PDF page 111</div></details>

[[Setup]]: Each player selects one (1) of their three (3) [[Battlefield|Battlefields]]. The other two are set aside and will not be used for this round of [[Play|play]]. The selected Battlefields are placed simultaneously in the [[Battlefield Zone]]. After this game, if a player won, the Battlefields that were used are to be removed and not selected again for this Match. One of the remaining Battlefields that were set aside must be chosen instead. ^cr-488-5

<details class="rule-ref"><summary title="Core rule 488.5 · PDF page 111" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 488.5 · PDF page 111</div></details>

If no player won a game, the [[Battlefield|battlefields]] presented for that game may be reused in a subsequent game. ^cr-488-5-a

<details class="rule-ref"><summary title="Core rule 488.5.a · PDF page 111" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 488.5.a · PDF page 111</div></details>

Format: Best of 3. The first player to reach the [[Victory Score]] in [[Points]] wins the game. The winner of that game earns One Game Win. Players then reset the game state, remove the [[Battlefield|Battlefields]] in [[Play|play]] from the game, choose new Battlefields from those set aside, and play again. The first player to earn Two Game Wins wins the match. ^cr-488-6

<details class="rule-ref"><summary title="Core rule 488.6 · PDF page 111-112" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 488.6 · PDF page 111-112</div></details>

This format may be played as best of 5. In such a case, during games 4 and 5 of the match players may present a [[Battlefield|battlefield]] that has been removed from the game. ^cr-488-6-a

<details class="rule-ref"><summary title="Core rule 488.6.a · PDF page 112" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 488.6.a · PDF page 112</div></details>

Players may only re-use a [[Battlefield|battlefield]] in this way if they have already presented each of their battlefields at least once during the match. ^cr-488-6-a-1

<details class="rule-ref"><summary title="Core rule 488.6.a.1 · PDF page 112" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 488.6.a.1 · PDF page 112</div></details>

Players may not present a [[Battlefield|battlefield]] more than twice in a match when re-using battlefields in this way. ^cr-488-6-a-2

<details class="rule-ref"><summary title="Core rule 488.6.a.2 · PDF page 112" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 488.6.a.2 · PDF page 112</div></details>

First [[Turn]] Process: The player going second channels an extra [[Rune]] from their [[Rune Deck]] during their first [[Channel Phase]] of the game. ^cr-488-7
