# Responsibility

[[Start Here|Home]] · [[Concept Index|Find a concept]] · [[Core Rules Index|Core rules]]

<span title="Core rule 412"></span> ^cr-412

<details class="rule-ref"><summary title="Core rule 412 · PDF page 77" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 412 · PDF page 77</div></details>

[[Game Action|Game Actions]] may be the responsibility of up to one player. The player that performs the Game Action is responsible for it. ^cr-412-1

**Example:** Cull the Weak is a [[Spell|spell]] that reads “Each player kills one of their [[Unit|units]].” When the spell resolves, each player picks a unit they [[Control|control]] and kills that unit. They are responsible for the death of their own unit.

<details class="rule-ref"><summary title="Core rule 412.1 · PDF page 77" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 412.1 · PDF page 77</div></details>

In the case where a [[Game Action]] is performed by procedures of the game and not by any player, that Game Action is not the responsibility of any player. ^cr-412-2

<details class="rule-ref"><summary title="Core rule 412.2 · PDF page 78" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 412.2 · PDF page 78</div></details>

Certain rules assign responsibility to players for [[Game Action|Game Actions]] that they are not normally responsible for. ^cr-412-3

<details class="rule-ref"><summary title="Core rule 412.3 · PDF page 78" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 412.3 · PDF page 78</div></details>

If an [[Ability|ability]] triggers when “you” do something, it triggers when a [[Game Action]] that you are responsible for occurs. ^cr-412-4

**Example:** A [[Gear|gear]] reads “When you [[Move|move]] an [[Enemy|enemy]] [[Unit|unit]], you may [[Exhaust|exhaust]] this to &#91;[[Stun]]&#93; it.” It will trigger whenever a move [[Game Action|game action]] that you are responsible for causes an enemy unit to move. If an opponent plays a [[Spell|spell]] that reads “choose a [[Battlefield]]. Each player may move a unit they don’t [[Control|control]] to that battlefield,” and a player that controls the gear chooses to move an enemy unit, their gear will trigger.

<details class="rule-ref"><summary title="Core rule 412.4 · PDF page 78" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 412.4 · PDF page 78</div></details>

Note that certain [[Game Action|Game Actions]], specifically [[Kill]], can be attributed to [[Spell|spells]] and [[Ability|abilities]]. This attribution is not the same as the responsibility a given player has for the kill game action. ^cr-412-5

<details class="rule-ref"><summary title="Core rule 412.5 · PDF page 78" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 412.5 · PDF page 78</div></details>

[[Spell|Spells]] and [[Ability|abilities]] have attribution for [[Game Action|game actions]], while players have responsibility. ^cr-412-5-a

<details class="rule-ref"><summary title="Core rule 412.5.a · PDF page 78" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 412.5.a · PDF page 78</div></details>

Some [[Game Effect|Game Effects]] may check if a player has performed a [[Game Action]] “with” a [[Game Object]]. In order to do so, the Game Action must be attributed to the [[Spell|spell]] or [[Ability|ability]] of that Game Object if necessary, the player must [[Control|control]] that spell or the ability of that Game Object, and the player must be responsible for the Game Action. ^cr-412-6

<details class="rule-ref"><summary title="Core rule 412.6 · PDF page 78" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 412.6 · PDF page 78</div></details>

[[Ability|Abilities]] granted via the [[Effect Text|effect text]] of a [[Game Object]] to another Game Object count for both Game Objects for this purpose. ^cr-412-6-a

<details class="rule-ref"><summary title="Core rule 412.6.a · PDF page 78" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 412.6.a · PDF page 78</div></details>
