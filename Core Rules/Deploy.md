# Deploy

[[Start Here|Home]] · [[Concept Index|Find a concept]] · [[Core Rules Index|Core rules]]

<span title="Core rule 830"></span> ^cr-830

<details class="rule-ref"><summary title="Core rule 830 · PDF page 140" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 830 · PDF page 140</div></details>

Deploy is a [[Passive Ability]] and a [[Triggered Ability]] [[Keywords|keyword]]. ^cr-830-1

<details class="rule-ref"><summary title="Core rule 830.1 · PDF page 140" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 830.1 · PDF page 140</div></details>

Deploy is present on [[Gear]]. ^cr-830-1-a

<details class="rule-ref"><summary title="Core rule 830.1.a · PDF page 140" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 830.1.a · PDF page 140</div></details>

Deploy is short for “This may be played or created to any [[Battlefield|battlefield]],” “[[Play]] or create this only to a battlefield,” “If this is not a [[Unit|unit]], it is not recalled in [[Cleanups|cleanups]],” and “When an opponent holds here, [[Kill|kill]] this.” ^cr-830-1-b

<details class="rule-ref"><summary title="Core rule 830.1.b · PDF page 140" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 830.1.b · PDF page 140</div></details>

Deploy grants permission for [[Gear]] to be played to any [[Battlefield]], including [[Enemy|enemy]] occupied and open battlefields. ^cr-830-1-b-1

<details class="rule-ref"><summary title="Core rule 830.1.b.1 · PDF page 140" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 830.1.b.1 · PDF page 140</div></details>

[[Gear]] with Deploy can be Moved by appropriate effects. ^cr-830-1-b-2

<details class="rule-ref"><summary title="Core rule 830.1.b.2 · PDF page 141" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 830.1.b.2 · PDF page 141</div></details>

Non-Unit [[Gear]] with Deploy are not recalled from [[Battlefield|Battlefields]] in step 5 of a [[Cleanups|Cleanup]]. ^cr-830-1-b-3

See [[Cleanups#^cr-318|Cleanups]] for more information.

<details class="rule-ref"><summary title="Core rule 830.1.b.3 · PDF page 141" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 830.1.b.3 · PDF page 141</div></details>

Multiple instances of Deploy are redundant. ^cr-830-2

<details class="rule-ref"><summary title="Core rule 830.2 · PDF page 141" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 830.2 · PDF page 141</div></details>

Deploy, and whether or not a [[Card|card]] has Deploy, is a characteristic of the card and may be checked or referenced by other [[Game Effect|Game Effects]]. ^cr-830-3

<details class="rule-ref"><summary title="Core rule 830.3 · PDF page 141" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 830.3 · PDF page 141</div></details>
