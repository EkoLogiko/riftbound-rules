# Playing or Activating an Ability

[[Start Here|Home]] · [[Concept Index|Find a concept]] · [[Core Rules Index|Core rules]]

<!-- flowchart-links:start -->
**Flowchart:** [[Playing or Activating Abilities Flowchart#Playing or activating abilities|Playing or activating abilities]]
<!-- flowchart-links:end -->

<span title="Core rule 399"></span> ^cr-399

<details class="rule-ref"><summary title="Core rule 399 · PDF page 75" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 399 · PDF page 75</div></details>

Playing or activating Abilities follows the same steps of [[Playing Cards|playing cards]]. ^cr-400

<details class="rule-ref"><summary title="Core rule 400 · PDF page 75" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 400 · PDF page 75</div></details>

[[Ability|Abilities]] when added to the [[Chain]] become [[Pending Chain Item|Pending Items]] until they complete the steps of Playing. ^cr-401

<details class="rule-ref"><summary title="Core rule 401 · PDF page 75" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 401 · PDF page 75</div></details>

When an [[Ability]] finishes the steps of playing it becomes a [[Finalized Chain Item]] just like a [[Spell]]. ^cr-401-1

<details class="rule-ref"><summary title="Core rule 401.1 · PDF page 75" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 401.1 · PDF page 75</div></details>

When an [[Ability]] with the &#91;Add&#93; action is finalized it resolves immediately, like a [[Unit]] or [[Gear]]. ^cr-401-2

<details class="rule-ref"><summary title="Core rule 401.2 · PDF page 75" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 401.2 · PDF page 75</div></details>

### 1. Activate or trigger the Ability

^cr-402

<details class="rule-ref"><summary title="Core rule 402 · PDF page 75" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 402 · PDF page 75</div></details>

Add a [[Pending Chain Item|Pending Item]] to the [[Chain|chain]] representing the [[Ability]] that is either being Activated or Triggered. Notably, although this Chain Item will not have a [[Card|card]] representing it, this will create a [[Closed State]]. ^cr-402-1

See [[Playing Cards#^cr-349|Playing Cards]] for more information.

<details class="rule-ref"><summary title="Core rule 402.1 · PDF page 75" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 402.1 · PDF page 75</div></details>

If there is currently a [[Game Effect|game effect]] being resolved, continue resolving the game effect instead of continuing the following steps. ^cr-402-2

<details class="rule-ref"><summary title="Core rule 402.2 · PDF page 75" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 402.2 · PDF page 75</div></details>

### 2. Make relevant choices

^cr-403

<details class="rule-ref"><summary title="Core rule 403 · PDF page 75" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 403 · PDF page 75</div></details>

If the first part of a [[Triggered Ability]]’s effect is “you may,” or “they may,” its controller decides whether or not to perform the Triggered Ability now. ^cr-403-1

<details class="rule-ref"><summary title="Core rule 403.1 · PDF page 75" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 403.1 · PDF page 75</div></details>

If they choose not to perform the [[Triggered Ability]] now, it is removed from the [[Chain|chain]]. ^cr-403-1-a

<details class="rule-ref"><summary title="Core rule 403.1.a · PDF page 75" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 403.1.a · PDF page 75</div></details>

Make all choices required for this [[Ability|ability]], such as targets, modes, or other relevant decisions. ^cr-403-2

See [[Playing Cards#^cr-349|Playing Cards]] for more information.

<details class="rule-ref"><summary title="Core rule 403.2 · PDF page 75" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 403.2 · PDF page 75</div></details>

If legal options are not available for an [[Activated Ability]], it is not legal to activate it. ^cr-403-3

<details class="rule-ref"><summary title="Core rule 403.3 · PDF page 76" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 403.3 · PDF page 76</div></details>

If there are not enough options to make legal choices for a [[Triggered Ability]] that has been put on the [[Chain|chain]], remove it from the Chain now. It ceases to be a [[Pending Chain Item|Pending Item]] but never becomes a [[Finalized Chain Item]]. ^cr-403-4

<details class="rule-ref"><summary title="Core rule 403.4 · PDF page 76" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 403.4 · PDF page 76</div></details>

This is not an [[Ability]] being countered. ^cr-403-4-a

<details class="rule-ref"><summary title="Core rule 403.4.a · PDF page 76" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 403.4.a · PDF page 76</div></details>

If there are legal options to choose, the [[Ability|ability]]’s controller must choose them. They may not decline this stage of playing a Trigger. ^cr-403-4-b

<details class="rule-ref"><summary title="Core rule 403.4.b · PDF page 76" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 403.4.b · PDF page 76</div></details>

### 3. Determine Total Cost

^cr-404

<details class="rule-ref"><summary title="Core rule 404 · PDF page 76" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 404 · PDF page 76</div></details>

Determine the [[Base Cost|base cost]] of the [[Ability]]. ^cr-404-1

<details class="rule-ref"><summary title="Core rule 404.1 · PDF page 76" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 404.1 · PDF page 76</div></details>

[[Activated Ability|Activated Abilities]] will have a [[Costs|cost]] listed before the “:” in their text. ^cr-404-1-a

<details class="rule-ref"><summary title="Core rule 404.1.a · PDF page 76" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 404.1.a · PDF page 76</div></details>

[[Triggered Ability|Triggered Abilities]] will typically not have a [[Base Cost|base cost]] associated with them when placed on the [[Chain|chain]] due to their conditions. ^cr-404-1-b

<details class="rule-ref"><summary title="Core rule 404.1.b · PDF page 76" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 404.1.b · PDF page 76</div></details>

If a [[Triggered Ability]] has a [[Costs|cost]] within [[Instructions|instructions]] (e.g. “&#91;do X&#93; to &#91;do Y&#93;”), the cost is taken as the [[Base Cost|base cost]]. ^cr-404-1-b-1

See [[Costs#^cr-204-3|Costs]] for more information on [[Costs within Instructions|costs within instructions]].

<details class="rule-ref"><summary title="Core rule 404.1.b.1 · PDF page 76" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 404.1.b.1 · PDF page 76</div></details>

Apply [[Costs|cost]] increases and decreases as a result of choices made in the prior step. ^cr-404-2

See [[Playing Cards#^cr-349|Playing Cards]] for more information.

<details class="rule-ref"><summary title="Core rule 404.2 · PDF page 76" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 404.2 · PDF page 76</div></details>

Apply any other [[Costs|cost]] increases or decreases as necessary. ^cr-404-3

See [[Playing Cards#^cr-349|Playing Cards]] for more information.

<details class="rule-ref"><summary title="Core rule 404.3 · PDF page 76" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 404.3 · PDF page 76</div></details>

### 4. Pay Costs

^cr-405

<details class="rule-ref"><summary title="Core rule 405 · PDF page 76" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 405 · PDF page 76</div></details>

Pay [[Costs|costs]] as determined in the prior step. ^cr-405-1

See [[Playing Cards#^cr-349|Playing Cards]] for more information.

<details class="rule-ref"><summary title="Core rule 405.1 · PDF page 76" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 405.1 · PDF page 76</div></details>

At this stage, players may decline to pay for [[Triggered Ability|Triggered Abilities]] that have incurred a [[Costs|cost]]. If they do, the [[Ability|ability]] will cease being a [[Pending Chain Item|Pending Item]] and be removed from the [[Chain]]. It never becomes a [[Finalized Chain Item]]. ^cr-405-2

<details class="rule-ref"><summary title="Core rule 405.2 · PDF page 76" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 405.2 · PDF page 76</div></details>

This is not an [[Ability]] being countered. ^cr-405-2-a

<details class="rule-ref"><summary title="Core rule 405.2.a · PDF page 76" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 405.2.a · PDF page 76</div></details>

### 5. Check Legality

^cr-406

<details class="rule-ref"><summary title="Core rule 406 · PDF page 76" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 406 · PDF page 76</div></details>

Ensure that the [[Ability]]’s targets are still legal. ^cr-406-1

<details class="rule-ref"><summary title="Core rule 406.1 · PDF page 76" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 406.1 · PDF page 76</div></details>

Ensure that the [[Ability]]’s effect would not create an illegal state. If it would, resolve in the same way you would resolve a [[Card]] that creates an illegal state. ^cr-406-2

See [[Playing Cards#^cr-349|Playing Cards]] for more information.

<details class="rule-ref"><summary title="Core rule 406.2 · PDF page 76" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 406.2 · PDF page 76</div></details>

### 6. Proceed with Play

^cr-407

<details class="rule-ref"><summary title="Core rule 407 · PDF page 76" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 407 · PDF page 76</div></details>

This [[Ability]] is no longer Pending. ^cr-407-1

<details class="rule-ref"><summary title="Core rule 407.1 · PDF page 77" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 407.1 · PDF page 77</div></details>

This [[Ability]] becomes a [[Finalized Chain Item]]. ^cr-407-2

<details class="rule-ref"><summary title="Core rule 407.2 · PDF page 77" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 407.2 · PDF page 77</div></details>

If there are other [[Pending Chain Item|Pending Chain Items]] on the [[Chain]], their controllers perform the remaining steps of playing now. ^cr-407-3

<details class="rule-ref"><summary title="Core rule 407.3 · PDF page 77" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 407.3 · PDF page 77</div></details>

Other players have an opportunity to [[Play|play]] Reactions before the resolution of [[Spell|spells]] and [[Ability|abilities]]. ^cr-407-4

See [[Chain#^cr-327|Chains]] for more information.

<details class="rule-ref"><summary title="Core rule 407.4 · PDF page 77" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 407.4 · PDF page 77</div></details>

Otherwise, execute the [[Ability]] just like a [[Spell]], then clear the [[Chain]] Item from the Chain. ^cr-407-5

<details class="rule-ref"><summary title="Core rule 407.5 · PDF page 77" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 407.5 · PDF page 77</div></details>
