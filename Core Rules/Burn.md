# Burn

[[Start Here|Home]] · [[Concept Index|Find a concept]] · [[Core Rules Index|Core rules]]

<span title="Core rule 441"></span> ^cr-441

<details class="rule-ref"><summary title="Core rule 441 · PDF page 96" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 441 · PDF page 96</div></details>

Burning is the act of [[Movement|moving]] [[Card|cards]] from the top of a player’s [[Main Deck]] to their [[Trash|trash]]. ^cr-441-1

<details class="rule-ref"><summary title="Core rule 441.1 · PDF page 96" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 441.1 · PDF page 96</div></details>

“When you burn” [[Ability|abilities]] or other [[Triggered Ability|Triggered Abilities]] that trigger on burning are executed after burning has occurred. ^cr-441-1-a

<details class="rule-ref"><summary title="Core rule 441.1.a · PDF page 96" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 441.1.a · PDF page 96</div></details>

This action is formatted as "Burn X." ^cr-441-2

<details class="rule-ref"><summary title="Core rule 441.2 · PDF page 96" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 441.2 · PDF page 96</div></details>

X is the number of [[Card|cards]] to be Burned. ^cr-441-2-a

<details class="rule-ref"><summary title="Core rule 441.2.a · PDF page 96" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 441.2.a · PDF page 96</div></details>

Burning is a [[Limited Action]]. ^cr-441-3

<details class="rule-ref"><summary title="Core rule 441.3 · PDF page 96" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 441.3 · PDF page 96</div></details>

A player must Burn [[Card|cards]] when instructed to do so by [[Game Effect|game effects]] or [[Costs|costs]]. ^cr-441-3-a

<details class="rule-ref"><summary title="Core rule 441.3.a · PDF page 96" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 441.3.a · PDF page 96</div></details>

When Burning is part of an effect, then a player must Burn as many [[Card|cards]] as possible. If instructed to burn more cards than they have in their [[Main Deck|main deck]], they burn that many cards, [[Burn Out|burn out]] and then burn the rest. ^cr-441-4

See [[Burn Out#^cr-432|Burn Out]] for more information.
