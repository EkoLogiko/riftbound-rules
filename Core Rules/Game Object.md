# Game Object

[[Start Here|Home]] · [[Concept Index|Find a concept]] · [[Core Rules Index|Core rules]]

<span title="Core rule 119"></span> ^cr-119

<details class="rule-ref"><summary title="Core rule 119 · PDF page 8" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 119 · PDF page 8</div></details>

A Game Object is any game piece that can produce one or more [[Game Effect|Game Effects]] or grant prerequisites for players to take [[Game Action|Game Actions]]. ^cr-120

<details class="rule-ref"><summary title="Core rule 120 · PDF page 8" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 120 · PDF page 8</div></details>

A Game Object does not include nor preclude any inherent properties beyond the [[Ability|ability]] to produce, or act as the prerequisite for, [[Game Effect|Game Effects]] and [[Game Action|Game Actions]]. ^cr-121

<details class="rule-ref"><summary title="Core rule 121 · PDF page 8" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 121 · PDF page 8</div></details>

A Game Object can be a literal object or a logical object. ^cr-122

<details class="rule-ref"><summary title="Core rule 122 · PDF page 8" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 122 · PDF page 8</div></details>

Game Objects include, but are not limited to, the following: ^cr-123

- [[Main Deck]] [[Card|cards]] in any [[Zone|zone]]
- [[Rune|Runes]] in any zone
- [[Legend|Legends]]
- [[Battlefield|Battlefields]]
- [[Token|Tokens]] in any zone
- [[Ability|Abilities]] of any type on the [[Chain|chain]]
- [[Counter (Object)|Counters]] and other status markers

<details class="rule-ref"><summary title="Core rule 123 · PDF page 8" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 123 · PDF page 8</div></details>

A Game Object that changes [[Zone|zones]] to or from a Non-Board Zone becomes a new object for the purposes of tracking that object. ^cr-124

<details class="rule-ref"><summary title="Core rule 124 · PDF page 8" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 124 · PDF page 8</div></details>

Whenever a Game Object changes [[Zone|zones]] to or from a Non-Board Zone, all [[Temporary]] Modifications of all kinds cease to be tracked on it in all capacities. ^cr-124-1

Examples:

- [[Damage]] is cleared.
- [[Counter (Object)|Counters]] are removed.
- Granted [[Keywords]] are no longer granted.
- Statuses are cleared.

<details class="rule-ref"><summary title="Core rule 124.1 · PDF page 8-9" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 124.1 · PDF page 8-9</div></details>

A Game Object can have any of the following statuses (non-exhaustive): [[Attached]], [[Attacker|Attacking]], [[Buffs|Buffed]], Banished, Controlled, [[Defender|Defending]], Empowered, [[Equipped]], [[Exhaust|Exhausted]], Facedown, [[Ready|Readied]], Replaced, [[Reveal|Revealed]], [[Stun|Stunned]], and any applied Layer effects. ^cr-124-2
