# Control of Cards and Other Objects

[[Start Here|Home]] · [[Concept Index|Find a concept]] · [[Core Rules Index|Core rules]]

<span title="Core rule 191"></span> ^cr-191

<details class="rule-ref"><summary title="Core rule 191 · PDF page 31" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 191 · PDF page 31</div></details>

Players [[Control|control]] their own [[Champion Legend]]. ^cr-191-1

<details class="rule-ref"><summary title="Core rule 191.1 · PDF page 31" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 191.1 · PDF page 31</div></details>

When a player Plays, Hides, or Creates a [[Card]] or other [[Game Object]], they are established as that Game Object's Controller. ^cr-191-2

<details class="rule-ref"><summary title="Core rule 191.2 · PDF page 31" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 191.2 · PDF page 31</div></details>

For [[Spell|Spells]], they are the Spell's Controller. ^cr-191-3

<details class="rule-ref"><summary title="Core rule 191.3 · PDF page 31" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 191.3 · PDF page 31</div></details>

That player chooses targets. ^cr-191-3-a

<details class="rule-ref"><summary title="Core rule 191.3.a · PDF page 31" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 191.3.a · PDF page 31</div></details>

That player chooses modes. ^cr-191-3-b

<details class="rule-ref"><summary title="Core rule 191.3.b · PDF page 31" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 191.3.b · PDF page 31</div></details>

That player pays [[Costs|costs]]. ^cr-191-3-c

<details class="rule-ref"><summary title="Core rule 191.3.c · PDF page 31" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 191.3.c · PDF page 31</div></details>

For [[Permanent|Permanents]] and [[Rune|Runes]], when they Enter [[Board|the Board]], that player is assigned as that [[Game Object]]'s Controller. ^cr-191-4

<details class="rule-ref"><summary title="Core rule 191.4 · PDF page 31" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 191.4 · PDF page 31</div></details>

That player may make decisions about the [[Game Object]]'s Inherent [[Ability|Abilities]]. ^cr-191-4-a

<details class="rule-ref"><summary title="Core rule 191.4.a · PDF page 31" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 191.4.a · PDF page 31</div></details>

That player may make decisions about the [[Game Object]]'s [[Unique]] [[Ability|Abilities]]. ^cr-191-4-b

<details class="rule-ref"><summary title="Core rule 191.4.b · PDF page 31" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 191.4.b · PDF page 31</div></details>

That player may make decisions about any [[Game Effect|game effects]] or decisions necessary while the [[Card|card]] is being played. ^cr-191-4-c

<details class="rule-ref"><summary title="Core rule 191.4.c · PDF page 31" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 191.4.c · PDF page 31</div></details>

That player may make decisions about any [[Game Effect|game effects]] created from "When you [[Play|play]] me" effects of [[Permanent|Permanents]]. ^cr-191-4-d

<details class="rule-ref"><summary title="Core rule 191.4.d · PDF page 31" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 191.4.d · PDF page 31</div></details>

For [[Ability|Abilities]], they are the Ability’s Controller. ^cr-191-5

<details class="rule-ref"><summary title="Core rule 191.5 · PDF page 32" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 191.5 · PDF page 32</div></details>

By default, the Controller of an [[Ability]]’s Source is the Controller of that Ability. ^cr-191-5-a

<details class="rule-ref"><summary title="Core rule 191.5.a · PDF page 32" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 191.5.a · PDF page 32</div></details>

If an [[Ability]]’s Source is located in a non-Board [[Zone]], the Ability’s Controller is the Owner of the Source. ^cr-191-5-a-1

<details class="rule-ref"><summary title="Core rule 191.5.a.1 · PDF page 32" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 191.5.a.1 · PDF page 32</div></details>

If an [[Ability]] allows players other than the Controller or Owner of its Source to [[Play|play]] it, the player that plays the Ability Controls the Ability. ^cr-191-5-a-2

<details class="rule-ref"><summary title="Core rule 191.5.a.2 · PDF page 32" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 191.5.a.2 · PDF page 32</div></details>

Changes to [[Control]] of an [[Ability]]’s Source do not change Control of that Ability. ^cr-191-5-b

<details class="rule-ref"><summary title="Core rule 191.5.b · PDF page 32" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 191.5.b · PDF page 32</div></details>

That player chooses targets. ^cr-191-5-c

<details class="rule-ref"><summary title="Core rule 191.5.c · PDF page 32" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 191.5.c · PDF page 32</div></details>

That player chooses modes. ^cr-191-5-d

<details class="rule-ref"><summary title="Core rule 191.5.d · PDF page 32" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 191.5.d · PDF page 32</div></details>

That player pays [[Costs|costs]]. ^cr-191-5-e

<details class="rule-ref"><summary title="Core rule 191.5.e · PDF page 32" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 191.5.e · PDF page 32</div></details>

When a [[Game Effect|game effect]] or [[Rules Text|rules text]] refers to the Controller of a specific object, it can be referring to either context interchangeably. ^cr-192

<details class="rule-ref"><summary title="Core rule 192 · PDF page 32" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 192 · PDF page 32</div></details>

The method of assignment of [[Control|control]] is different, but the status of Control is the same across all [[Game Object|Game Objects]]. ^cr-192-1
