<details class="rule-ref"><summary title="Core rule 424 · PDF page 84" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 424 · PDF page 84</div></details>

Stunning is the act of selecting one or more [[Unit|Units]] on [[Board|the Board]] and rendering them Stunned. ^cr-424-1

<details class="rule-ref"><summary title="Core rule 424.1 · PDF page 84" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 424.1 · PDF page 84</div></details>

Stunned is a binary state. A [[Unit]] is Stunned or it isn't. ^cr-424-1-a

<details class="rule-ref"><summary title="Core rule 424.1.a · PDF page 84" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 424.1.a · PDF page 84</div></details>

A Stunned [[Unit]] can not be Stunned again. ^cr-424-1-a-1

**Example:** Eclipse Herald has the [[Ability|ability]] "When you stun an [[Enemy|enemy]] [[Unit|unit]], [[Ready|ready]] me and give me +1 &#91;M&#93; this [[Turn|turn]]." Its controller plays a [[Spell|spell]] that reads "Stun a unit." They may choose a unit that's already stunned, but if they do, Eclipse Herald will not trigger.

<details class="rule-ref"><summary title="Core rule 424.1.a.1 · PDF page 84" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 424.1.a.1 · PDF page 84</div></details>

Stunned [[Unit|Units]] lose the Stunned status during step 3d of the end of [[Turn|turn]] [[Cleanups|cleanup]]. ^cr-424-1-a-2

<details class="rule-ref"><summary title="Core rule 424.1.a.2 · PDF page 84" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 424.1.a.2 · PDF page 84</div></details>

A Stunned [[Unit]] does not contribute its [[Might|might]] to [[Damage|damage]] in the [[Combat|combat]] damage step. ^cr-424-1-b

See [[Combat Procedure#^cr-467|The Combat Damage Step]] for more information.

<details class="rule-ref"><summary title="Core rule 424.1.b · PDF page 84" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 424.1.b · PDF page 84</div></details>

A Stunned [[Unit]] must still have [[Damage|damage]] applied to it equal to, or greater than, its full [[Might|might]] value to be [[Kill|killed]]. ^cr-424-1-c

<details class="rule-ref"><summary title="Core rule 424.1.c · PDF page 84" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 424.1.c · PDF page 84</div></details>

Stunning is a [[Limited Action]]. ^cr-424-2

<details class="rule-ref"><summary title="Core rule 424.2 · PDF page 84" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 424.2 · PDF page 84</div></details>

Players may only Stun [[Unit|Units]] when directed to by [[Game Effect|Game Effects]]. ^cr-424-2-a

<details class="rule-ref"><summary title="Core rule 424.2.a · PDF page 84" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 424.2.a · PDF page 84</div></details>
