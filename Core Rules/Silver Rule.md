# Silver Rule

[[Start Here|Home]] · [[Concept Index|Find a concept]] · [[Core Rules Index|Core rules]]

<span title="Core rule 050"></span> ^cr-050

<details class="rule-ref"><summary title="Core rule 050 · PDF page 1" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 050 · PDF page 1</div></details>

[[Card]] text uses different terminology than rules. Card text should be interpreted according to these rules, not as though it were text within these rules. ^cr-051

<details class="rule-ref"><summary title="Core rule 051 · PDF page 1" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 051 · PDF page 1</div></details>

[[Card]], when written in card effects, is shorthand for "[[Main Deck]] card." [[Rune|Runes]], [[Legend|legends]], and [[Battlefield|battlefields]] are not considered cards when executing the [[Ability|abilities]] and effects of [[Game Object|game objects]]. They are considered cards for the purposes of these rules. ^cr-052

<details class="rule-ref"><summary title="Core rule 052 · PDF page 1" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 052 · PDF page 1</div></details>

[[Card|Cards]] refer to themselves in the first person. ^cr-053

<details class="rule-ref"><summary title="Core rule 053 · PDF page 1" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 053 · PDF page 1</div></details>

* [[Unit|Units]] and [[Legend|legends]] say "I," "me," etc. ^cr-053-1

<details class="rule-ref"><summary title="Core rule 053.1 · PDF page 1" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 053.1 · PDF page 1</div></details>

* [[Gear]] and [[Spell|spells]] say "this." ^cr-053-2

<details class="rule-ref"><summary title="Core rule 053.2 · PDF page 1" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 053.2 · PDF page 1</div></details>

* [[Battlefield|Battlefields]] say "here." ^cr-053-3

<details class="rule-ref"><summary title="Core rule 053.3 · PDF page 1" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 053.3 · PDF page 1</div></details>

* [[Card|Cards]] may refer to themselves by their [[Card Name|name]] for clarity. This is shorthand for the above terms. ^cr-053-4
