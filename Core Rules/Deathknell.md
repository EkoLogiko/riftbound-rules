<details class="rule-ref"><summary title="Core rule 808 · PDF page 127" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 808 · PDF page 127</div></details>

Deathknell is a [[Triggered Ability]] [[Keywords|keyword]]. ^cr-808-1

<details class="rule-ref"><summary title="Core rule 808.1 · PDF page 127" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 808.1 · PDF page 127</div></details>

It is present on [[Permanent|Permanents]]. ^cr-808-1-a

<details class="rule-ref"><summary title="Core rule 808.1.a · PDF page 127" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 808.1.a · PDF page 127</div></details>

It is formatted as "&#91;Deathknell&#93;&#91;>&#93; &#91;Effect&#93;". ^cr-808-1-b

<details class="rule-ref"><summary title="Core rule 808.1.b · PDF page 127" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 808.1.b · PDF page 127</div></details>

&#91;Effect&#93; is the [[Rules Text|rules text]] for the specific instance of Deathknell. This is referred to as the Deathknell effect. ^cr-808-1-b-1

<details class="rule-ref"><summary title="Core rule 808.1.b.1 · PDF page 127" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 808.1.b.1 · PDF page 127</div></details>

It is functionally short for "When I die, &#91;Effect&#93;." ^cr-808-1-c

<details class="rule-ref"><summary title="Core rule 808.1.c · PDF page 127" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 808.1.c · PDF page 127</div></details>

&#91;Effect&#93; is the [[Rules Text|rules text]] of the Deathknell effect. ^cr-808-1-c-1

<details class="rule-ref"><summary title="Core rule 808.1.c.1 · PDF page 127" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 808.1.c.1 · PDF page 127</div></details>

&#91;Effect&#93; may be written in the past tense. In doing so, it refers to the moment the Deathknell trigger was added to the [[Chain|chain]], not any previous moment. ^cr-808-1-c-2

<details class="rule-ref"><summary title="Core rule 808.1.c.2 · PDF page 127" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 808.1.c.2 · PDF page 127</div></details>

The Trigger for this and similar effects that trigger on their source’s death is the [[Permanent]] being [[Kill|Killed]] and sent to the [[Trash]]. ^cr-808-1-d

<details class="rule-ref"><summary title="Core rule 808.1.d · PDF page 127" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 808.1.d · PDF page 127</div></details>

If the [[Permanent]] with the effect is not sent to the [[Trash]], for example because its "[[Kill|killed]]" event was replaced with a recall, the [[Triggered Ability|triggered ability]] will be removed from the [[Chain|chain]]. ^cr-808-1-d-1

**Example:** Draven, Audacious is [[Kill|killed]] [[In Combat|in combat]]. Draven reads in part “When I die in combat, choose an opponent. They gain 1 point.” Draven’s controller has a Zhonya’s Hourglass in [[Base|base]]. Draven’s death is replaced by him being healed, recalled, and [[Exhaust|exhausted]]. Draven’s [[Triggered Ability|triggered ability]] will be removed from the [[Chain|chain]].

<details class="rule-ref"><summary title="Core rule 808.1.d.1 · PDF page 128" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 808.1.d.1 · PDF page 128</div></details>

The trigger will be added to the [[Chain|chain]] as a [[Pending Chain Item|Pending Item]] before the [[Card|card]] with an [[Ability|ability]] that triggers on its own death is moved to the [[Trash|trash]] due to a [[Kill]] instruction or a [[Cleanups|Cleanup]]. ^cr-808-1-d-2

<details class="rule-ref"><summary title="Core rule 808.1.d.2 · PDF page 128" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 808.1.d.2 · PDF page 128</div></details>

Before the [[Card|card]] is moved to the [[Trash]], note its [[Location|location]], its attributes, and any other details related to the effect of its [[Triggered Ability|triggered ability]] to process the trigger after it has been Finalized. ^cr-808-1-d-3

<details class="rule-ref"><summary title="Core rule 808.1.d.3 · PDF page 128" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 808.1.d.3 · PDF page 128</div></details>

Each instance of Deathknell a [[Permanent]] may have will trigger separately. ^cr-808-2

<details class="rule-ref"><summary title="Core rule 808.2 · PDF page 128" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 808.2 · PDF page 128</div></details>

The controller will choose the order to add these Triggers to the [[Chain|chain]]. ^cr-808-2-a

<details class="rule-ref"><summary title="Core rule 808.2.a · PDF page 128" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 808.2.a · PDF page 128</div></details>

Deathknell, and whether or not a [[Permanent|permanent]] has Deathknell, is a characteristic of the permanent and may be checked or referenced by other [[Game Effect|Game Effects]]. ^cr-808-3
