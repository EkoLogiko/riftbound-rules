# Main Phase

<span title="Core rule 316"></span> ^cr-316

<details class="rule-ref"><summary title="Core rule 316 · PDF page 38" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 316 · PDF page 38</div></details>

When all steps of the [[Start of Turn]] have been completed, the Main Phase begins. ^cr-316-1

<details class="rule-ref"><summary title="Core rule 316.1 · PDF page 38" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 316.1 · PDF page 38</div></details>

The following [[Task|Tasks]] become Outstanding in the specified order: ^cr-316-2

<details class="rule-ref"><summary title="Core rule 316.2 · PDF page 38" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 316.2 · PDF page 38</div></details>

1. Each player's [[Rune Pool]] empties. Any unspent [[Energy]] and [[Power]] are lost. ^cr-316-3

See [[Rune Pool#^cr-165|Rune Pools]] for more information.

<details class="rule-ref"><summary title="Core rule 316.3 · PDF page 38" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 316.3 · PDF page 38</div></details>

2. At the start of Main Phase [[Game Effect|game effects]] take place. ^cr-316-4

<details class="rule-ref"><summary title="Core rule 316.4 · PDF page 38" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 316.4 · PDF page 38</div></details>

The Main Phase has no defined structure. ^cr-316-5

<details class="rule-ref"><summary title="Core rule 316.5 · PDF page 38" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 316.5 · PDF page 38</div></details>

A player may take any number of [[Discretionary Action|Discretionary Actions]] they are able to perform during this phase. ^cr-316-5-a

See [[Game Action#^cr-411-1|Discretionary Actions]] for more information.

<details class="rule-ref"><summary title="Core rule 316.5.a · PDF page 38" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 316.5.a · PDF page 38</div></details>

This is denoted as a [[Neutral Open State]], and only [[Turn|the Turn]] Player has the [[Ability|ability]] to [[Play|play]] [[Spell|spells]] or activate abilities. ^cr-316-5-b

See [[Turn States#^cr-307|States of the Turn]] for more information.

<details class="rule-ref"><summary title="Core rule 316.5.b · PDF page 38-39" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 316.5.b · PDF page 38-39</div></details>

In [[Modes of Play]] with teammates, [[Turn|the Turn]] Player's teammates may [[Play|play]] [[Spell|spells]] and activate [[Ability|abilities]], including ones without Action or Reaction. They can only do so when the Turn Player invites them to do so with their own [[Priority]]. ^cr-316-5-b-1

<details class="rule-ref"><summary title="Core rule 316.5.b.1 · PDF page 39" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 316.5.b.1 · PDF page 39</div></details>

As a result of a player taking [[Discretionary Action|Discretionary Actions]], one or more structured phases may occur. ^cr-316-6

<details class="rule-ref"><summary title="Core rule 316.6 · PDF page 39" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 316.6 · PDF page 39</div></details>

[[Combat]] ^cr-316-7

<details class="rule-ref"><summary title="Core rule 316.7 · PDF page 39" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 316.7 · PDF page 39</div></details>

A [[Combat]] occurs as a result of [[Unit|Units]] controlled by opposing players being present at the same [[Battlefield]]. ^cr-316-7-a

<details class="rule-ref"><summary title="Core rule 316.7.a · PDF page 39" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 316.7.a · PDF page 39</div></details>

This could be the result of a [[Standard Move]] Intrinsic [[Ability]], a [[Spell]], or other [[Game Effect]]. ^cr-316-7-b

<details class="rule-ref"><summary title="Core rule 316.7.b · PDF page 39" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 316.7.b · PDF page 39</div></details>

The source effect does not change the structure or [[Flow|flow]] of [[Combat]] once initiated. ^cr-316-7-c

<details class="rule-ref"><summary title="Core rule 316.7.c · PDF page 39" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 316.7.c · PDF page 39</div></details>

A [[Combat]] can only occur between two players. ^cr-316-7-d

See [[Combat#^cr-461|Combat]] for more information.

<details class="rule-ref"><summary title="Core rule 316.7.d · PDF page 39" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 316.7.d · PDF page 39</div></details>

[[Play]] proceeds following the steps of [[Combat|combat]]. ^cr-316-7-e

See [[Combat Procedure#^cr-465|The Steps of Combat]] for more information.

<details class="rule-ref"><summary title="Core rule 316.7.e · PDF page 39" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 316.7.e · PDF page 39</div></details>

[[Combat]] will also include a [[Showdowns|Showdown]]. ^cr-316-7-f

<details class="rule-ref"><summary title="Core rule 316.7.f · PDF page 39" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 316.7.f · PDF page 39</div></details>

[[Showdowns]] ^cr-316-8

<details class="rule-ref"><summary title="Core rule 316.8 · PDF page 39" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 316.8 · PDF page 39</div></details>

A [[Showdowns|Showdown]] occurs when a [[Combat]] occurs. ^cr-316-8-a

<details class="rule-ref"><summary title="Core rule 316.8.a · PDF page 39" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 316.8.a · PDF page 39</div></details>

[[Showdowns]] that occur as a result of [[Combat]] are a Sub-Phase of Combat. ^cr-316-8-a-1

<details class="rule-ref"><summary title="Core rule 316.8.a.1 · PDF page 39" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 316.8.a.1 · PDF page 39</div></details>

A [[Showdowns|Showdown]] is marked as Staged at a [[Battlefield]] in the [[Cleanups|cleanup]] after the [[Contested]] status is applied to that Battlefield. ^cr-316-8-b

<details class="rule-ref"><summary title="Core rule 316.8.b · PDF page 39" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 316.8.b · PDF page 39</div></details>

[[Showdowns]] that occur as a result of a player [[Movement|moving]] to an empty [[Battlefield]] are a stand-alone Phase and do not create a [[Combat]]. ^cr-316-8-b-1

<details class="rule-ref"><summary title="Core rule 316.8.b.1 · PDF page 39" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 316.8.b.1 · PDF page 39</div></details>

These [[Showdowns]] are called Non-Combat Showdowns. During the proceedings of a Non-Combat Showdown, [[Unit|units]] controlled by a different player may become present at the [[Battlefield]] where the Showdown is ongoing. This will cause the Showdown to become a [[Combat]] Showdown in the following [[Cleanups|cleanup]]. ^cr-316-8-b-1-a

<details class="rule-ref"><summary title="Core rule 316.8.b.1.a · PDF page 39" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 316.8.b.1.a · PDF page 39</div></details>

A [[Showdowns|Showdown]] is a structured Window of Opportunity where Players may [[Play|play]] [[Card|cards]] and activate [[Ability|abilities]] with Action or Reaction. ^cr-316-8-c

See [[Showdowns#^cr-341|Showdowns]] for more information.

<details class="rule-ref"><summary title="Core rule 316.8.c · PDF page 39" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 316.8.c · PDF page 39</div></details>

When a player has no more [[Discretionary Action|Discretionary Actions]] they wish to execute, they must indicate they are ending their [[Turn|turn]]. ^cr-316-9

<details class="rule-ref"><summary title="Core rule 316.9 · PDF page 39" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 316.9 · PDF page 39</div></details>

This ends the Main Phase. ^cr-316-9-a

<details class="rule-ref"><summary title="Core rule 316.9.a · PDF page 39" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 316.9.a · PDF page 39</div></details>

[[Play]] proceeds to the [[Ending Phase]]. ^cr-316-9-b

<details class="rule-ref"><summary title="Core rule 316.9.b · PDF page 39" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 316.9.b · PDF page 39</div></details>
