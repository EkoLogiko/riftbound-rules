<details class="rule-ref"><summary title="Core rule 823.1.a · PDF page 137" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 823.1.a · PDF page 137</div></details>

Hunt is both a [[Conquer]] and a [[Hold Effect|Hold effect]]. ^cr-823-1-b

<details class="rule-ref"><summary title="Core rule 823.1.b · PDF page 137" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 823.1.b · PDF page 137</div></details>

Hunt is formatted as “Hunt X” ^cr-823-1-c

<details class="rule-ref"><summary title="Core rule 823.1.c · PDF page 137" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 823.1.c · PDF page 137</div></details>

Hunt is functionally short for: “When I [[Conquer]] or [[Hold]], my controller gains X XP.” ^cr-823-1-c-1

See [[XP#^cr-728|XP]] for more information.

<details class="rule-ref"><summary title="Core rule 823.1.c.1 · PDF page 137" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 823.1.c.1 · PDF page 137</div></details>

If X is omitted, it is presumed to be 1. ^cr-823-1-c-2

<details class="rule-ref"><summary title="Core rule 823.1.c.2 · PDF page 137" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 823.1.c.2 · PDF page 137</div></details>

X is referred to as the Hunt Value. ^cr-823-1-c-3

<details class="rule-ref"><summary title="Core rule 823.1.c.3 · PDF page 137" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 823.1.c.3 · PDF page 137</div></details>

If a [[Unit]] has Hunt, or has been granted Hunt, and is granted Hunt by an additional source, the Hunt Value of all granted Hunt [[Keywords|keywords]] is summed. ^cr-823-2

<details class="rule-ref"><summary title="Core rule 823.2 · PDF page 137" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 823.2 · PDF page 137</div></details>

Hunt, and whether or not a [[Unit|unit]] has Hunt, is a characteristic of the Unit and may be checked or referenced by other [[Game Effect|Game Effects]]. ^cr-823-3
