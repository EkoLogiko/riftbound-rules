# Reflexive Trigger

[[Start Here|Home]] · [[Concept Index|Find a concept]] · [[Core Rules Index|Core rules]]

<span title="Core rule 387"></span> ^cr-387

<details class="rule-ref"><summary title="Core rule 387 · PDF page 73" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 387 · PDF page 73</div></details>

Reflexive Triggers are a type of [[Triggered Ability]] that create one or more [[Chain]] Items when their condition is met. ^cr-388

<details class="rule-ref"><summary title="Core rule 388 · PDF page 73" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 388 · PDF page 73</div></details>

Reflexive Triggers can be recognized by the phrase “Do this:” or “Do one of the following:”. ^cr-388-1

<details class="rule-ref"><summary title="Core rule 388.1 · PDF page 73" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 388.1 · PDF page 73</div></details>

“Do this” can be followed by “N times.” The Reflexive Trigger will thus be added to the [[Chain|chain]] N times when its condition is met. ^cr-388-1-a

<details class="rule-ref"><summary title="Core rule 388.1.a · PDF page 73" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 388.1.a · PDF page 73</div></details>

“Do one of the following” can instead be “Do X of the following” or “Do the following”. The effect will specify which of the related Reflexive Triggers will go on the [[Chain|chain]] when the condition is met. ^cr-388-1-b

<details class="rule-ref"><summary title="Core rule 388.1.b · PDF page 73" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 388.1.b · PDF page 73</div></details>

Reflexive Triggers will be preceded by their conditions, if any. If no condition is present in the [[Ability|ability]] then the Reflexive Trigger will always be added to the [[Chain]]. ^cr-388-2

<details class="rule-ref"><summary title="Core rule 388.2 · PDF page 73" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 388.2 · PDF page 73</div></details>

If present, the Condition of a Reflexive Trigger will follow the same format as a [[Triggered Ability]]. ^cr-388-3

<details class="rule-ref"><summary title="Core rule 388.3 · PDF page 73" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 388.3 · PDF page 73</div></details>

If a Reflexive Trigger says “you may” or “they may” as the first part of its Effect, the controller of its source will choose whether or not to perform the Reflexive Trigger during finalization. ^cr-388-4

**Example:** Death From Below is a [[Spell|spell]] that reads in part “Then, if it had 3 [[Might|might]] or less, do this: You may [[Play|play]] this from your [[Trash|trash]] for &#91;A&#93;.” The reflexive trigger is added to the [[Chain|chain]] when the spell is resolving, and then on finalization of the reflexive trigger its controller will decide if they want to perform the effect. If they don’t, it is removed from the chain.

<details class="rule-ref"><summary title="Core rule 388.4 · PDF page 73" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 388.4 · PDF page 73</div></details>

Reflexive Triggers use the [[Chain]]. ^cr-389

<details class="rule-ref"><summary title="Core rule 389 · PDF page 73" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 389 · PDF page 73</div></details>

A new [[Ability|ability]] is created and added to the [[Chain|chain]] as a [[Pending Chain Item|Pending Item]]. ^cr-389-1

See [[Playing or Activating an Ability#^cr-399|Playing or Activating Abilities]] for more information.

<details class="rule-ref"><summary title="Core rule 389.1 · PDF page 74" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 389.1 · PDF page 74</div></details>

If a Reflexive Trigger creates more than one [[Pending Chain Item|Pending Item]] it creates them all in order, but does not go beyond the first step of adding them to the [[Chain]]. ^cr-389-2

See [[Playing or Activating an Ability#^cr-399|Playing or Activating Abilities]] for more information.
