# Weaponmaster

[[Start Here|Home]] · [[Concept Index|Find a concept]] · [[Core Rules Index|Core rules]]

<span title="Core rule 821"></span> ^cr-821

<details class="rule-ref"><summary title="Core rule 821 · PDF page 136" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 821 · PDF page 136</div></details>

Weaponmaster is a [[Triggered Ability]] [[Keywords|keyword]]. ^cr-821-1

<details class="rule-ref"><summary title="Core rule 821.1 · PDF page 136" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 821.1 · PDF page 136</div></details>

Weaponmaster is present on [[Unit|Units]]. ^cr-821-1-a

<details class="rule-ref"><summary title="Core rule 821.1.a · PDF page 136" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 821.1.a · PDF page 136</div></details>

Weaponmaster is a [[Play Effect]] that chooses an [[Equipment]] you [[Control|control]] and allows you to pay its [[Equip]] [[Costs|cost]] at a discount, regardless of the usual timing of the Equip [[Ability|ability]], to [[Attach]] that Equipment to the [[Unit|unit]] with Weaponmaster. ^cr-821-1-b

<details class="rule-ref"><summary title="Core rule 821.1.b · PDF page 136" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 821.1.b · PDF page 136</div></details>

Weaponmaster is functionally short for: “When you [[Play|play]] me, you may choose a [[Card]] you [[Control|control]] with the [[Equipment]] [[Tag|tag]]. Necessary portions of its [[Rules Text]] are no longer [[Inactive]] if they are currently Inactive. Pay the [[Costs|cost]] of its [[Equip]] [[Ability|ability]], reduced by &#91;A&#93;, to [[Attach|attach]] it to this [[Unit|unit]].” ^cr-821-1-c

See [[Attachment#^cr-716|Attachment]] for more information.

<details class="rule-ref"><summary title="Core rule 821.1.c · PDF page 136" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 821.1.c · PDF page 136</div></details>

Weaponmaster can choose an [[Equipment]] whether it has an [[Equip]] [[Ability|ability]] or not. ^cr-821-1-c-1

<details class="rule-ref"><summary title="Core rule 821.1.c.1 · PDF page 136" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 821.1.c.1 · PDF page 136</div></details>

The [[Costs|cost]] of the [[Equip]] [[Ability|ability]] is determined as though that Equip ability was being activated choosing the [[Unit|unit]] with the Weaponmaster ability, as modulated by any abilities that alter Equip costs. ^cr-821-1-c-2

<details class="rule-ref"><summary title="Core rule 821.1.c.2 · PDF page 136" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 821.1.c.2 · PDF page 136</div></details>

The [[Equip]] [[Ability|ability]] is not actually activated when its [[Costs|cost]] is determined in this way. An effect that grants an [[Activated Ability|activated ability]] a cost reduction when it is played will not apply to the Equip cost calculated during the resolution of a Weaponmaster trigger, because the Equip ability is not actually played. ^cr-821-1-c-2-a

<details class="rule-ref"><summary title="Core rule 821.1.c.2.a · PDF page 136" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 821.1.c.2.a · PDF page 136</div></details>

Effects that reduce the [[Costs|cost]] of [[Equip]] [[Ability|abilities]] without referring to those abilities being played, or the Equip ability being referenced in specific, will be included when calculating costs in this way. ^cr-821-1-c-2-b

<details class="rule-ref"><summary title="Core rule 821.1.c.2.b · PDF page 136" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 821.1.c.2.b · PDF page 136</div></details>

If the chosen [[Card|card]]’s [[Equip]] [[Costs|cost]] does not contain &#91;A&#93;, it can still be paid, but will not be reduced. ^cr-821-1-c-3

<details class="rule-ref"><summary title="Core rule 821.1.c.3 · PDF page 136" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 821.1.c.3 · PDF page 136</div></details>

If the chosen [[Card|card]] doesn’t have an [[Equip]] [[Costs|cost]], it can’t be paid. ^cr-821-1-c-4

<details class="rule-ref"><summary title="Core rule 821.1.c.4 · PDF page 136" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 821.1.c.4 · PDF page 136</div></details>

If the chosen [[Card|card]]’s [[Equip]] [[Costs|cost]] can’t be paid, if it can’t be [[Detach|detached]] from its current [[Top-most Card|Top-Most card]], or if it can’t be [[Attached|attached]] to the [[Unit|unit]] with the Weaponmaster [[Ability|ability]], it stays in its current [[Location|location]], Attached to anything it was already Attached to. ^cr-821-1-c-5

<details class="rule-ref"><summary title="Core rule 821.1.c.5 · PDF page 136" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 821.1.c.5 · PDF page 136</div></details>

The [[Equip]] [[Ability|ability]] is not activated this way, and the [[Unit|unit]] with the Weaponmaster ability is not chosen. ^cr-821-1-c-6

<details class="rule-ref"><summary title="Core rule 821.1.c.6 · PDF page 136" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 821.1.c.6 · PDF page 136</div></details>

Multiple instances of Weaponmaster trigger separately, and can choose different targets. ^cr-821-1-c-7

<details class="rule-ref"><summary title="Core rule 821.1.c.7 · PDF page 136" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 821.1.c.7 · PDF page 136</div></details>

If you choose the same target with multiple instances of Weaponmaster, each will resolve separately. ^cr-821-1-d

<details class="rule-ref"><summary title="Core rule 821.1.d · PDF page 136" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 821.1.d · PDF page 136</div></details>

Weaponmaster has no function while on [[Board|the board]]. ^cr-821-2

<details class="rule-ref"><summary title="Core rule 821.2 · PDF page 137" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 821.2 · PDF page 137</div></details>

Weaponmaster, and whether or not a [[Unit|unit]] has Weaponmaster, is a characteristic of the Unit and may be checked or referenced by other [[Game Effect|Game Effects]]. ^cr-821-3
