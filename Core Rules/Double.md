# Double

[[Start Here|Home]] · [[Concept Index|Find a concept]] · [[Core Rules Index|Core rules]]

<span title="Core rule 433"></span> ^cr-433

<details class="rule-ref"><summary title="Core rule 433 · PDF page 90" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 433 · PDF page 90</div></details>

Doubling is the act of increasing a numeric attribute by an amount equal to that attribute’s current value. ^cr-433-1

<details class="rule-ref"><summary title="Core rule 433.1 · PDF page 90" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 433.1 · PDF page 90</div></details>

This creates an effect that modulates that attribute by that specific amount for the duration specified by the [[Game Effect]] that instructed the player to perform this action. ^cr-433-1-a

**Example:** A [[Unit|unit]] with 3 [[Base Might|base Might]] and [[Shield]] 2 is [[In Combat|in combat]] as a [[Defender]]. Since Shield applies, its current [[Might]] is 5. A player chooses it as the target for Last Stand, a [[Spell|spell]] that reads in part “Double a [[Friendly|friendly]] unit's Might this [[Turn|turn]].” Its current Might is 5, so it gets +5 Might this turn, for a current Might of 10. After [[Combat|combat]], Shield no longer applies, but the +5 Might from Last Stand does, so the unit’s Might is 8.

<details class="rule-ref"><summary title="Core rule 433.1.a · PDF page 90" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 433.1.a · PDF page 90</div></details>

Some [[Game Effect|Game Effects]] may also cause [[Damage]] to be Doubled; in this case, those effects are the equivalent to a [[Replacement Effect|replacement effect]] that reads “If I would take damage from a source, I take double that damage from that source instead.” or “If &#91;I/this&#93; would [[Deal|deal]] damage, &#91;I/this&#93; deal double that damage instead.” The source of the Damage in these cases remains the same after Doubling. ^cr-433-1-b

<details class="rule-ref"><summary title="Core rule 433.1.b · PDF page 90" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 433.1.b · PDF page 90</div></details>

Doubling is a [[Limited Action]]. ^cr-433-2

<details class="rule-ref"><summary title="Core rule 433.2 · PDF page 90" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 433.2 · PDF page 90</div></details>

Players may only Double when [[Game Effect|Game Effects]] direct them to do so. ^cr-433-2-a

<details class="rule-ref"><summary title="Core rule 433.2.a · PDF page 90" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 433.2.a · PDF page 90</div></details>
