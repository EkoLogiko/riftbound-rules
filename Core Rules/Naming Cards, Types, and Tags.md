# Naming Cards, Types, and Tags

[[Start Here|Home]] · [[Concept Index|Find a concept]] · [[Core Rules Index|Core rules]]

<span title="Core rule 759"></span> ^cr-759

<details class="rule-ref"><summary title="Core rule 759 · PDF page 124" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 759 · PDF page 124</div></details>

Some [[Game Effect|Game Effects]] may instruct a player to [[Card Name|name]] or guess a [[Card|card]], type, or [[Tag|tag]]. ^cr-760

<details class="rule-ref"><summary title="Core rule 760 · PDF page 124" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 760 · PDF page 124</div></details>

The act of naming a [[Card|card]] in this way may be accomplished in one of two ways: ^cr-761

<details class="rule-ref"><summary title="Core rule 761 · PDF page 124" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 761 · PDF page 124</div></details>

1. Stating the exact [[Card Name|name]] of the [[Card|card]]. ^cr-761-1

**Example:** “Kai’Sa, Evolutionary” identifies the [[Card|card]] Kai’Sa, Evolutionary.

<details class="rule-ref"><summary title="Core rule 761.1 · PDF page 124" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 761.1 · PDF page 124</div></details>

2. Identifying a combination of traits and characteristics that can identify that [[Card|card]] uniquely. ^cr-761-2

**Example:** “The blue Kai’Sa,” “the 6 &#91;M&#93; Kai’Sa” or “the &#91;6&#93; [[Energy]] Kai’Sa” are sufficient to identify Kai’Sa, Evolutionary when there are no other [[Card|cards]] that satisfy those traits.

**Example:** If there is only one [[Unit|unit]] with Kato in their [[Card Name|name]], saying “Kato” is sufficient to identify the [[Card|card]] in question even if the exact name of the card is “Kato the Arm.”

<details class="rule-ref"><summary title="Core rule 761.2 · PDF page 124" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 761.2 · PDF page 124</div></details>

When instructed to [[Card Name|name]] a [[Card|card]], a player must name a card that is legal in the Format being played. ^cr-762

<details class="rule-ref"><summary title="Core rule 762 · PDF page 124" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 762 · PDF page 124</div></details>

They cannot [[Card Name|name]] a [[Card|card]] that doesn’t exist. ^cr-762-1

<details class="rule-ref"><summary title="Core rule 762.1 · PDF page 124" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 762.1 · PDF page 124</div></details>

A player cannot choose the [[Card Name|name]] of a [[Token|token]] when instructed to name a [[Card|card]]. ^cr-762-2

<details class="rule-ref"><summary title="Core rule 762.2 · PDF page 124" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 762.2 · PDF page 124</div></details>

When instructed to [[Card Name|name]] a [[Tag|tag]], a player cannot choose to name a tag that does not exist on [[Card|cards]] or [[Token|tokens]] in Riftbound. ^cr-763

<details class="rule-ref"><summary title="Core rule 763 · PDF page 124" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 763 · PDF page 124</div></details>
