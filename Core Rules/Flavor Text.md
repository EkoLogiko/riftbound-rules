# Flavor Text

[[Start Here|Home]] · [[Concept Index|Find a concept]] · [[Core Rules Index|Core rules]]

<span title="Core rule 138"></span> ^cr-138

<details class="rule-ref"><summary title="Core rule 138 · PDF page 17" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 138 · PDF page 17</div></details>

Flavor text is text that appears at the bottom of some [[Card|cards]] to provide aesthetic enjoyment. It conveys no gameplay information. ^cr-138-1

**Example:** The [[Card|card]] Void Seeker features a quote from the character Kai'Sa. It does not have the Kai'Sa [[Tag|tag]] and has no gameplay connection to the [[Champion|Champion unit]] Kai'Sa.

<details class="rule-ref"><summary title="Core rule 138.1 · PDF page 17" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 138.1 · PDF page 17</div></details>

Flavor text is located at the bottom of the section provided for [[Rules Text|rules text]], usually in a shaded bar. It appears in italics. ^cr-138-2
