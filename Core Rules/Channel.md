# Channel

[[Start Here|Home]] · [[Concept Index|Find a concept]] · [[Core Rules Index|Core rules]]

<span title="Core rule 431"></span> ^cr-431

<details class="rule-ref"><summary title="Core rule 431 · PDF page 89" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 431 · PDF page 89</div></details>

Channeling is the action of taking one or more [[Rune|Runes]] from the top of a player's [[Rune Deck]] and putting them on [[Board|the board]]. ^cr-431-1

<details class="rule-ref"><summary title="Core rule 431.1 · PDF page 89" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 431.1 · PDF page 89</div></details>

The [[Game Effect]] that instructs a player to channel 1 or more [[Rune|runes]] may specify the conditions or circumstances under which those runes enter [[Board|the board]]. ^cr-431-2

**Example:** A [[Spell|spell]] reads "Channel 1 [[Rune|rune]] [[Exhaust|exhausted]]." As that spell resolves, its controller puts the top rune of their [[Rune Deck|rune deck]] onto [[Board|the board]] and that rune enters the board exhausted rather than [[Ready|ready]].

<details class="rule-ref"><summary title="Core rule 431.2 · PDF page 89" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 431.2 · PDF page 89</div></details>

By default, [[Rune|runes]] are channeled [[Ready|readied]]. ^cr-431-2-a

<details class="rule-ref"><summary title="Core rule 431.2.a · PDF page 89" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 431.2.a · PDF page 89</div></details>

If there aren’t sufficient [[Rune|runes]] in the [[Rune Deck]], channel as many as possible. ^cr-431-3

<details class="rule-ref"><summary title="Core rule 431.3 · PDF page 89" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 431.3 · PDF page 89</div></details>

Channeling is a [[Limited Action]]. ^cr-431-4

<details class="rule-ref"><summary title="Core rule 431.4 · PDF page 89" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 431.4 · PDF page 89</div></details>

A player Channels two [[Rune|Runes]] during the [[Channel Phase]] on their [[Turn|turn]]. ^cr-431-4-a

<details class="rule-ref"><summary title="Core rule 431.4.a · PDF page 89" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 431.4.a · PDF page 89</div></details>

Players may also Channel [[Rune|runes]] when [[Game Effect|Game Effects]] direct them to do so. ^cr-431-4-b

<details class="rule-ref"><summary title="Core rule 431.4.b · PDF page 89" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 431.4.b · PDF page 89</div></details>

This action is formatted as "Channel X [[Rune|rune]](s)," optionally followed by conditions or stipulations. e.g., "Channel 1 rune." e.g., "When you [[Play|play]] me, channel 1 rune [[Exhaust|exhausted]]." e.g., "Channel 2 runes exhausted. If you couldn't channel 2 runes this way, [[Draw|draw]] 1." ^cr-431-5
