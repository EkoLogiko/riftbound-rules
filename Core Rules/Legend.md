Legends are [[Game Object|Game Objects]]. ^cr-174

<details class="rule-ref"><summary title="Core rule 174 · PDF page 26" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 174 · PDF page 26</div></details>

Legends are Owned by a player. ^cr-174-1

<details class="rule-ref"><summary title="Core rule 174.1 · PDF page 26" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 174.1 · PDF page 26</div></details>

Legends are not shuffled into Decks at the start of a game. ^cr-174-2

<details class="rule-ref"><summary title="Core rule 174.2 · PDF page 26" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 174.2 · PDF page 26</div></details>

Legends are not played during the course of regular [[Play|play]]. ^cr-174-2-a

<details class="rule-ref"><summary title="Core rule 174.2.a · PDF page 26" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 174.2.a · PDF page 26</div></details>

Legends are established at the start of a game, and remain in place for the duration of regular [[Play|play]]. Legends may be Created during the course of play. They will be Created [[Ready|ready]] unless the effect specifies otherwise. ^cr-174-2-b

<details class="rule-ref"><summary title="Core rule 174.2.b · PDF page 26" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 174.2.b · PDF page 26</div></details>

Legends cannot be [[Kill|Killed]] during the course of regular [[Play|play]]. ^cr-174-3

<details class="rule-ref"><summary title="Core rule 174.3 · PDF page 26" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 174.3 · PDF page 26</div></details>

Legends cannot be Moved. ^cr-174-4

<details class="rule-ref"><summary title="Core rule 174.4 · PDF page 26" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 174.4 · PDF page 26</div></details>

Legends can be targeted by [[Spell|spells]] or [[Game Effect|game effects]]. ^cr-174-5

<details class="rule-ref"><summary title="Core rule 174.5 · PDF page 26" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 174.5 · PDF page 26</div></details>

Legends can have [[Passive Ability|Passive Abilities]]. ^cr-174-6

See [[Passive Ability#^cr-363|Passive Abilities]] for more information.

<details class="rule-ref"><summary title="Core rule 174.6 · PDF page 26" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 174.6 · PDF page 26</div></details>

Legends can have [[Triggered Ability|Triggered Abilities]]. ^cr-174-7

See [[Triggered Ability#^cr-382|Triggered Abilities]] for more information.

<details class="rule-ref"><summary title="Core rule 174.7 · PDF page 26" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 174.7 · PDF page 26</div></details>

Legends can have [[Activated Ability|Activated Abilities]]. ^cr-174-8

See [[Activated Ability#^cr-376|Activated Abilities]] for more information.

<details class="rule-ref"><summary title="Core rule 174.8 · PDF page 26" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 174.8 · PDF page 26</div></details>

Legends are not [[Permanent|Permanents]]. ^cr-175

<details class="rule-ref"><summary title="Core rule 175 · PDF page 26" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 175 · PDF page 26</div></details>

Legends may have one or more Domains. ^cr-176

<details class="rule-ref"><summary title="Core rule 176 · PDF page 26" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 176 · PDF page 26</div></details>

The [[Champion Legend]] determines the [[Domain Identity]] of [[Card|cards]] its owner can include. ^cr-176-1

See [[Deck Construction#^cr-101|Deck Construction]] for more information.
