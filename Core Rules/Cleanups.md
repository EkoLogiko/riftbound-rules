A Cleanup will be made an [[Outstanding Task]] at the following times: ^cr-319

<details class="rule-ref"><summary title="Core rule 319 · PDF page 40" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 319 · PDF page 40</div></details>

After the game transitions to or from an Open or [[Closed State|Closed state]] ^cr-319-1

<details class="rule-ref"><summary title="Core rule 319.1 · PDF page 40" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 319.1 · PDF page 40</div></details>

After the game transitions between Phases, unless specified otherwise ^cr-319-2

<details class="rule-ref"><summary title="Core rule 319.2 · PDF page 40" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 319.2 · PDF page 40</div></details>

After a [[Pending Chain Item|Pending Item]] is added to the [[Chain]] ^cr-319-3

<details class="rule-ref"><summary title="Core rule 319.3 · PDF page 40" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 319.3 · PDF page 40</div></details>

After a [[Pending Chain Item|Pending Item]] becomes a [[Finalized Chain Item|Finalized Item]] on the [[Chain]] ^cr-319-4

<details class="rule-ref"><summary title="Core rule 319.4 · PDF page 40" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 319.4 · PDF page 40</div></details>

After a [[Chain]] Item is removed from the Chain for any reason ^cr-319-5

<details class="rule-ref"><summary title="Core rule 319.5 · PDF page 40" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 319.5 · PDF page 40</div></details>

After any number of [[Game Object|Game Objects]] enter or leave [[Board|the Board]] ^cr-319-6

<details class="rule-ref"><summary title="Core rule 319.6 · PDF page 40" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 319.6 · PDF page 40</div></details>

After the status of any number of [[Game Object|Game Objects]] changes for any reason ^cr-319-7

<details class="rule-ref"><summary title="Core rule 319.7 · PDF page 40" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 319.7 · PDF page 40</div></details>

After a [[Move]] is completed ^cr-319-8

<details class="rule-ref"><summary title="Core rule 319.8 · PDF page 40" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 319.8 · PDF page 40</div></details>

While a Cleanup is occurring, [[Chain]] Items cannot be Finalized or Resolved. ^cr-320

<details class="rule-ref"><summary title="Core rule 320 · PDF page 41" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 320 · PDF page 41</div></details>

New [[Pending Chain Item|Pending Items]] can be added, but [[Finalized Chain Item|Finalized Items]] cannot be executed and [[Priority and Focus]] are not passed or awarded. ^cr-320-1

<details class="rule-ref"><summary title="Core rule 320.1 · PDF page 41" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 320.1 · PDF page 41</div></details>

Similarly, while [[Chain]] Items are Resolving, a Cleanup cannot occur. ^cr-321

<details class="rule-ref"><summary title="Core rule 321 · PDF page 41" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 321 · PDF page 41</div></details>

If an event occurs during the Resolution of a [[Chain]] Item that qualifies for a Cleanup, that Cleanup will be made an [[Outstanding Task]]. ^cr-321-1

<details class="rule-ref"><summary title="Core rule 321.1 · PDF page 41" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 321.1 · PDF page 41</div></details>

If an event occurs during a Cleanup that qualifies for a Cleanup, another Cleanup will occur immediately after the first completes, repeating until a Cleanup occurs with no new change in the game’s state. ^cr-322

<details class="rule-ref"><summary title="Core rule 322 · PDF page 41" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 322 · PDF page 41</div></details>

These new Cleanups are themselves [[Outstanding Task|Outstanding Tasks]]. ^cr-322-1

<details class="rule-ref"><summary title="Core rule 322.1 · PDF page 41" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 322.1 · PDF page 41</div></details>

When a Cleanup occurs, the following [[Task|Tasks]] become Outstanding in the order described: ^cr-323

<details class="rule-ref"><summary title="Core rule 323 · PDF page 41" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 323 · PDF page 41</div></details>

1. If a player has [[Points|points]] greater than or equal to the [[Victory Score]], and more points than every opponent, that player wins. ^cr-323-1

<details class="rule-ref"><summary title="Core rule 323.1 · PDF page 41" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 323.1 · PDF page 41</div></details>

2. Assign or Remove the [[Attacker]] or [[Defender]] designation from [[Unit|Units]] as needed if there is a [[Combat]] in progress ^cr-323-2

<details class="rule-ref"><summary title="Core rule 323.2 · PDF page 41" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 323.2 · PDF page 41</div></details>

If there are [[Unit|Units]] present at the [[Battlefield]] the [[Combat]] is taking place at, but do not have a designation, they gain the same designation as their Controller now ^cr-323-2-a

<details class="rule-ref"><summary title="Core rule 323.2.a · PDF page 41" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 323.2.a · PDF page 41</div></details>

If there are [[Unit|Units]] present at the [[Battlefield]] the [[Combat]] is taking place at, but have the opposite designation of their controller, they lose that designation, and gain the same designation as their controller now ^cr-323-2-b

<details class="rule-ref"><summary title="Core rule 323.2.b · PDF page 41" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 323.2.b · PDF page 41</div></details>

If there are [[Unit|Units]] at [[Location|locations]] other than the [[Battlefield]] that the [[Combat]] is taking place at, but have either [[Attacker]] or [[Defender]] designations, they lose those designations now ^cr-323-2-c

<details class="rule-ref"><summary title="Core rule 323.2.c · PDF page 41" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 323.2.c · PDF page 41</div></details>

3. Handle outstanding [[Board|board]] state ^cr-323-3

<details class="rule-ref"><summary title="Core rule 323.3 · PDF page 41" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 323.3 · PDF page 41</div></details>

3a. All [[Unit|Units]] that have [[Lethal Damage]] marked on them are [[Kill|killed]] and placed in their owners' [[Trash]]. ^cr-323-4

See [[Unit#^cr-142-4|Unit]] for more information on [[Lethal Damage|lethal damage]].

<details class="rule-ref"><summary title="Core rule 323.4 · PDF page 41" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 323.4 · PDF page 41</div></details>

4. Players lose [[Control|control]] of any controlled [[Battlefield|Battlefields]] without their [[Unit|Units]] occupying them if [[Turn|the turn]] is in an [[Open State]] and there is no [[Showdowns|Showdown]] or [[Combat]] ongoing there. ^cr-323-5

<details class="rule-ref"><summary title="Core rule 323.5 · PDF page 41" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 323.5 · PDF page 41</div></details>

5. Recall all of the following [[Game Object|Game Objects]], unless an effect would indicate otherwise: Unattached non-Unit [[Gear]] located at [[Battlefield|Battlefields]] Non-Unit [[Rune|Runes]] located at Battlefields Unattached [[Permanent|Permanents]] and Runes in [[Base|Bases]] other than their controller’s ^cr-323-6

<details class="rule-ref"><summary title="Core rule 323.6 · PDF page 41" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 323.6 · PDF page 41</div></details>

Remove all [[Hidden]] [[Card|cards]] from all [[Battlefield|Battlefields]] that are not controlled by the same player and place them in their owner's [[Trash]]. ^cr-323-6-a

<details class="rule-ref"><summary title="Core rule 323.6.a · PDF page 41" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 323.6.a · PDF page 41</div></details>

6. Mark a [[Showdowns|Showdown]] as Staged at each [[Battlefield]] that [[Contested]] was applied to and that has no ongoing [[Combat]]. ^cr-323-7

<details class="rule-ref"><summary title="Core rule 323.7 · PDF page 41" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 323.7 · PDF page 41</div></details>

The [[Showdowns|Showdown]] remains Staged at that [[Battlefield]] as long as it is [[Contested]] and has [[Unit|units]] present controlled by the player that applied Contested. ^cr-323-7-a

<details class="rule-ref"><summary title="Core rule 323.7.a · PDF page 41" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 323.7.a · PDF page 41</div></details>

7. Mark a [[Combat]] as Staged at each [[Battlefield]] that [[Contested]] was applied to that have [[Unit|Units]] present controlled by opposing players, and that has no ongoing Combat. ^cr-323-8

<details class="rule-ref"><summary title="Core rule 323.8 · PDF page 41" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 323.8 · PDF page 41</div></details>

7a. If [[Unit|Units]] of two opposing players are no longer present at a [[Battlefield]] that has a [[Combat]] Staged before it has opened, the Combat will cease being Staged ^cr-323-9

<details class="rule-ref"><summary title="Core rule 323.9 · PDF page 42" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 323.9 · PDF page 42</div></details>

8. Remove [[Contested]] status from each [[Battlefield]] without [[Unit|Units]] controlled by the player who applied Contested to that Battlefield and without a [[Showdowns|Showdown]] or [[Combat]] ongoing there. ^cr-323-10

<details class="rule-ref"><summary title="Core rule 323.10 · PDF page 42" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 323.10 · PDF page 42</div></details>

If as a result of the removal of [[Contested]] status there are [[Unit|Units]] located at an uncontested [[Battlefield]] that their controller does not [[Control|control]], their controller applies Contested status to that Battlefield. ^cr-323-10-a

<details class="rule-ref"><summary title="Core rule 323.10.a · PDF page 42" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 323.10.a · PDF page 42</div></details>

9. If the current state is a [[Neutral Open State]] and one or more [[Showdowns]] are Staged at [[Battlefield|Battlefields]] without a [[Combat]] staged, [[Turn|the Turn]] Player chooses one of those Battlefields. A Showdown begins there. ^cr-323-11

<details class="rule-ref"><summary title="Core rule 323.11 · PDF page 42" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 323.11 · PDF page 42</div></details>

10. If the current state is a [[Neutral Open State]] and one or more Combats are Staged at [[Battlefield|Battlefields]], [[Turn|the Turn]] Player chooses one of those Battlefields. [[Combat]] begins there. ^cr-323-12

<details class="rule-ref"><summary title="Core rule 323.12 · PDF page 42" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 323.12 · PDF page 42</div></details>

10a. If the current state is [[Showdown Open State]] and [[Combat]] is Staged at a [[Battlefield]] where there is a Non-Combat [[Showdowns|Showdown]] ongoing, that Showdown becomes a Combat Showdown. ^cr-323-13

<details class="rule-ref"><summary title="Core rule 323.13 · PDF page 42" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 323.13 · PDF page 42</div></details>

Special Cleanups are Cleanup steps invoked at specific times that have additional steps not present in a normal Cleanup. ^cr-324

<details class="rule-ref"><summary title="Core rule 324 · PDF page 42" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 324 · PDF page 42</div></details>

When a Special Cleanup is invoked, the [[Unique|unique]] steps added will be inserted and defined by the sub-section that invokes it. ^cr-324-1

**Example:** When a [[Combat]] Cleanup is invoked, the Combat section defines what steps are added to the Cleanup.

See [[Combat Procedure#^cr-468|The Resolution Step]] for more information.

**Example:** When an End of [[Turn]] Cleanup is invoked, the End of Turn Phase subsection defines what steps are added to the Cleanup.

See [[Ending Phase#^cr-317|The Ending Phase]] for more information.

<details class="rule-ref"><summary title="Core rule 324.1 · PDF page 42" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 324.1 · PDF page 42</div></details>

If events during a Special Cleanup require another Cleanup, a normal Cleanup is invoked, not another iteration of the Special Cleanup. ^cr-324-2

<details class="rule-ref"><summary title="Core rule 324.2 · PDF page 42" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 324.2 · PDF page 42</div></details>
