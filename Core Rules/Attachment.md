# Attachment

[[Start Here|Home]] · [[Concept Index|Find a concept]] · [[Core Rules Index|Core rules]]

<span title="Core rule 716"></span> ^cr-716

<details class="rule-ref"><summary title="Core rule 716 · PDF page 117" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 716 · PDF page 117</div></details>

[[Attach|Attaching]] is a [[Limited Action|limited action]] that causes [[Card|cards]] to become linked to each other to combine their effects in some way. This causes one card to become [[Attached]] and the other to become A [[Top-most Card|Top-Most Card]]. ^cr-717

See [[Attach#^cr-435|Attach]] for more information.

<details class="rule-ref"><summary title="Core rule 717 · PDF page 117" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 717 · PDF page 117</div></details>

[[Attached]] is the state of a [[Card|card]] being linked to another card in this way. ^cr-718

<details class="rule-ref"><summary title="Core rule 718 · PDF page 117" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 718 · PDF page 117</div></details>

A [[Card|card]] remains in this state until [[Detach|Detached]]. ^cr-718-1

<details class="rule-ref"><summary title="Core rule 718.1 · PDF page 117" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 718.1 · PDF page 117</div></details>

While in this state, the [[Card|card]]’s printed [[Rules Text]] is [[Inactive]]. ^cr-718-2

See [[Inactive#^cr-720|Inactive]] for more information.

<details class="rule-ref"><summary title="Core rule 718.2 · PDF page 117" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 718.2 · PDF page 117</div></details>

While in this state, [[Ability|Abilities]] in the [[Card|card]]’s [[Effect Text]] are appended to the [[Rules Text]] of the [[Top-most Card|Top-Most Card]]. ^cr-718-3

<details class="rule-ref"><summary title="Core rule 718.3 · PDF page 117" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 718.3 · PDF page 117</div></details>

While in this state, the [[Card|card]]’s [[Might Bonus]] modulates the [[Top-most Card|Top-Most Card]]’s [[Might]] by the value listed. ^cr-718-4

<details class="rule-ref"><summary title="Core rule 718.4 · PDF page 117" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 718.4 · PDF page 117</div></details>

[[Attached]] [[Card|cards]] still have all properties of being a card on [[Board|the board]] while in this state. ^cr-718-5

<details class="rule-ref"><summary title="Core rule 718.5 · PDF page 118" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 718.5 · PDF page 118</div></details>

[[Attached]] [[Card|cards]] still have all Types and Tags while Attached. ^cr-718-5-a

<details class="rule-ref"><summary title="Core rule 718.5.a · PDF page 118" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 718.5.a · PDF page 118</div></details>

[[Attached]] [[Card|cards]] still can be chosen or targeted by [[Game Effect|game effects]] while Attached. ^cr-718-5-b

<details class="rule-ref"><summary title="Core rule 718.5.b · PDF page 118" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 718.5.b · PDF page 118</div></details>

[[Attached]] [[Card|cards]] cannot be moved separately from the [[Top-most Card|Top-Most Card]] they are Attached to. ^cr-718-5-c

<details class="rule-ref"><summary title="Core rule 718.5.c · PDF page 118" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 718.5.c · PDF page 118</div></details>

A [[Card|card]] may be [[Attached]] only to a single [[Top-most Card|Top-Most card]] at a time. ^cr-718-5-d

<details class="rule-ref"><summary title="Core rule 718.5.d · PDF page 118" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 718.5.d · PDF page 118</div></details>

[[Attached]] [[Card|cards]] may have different Controllers from their [[Top-most Card|Top-Most card]]. ^cr-718-5-e

<details class="rule-ref"><summary title="Core rule 718.5.e · PDF page 118" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 718.5.e · PDF page 118</div></details>

Changes in [[Control]] of the [[Top-most Card|Top-Most card]] do not impact Control of [[Attached]] [[Card|cards]] and vice versa. ^cr-718-5-f

<details class="rule-ref"><summary title="Core rule 718.5.f · PDF page 118" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 718.5.f · PDF page 118</div></details>

An [[Attached]] [[Card|card]] still appends the [[Ability|abilities]] in its [[Effect Text]] to the [[Rules Text]] of the [[Top-most Card|Top-Most card]] and modulates the Top-Most Card’s [[Might]] by its [[Might Bonus]]. ^cr-718-5-g

<details class="rule-ref"><summary title="Core rule 718.5.g · PDF page 118" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 718.5.g · PDF page 118</div></details>

Only non-Unit [[Game Object|Game Objects]] may be [[Attached]]. ^cr-718-6

<details class="rule-ref"><summary title="Core rule 718.6 · PDF page 118" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 718.6 · PDF page 118</div></details>

If a non-Unit [[Game Object]] that is [[Attached]] becomes a [[Unit]] through any means, it [[Detach|detaches]] as it becomes a Unit. ^cr-718-6-a

<details class="rule-ref"><summary title="Core rule 718.6.a · PDF page 118" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 718.6.a · PDF page 118</div></details>

A [[Top-most Card|Top-Most Card]] is a [[Card|card]] that has one or more cards linked to it through the process of [[Attach|Attaching]]. ^cr-719

<details class="rule-ref"><summary title="Core rule 719 · PDF page 118" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 719 · PDF page 118</div></details>

The [[Effect Text]] of all [[Card|cards]] [[Attached]] to this card are appended to the [[Rules Text]] of this card for as long as they remain Attached. ^cr-719-1

<details class="rule-ref"><summary title="Core rule 719.1 · PDF page 118" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 719.1 · PDF page 118</div></details>

This [[Card|card]] ceases being a [[Top-most Card|Top-Most Card]] when there are no longer any cards [[Attached]] to it. ^cr-719-2

<details class="rule-ref"><summary title="Core rule 719.2 · PDF page 118" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 719.2 · PDF page 118</div></details>

A [[Top-most Card|Top-Most Card]] and all [[Card|cards]] [[Attached]] to it are at the same [[Location|location]]. ^cr-719-3

<details class="rule-ref"><summary title="Core rule 719.3 · PDF page 118" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 719.3 · PDF page 118</div></details>

When the [[Top-most Card|Top-Most Card]] changes [[Location|locations]], all [[Attached]] [[Card|cards]] change locations with it. ^cr-719-3-a

<details class="rule-ref"><summary title="Core rule 719.3.a · PDF page 118" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 719.3.a · PDF page 118</div></details>

The [[Exhaust|Exhausted]] and [[Ready]] state of the [[Top-most Card|Top-Most card]] does not affect nor change the status of the [[Attached]] [[Card|cards]] and vice versa. ^cr-719-4

<details class="rule-ref"><summary title="Core rule 719.4 · PDF page 118" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 719.4 · PDF page 118</div></details>

This is true of all statuses aside from [[Location|location]], [[Attached]], and Top-Most. ^cr-719-4-a

**Example:** If the [[Top-most Card|top-most card]] becomes [[Stun|stunned]], it does not affect the state of any [[Attached|attached]] [[Card|cards]].

**Example:** If an [[Attached|attached]] [[Card|card]] becomes empowered, it does not affect the state of its [[Top-most Card|top-most card]].

<details class="rule-ref"><summary title="Core rule 719.4.a · PDF page 118" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 719.4.a · PDF page 118</div></details>

When a [[Top-most Card|Top-Most Card]] changes [[Zone|zones]] from a [[Board|board]] zone to a non-board zone, all [[Attached]] [[Card|cards]] [[Detach]] from it, remaining in their current zones. ^cr-719-5

<details class="rule-ref"><summary title="Core rule 719.5 · PDF page 118" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 719.5 · PDF page 118</div></details>

The player that controls the [[Top-most Card|Top-Most Card]] that changed [[Zone|zones]] decides the order these [[Card|cards]] [[Detach]] in, and thus the order of any relevant effects that occur due to the Detach occurring. ^cr-719-5-a

<details class="rule-ref"><summary title="Core rule 719.5.a · PDF page 118" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 719.5.a · PDF page 118</div></details>
