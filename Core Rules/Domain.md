# Domain

[[Start Here|Home]] · [[Concept Index|Find a concept]] · [[Core Rules Index|Core rules]]

<span title="Core rule 134"></span> ^cr-134

<details class="rule-ref"><summary title="Core rule 134 · PDF page 12" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 134 · PDF page 12</div></details>

Most [[Card|cards]] belong to one or more of six Domains, identified by one or more [[Symbols|symbols]] in the lower right corner. ^cr-134-1

<details class="rule-ref"><summary title="Core rule 134.1 · PDF page 12" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 134.1 · PDF page 12</div></details>

Each Domain has an associated color, a [[Unique|unique]] symbol, and a shorthand used to represent that symbol in written text. ^cr-134-2

<details class="rule-ref"><summary title="Core rule 134.2 · PDF page 12" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 134.2 · PDF page 12</div></details>

Fury is associated with the color red and represented by a circular symbol with three projecting [[Points|points]]. Its shorthand is &#91;R&#93;. ^cr-134-2-a

<details class="rule-ref"><summary title="Core rule 134.2.a · PDF page 12" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 134.2.a · PDF page 12</div></details>

Calm is associated with the color green and represented by a symbol resembling a leaf. Its shorthand is &#91;G&#93;. ^cr-134-2-b

<details class="rule-ref"><summary title="Core rule 134.2.b · PDF page 12" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 134.2.b · PDF page 12</div></details>

Mind is associated with the color blue and represented by a symbol resembling a sun and moon. Its shorthand is &#91;B&#93;. ^cr-134-2-c

<details class="rule-ref"><summary title="Core rule 134.2.c · PDF page 12" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 134.2.c · PDF page 12</div></details>

Body is associated with the color orange and represented by a blocky diamond-shaped symbol. Its shorthand is &#91;O&#93;. ^cr-134-2-d

<details class="rule-ref"><summary title="Core rule 134.2.d · PDF page 12" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 134.2.d · PDF page 12</div></details>

Chaos is associated with the color purple and represented by a hexagonal symbol with swirls emanating from its center. Its shorthand is &#91;P&#93;. ^cr-134-2-e

<details class="rule-ref"><summary title="Core rule 134.2.e · PDF page 12" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 134.2.e · PDF page 12</div></details>

Order is associated with the color yellow and represented by an angular winged symbol. Its shorthand is &#91;Y&#93;. ^cr-134-2-f
