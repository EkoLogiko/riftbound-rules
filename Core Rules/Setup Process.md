Each player separates their [[Champion Legend]] and places it in the [[Legend Zone]]. ^cr-111

<details class="rule-ref"><summary title="Core rule 111 · PDF page 7" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 111 · PDF page 7</div></details>

Each player separates their [[Chosen Champion]] and places it in the [[Champion Zone]]. ^cr-112

<details class="rule-ref"><summary title="Core rule 112 · PDF page 7" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 112 · PDF page 7</div></details>

Each player sets aside their [[Battlefield|Battlefields]]. ^cr-113

<details class="rule-ref"><summary title="Core rule 113 · PDF page 7" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 113 · PDF page 7</div></details>

Your Mode of [[Play]] will dictate how these are used and placed into the [[Battlefield Zone]]. ^cr-113-1

See [[Modes of Play#^cr-483|Modes of Play]] for more information.

<details class="rule-ref"><summary title="Core rule 113.1 · PDF page 7" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 113.1 · PDF page 7</div></details>

Each player shuffles their Main and [[Rune]] Decks, separately, then places them into their respective [[Zone|Zones]]. ^cr-114

<details class="rule-ref"><summary title="Core rule 114 · PDF page 7" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 114 · PDF page 7</div></details>

The [[Main Deck]] is placed in the [[Main Deck Zone]]. ^cr-114-1

<details class="rule-ref"><summary title="Core rule 114.1 · PDF page 7" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 114.1 · PDF page 7</div></details>

The [[Rune Deck]] is placed in the [[Rune Deck Zone]]. ^cr-114-2

<details class="rule-ref"><summary title="Core rule 114.2 · PDF page 7" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 114.2 · PDF page 7</div></details>

Determine [[Turn]] Order using any fair random method agreed on by all players. ^cr-115

<details class="rule-ref"><summary title="Core rule 115 · PDF page 7" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 115 · PDF page 7</div></details>

[[Turn]] Order is established as a repeating set of the players. ^cr-115-1

<details class="rule-ref"><summary title="Core rule 115.1 · PDF page 8" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 115.1 · PDF page 8</div></details>

The Mode of [[Play]] will specify how to determine a First Player. ^cr-115-1-a

<details class="rule-ref"><summary title="Core rule 115.1.a · PDF page 8" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 115.1.a · PDF page 8</div></details>

If not otherwise specified, Seating then determines the sequence, [[Play|play]] proceeding clockwise from the First Player. ^cr-115-1-b

<details class="rule-ref"><summary title="Core rule 115.1.b · PDF page 8" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 115.1.b · PDF page 8</div></details>

The First Player is the player who becomes [[Turn|the Turn]] Player first. ^cr-115-1-b-1

<details class="rule-ref"><summary title="Core rule 115.1.b.1 · PDF page 8" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 115.1.b.1 · PDF page 8</div></details>

[[Turn|The Turn]] Order generates a looping queue of turns, starting with the First Player and repeating until the game ends. ^cr-115-1-c

<details class="rule-ref"><summary title="Core rule 115.1.c · PDF page 8" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 115.1.c · PDF page 8</div></details>

See the selected Mode of [[Play]] for any adjustments to each player's first [[Turn|turn]]. ^cr-115-2

See [[Modes of Play#^cr-483|Modes of Play]] for more information.

<details class="rule-ref"><summary title="Core rule 115.2 · PDF page 8" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 115.2 · PDF page 8</div></details>

Players each [[Draw|draw]] 4. ^cr-116

<details class="rule-ref"><summary title="Core rule 116 · PDF page 8" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 116 · PDF page 8</div></details>

In [[Turn|turn]] order, players perform their Mulligan. ^cr-117

<details class="rule-ref"><summary title="Core rule 117 · PDF page 8" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 117 · PDF page 8</div></details>

A player may choose up to two [[Card|cards]] in their [[Hand|hand]]. They set those cards aside. ^cr-117-1

<details class="rule-ref"><summary title="Core rule 117.1 · PDF page 8" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 117.1 · PDF page 8</div></details>

Then, that player draws as many [[Card|cards]] as they set aside. ^cr-117-2

<details class="rule-ref"><summary title="Core rule 117.2 · PDF page 8" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 117.2 · PDF page 8</div></details>

Finally, that player Recycles the [[Card|cards]] that were set aside. ^cr-117-3

See [[Recycle#^cr-417|Recycle]] for more information.

<details class="rule-ref"><summary title="Core rule 117.3 · PDF page 8" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 117.3 · PDF page 8</div></details>

Begin [[Play|play]] with the First Player taking their [[Turn|turn]]. ^cr-118
