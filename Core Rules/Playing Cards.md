Playing a [[Card|card]] is the act of a player utilizing their cards. ^cr-350

<details class="rule-ref"><summary title="Core rule 350 · PDF page 46" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 350 · PDF page 46</div></details>

A [[Card|card]] is Played when it has finished this process in its entirety. ^cr-350-1

<details class="rule-ref"><summary title="Core rule 350.1 · PDF page 46" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 350.1 · PDF page 46</div></details>

[[Token|Tokens]] are not [[Card|cards]], but can still be Played. ^cr-350-2

See [[Token#^cr-179|Tokens]] for more information.

<details class="rule-ref"><summary title="Core rule 350.2 · PDF page 46" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 350.2 · PDF page 46</div></details>

[[Card|Cards]] have different behaviors when played. ^cr-351

<details class="rule-ref"><summary title="Core rule 351 · PDF page 46" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 351 · PDF page 46</div></details>

[[Permanent|Permanents]] become [[Game Object|Game Objects]] when Played. ^cr-351-1

<details class="rule-ref"><summary title="Core rule 351.1 · PDF page 46" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 351.1 · PDF page 46</div></details>

[[Spell|Spells]] create [[Game Effect|game effects]] that are executed, then the [[Card|card]] is placed in the [[Trash|trash]] after resolving. ^cr-351-2

<details class="rule-ref"><summary title="Core rule 351.2 · PDF page 46" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 351.2 · PDF page 46</div></details>

[[Card|Cards]] have different states during the process of being played. ^cr-352

<details class="rule-ref"><summary title="Core rule 352 · PDF page 46" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 352 · PDF page 46</div></details>

When initially being played [[Card|cards]] are Pending, as [[Pending Chain Item|Pending Chain Items]]. ^cr-352-1

<details class="rule-ref"><summary title="Core rule 352.1 · PDF page 46" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 352.1 · PDF page 46</div></details>

Near the end of the process [[Card|cards]] will cease being Pending and become [[Finalized Chain Item|Finalized Chain Items]]. ^cr-352-2
