# Costs

<span title="Core rule 201"></span> ^cr-201

<details class="rule-ref"><summary title="Core rule 201 · PDF page 33" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 201 · PDF page 33</div></details>

Some [[Game Effect|Game Effects]] will instruct players to pay resources, spend [[Counter (Object)|counters]] or XP, or perform [[Game Action|game actions]] as a Cost in order to perform a linked Effect. ^cr-202

<details class="rule-ref"><summary title="Core rule 202 · PDF page 33" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 202 · PDF page 33</div></details>

Costs must be paid in order to get their linked Effect. ^cr-203

<details class="rule-ref"><summary title="Core rule 203 · PDF page 33" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 203 · PDF page 33</div></details>

Paying a Cost requires a player to perform the appropriate [[Game Action|game action]]: pay resources, spend [[Counter (Object)|counters]] or XP, [[Kill|kill]] [[Unit|units]], etc. ^cr-203-1

<details class="rule-ref"><summary title="Core rule 203.1 · PDF page 33" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 203.1 · PDF page 33</div></details>

The Cost is still considered paid even if the associated [[Game Action|game action]] is replaced. ^cr-203-2

<details class="rule-ref"><summary title="Core rule 203.2 · PDF page 33" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 203.2 · PDF page 33</div></details>

If the [[Game Action|game action]] associated with a Cost is impossible for any reason such that a player cannot perform it, then they cannot pay the Cost and they will not execute the linked Effect. ^cr-203-3

<details class="rule-ref"><summary title="Core rule 203.3 · PDF page 33" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 203.3 · PDF page 33</div></details>

Costs paid in this way [[Might|might]] be: ^cr-204

<details class="rule-ref"><summary title="Core rule 204 · PDF page 33" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 204 · PDF page 33</div></details>

[[Base]] Costs: These costs are the most fundamental costs that must be paid to finalize a [[Card|card]] or [[Ability|ability]]. ^cr-204-1

<details class="rule-ref"><summary title="Core rule 204.1 · PDF page 33" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 204.1 · PDF page 33</div></details>

On [[Card|cards]], the [[Base Cost]] is found in the upper left corner of the card. ^cr-204-1-a

<details class="rule-ref"><summary title="Core rule 204.1.a · PDF page 33" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 204.1.a · PDF page 33</div></details>

On [[Activated Ability|activated abilities]], the [[Base Cost]] is the resource or instruction written before the “:”. If there are multiple choices for costs to pay for an activated ability before the “:”, the Base Cost is whatever cost the player chooses from among those options. ^cr-204-1-b

**Example:** [[Legion]] Marauder is a [[Unit|unit]] that reads in part “&#91;[[Empower (Keyword)|Empower]]&#93; — &#91;1&#93; or &#91;C&#93;.” This is functionally short for “&#91;1&#93; or &#91;C&#93;: Empower me. [[Play]] only if not empowered.” When finalizing the [[Ability|ability]] to the [[Chain|chain]], the controller of the chain item will choose one of the [[Base|base]] costs to pay. That is the [[Base Cost|base cost]] of the ability.

<details class="rule-ref"><summary title="Core rule 204.1.b · PDF page 33" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 204.1.b · PDF page 33</div></details>

On [[Triggered Ability|Triggered Abilities]], the [[Base Cost]] if it is present is the [[Costs within Instructions]] that appears as the first part of the effect. It must be paid to finalize the triggered ability. ^cr-204-1-c

See [[Costs#^cr-204-3|Costs within Instructions]] for more information.

**Example:** Overzealous Fan is a [[Unit|unit]] that reads “When I defend, you may [[Kill|kill]] me to [[Move|move]] an [[Attacker|attacking]] unit to its [[Base|base]].” In order to finalize the [[Ability|ability]] to the [[Chain|chain]], its controller must kill Overzealous Fan.

<details class="rule-ref"><summary title="Core rule 204.1.c · PDF page 33-34" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 204.1.c · PDF page 33-34</div></details>

Additional Costs: These Costs are in addition to the [[Base Cost|base cost]] of the [[Card|card]] or [[Ability|ability]] and will include “as an [[Additional Cost|additional cost]].” ^cr-204-2

<details class="rule-ref"><summary title="Core rule 204.2 · PDF page 34" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 204.2 · PDF page 34</div></details>

Additional Costs must be paid to finalize the [[Card|card]] or [[Ability|ability]], in addition to the [[Base Cost|base cost]]. ^cr-204-2-a

<details class="rule-ref"><summary title="Core rule 204.2.a · PDF page 34" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 204.2.a · PDF page 34</div></details>

[[Costs within Instructions]]: These Costs are part of the resolution of a [[Spell|spell]] or [[Ability|ability]], and will take the form “&#91;do X&#93; to &#91;do Y&#93;.” ^cr-204-3

<details class="rule-ref"><summary title="Core rule 204.3 · PDF page 34" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 204.3 · PDF page 34</div></details>

When [[Costs within Instructions]] appear in [[Spell|spells]], [[Activated Ability|activated abilities]], or in later parts of [[Triggered Ability|triggered abilities]], the cost must be paid to get the effect during resolution of the spell or [[Ability|ability]]. ^cr-204-3-a

**Example:** Bullet Time is a [[Spell|spell]] that reads “Pay any amount of &#91;A&#93; to [[Deal|deal]] that much [[Damage|damage]] to all [[Enemy|enemy]] [[Unit|units]] at a [[Battlefield|battlefield]].” As the spell resolves, its controller pays any amount of &#91;A&#93; as a cost, and deals that much damage to all units at a battlefield as the effect.

**Example:** Ancient Henge is a [[Gear|gear]] that reads “&#91;[[Reaction (Keyword)|Reaction]]&#93;&#91;>&#93; &#91;E&#93;: Pay any amount of [[Energy]] to Add that much &#91;A&#93;.” As the [[Ability|ability]] resolves, its controller pays any amount of Energy as a cost, and Adds that much &#91;A&#93; as the effect.

**Example:** Insightful Investigator is a [[Unit|unit]] that reads “When you [[Play|play]] me, choose an opponent. They [[Reveal|reveal]] their [[Hand|hand]]. You may pay 2 XP to choose a [[Card|card]] from their hand. If you do, they [[Discard|discard]] that card and [[Draw|draw]] 1.” As the [[Ability|ability]] resolves, its controller may pay 2 XP as a cost, and chooses a card from that player’s hand as the effect.

<details class="rule-ref"><summary title="Core rule 204.3.a · PDF page 34" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 204.3.a · PDF page 34</div></details>

Applied Costs: These Costs are applied to one or more [[Game Action|Game Actions]], and typically take the form of a [[Passive Ability|passive ability]] with a Cost within [[Instructions]] preceded by “must.” ^cr-204-4

**Example:** Mageseeker Investigator reads in part “Opponents must pay &#91;A&#93; for each [[Unit|unit]] beyond the first to [[Move|move]] multiple units to my [[Battlefield|battlefield]] at the same time.” This is an [[Applied Cost|applied cost]].

<details class="rule-ref"><summary title="Core rule 204.4 · PDF page 34" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 204.4 · PDF page 34</div></details>

The associated [[Game Action]] is the linked Effect for the Cost. ^cr-204-4-a

<details class="rule-ref"><summary title="Core rule 204.4.a · PDF page 34" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 204.4.a · PDF page 34</div></details>

Applied Costs are paid as the [[Game Action]] is performed. They do not use the [[Chain|chain]] and cannot be reacted to. ^cr-204-4-b

<details class="rule-ref"><summary title="Core rule 204.4.b · PDF page 34" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 204.4.b · PDF page 34</div></details>

[[Ability|Abilities]] that Add resources with the [[Reaction (Keyword)|Reaction keyword]] can be activated at any time when costs need to be paid. ^cr-204-4-b-1

See [[Add#^cr-430|Add]] for more information.

<details class="rule-ref"><summary title="Core rule 204.4.b.1 · PDF page 34" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 204.4.b.1 · PDF page 34</div></details>

If a player can’t pay or chooses not to pay the [[Applied Cost]], they cannot perform the associated [[Game Action]]. ^cr-204-4-c

<details class="rule-ref"><summary title="Core rule 204.4.c · PDF page 34" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 204.4.c · PDF page 34</div></details>

An instruction that requires a player to pay resources or spend [[Counter (Object)|counters]] or XP that does not also have a linked Effect, is not a Cost. ^cr-205

**Example:** A [[Card|card]] effect reads, “When I attack, you may pay &#91;4&#93;&#91;C&#93;. If you do, [[Kill|kill]] a [[Unit|unit]] here.” Paying &#91;4&#93;&#91;C&#93; in this way is not a cost of the [[Ability|ability]], [[Base|base]] or otherwise, but a [[Game Action|game action]] being performed by a player. The later instruction checks whether the game action was performed, not whether a cost was paid—if paying &#91;4&#93;&#91;C&#93; was replaced for any reason, the later linked instruction will not execute.

<details class="rule-ref"><summary title="Core rule 205 · PDF page 34" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 205 · PDF page 34</div></details>

Effects that need to determine a [[Card|card]] or [[Token|token]]’s cost for any purpose always use its printed—or if a [[Copy|copy]] effect is applied, copied—cost, even if that cost is increased, decreased, or ignored as the card is played. ^cr-206

**Example:** Sky Splitter is a [[Spell|spell]] that costs &#91;8&#93; and says in part “This spell's [[Energy Cost|Energy cost]] is reduced by the highest [[Might]] among [[Unit|units]] you [[Control|control]].” Lux, Illuminated is a unit that says “When you [[Play|play]] a spell that costs 5 or more, give me +3 &#91;M&#93; this [[Turn|turn]].” If a player who controls Lux plays Sky Splitter, Lux’s [[Ability|ability]] will trigger, regardless of how much was actually paid for Sky Splitter.

**Example:** Defy is a [[Spell|spell]] which reads “Counter a spell that costs no more than &#91;4&#93; and no more than &#91;A&#93;.” Rocket Barrage is a spell that costs &#91;4&#93;&#91;C&#93; and has a [[Repeat]] cost of &#91;4&#93;&#91;C&#93;. Rocket Barrage is a legal target for Defy even if Rocket Barrage’s Repeat cost is paid, because Defy only checks the printed or copied cost of its target.

**Example:** Atakhan is a [[Unit|unit]] that reads in part “You may [[Kill|kill]] a [[Friendly|friendly]] unit as an [[Additional Cost|additional cost]] to [[Play|play]] me. If you do, I cost &#91;1&#93; less for each [[Energy]] it costs and &#91;Y&#93; less for each [[Power]] it costs.” If a player plays Atakhan and chooses to kill a Reflection [[Token|token]] that is currently a [[Copy|copy]] of Noxus Hopeful, Atakhan will cost &#91;4&#93; less.

<details class="rule-ref"><summary title="Core rule 206 · PDF page 34-35" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 206 · PDF page 34-35</div></details>

Effects that need to determine an [[Ability|ability]]’s cost for any purpose use its [[Base Cost|base cost]], ignoring any alterations to that base cost unless otherwise specified. ^cr-206-1

**Example:** A [[Card|card]] reads “When you [[Play|play]] an [[Activated Ability|activated ability]] with [[Energy Cost|Energy cost]] &#91;7&#93; or more, you may [[Exhaust|exhaust]] me to [[Ready|ready]] up to 2 [[Rune|runes]].” A [[Gear|gear]] has an activated ability that reads “&#91;12&#93;, [[Banish]] this: Choose an opponent. Banish all [[Unit|units]] they [[Control|control]]. This [[Ability|ability]] costs &#91;1&#93; less for each point the chosen opponent has.” The ability of the first card will trigger when the activated ability is played, even if the chosen opponent has 6 or more [[Points|points]].

**Example:** An [[Equipment|equipment]] has an [[Ability|ability]] that reads “[[Equip]] &#91;4&#93;&#91;A&#93;. This ability costs &#91;1&#93; less for each occupied [[Enemy|enemy]] [[Battlefield|battlefield]].” If its controller plays a [[Unit|unit]] with [[Weaponmaster]], the Weaponmaster trigger will refer to the cost including the alterations. This is because Weaponmaster specifies that it includes modifications to the cost.
