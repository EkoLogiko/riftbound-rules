# Linked Ability

[[Start Here|Home]] · [[Concept Index|Find a concept]] · [[Core Rules Index|Core rules]]

<span title="Core rule 394"></span> ^cr-394

<details class="rule-ref"><summary title="Core rule 394 · PDF page 75" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 394 · PDF page 75</div></details>

Linked Abilities are a set of [[Ability|Abilities]] with one or more of the component Abilities referencing the other Abilities in the set. ^cr-395

<details class="rule-ref"><summary title="Core rule 395 · PDF page 75" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 395 · PDF page 75</div></details>

Component [[Ability|Abilities]] can reference other Abilities in the set by means of referencing those Abilities directly or by referencing [[Game Object|Game Objects]] affected by or mentioned in another Ability in the set. ^cr-395-1

<details class="rule-ref"><summary title="Core rule 395.1 · PDF page 75" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 395.1 · PDF page 75</div></details>

In order for a set of [[Ability|Abilities]] to be Linked, they must be present in the printed Effect or [[Rules Text]] of the same [[Game Object]], or be granted by the same source to another Game Object. ^cr-396

**Example:** The Zero Drive is an [[Equipment]] [[Gear|gear]] whose [[Rules Text|rules text]] reads in part “&#91;3&#93;&#91;B&#93;, [[Banish]] this: [[Play]] all [[Unit|units]] banished with this, ignoring their [[Costs|costs]].” The Zero Drive’s [[Effect Text|effect text]] reads “&#91;Deathnkell&#93;&#91;>&#93; Banish me.” The granted [[Deathknell]] [[Ability|ability]] is linked with the Zero Drive’s [[Activated Ability|activated ability]].

<details class="rule-ref"><summary title="Core rule 396 · PDF page 75" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 396 · PDF page 75</div></details>

Linked Abilities can contain component [[Ability|Abilities]] of any type. ^cr-397

<details class="rule-ref"><summary title="Core rule 397 · PDF page 75" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 397 · PDF page 75</div></details>

A component Linked Ability that references a [[Game Object]] affected by another [[Ability]] in the set may only interact with Game Objects affected by the Abilities it is Linked with. ^cr-398

**Example:** The Zero Drive is an [[Equipment]] [[Gear|gear]] whose [[Rules Text|rules text]] reads in part “&#91;3&#93;&#91;B&#93;, [[Banish]] this: [[Play]] all [[Unit|units]] banished with this, ignoring their [[Costs|costs]].” Any units banished by effects other than component Linked Abilities in the same set as the [[Activated Ability|activated ability]] cannot be played when resolving the activated ability.
