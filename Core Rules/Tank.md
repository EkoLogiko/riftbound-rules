Tank is a [[Passive Ability]] [[Keywords|keyword]]. ^cr-815-1

<details class="rule-ref"><summary title="Core rule 815.1 · PDF page 132" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 815.1 · PDF page 132</div></details>

It is present on [[Unit|Units]]. ^cr-815-1-a

<details class="rule-ref"><summary title="Core rule 815.1.a · PDF page 132" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 815.1.a · PDF page 132</div></details>

It is functionally short for "I must be assigned [[Lethal Damage|lethal damage]] before any other [[Unit|unit]] with the same controller as me that does not have &#91;Tank&#93; during the [[Combat]] [[Damage]] step." ^cr-815-1-b

<details class="rule-ref"><summary title="Core rule 815.1.b · PDF page 132" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 815.1.b · PDF page 132</div></details>

It alters how players can elect to assign [[Combat|combat]] [[Damage|damage]] during combat. ^cr-815-1-c

<details class="rule-ref"><summary title="Core rule 815.1.c · PDF page 132" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 815.1.c · PDF page 132</div></details>

Players must still assign [[Lethal Damage|lethal damage]] to a [[Unit|unit]] before [[Movement|moving]] to the next when assigning their [[Damage|damage]]. ^cr-815-1-c-1

<details class="rule-ref"><summary title="Core rule 815.1.c.1 · PDF page 133" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 815.1.c.1 · PDF page 133</div></details>

If more than one [[Unit|unit]] with Tank is present with the same controller [[In Combat|in Combat]], [[Damage|damage]] may be assigned to any of them. Units without Tank are invalid assignments until all units with Tank have [[Lethal Damage|lethal damage]] assigned to them. ^cr-815-1-c-2

<details class="rule-ref"><summary title="Core rule 815.1.c.2 · PDF page 133" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 815.1.c.2 · PDF page 133</div></details>

Multiple instances of Tank are redundant. ^cr-815-2

<details class="rule-ref"><summary title="Core rule 815.2 · PDF page 133" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 815.2 · PDF page 133</div></details>

Tank, and whether or not a [[Unit|unit]] has Tank, is a characteristic of the Unit and may be checked or referenced by other [[Game Effect|Game Effects]]. ^cr-815-3
