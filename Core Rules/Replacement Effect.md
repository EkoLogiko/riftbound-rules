# Replacement Effect

<!-- flowchart-links:end -->


<span title="Core rule 367"></span> ^cr-367

<details class="rule-ref"><summary title="Core rule 367 · PDF page 62" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 367 · PDF page 62</div></details>

An [[Ability|ability]] that alters the application of another [[Game Effect|game effect]] or game rule. ^cr-368

<details class="rule-ref"><summary title="Core rule 368 · PDF page 62" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 368 · PDF page 62</div></details>

[[Passive Ability|Passive Abilities]] can be Replacement Effects. ^cr-368-1

<details class="rule-ref"><summary title="Core rule 368.1 · PDF page 62" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 368.1 · PDF page 62</div></details>

Replacement Effects intercede during the execution of a [[Game Effect]] and alter its execution. ^cr-369

<details class="rule-ref"><summary title="Core rule 369 · PDF page 62" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 369 · PDF page 62</div></details>

A Replacement Effect can usually be identified by the presence of the terms “as,” “would,” or "instead." ^cr-369-1

**Example:** Zhonya's Hourglass reads "The next time a [[Friendly|friendly]] [[Unit|unit]] would die, [[Kill|kill]] this instead. [[Heal]] that unit, [[Exhaust|exhaust]] it, and recall it." This is a replacement effect that alters the execution of any [[Game Effect]] that would kill a friendly unit.

**Example:** Undertitan is a [[Unit|unit]] that reads in part “As I’m [[Reveal|revealed]] from your deck, &#91;Add&#93; &#91;2&#93;.” This is a replacement effect that alters the execution of any [[Game Effect]] that reveals Undertitan from your deck.

<details class="rule-ref"><summary title="Core rule 369.1 · PDF page 62" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 369.1 · PDF page 62</div></details>

Some [[Game Action|Game Actions]] are themselves Replacement Effects. ^cr-369-2

**Example:** Burning Out is a replacement effect.

**Example:** Preventing [[Damage]] is a replacement effect.

<details class="rule-ref"><summary title="Core rule 369.2 · PDF page 62" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 369.2 · PDF page 62</div></details>

Replacement Effects that apply to a [[Unit|unit]] as it enters [[Board|the Board]] can be identified by describing how the unit enters, or by describing a [[Game Action|game action]] that occurs “as” a unit enters. ^cr-369-3

**Example:** Master Yi, Honed reads “I enter [[Ready|ready]].” This applies a replacement effect to the way that [[Unit|units]] normally enter. The event of him entering [[Exhaust|exhausted]] is replaced by one where he enters ready.

**Example:** Baron Nashor reads “As you [[Play|play]] me, add the Baron Pit [[Battlefield|battlefield]] [[Token|token]] to [[Board|the board]] if it's not there already. If you do, I enter there.” The last sentence of his [[Ability|ability]] is a replacement effect that replaces the event of him entering at his original play [[Location|location]] with him entering at the Baron Pit if it was created.

<details class="rule-ref"><summary title="Core rule 369.3 · PDF page 62" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 369.3 · PDF page 62</div></details>

A Replacement Effect can alter the typical [[Flow|flow]] of [[Play|play]], including other [[Card|cards]]' executions. ^cr-370

<details class="rule-ref"><summary title="Core rule 370 · PDF page 63" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 370 · PDF page 63</div></details>

Replacement Effects apply to any event or instruction that qualifies for their application. A Replacement Effect will specify the circumstances by which an event or instruction will qualify to be replaced. ^cr-370-1

<details class="rule-ref"><summary title="Core rule 370.1 · PDF page 63" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 370.1 · PDF page 63</div></details>

An event is the singular moment that results from a [[Game Action]] being performed or from a [[Game Object]] changing state. ^cr-370-1-a

**Example:** The moment that results from a [[Unit|unit]] being [[Kill|killed]] is an event that can be referenced by [[Game Effect|game effects]], or even skipped entirely.

**Example:** The moment that results from a [[Unit|unit]] becoming [[Mighty]] is an event that can be referenced by [[Game Effect|game effects]], or even skipped entirely.

<details class="rule-ref"><summary title="Core rule 370.1.a · PDF page 63" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 370.1.a · PDF page 63</div></details>

Modifying or replacing an event is the same as modifying or replacing that [[Game Action]] or change in state that generated that event. ^cr-370-1-a-1

**Example:** Zhonya’s Hourglass reads in part “If a [[Friendly|friendly]] [[Unit|unit]] would die, [[Kill|kill]] this instead. [[Heal]] that unit, [[Exhaust|exhaust]] it, and recall it.” A unit’s death being replaced by Zhonya’s Hourglass is the same as the kill action that caused that death not occurring.

**Example:** A [[Card|card]] reads in part “The next time an [[Enemy|enemy]] [[Unit|unit]] would become [[Mighty]] this [[Turn|turn]], [[Banish|banish]] it instead. Its controller plays a 3 &#91;M&#93; Mech unit [[Token|token]] to its [[Location|location]].” A unit becoming Mighty being replaced by this effect means the unit never became Mighty—no effects that trigger on units becoming Mighty will trigger.

<details class="rule-ref"><summary title="Core rule 370.1.a.1 · PDF page 63" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 370.1.a.1 · PDF page 63</div></details>

An event can occur simultaneously with other events only when those events are all the result of the same [[Game Action]] or change in state occurring. ^cr-370-1-a-2

**Example:** A [[Spell|spell]] reads in part “[[Kill]] up to two [[Unit|units]] at [[Battlefield|battlefields]].” When that spell resolves, the units targeted are killed simultaneously because their deaths result from the same [[Game Action|game action]].

**Example:** A [[Spell|spell]] reads in part “[[Kill]] a [[Friendly|friendly]] [[Unit|unit]]. If you do, kill an [[Enemy|enemy]] unit with no more [[Might]] than it.” When that spell resolves, the units are not killed simultaneously. There are two kill [[Game Action|game actions]] being performed in the [[Instructions|instructions]] of the spell. The friendly unit is killed first, followed by the enemy unit.

<details class="rule-ref"><summary title="Core rule 370.1.a.2 · PDF page 63" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 370.1.a.2 · PDF page 63</div></details>

When a Replacement Effect applies, it replaces the qualifying event with one or more [[Game Action|Game Actions]] or events, or the qualifying instruction with another instruction. ^cr-370-1-b

<details class="rule-ref"><summary title="Core rule 370.1.b · PDF page 63" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 370.1.b · PDF page 63</div></details>

In the case of Replacement Effects that describe a [[Game Action|game action]] to occur “as” an event occurs, the described event is replaced by that same event plus the game action being performed. ^cr-370-1-b-1

**Example:** Undertitan is a [[Unit|unit]] that reads in part “As I’m [[Reveal|revealed]] from your deck, &#91;Add&#93; &#91;2&#93;.” The event of Undertitan being revealed from your deck is replaced by Undertitan being revealed from your deck and adding &#91;2&#93; [[Energy]] to your [[Rune Pool]].

<details class="rule-ref"><summary title="Core rule 370.1.b.1 · PDF page 63" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 370.1.b.1 · PDF page 63</div></details>

Replacement Effects are applied before any qualifying event has actually occurred. ^cr-370-1-c

<details class="rule-ref"><summary title="Core rule 370.1.c · PDF page 63" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 370.1.c · PDF page 63</div></details>

If the Replacement Effect of a [[Game Object]] applies to an event that involves that same Game Object while it is in a secret [[Zone|zone]], it applies to and replaces such an event simultaneously with that event occurring instead. The replacing event still occurs in the order specified by the instruction that generated it, and the original event does not occur if it is replaced. ^cr-370-1-c-1

**Example:** Nocturne, Horrifying reads in part “As you look at or [[Reveal|reveal]] me from the top of your deck, you may [[Banish|banish]] me. If you do, you may [[Play|play]] me for &#91;A&#93;.” Because Nocturne’s replacement effect replaces an event that applies while he is in a secret [[Zone|zone]], it applies to the event of him being looked at or revealed from the top of a player’s [[Main Deck]] simultaneously with that event occurring.

**Example:** A [[Card|card]] reads in part “If you would [[Burn|burn]] this, you may burn this and an additional card instead.” Because the replacement effect applies to the card while it is in a secret [[Zone|zone]], it applies simultaneously with the event occurring. Another card reads “If a player would put a card into their [[Trash|trash]] from their [[Main Deck]], [[Banish|banish]] it instead.” This replacement effect is active on [[Board|the board]], and thus applies before the qualifying event occurs. Because these replacement effects are applied at different timings, they are applied in order. The card will be banished first, and subsequently its replacement effect will have nothing to replace.

<details class="rule-ref"><summary title="Core rule 370.1.c.1 · PDF page 63-64" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 370.1.c.1 · PDF page 63-64</div></details>

A Replacement Effect can only be applied once to an event, or to any [[Game Action|Game Actions]] or events that replace that event. ^cr-370-2

**Example:** A player plays a [[Spell|spell]] that reads “[[Gear|gear]] you [[Control|control]] become 1 &#91;M&#93; gear [[Unit|units]] this [[Turn|turn]].” They control two copies of Zhonya’s Hourglass when the spell resolves. If one of those copies is [[Kill|killed]], both of their Replacement Effects will be applied. Whichever is applied first, that Replacement Effect can’t be applied again. When it is applied, it kills its source, which creates an event the other can apply its Replacement Effect to. Once they’ve both applied their Replacement Effect to the original death event and the event that replaced it, they cannot go any further. At that point, whichever Zhonya’s Hourglass applied its Replacement Effect last will die.

<details class="rule-ref"><summary title="Core rule 370.2 · PDF page 64" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 370.2 · PDF page 64</div></details>

If a [[Game Object]] has a Replacement Effect that is active in a specific [[Zone|zone]], it is evaluated and subsequently applied if it enters that zone before an event occurs that it could replace. ^cr-370-3

**Example:** A [[Unit|unit]] that reads “if a unit you [[Control|control]] would die, you may [[Banish|banish]] me from your [[Trash|trash]] instead. If you do, [[Heal|heal]] that unit, [[Exhaust|exhaust]] it and recall it.” The first unit dies simultaneously with a 1 &#91;M&#93; Recruit [[Token|token]]. It does not enter the trash before the Recruit dies, so it will not be able to replace its death.

<details class="rule-ref"><summary title="Core rule 370.3 · PDF page 64" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 370.3 · PDF page 64</div></details>

A [[Game Object]] can apply its Replacement Effects to any qualifying events that occur simultaneously with it leaving the [[Zone|zone]] that its Replacement Effect is active in. ^cr-370-4

**Example:** Soraka, Wanderer has a Replacement Effect that reads, “If another [[Unit|unit]] you [[Control|control]] here would die, if it has less [[Might]] than me, instead [[Heal|heal]] it, [[Exhaust|exhaust]] it, and recall it.” Soraka’s replacement can be applied to any qualifying event that occurs simultaneously with her leaving [[Board|the board]], including to units that die simultaneously with her.

<details class="rule-ref"><summary title="Core rule 370.4 · PDF page 64" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 370.4 · PDF page 64</div></details>

Some Replacement Effects will begin with “once each [[Turn|turn]],” or “N times each turn.” ^cr-371

<details class="rule-ref"><summary title="Core rule 371 · PDF page 64" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 371 · PDF page 64</div></details>

These Replacement Effects may only be applied to the specified number of events each [[Turn|turn]]. Once they have been applied to that many events, they cannot be applied to a later event in the same turn. ^cr-371-1

<details class="rule-ref"><summary title="Core rule 371.1 · PDF page 64" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 371.1 · PDF page 64</div></details>

If the Replacement Effect says a player “may” apply the Replacement Effect, the player has the choice of whether or not to apply it. ^cr-371-2

<details class="rule-ref"><summary title="Core rule 371.2 · PDF page 64" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 371.2 · PDF page 64</div></details>

When an event the Replacement Effect could apply to occurs, the player who controls the Replacement Effect may choose to apply it to the event. ^cr-371-2-a

<details class="rule-ref"><summary title="Core rule 371.2.a · PDF page 64" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 371.2.a · PDF page 64</div></details>

If they do not, it has not been applied this [[Turn|turn]]. ^cr-371-2-b

**Example:** Zilean, Time mage reads “Once each [[Turn|turn]], if you would [[Play|play]] a [[Token|token]] [[Unit|unit]] while I'm at a [[Battlefield|battlefield]], you may play that token and an additional [[Copy|copy]] of it instead.” When his controller plays a token, they can choose not to apply the replacement effect to that event. If they do, they can choose to apply it to a later event of a token being played.

<details class="rule-ref"><summary title="Core rule 371.2.b · PDF page 64" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 371.2.b · PDF page 64</div></details>

If more than one Replacement Effect applies to the same event being executed, then the controller of the object being acted on determines the order the Replacement Effects will apply. ^cr-372

<details class="rule-ref"><summary title="Core rule 372 · PDF page 64" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 372 · PDF page 64</div></details>

If it is a player being acted on, that player decides the order the Replacement Effects will apply. ^cr-372-1

<details class="rule-ref"><summary title="Core rule 372.1 · PDF page 65" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 372.1 · PDF page 65</div></details>

If the affected object is an [[Uncontrolled Battlefield]] then the Current [[Turn Player]] decides the order the Replacement Effects will apply. ^cr-372-2

<details class="rule-ref"><summary title="Core rule 372.2 · PDF page 65" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 372.2 · PDF page 65</div></details>

If more than one event occurs simultaneously that Replacement Effects could apply to, each event is treated separately and individually for the purposes of Replacement Effects, and Replacement Effects with the same controller are applied in the order of their controller’s choosing. ^cr-373

**Example:** Two [[Unit|units]] controlled by the same player die in the same [[Cleanups|cleanup]]. That player also controls Zhonya’s Hourglass. They must decide which event to apply Zhonya’s Hourglass to first.

<details class="rule-ref"><summary title="Core rule 373 · PDF page 65" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 373 · PDF page 65</div></details>

Although these events are simultaneous, the applied Replacement Effects are ordered. If multiple applied Replacement Effects with different controllers would execute simultaneously, they execute in [[Turn|turn]] order. ^cr-373-1

<details class="rule-ref"><summary title="Core rule 373.1 · PDF page 65" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 373.1 · PDF page 65</div></details>

When executing Replacement Effects, the [[Game Action|Game Actions]] that comprise their [[Instructions|instructions]] are performed before any simultaneous unmodified events. ^cr-373-1-a

**Example:** Two [[Unit|units]] die simultaneously. One of those units has their death replaced by being healed, [[Exhaust|exhausted]], and recalled. The healing, exhausting, and recalling of that unit will be performed before the other dies.

<details class="rule-ref"><summary title="Core rule 373.1.a · PDF page 65" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 373.1.a · PDF page 65</div></details>

When applying Replacement Effects to events that occur simultaneously, each Replacement Effect may only be applied in one sequence, to any number of events that are qualified to be replaced. ^cr-373-2

**Example:** Soraka, Wanderer reads “If another [[Unit|unit]] you [[Control|control]] here would die, if it has less [[Might]] than me, instead [[Heal|heal]] it, [[Exhaust|exhaust]] it, and recall it.” Soraka dies simultaneously with two 1 &#91;M&#93; Recruit [[Token|tokens]] at the same [[Battlefield|battlefield]] and two 1 &#91;M&#93; Recruit tokens in [[Base|base]]. Soraka has a Guardian Angel [[Attached|attached]] to her when she dies, which appends “If I would die, [[Kill|kill]] Guardian Angel instead. Heal me, exhaust me, and recall me” to Soraka’s [[Rules Text|rules text]]. There are several possible ways to order the Replacement Effects being applied to the various events: If Soraka’s Replacement Effect is applied first, it saves the Recruits at the same battlefield as her but not the Recruits in base. If the Replacement Effect appended by Guardian Angel then saves Soraka, she cannot apply her Replacement Effect to the Recruits in base as her Replacement Effect has already been applied to an event simultaneous with it dying. If the Replacement Effect appended by Guardian Angel is applied first, it saves Soraka and [[Recalls|recalls]] her - then when Soraka’s Replacement Effect is applied, it can only save the Recruits in base.

<details class="rule-ref"><summary title="Core rule 373.2 · PDF page 65" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 373.2 · PDF page 65</div></details>

A sequence of Replacement Effects is an uninterrupted series of applications to a set of simultaneous events. ^cr-373-2-a

<details class="rule-ref"><summary title="Core rule 373.2.a · PDF page 65" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 373.2.a · PDF page 65</div></details>

A Replacement Effect that replaces an event or [[Game Action]] that is part of another Replacement Effect will not interrupt the sequence of the replaced Replacement Effect’s application. ^cr-373-2-a-1

<details class="rule-ref"><summary title="Core rule 373.2.a.1 · PDF page 65" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 373.2.a.1 · PDF page 65</div></details>

A Replacement Effect’s controller is the player that controls the source of the Replacement Effect. ^cr-374

<details class="rule-ref"><summary title="Core rule 374 · PDF page 65" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 374 · PDF page 65</div></details>

If an event that a Replacement Effect applies to would be modified by the [[Game Effect]] that generated that event, or the results of that event would be modified by a [[Game Action]] from a [[Linked Ability|linked ability]] that references the replaced event, the Replacement Effect will inherit those modifications. ^cr-375

**Example:** Treasure Hunter reads “When I [[Move|move]], [[Play|play]] a Gold [[Gear|gear]] [[Token|token]] [[Exhaust|exhausted]].” A Replacement Effect that says “if you would play a token gear, play that token and an additional [[Copy|copy]] instead” is applied to the event of the Gold gear token being played. The additional copy will also be exhausted, as it inherits the “exhausted” modification.

**Example:** Another Replacement Effect says “if you would [[Play|play]] a [[Token|token]], [[Draw|draw]] 1 instead.” The modification from Treasure Hunter’s [[Ability|ability]] cannot apply, so we ignore it.

**Example:** A [[Spell|spell]] reads “[[Play|play]] a [[Ready|ready]] 3 &#91;M&#93; Mech [[Token|token]]. Then do this: Give it [[Temporary]].” A Replacement Effect that says “if you would play a [[Unit|unit]] token, play that token and a 1 &#91;M&#93; Recruit token instead” is applied to the event of the Mech token being made. The Recruit token enters ready and is given Temporary.
