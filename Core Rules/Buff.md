# Buff

[[Start Here|Home]] · [[Concept Index|Find a concept]] · [[Core Rules Index|Core rules]]

<span title="Core rule 427"></span> ^cr-427

<details class="rule-ref"><summary title="Core rule 427 · PDF page 86" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 427 · PDF page 86</div></details>

Buffing is the action of placing a [[Buffs|Buff]] counter on a [[Unit]]. ^cr-427-1

See [[Buffs#^cr-701|Buffs]] for more information.

<details class="rule-ref"><summary title="Core rule 427.1 · PDF page 86" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 427.1 · PDF page 86</div></details>

A [[Buffs|Buff]] is also an object. ^cr-427-1-a

<details class="rule-ref"><summary title="Core rule 427.1.a · PDF page 86" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 427.1.a · PDF page 86</div></details>

To [[Buffs|Buff]] a [[Unit|unit]], place a Buff Counter on it if it does not have one already ^cr-427-1-b

<details class="rule-ref"><summary title="Core rule 427.1.b · PDF page 86" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 427.1.b · PDF page 86</div></details>

If the [[Unit|unit]] already has a [[Buffs|Buff]] Counter on it, it does not get another one. ^cr-427-1-b-1

<details class="rule-ref"><summary title="Core rule 427.1.b.1 · PDF page 86" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 427.1.b.1 · PDF page 86</div></details>

Some effects may grant a [[Game Object]] permission to be [[Buffs|Buffed]] multiple times. Such an effect ignores this restriction. ^cr-427-1-b-2

<details class="rule-ref"><summary title="Core rule 427.1.b.2 · PDF page 86" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 427.1.b.2 · PDF page 86</div></details>

[[Unit|Units]] with [[Buffs|Buff]] [[Counter (Object)|Counters]] can still be chosen for actions that Buff units, but will not be Buffed as part of the execution. ^cr-427-1-c

**Example:** A [[Spell|spell]] reads "[[Buffs|Buff]] a [[Unit|unit]]. Then, if it was buffed this way, [[Draw|draw]] a [[Card|card]]." It will place a buff counter on a unit that has no buff counter, and then its controller will draw a card. However, if the player chooses a unit with a buff counter on it already, then the card will not be drawn.

**Example:** A [[Unit|unit]] reads “When you [[Buffs|buff]] me, [[Ready|ready]] me.” If that unit is chosen for a [[Game Effect|game effect]] that would buff it and it is already buffed, its [[Ability|ability]] will not trigger.

<details class="rule-ref"><summary title="Core rule 427.1.c · PDF page 86" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 427.1.c · PDF page 86</div></details>

Buffing is a [[Limited Action]]. ^cr-427-2

<details class="rule-ref"><summary title="Core rule 427.2 · PDF page 86" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 427.2 · PDF page 86</div></details>

Players may only [[Buffs|Buff]] [[Unit|units]] when [[Game Effect|Game Effects]] direct them to do so. ^cr-427-2-a

<details class="rule-ref"><summary title="Core rule 427.2.a · PDF page 86" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 427.2.a · PDF page 86</div></details>

This action is formatted as "[[Buffs|Buff]] &#91;one or more [[Unit|units]]&#93;." e.g., "Buff a unit." e.g., "Buff a [[Friendly|friendly]] unit." e.g., "Buff two friendly units at the same [[Battlefield|battlefield]]." ^cr-427-3
