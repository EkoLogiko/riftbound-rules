# Passive Ability

[[Start Here|Home]] · [[Concept Index|Find a concept]] · [[Core Rules Index|Core rules]]

<span title="Core rule 363"></span> ^cr-363

<details class="rule-ref"><summary title="Core rule 363 · PDF page 61" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 363 · PDF page 61</div></details>

Conditions, rules, constraints, or statements that affect the course of regular [[Play|play]]. ^cr-364

<details class="rule-ref"><summary title="Core rule 364 · PDF page 61" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 364 · PDF page 61</div></details>

These [[Ability|abilities]] have a wide variety of formats to recognize. ^cr-364-1

**Example:** "I get +1 &#91;M&#93; while you have 2 or more [[Card|cards]] in your [[Hand|hand]]."

**Example:** "[[Friendly]] Yordles at my [[Battlefield|battlefield]] have &#91;[[Shield]]&#93;."

<details class="rule-ref"><summary title="Core rule 364.1 · PDF page 61" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 364.1 · PDF page 61</div></details>

They can be recognized by being statements of fact. ^cr-364-2

<details class="rule-ref"><summary title="Core rule 364.2 · PDF page 61" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 364.2 · PDF page 61</div></details>

Passive Abilities can be conditional. ^cr-364-3

<details class="rule-ref"><summary title="Core rule 364.3 · PDF page 61" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 364.3 · PDF page 61</div></details>

Conditional Passive Abilities can be recognized by the occurrence of "if" or "while" as part of the statement of the [[Ability|ability]]. ^cr-364-3-a

**Example:** "While I'm [[Attacker|attacking]] or [[Defender|defending]] [[Alone|alone]], I have +2 &#91;M&#93;."

**Example:** "If an opponent controls a [[Battlefield|battlefield]], I enter [[Ready|ready]]."

<details class="rule-ref"><summary title="Core rule 364.3.a · PDF page 62" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 364.3.a · PDF page 62</div></details>

### Presence on Permanents

^cr-365

<details class="rule-ref"><summary title="Core rule 365 · PDF page 62" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 365 · PDF page 62</div></details>

Passive Abilities of [[Permanent|Permanents]] are typically only active while on [[Board|the Board]]. ^cr-365-1

<details class="rule-ref"><summary title="Core rule 365.1 · PDF page 62" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 365.1 · PDF page 62</div></details>

### Presence on Card outside of the Board

^cr-366

<details class="rule-ref"><summary title="Core rule 366 · PDF page 62" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 366 · PDF page 62</div></details>

Passive Abilities of [[Card|cards]] in [[Zone|zones]] that are outside of [[Board|the Board]] will self-describe their context. ^cr-366-1

**Example:** The passive ability "[[Play]] me only during an opponent's [[Turn|turn]]." applies in any [[Zone|zone]] from which that [[Card|card]] can be played.

**Example:** Undying [[Legion]] has a passive ability that reads “&#91;Legion&#93;&#91;>&#93; You may [[Play|play]] me from your [[Trash|trash]] for &#91;3&#93;&#91;C&#93;.” That passive ability only applies when Undying Legion is in the trash.

<details class="rule-ref"><summary title="Core rule 366.1 · PDF page 62" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 366.1 · PDF page 62</div></details>

Passive Abilities can alter the [[Costs|costs]] of [[Card|cards]] as they are played. ^cr-366-2

<details class="rule-ref"><summary title="Core rule 366.2 · PDF page 62" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 366.2 · PDF page 62</div></details>

These apply at all times in any [[Zone|zone]] from which the [[Card|card]] with the [[Ability|ability]] can be played. ^cr-366-2-a

<details class="rule-ref"><summary title="Core rule 366.2.a · PDF page 62" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 366.2.a · PDF page 62</div></details>
