# Temporary

[[Start Here|Home]] · [[Concept Index|Find a concept]] · [[Core Rules Index|Core rules]]

<span title="Core rule 816"></span> ^cr-816

<details class="rule-ref"><summary title="Core rule 816 · PDF page 133" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 816 · PDF page 133</div></details>

Temporary is a [[Triggered Ability]] [[Keywords|keyword]]. ^cr-816-1

<details class="rule-ref"><summary title="Core rule 816.1 · PDF page 133" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 816.1 · PDF page 133</div></details>

It is present on [[Permanent|Permanents]]. ^cr-816-1-a

<details class="rule-ref"><summary title="Core rule 816.1.a · PDF page 133" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 816.1.a · PDF page 133</div></details>

It is functionally short for "At the start of this [[Permanent|permanent]]'s controller's [[Beginning Phase]], before [[Scoring|scoring]], [[Kill|kill]] this." ^cr-816-1-b

<details class="rule-ref"><summary title="Core rule 816.1.b · PDF page 133" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 816.1.b · PDF page 133</div></details>

The Trigger Condition is the controller of the [[Permanent|permanent]]'s [[Beginning Phase]] starting. ^cr-816-1-c

<details class="rule-ref"><summary title="Core rule 816.1.c · PDF page 133" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 816.1.c · PDF page 133</div></details>

Multiple instances of Temporary are redundant. ^cr-816-2

<details class="rule-ref"><summary title="Core rule 816.2 · PDF page 133" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 816.2 · PDF page 133</div></details>

Regardless of how many instances there are, the [[Ability|ability]] will only trigger once. ^cr-816-2-a

<details class="rule-ref"><summary title="Core rule 816.2.a · PDF page 133" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 816.2.a · PDF page 133</div></details>

Temporary, and whether or not a [[Permanent|permanent]] has Temporary, is a characteristic of the permanent and may be checked or referenced by other [[Game Effect|Game Effects]]. ^cr-816-3

<details class="rule-ref"><summary title="Core rule 816.3 · PDF page 133" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 816.3 · PDF page 133</div></details>
