# Can't Beats Can

[[Start Here|Home]] · [[Concept Index|Find a concept]] · [[Core Rules Index|Core rules]]

<span title="Core rule 054"></span> ^cr-054

<details class="rule-ref"><summary title="Core rule 054 · PDF page 1" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 054 · PDF page 1</div></details>

[[Card|Cards]] that forbid actions or effects, as a broad method of determination, supersede cards that allow or permit that same action or effect. ^cr-054-1

<details class="rule-ref"><summary title="Core rule 054.1 · PDF page 1" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 054.1 · PDF page 1</div></details>

If a [[Card|card]] specifies that an action can “only” be performed under certain circumstances, it cannot be performed under any other circumstances. ^cr-054-2

<details class="rule-ref"><summary title="Core rule 054.2 · PDF page 1" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 054.2 · PDF page 1</div></details>

When executing [[Card|card]] text, do as much as you can, ignoring impossible [[Instructions|instructions]]. ^cr-055

<details class="rule-ref"><summary title="Core rule 055 · PDF page 1" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 055 · PDF page 1</div></details>

If all of a [[Card|card]]’s [[Instructions|instructions]] are impossible, it is still played and resolved, but nothing happens. ^cr-055-1

<details class="rule-ref"><summary title="Core rule 055.1 · PDF page 1" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 055.1 · PDF page 1</div></details>

[[Card|Cards]] a player owns may never be placed into a non-Board [[Zone|zone]] belonging to another player. ^cr-056

<details class="rule-ref"><summary title="Core rule 056 · PDF page 1" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 056 · PDF page 1</div></details>

[[Non-Board Zones|Non-Board zones]] corresponding to a player include [[Main Deck]], [[Rune Deck]], [[Trash]], [[Hand]], [[Champion Zone|Chosen Champion zone]], and [[Banishment]]. ^cr-056-1

<details class="rule-ref"><summary title="Core rule 056.1 · PDF page 1" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 056.1 · PDF page 1</div></details>

If a [[Card|card]] would enter such a [[Zone|zone]], it goes to its owner’s corresponding zone instead. ^cr-056-2
