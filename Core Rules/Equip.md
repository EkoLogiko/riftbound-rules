# Equip

[[Start Here|Home]] · [[Concept Index|Find a concept]] · [[Core Rules Index|Core rules]]

<span title="Core rule 818"></span> ^cr-818

<details class="rule-ref"><summary title="Core rule 818 · PDF page 133" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 818 · PDF page 133</div></details>

Equip is an [[Activated Ability]] [[Keywords|keyword]]. ^cr-818-1

<details class="rule-ref"><summary title="Core rule 818.1 · PDF page 133" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 818.1 · PDF page 133</div></details>

Equip is present on [[Gear]] with the [[Tag|tag]] [[Equipment]]. ^cr-818-1-a

<details class="rule-ref"><summary title="Core rule 818.1.a · PDF page 133" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 818.1.a · PDF page 133</div></details>

Equip has a [[Costs|cost]] to activate and [[Attach|Attaches]] the [[Card|card]] with Equip to a chosen [[Unit]] when the cost is paid. ^cr-818-1-b

<details class="rule-ref"><summary title="Core rule 818.1.b · PDF page 133" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 818.1.b · PDF page 133</div></details>

Equip’s choice is a Target. ^cr-818-1-b-1

<details class="rule-ref"><summary title="Core rule 818.1.b.1 · PDF page 134" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 818.1.b.1 · PDF page 134</div></details>

The chosen [[Unit]] will become the [[Top-most Card|Top-Most Card]] for the [[Attach]] action. ^cr-818-1-b-2

<details class="rule-ref"><summary title="Core rule 818.1.b.2 · PDF page 134" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 818.1.b.2 · PDF page 134</div></details>

Equip is formatted as “Equip &#91;[[Costs|Cost]]&#93;” ^cr-818-1-c

<details class="rule-ref"><summary title="Core rule 818.1.c · PDF page 134" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 818.1.c · PDF page 134</div></details>

If paying [[Costs|costs]] or making choices for this [[Ability|ability]] causes [[Triggered Ability|triggered abilities]] to trigger, they will be placed on the [[Chain|chain]] above this ability in a Pending state. ^cr-818-1-c-1

See [[Activated Ability#^cr-376|Activated Abilities]] for more information.

<details class="rule-ref"><summary title="Core rule 818.1.c.1 · PDF page 134" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 818.1.c.1 · PDF page 134</div></details>

Equip is functionally short for “&#91;[[Costs|Cost]]&#93;: [[Attach]] this [[Gear|gear]] to a [[Unit|unit]] you [[Control|control]].” ^cr-818-1-c-2

<details class="rule-ref"><summary title="Core rule 818.1.c.2 · PDF page 134" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 818.1.c.2 · PDF page 134</div></details>

Equip [[Costs|costs]] may include both resource costs and non-resource costs. ^cr-818-1-c-3

<details class="rule-ref"><summary title="Core rule 818.1.c.3 · PDF page 134" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 818.1.c.3 · PDF page 134</div></details>

Equip [[Ability|abilities]] may also include text that alters the Equip [[Costs|cost]]. Such text is taken into account when determining a [[Card|card]]’s Equip cost when paying for the ability. ^cr-818-1-c-4

<details class="rule-ref"><summary title="Core rule 818.1.c.4 · PDF page 134" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 818.1.c.4 · PDF page 134</div></details>

Equip [[Ability|abilities]] may include text that alters the timing or [[Targeting|targeting]] of the Equip ability. ^cr-818-1-c-5

<details class="rule-ref"><summary title="Core rule 818.1.c.5 · PDF page 134" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 818.1.c.5 · PDF page 134</div></details>

When the [[Attach]] action completes from this [[Keywords|keyword]], the [[Unit]] that was chosen is considered to have been [[Equipped]] by the [[Gear]] with this [[Ability|ability]]. ^cr-818-2

<details class="rule-ref"><summary title="Core rule 818.2 · PDF page 134" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 818.2 · PDF page 134</div></details>

This is an event other [[Game Effect|Game Effects]] and [[Triggered Ability|Triggered Abilities]] can reference. ^cr-818-2-a

<details class="rule-ref"><summary title="Core rule 818.2.a · PDF page 134" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 818.2.a · PDF page 134</div></details>

[[Equipped]] is the state of a [[Top-most Card|Top-Most Card]] being [[Attached]] by one or more [[Card|cards]] that are [[Equipment]]. ^cr-818-3

<details class="rule-ref"><summary title="Core rule 818.3 · PDF page 134" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 818.3 · PDF page 134</div></details>

The state of being [[Equipped]] is synchronous with that of the [[Attached]] state of the [[Equipment]]. ^cr-818-3-a

<details class="rule-ref"><summary title="Core rule 818.3.a · PDF page 134" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 818.3.a · PDF page 134</div></details>

A [[Top-most Card|Top-Most Card]] is [[Equipped]] as long as one or more of its [[Attached]] [[Card|cards]] are [[Equipment]]. ^cr-818-3-b

<details class="rule-ref"><summary title="Core rule 818.3.b · PDF page 134" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 818.3.b · PDF page 134</div></details>

The state of being [[Equipped]] corresponds to a [[Top-most Card|Top-Most card]] having a [[Card|card]] with Equip that is [[Attached]] to it. ^cr-818-3-c

<details class="rule-ref"><summary title="Core rule 818.3.c · PDF page 134" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 818.3.c · PDF page 134</div></details>

Multiple instances of Equip are equivalent to multiple [[Activated Ability|Activated Abilities]] and can each be activated separately by paying the corresponding [[Costs|costs]]. ^cr-818-4

<details class="rule-ref"><summary title="Core rule 818.4 · PDF page 134" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 818.4 · PDF page 134</div></details>

Equip, and whether or not a [[Gear]] has Equip, is a characteristic of the Gear and may be checked or referenced by other [[Game Effect|Game Effects]]. ^cr-818-5

<details class="rule-ref"><summary title="Core rule 818.5 · PDF page 134" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 818.5 · PDF page 134</div></details>

Whether or not a [[Gear]] has Equip may be referenced even if the [[Rules Text]] of the Gear is [[Inactive]]. ^cr-818-5-a

See [[Attachment#^cr-716|Attachment]] for more information.

<details class="rule-ref"><summary title="Core rule 818.5.a · PDF page 134" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 818.5.a · PDF page 134</div></details>
