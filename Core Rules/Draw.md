# Draw

[[Start Here|Home]] · [[Concept Index|Find a concept]] · [[Core Rules Index|Core rules]]

<span title="Core rule 414"></span> ^cr-414

<details class="rule-ref"><summary title="Core rule 414 · PDF page 78" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 414 · PDF page 78</div></details>

Drawing a [[Card|card]] takes a single card from a [[Zone|zone]] and adds it to the player's [[Hand]]. ^cr-414-1

<details class="rule-ref"><summary title="Core rule 414.1 · PDF page 78" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 414.1 · PDF page 78</div></details>

Unless specified otherwise, drawing takes [[Card|cards]] from the top of the [[Main Deck]]. ^cr-414-1-a

<details class="rule-ref"><summary title="Core rule 414.1.a · PDF page 78" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 414.1.a · PDF page 78</div></details>

This is a [[Limited Action]]. ^cr-414-2

<details class="rule-ref"><summary title="Core rule 414.2 · PDF page 78" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 414.2 · PDF page 78</div></details>

Each player draws 1 during the [[Draw Phase]] on their [[Turn|turn]]. ^cr-414-2-a

<details class="rule-ref"><summary title="Core rule 414.2.a · PDF page 78" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 414.2.a · PDF page 78</div></details>

The player may draw [[Card|cards]] when instructed to do so by other [[Game Effect|game effects]]. ^cr-414-2-b

<details class="rule-ref"><summary title="Core rule 414.2.b · PDF page 78" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 414.2.b · PDF page 78</div></details>

This action, when instructed, is formatted as "Draw X." ^cr-414-3

<details class="rule-ref"><summary title="Core rule 414.3 · PDF page 78" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 414.3 · PDF page 78</div></details>

If a player attempts to draw more [[Card|cards]] than are available in their [[Main Deck]], they do the following: ^cr-414-4

<details class="rule-ref"><summary title="Core rule 414.4 · PDF page 78" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 414.4 · PDF page 78</div></details>

Draw as many as possible. ^cr-414-4-a

<details class="rule-ref"><summary title="Core rule 414.4.a · PDF page 78" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 414.4.a · PDF page 78</div></details>

Perform a [[Burn Out]]. ^cr-414-4-b

See [[Burn Out#^cr-432|Burn Out]] for more information.

<details class="rule-ref"><summary title="Core rule 414.4.b · PDF page 78" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 414.4.b · PDF page 78</div></details>

Draw the remaining [[Card|cards]] needed to complete the Draw action. ^cr-414-4-c

<details class="rule-ref"><summary title="Core rule 414.4.c · PDF page 78" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 414.4.c · PDF page 78</div></details>
