# Deck Construction

[[Start Here|Home]] · [[Concept Index|Find a concept]] · [[Core Rules Index|Core rules]]

<span title="Core rule 101"></span> ^cr-101

<details class="rule-ref"><summary title="Core rule 101 · PDF page 2" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 101 · PDF page 2</div></details>

Riftbound is a Trading [[Card]] Game where a player must provide their own cards to [[Play|play]] against other players. ^cr-102

<details class="rule-ref"><summary title="Core rule 102 · PDF page 2" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 102 · PDF page 2</div></details>

To [[Play|play]] Riftbound, a player must have a [[Main Deck]], a [[Rune Deck]], a [[Champion Legend]], and a number of [[Battlefield|Battlefields]] determined by the Mode of Play. These are collectively referred to as a player’s deck. ^cr-103

<details class="rule-ref"><summary title="Core rule 103 · PDF page 2" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 103 · PDF page 2</div></details>

[[Card|Cards]] in a player’s deck or rules of a Game Mode may indicate additional choices to be made while building the deck. ^cr-103-1

**Example:** A [[Unit|unit]] reads in part “If &#91;[[Card Name|Name]]&#93; is in your deck, choose 3 different [[Legend|legends]] in addition to your starting legend.” This decision is made while building the deck.

**Example:** The rules of a game mode read in part “Choose an additional [[Chosen Champion]] with a different [[Champion Tag]] and [[Domain]] than your [[Champion Legend]]. Place it in the [[Champion Zone]] at the start of the game alongside your other Chosen Champion. Your deck’s [[Domain Identity]] includes that additional Chosen Champion’s Domain, if applicable.” The Chosen Champion chosen this way is decided while building the deck.

<details class="rule-ref"><summary title="Core rule 103.1 · PDF page 2" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 103.1 · PDF page 2</div></details>

### 1 Champion Legend

^cr-103-2

<details class="rule-ref"><summary title="Core rule 103.2 · PDF page 2" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 103.2 · PDF page 2</div></details>

This is placed in the [[Legend Zone]] at the start of the game. ^cr-103-2-a

<details class="rule-ref"><summary title="Core rule 103.2.a · PDF page 2" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 103.2.a · PDF page 2</div></details>

This will dictate the [[Domain Identity]] of the deck. ^cr-103-2-b

<details class="rule-ref"><summary title="Core rule 103.2.b · PDF page 2" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 103.2.b · PDF page 2</div></details>

[[Card|Cards]] included in your deck must abide by your [[Domain Identity]]. ^cr-103-2-b-1

<details class="rule-ref"><summary title="Core rule 103.2.b.1 · PDF page 2" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 103.2.b.1 · PDF page 2</div></details>

Your deck’s [[Domain Identity]] is dictated by the domains of your [[Champion Legend]]. In the default [[Card|card]] frame, these domains appear as [[Symbols|symbols]] in the [[Legend|legend]]’s upper left corner. ^cr-103-2-b-2

<details class="rule-ref"><summary title="Core rule 103.2.b.2 · PDF page 2" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 103.2.b.2 · PDF page 2</div></details>

If a [[Card|card]] has a single [[Domain]], then that card is permitted in the [[Domain Identity]] that corresponds to the same Domain. ^cr-103-2-b-3

<details class="rule-ref"><summary title="Core rule 103.2.b.3 · PDF page 2" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 103.2.b.3 · PDF page 2</div></details>

If a [[Card|card]] has more than one [[Domain]], then that card is permitted only in a [[Domain Identity]] that contains all of the indicated Domains on that card. ^cr-103-2-b-4

<details class="rule-ref"><summary title="Core rule 103.2.b.4 · PDF page 2" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 103.2.b.4 · PDF page 2</div></details>

If a [[Card|card]] has no [[Domain]], then that card is permitted in decks of any [[Domain Identity]]. ^cr-103-2-b-5

<details class="rule-ref"><summary title="Core rule 103.2.b.5 · PDF page 2" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 103.2.b.5 · PDF page 2</div></details>

Some [[Game Effect|Game Effects]] may allow a player to add [[Card|cards]] to their deck irrespective of those cards’ Domains. Those cards are considered part of their deck’s [[Domain Identity]], regardless of their [[Domain]]. ^cr-103-2-b-6

<details class="rule-ref"><summary title="Core rule 103.2.b.6 · PDF page 2" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 103.2.b.6 · PDF page 2</div></details>

A [[Main Deck]] of at least 40 [[Card|cards]]: A [[Chosen Champion]] [[Unit]], as well as Units, [[Gear]], and [[Spell|Spells]] ^cr-103-3

<details class="rule-ref"><summary title="Core rule 103.3 · PDF page 2" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 103.3 · PDF page 2</div></details>

### Chosen Champion

^cr-103-3-a

<details class="rule-ref"><summary title="Core rule 103.3.a · PDF page 2" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 103.3.a · PDF page 2</div></details>

This will be placed in the [[Champion Zone]] at the start of the game. ^cr-103-3-a-1

<details class="rule-ref"><summary title="Core rule 103.3.a.1 · PDF page 2" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 103.3.a.1 · PDF page 2</div></details>

Must be a [[Champion|champion unit]] with a [[Champion Tag|champion tag]] that matches the [[Tag|tag]] on your [[Champion Legend]]. ^cr-103-3-a-2

**Example:** Loose Cannon has the [[Tag|tag]] Jinx. Therefore, a player could choose Jinx, Rebel or Jinx, Demolitionist as their [[Chosen Champion]], because they also have the tag Jinx.

**Example:** Tibbers has the [[Tag|tag]] Annie, but it is a [[Signature|signature]] [[Unit|unit]], not a [[Champion|champion unit]]. It cannot be your [[Chosen Champion]], even if your [[Champion Legend]] has the tag Annie.

<details class="rule-ref"><summary title="Core rule 103.3.a.2 · PDF page 2-3" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 103.3.a.2 · PDF page 2-3</div></details>

A player’s [[Chosen Champion]] is both the specific [[Card|card]] chosen for this slot during Deck Building and also any [[Champion|Champion Unit]] with the same [[Card Name|name]] as the specific card selected for this specific slot during the course of [[Play|play]]. ^cr-103-3-a-3

**Example:** A player chose Jinx, Rebel as their [[Chosen Champion]]. One [[Copy|copy]] of Jinx, Rebel starts the game in their [[Champion Zone|Chosen Champion zone]]. Any additional copies of Jinx, Rebel in their [[Main Deck]], their [[Hand|hand]], their [[Trash|trash]], or on [[Board|the board]] also count as their Chosen Champion for any game rules and effects that care about Chosen Champion status during the game.

<details class="rule-ref"><summary title="Core rule 103.3.a.3 · PDF page 3" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 103.3.a.3 · PDF page 3</div></details>

Your [[Main Deck]] can include up to 3 copies of the same named [[Card|card]]. ^cr-103-3-b

<details class="rule-ref"><summary title="Core rule 103.3.b · PDF page 3" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 103.3.b · PDF page 3</div></details>

This includes your [[Chosen Champion]]. ^cr-103-3-b-1

**Example:** A deck could include Volibear, Furious as its [[Chosen Champion]] and still include 2 more copies of Volibear, Furious in their [[Main Deck]].

<details class="rule-ref"><summary title="Core rule 103.3.b.1 · PDF page 3" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 103.3.b.1 · PDF page 3</div></details>

[[Card|Cards]] have different names even if they represent the same character. ^cr-103-3-b-2

**Example:** A deck could include 3 copies of Yasuo, Remorseful and 3 copies of Yasuo, Windrider, because they have different names.

<details class="rule-ref"><summary title="Core rule 103.3.b.2 · PDF page 3" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 103.3.b.2 · PDF page 3</div></details>

Subject to [[Domain Identity]]. ^cr-103-3-c

<details class="rule-ref"><summary title="Core rule 103.3.c · PDF page 3" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 103.3.c · PDF page 3</div></details>

Your deck may only contain 3 total [[Signature|Signature cards]] that have the same [[Champion Tag|Champion tag]] as your [[Champion Legend]]. ^cr-103-3-d

<details class="rule-ref"><summary title="Core rule 103.3.d · PDF page 3" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 103.3.d · PDF page 3</div></details>

Regardless of [[Card Name|name]], a deck may only contain a sum total of 3 [[Signature|Signature cards]]. ^cr-103-3-d-1

<details class="rule-ref"><summary title="Core rule 103.3.d.1 · PDF page 3" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 103.3.d.1 · PDF page 3</div></details>

All of the [[Signature|Signature cards]] must have the [[Champion Tag|Champion tag]] that corresponds to the [[Champion Legend]] of the deck. ^cr-103-3-d-2

<details class="rule-ref"><summary title="Core rule 103.3.d.2 · PDF page 3" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 103.3.d.2 · PDF page 3</div></details>

[[Signature|Signature cards]] are not [[Champion|Champion units]] and cannot be placed in the [[Champion Zone]]. ^cr-103-3-d-3

<details class="rule-ref"><summary title="Core rule 103.3.d.3 · PDF page 3" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 103.3.d.3 · PDF page 3</div></details>

Subject to [[Card|card]] legality of the Format being played. ^cr-103-3-e

<details class="rule-ref"><summary title="Core rule 103.3.e · PDF page 3" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 103.3.e · PDF page 3</div></details>
