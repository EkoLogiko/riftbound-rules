# Counter (Object)

[[Start Here|Home]] · [[Concept Index|Find a concept]] · [[Core Rules Index|Core rules]]

<span title="Core rule 741"></span> ^cr-741

<details class="rule-ref"><summary title="Core rule 741 · PDF page 122" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 741 · PDF page 122</div></details>

Counters are [[Game Object|Game Objects]] generated by and given to other Game Objects on [[Board|the board]] during [[Play|play]]. ^cr-742

<details class="rule-ref"><summary title="Core rule 742 · PDF page 122" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 742 · PDF page 122</div></details>

Unlike other [[Game Object|Game Objects]], Counters are not targeted by [[Spell|spells]] and [[Ability|abilities]]. If an effect instructs a player to interact with a Counter, the Counter is chosen when the corresponding instruction executes. ^cr-742-1

<details class="rule-ref"><summary title="Core rule 742.1 · PDF page 122" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 742.1 · PDF page 122</div></details>

Counters serve to track semi-permanent effects on [[Game Object|Game Objects]]. ^cr-743

<details class="rule-ref"><summary title="Core rule 743 · PDF page 122" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 743 · PDF page 122</div></details>

Counters can have [[Game Effect|game effects]] themselves, or serve as the prerequisite for game effects. ^cr-744

<details class="rule-ref"><summary title="Core rule 744 · PDF page 122" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 744 · PDF page 122</div></details>

Counters can be spent by [[Game Effect|game effects]]. ^cr-745

<details class="rule-ref"><summary title="Core rule 745 · PDF page 122" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 745 · PDF page 122</div></details>

In order to do so, that player must remove that many counters of the specified type from the specified [[Game Object|Game Objects]]. ^cr-745-1

<details class="rule-ref"><summary title="Core rule 745.1 · PDF page 122" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 745.1 · PDF page 122</div></details>

If no type of counter is specified, any counter can be removed this way. ^cr-745-1-a

<details class="rule-ref"><summary title="Core rule 745.1.a · PDF page 122" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 745.1.a · PDF page 122</div></details>

If no type of [[Game Object]] is specified, then counters can be removed from any Game Objects with the specified counter. ^cr-745-1-b

<details class="rule-ref"><summary title="Core rule 745.1.b · PDF page 122" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 745.1.b · PDF page 122</div></details>

In order to spend a Counter, the spending player must [[Control|control]] the [[Game Object]] the Counter is placed on. ^cr-745-2

<details class="rule-ref"><summary title="Core rule 745.2 · PDF page 122" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 745.2 · PDF page 122</div></details>

Some effects may [[Move|move]] a Counter between two [[Game Object|Game Objects]]. The Counter is either on the first Game Object or the second. There is no state for a Counter being between either object. ^cr-746

<details class="rule-ref"><summary title="Core rule 746 · PDF page 122" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 746 · PDF page 122</div></details>

Counters that leave a [[Game Object]] without being placed on another game object cease to exist. ^cr-747

<details class="rule-ref"><summary title="Core rule 747 · PDF page 122" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 747 · PDF page 122</div></details>

[[Game Object|Game Objects]] that change [[Zone|zones]] to a non-board zone lose all of their Counters. ^cr-748

See [[Game Object#^cr-124|Game Object]] for more information on [[Temporary|temporary]] modifications.

<details class="rule-ref"><summary title="Core rule 748 · PDF page 122" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 748 · PDF page 122</div></details>

Counters do not have a controller. ^cr-749
