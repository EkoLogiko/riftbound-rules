# Hide

[[Start Here|Home]] · [[Concept Index|Find a concept]] · [[Core Rules Index|Core rules]]

<span title="Core rule 422"></span> ^cr-422

<details class="rule-ref"><summary title="Core rule 422 · PDF page 83" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 422 · PDF page 83</div></details>

Hiding a [[Card|card]] is the act of placing a card facedown at a [[Battlefield]] you [[Control|control]]. ^cr-422-1

<details class="rule-ref"><summary title="Core rule 422.1 · PDF page 83" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 422.1 · PDF page 83</div></details>

Hiding is a [[Discretionary Action]]. ^cr-422-2

<details class="rule-ref"><summary title="Core rule 422.2 · PDF page 83" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 422.2 · PDF page 83</div></details>

The [[Hidden]] [[Keywords|keyword]] allows a player to pay a [[Costs|cost]] to Hide a [[Card|card]] any time they have a Hidden card in their [[Hand|hand]] or [[Champion Zone]] and meet the prerequisites. ^cr-422-2-a

See [[Hidden#^cr-811|Hidden]] for more information.

<details class="rule-ref"><summary title="Core rule 422.2.a · PDF page 83" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 422.2.a · PDF page 83</div></details>

[[Card|Cards]] that are facedown at [[Battlefield|Battlefields]] have their gameplay properties and permissions defined by the effect that put them there. ^cr-422-3

**Example:** [[Card|Cards]] that players Hide with the [[Hidden]] [[Keywords|keyword]] can be Played for &#91;0&#93; on any subsequent [[Turn|turn]] as a property of the Hidden keyword.

<details class="rule-ref"><summary title="Core rule 422.3 · PDF page 83" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 422.3 · PDF page 83</div></details>

If a facedown [[Card|card]] would change [[Zone|zones]] or if the game ends, its owner reveals it to all players. ^cr-422-4

See [[Privacy#^cr-128|Privacy]] for more information.
