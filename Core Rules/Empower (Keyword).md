# Empower (Keyword)

[[Start Here|Home]] · [[Concept Index|Find a concept]] · [[Core Rules Index|Core rules]]

<span title="Core rule 827"></span> ^cr-827

<details class="rule-ref"><summary title="Core rule 827 · PDF page 139" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 827 · PDF page 139</div></details>

Empower is an [[Activated Ability]] [[Keywords|keyword]]. ^cr-827-1

<details class="rule-ref"><summary title="Core rule 827.1 · PDF page 139" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 827.1 · PDF page 139</div></details>

Empower is normally present on [[Permanent|permanents]] and [[Legend|legends]]. ^cr-827-1-a

<details class="rule-ref"><summary title="Core rule 827.1.a · PDF page 139" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 827.1.a · PDF page 139</div></details>

Empower has a [[Costs|cost]] to activate and Empowers the source of the [[Ability|ability]] when the cost is paid. ^cr-827-1-b

See [[Empower (Game Action)#^cr-442|Empower (Game Action)]] for more information.

<details class="rule-ref"><summary title="Core rule 827.1.b · PDF page 139" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 827.1.b · PDF page 139</div></details>

The source [[Game Object|game object]] is not a target of the Empower [[Ability|ability]]. ^cr-827-1-b-1

<details class="rule-ref"><summary title="Core rule 827.1.b.1 · PDF page 139" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 827.1.b.1 · PDF page 139</div></details>

Empower is formatted as “Empower &#91;[[Costs|Cost]]&#93;” ^cr-827-1-c

<details class="rule-ref"><summary title="Core rule 827.1.c · PDF page 139" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 827.1.c · PDF page 139</div></details>

Empower is functionally short for “&#91;[[Costs|Cost]]&#93;: Empower this. [[Play]] only if not Empowered.” ^cr-827-1-c-1

<details class="rule-ref"><summary title="Core rule 827.1.c.1 · PDF page 139" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 827.1.c.1 · PDF page 139</div></details>

Empower [[Costs|costs]] may include both resource costs and non-resource costs. ^cr-827-1-c-2

<details class="rule-ref"><summary title="Core rule 827.1.c.2 · PDF page 139" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 827.1.c.2 · PDF page 139</div></details>

Empower [[Ability|abilities]] may also include text that alters the Empower [[Costs|cost]]. Such text is taken into account when determining a [[Card|card]]’s Empower cost for any reason. ^cr-827-1-c-3

<details class="rule-ref"><summary title="Core rule 827.1.c.3 · PDF page 139" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 827.1.c.3 · PDF page 139</div></details>

Empower [[Ability|abilities]] may include text that alters the timing of the Empower ability. ^cr-827-1-c-4

<details class="rule-ref"><summary title="Core rule 827.1.c.4 · PDF page 139" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 827.1.c.4 · PDF page 139</div></details>

[[Game Object|Game Objects]] with Empower [[Ability|abilities]] may have or gain permissions to be Empowered multiple times. Such Game Objects ignore the normal “[[Play]] only if not Empowered.” restriction on Empower abilities. ^cr-827-1-c-5

<details class="rule-ref"><summary title="Core rule 827.1.c.5 · PDF page 139" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 827.1.c.5 · PDF page 139</div></details>

When the [[Empower (Game Action)|Empower action]] completes from this [[Keywords|keyword]], the source [[Permanent|permanent]] or [[Legend|legend]] becomes Empowered. ^cr-827-2

<details class="rule-ref"><summary title="Core rule 827.2 · PDF page 139" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 827.2 · PDF page 139</div></details>

This is an event other [[Game Effect|Game Effects]] and [[Triggered Ability|Triggered Abilities]] can reference. ^cr-827-2-a

<details class="rule-ref"><summary title="Core rule 827.2.a · PDF page 139" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 827.2.a · PDF page 139</div></details>

Multiple instances of Empower are equivalent to multiple [[Activated Ability|activated abilities]] and can each be activated separately by paying the corresponding [[Costs|costs]]. ^cr-827-3

<details class="rule-ref"><summary title="Core rule 827.3 · PDF page 139" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 827.3 · PDF page 139</div></details>

Empower and whether a [[Permanent|permanent]] or [[Legend|legend]] has Empower are a characteristic of those [[Game Object|Game Objects]] and may be checked or referenced by other [[Game Effect|Game Effects]]. ^cr-827-4

<details class="rule-ref"><summary title="Core rule 827.4 · PDF page 139" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 827.4 · PDF page 139</div></details>
