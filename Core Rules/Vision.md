# Vision

[[Start Here|Home]] · [[Concept Index|Find a concept]] · [[Core Rules Index|Core rules]]

<span title="Core rule 817"></span> ^cr-817

<details class="rule-ref"><summary title="Core rule 817 · PDF page 133" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 817 · PDF page 133</div></details>

Vision is a [[Triggered Ability]] [[Keywords|keyword]]. ^cr-817-1

<details class="rule-ref"><summary title="Core rule 817.1 · PDF page 133" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 817.1 · PDF page 133</div></details>

It is present on [[Permanent|Permanents]]. ^cr-817-1-a

<details class="rule-ref"><summary title="Core rule 817.1.a · PDF page 133" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 817.1.a · PDF page 133</div></details>

It is functionally short for "When this is played, &#91;[[Predict]]&#93;.” ^cr-817-1-b

<details class="rule-ref"><summary title="Core rule 817.1.b · PDF page 133" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 817.1.b · PDF page 133</div></details>

The trigger is the [[Permanent|permanent]] entering [[Board|the Board]]. ^cr-817-1-c

<details class="rule-ref"><summary title="Core rule 817.1.c · PDF page 133" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 817.1.c · PDF page 133</div></details>

Multiple instances of Vision trigger separately. ^cr-817-2

<details class="rule-ref"><summary title="Core rule 817.2 · PDF page 133" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 817.2 · PDF page 133</div></details>

The player may choose to [[Recycle|recycle]] or not recycle for each instance of Vision separately. ^cr-817-2-a

<details class="rule-ref"><summary title="Core rule 817.2.a · PDF page 133" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 817.2.a · PDF page 133</div></details>

If the player does not [[Recycle|recycle]] the top [[Card|card]] and nothing else happens in between the triggers resolving, each instance of Vision will see the same card. ^cr-817-2-b

<details class="rule-ref"><summary title="Core rule 817.2.b · PDF page 133" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 817.2.b · PDF page 133</div></details>

Vision, and whether or not a [[Permanent|permanent]] has Vision, is a characteristic of the permanent and may be checked or referenced by other [[Game Effect|Game Effects]]. ^cr-817-3

<details class="rule-ref"><summary title="Core rule 817.3 · PDF page 133" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 817.3 · PDF page 133</div></details>
