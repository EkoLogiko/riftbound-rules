# Card Category

[[Start Here|Home]] · [[Concept Index|Find a concept]] · [[Core Rules Index|Core rules]]

<span title="Core rule 133"></span> ^cr-133

<details class="rule-ref"><summary title="Core rule 133 · PDF page 11" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 133 · PDF page 11</div></details>

A [[Card|card]] can have one or more Categories and Sub-Categories based on the properties of its front and back sides. ^cr-133-1

<details class="rule-ref"><summary title="Core rule 133.1 · PDF page 11" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 133.1 · PDF page 11</div></details>

These Categories and Sub-Categories dictate the behaviors of the [[Card|card]] during [[Play|play]]. ^cr-133-2

<details class="rule-ref"><summary title="Core rule 133.2 · PDF page 11" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 133.2 · PDF page 11</div></details>

[[Spell|Spells]] and other effects can refer to categories, sub-categories, [[Supertype|supertypes]], [[Card|card]] types, tags, and other characteristics inclusively or exclusively. ^cr-133-3

**Example:** A "non-unit [[Card|card]]" is any card that is not a [[Unit|unit]].

**Example:** A "[[Unit|unit]]" is any [[Game Object|game object]] that is a unit, regardless of any other categories it belongs to.

<details class="rule-ref"><summary title="Core rule 133.3 · PDF page 11" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 133.3 · PDF page 11</div></details>

When characteristics are referred to in this way, it refers to any [[Game Object]] with the appropriate characteristic on [[Board|the board]], unless the [[Zone|zone]] is specified implicitly or explicitly by the effect doing the referring or the nature of the characteristic. ^cr-133-3-a

**Example:** A "Yeti" refers to a [[Game Object|game object]] with the Yeti [[Tag|tag]] on [[Board|the board]].

**Example:** A "[[Spell|spell]]" refers to a spell on the [[Chain|chain]], because spells cannot exist as [[Game Object|game objects]] on [[Board|the board]].

**Example:** A "[[Spell|spell]] in your [[Trash|trash]]" refers to a spell [[Card|card]] in your trash because the effect specifies the [[Zone|zone]] in question.

<details class="rule-ref"><summary title="Core rule 133.3.a · PDF page 11" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 133.3.a · PDF page 11</div></details>

[[Main Deck]] [[Card|Cards]] begin the game in the Main Deck or (in the case of a [[Chosen Champion]]) the [[Champion Zone]]. ^cr-133-4

<details class="rule-ref"><summary title="Core rule 133.4 · PDF page 11" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 133.4 · PDF page 11</div></details>

[[Permanent|Permanents]] ^cr-133-4-a

<details class="rule-ref"><summary title="Core rule 133.4.a · PDF page 11" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 133.4.a · PDF page 11</div></details>

An umbrella sub-category encompassing [[Main Deck]] [[Game Object|Game Objects]] that remain on [[Board|the board]] after being played. ^cr-133-4-a-1

<details class="rule-ref"><summary title="Core rule 133.4.a.1 · PDF page 11" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 133.4.a.1 · PDF page 11</div></details>

[[Unit]] and [[Gear]] are [[Permanent|permanent]] types. ^cr-133-4-a-2

<details class="rule-ref"><summary title="Core rule 133.4.a.2 · PDF page 11" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 133.4.a.2 · PDF page 11</div></details>

[[Spell|Spells]] ^cr-133-4-b

<details class="rule-ref"><summary title="Core rule 133.4.b · PDF page 11" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 133.4.b · PDF page 11</div></details>

A sub-category encompassing [[Main Deck]] [[Card|cards]] with the [[Spell|spell]] type, which do not remain on [[Board|the board]] after being played. ^cr-133-4-b-1

<details class="rule-ref"><summary title="Core rule 133.4.b.1 · PDF page 11" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 133.4.b.1 · PDF page 11</div></details>

[[Rune Deck]] [[Card|Cards]] begin the game in the Rune Deck. ^cr-133-5

<details class="rule-ref"><summary title="Core rule 133.5 · PDF page 11" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 133.5 · PDF page 11</div></details>

[[Rune|Runes]] ^cr-133-5-a

<details class="rule-ref"><summary title="Core rule 133.5.a · PDF page 11" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 133.5.a · PDF page 11</div></details>

A sub-category encompassing [[Card|cards]] with the [[Rune|rune]] type. These are channeled rather than played. They remain on [[Board|the board]] after being channeled, but they are not [[Permanent|permanents]], as they are not [[Main Deck]] cards. ^cr-133-5-a-1

<details class="rule-ref"><summary title="Core rule 133.5.a.1 · PDF page 11" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 133.5.a.1 · PDF page 11</div></details>

Other [[Card|Cards]] are not part of either the Main or [[Rune]] Decks and begin the game in a [[Zone|zone]] determined by their type. ^cr-133-6

<details class="rule-ref"><summary title="Core rule 133.6 · PDF page 11" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 133.6 · PDF page 11</div></details>

[[Battlefield|Battlefields]] ^cr-133-6-a

<details class="rule-ref"><summary title="Core rule 133.6.a · PDF page 12" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 133.6.a · PDF page 12</div></details>

A sub-category encompassing [[Card|cards]] with the [[Battlefield|battlefield]] type. They are not played or channeled. They start the game on [[Board|the board]]. ^cr-133-6-a-1

<details class="rule-ref"><summary title="Core rule 133.6.a.1 · PDF page 12" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 133.6.a.1 · PDF page 12</div></details>

[[Legend|Legends]] ^cr-133-6-b

<details class="rule-ref"><summary title="Core rule 133.6.b · PDF page 12" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 133.6.b · PDF page 12</div></details>

A sub-category encompassing [[Card|cards]] with the [[Legend|legend]] type. They are not played or channeled. They start the game in the [[Legend Zone]] and cannot typically leave it during [[Play|play]]. ^cr-133-6-b-1

<details class="rule-ref"><summary title="Core rule 133.6.b.1 · PDF page 12" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 133.6.b.1 · PDF page 12</div></details>

[[Supertype|Supertypes]] are Categories that may apply to [[Game Object|game objects]] of [[Multiple Card Types|multiple types]]. They are listed before a [[Card|card]]’s type. ^cr-133-7

<details class="rule-ref"><summary title="Core rule 133.7 · PDF page 12" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 133.7 · PDF page 12</div></details>

[[Champion]] is a [[Supertype|supertype]] that applies exclusively to [[Unit|units]]. It impacts the rules for deckbuilding. ^cr-133-7-a

See [[Deck Construction#^cr-103-3-a|Chosen Champion]] for more information.

<details class="rule-ref"><summary title="Core rule 133.7.a · PDF page 12" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 133.7.a · PDF page 12</div></details>

[[Signature]] is a [[Supertype|supertype]] that may apply to [[Game Object|game objects]] of any [[Card|card]] type. It impacts the rules for deckbuilding. ^cr-133-7-b

See [[Deck Construction#^cr-103-3-d|Deck Construction]] for more information about [[Signature|Signature cards]].

<details class="rule-ref"><summary title="Core rule 133.7.b · PDF page 12" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 133.7.b · PDF page 12</div></details>

Tags are Categories that may apply to [[Game Object|game objects]] of [[Multiple Card Types|multiple types]]. They are listed after a [[Card|card]]’s type. ^cr-133-8

<details class="rule-ref"><summary title="Core rule 133.8 · PDF page 12" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 133.8 · PDF page 12</div></details>

Tags have no innate rules meaning, but may be referenced by game rules and [[Card|card]] effects. ^cr-133-8-a

<details class="rule-ref"><summary title="Core rule 133.8.a · PDF page 12" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 133.8.a · PDF page 12</div></details>

Tags used to link [[Legend|Legends]], [[Champion|Champion Units]], and [[Signature|Signature cards]] are known as [[Champion Tag|Champion Tags]]. ^cr-133-8-b

<details class="rule-ref"><summary title="Core rule 133.8.b · PDF page 12" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 133.8.b · PDF page 12</div></details>
