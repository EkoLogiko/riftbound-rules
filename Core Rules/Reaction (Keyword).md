<span title="Core rule 813"></span> ^cr-813

<details class="rule-ref"><summary title="Core rule 813 · PDF page 131" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 813 · PDF page 131</div></details>

Reaction is a Permissive [[Keywords|keyword]]. ^cr-813-1

<details class="rule-ref"><summary title="Core rule 813.1 · PDF page 131" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 813.1 · PDF page 131</div></details>

It can be present on [[Card|Cards]], [[Rune]] [[Ability|Abilities]], [[Legend]] Abilities and [[Permanent]] Abilities. ^cr-813-1-a

<details class="rule-ref"><summary title="Core rule 813.1.a · PDF page 131" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 813.1.a · PDF page 131</div></details>

Reaction grants the corresponding [[Card|card]] or effect all [[Ability|abilities]] and permissions of Action. ^cr-813-1-b

<details class="rule-ref"><summary title="Core rule 813.1.b · PDF page 131" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 813.1.b · PDF page 131</div></details>

Reaction, additionally, is functionally short for the following: ^cr-813-1-c

<details class="rule-ref"><summary title="Core rule 813.1.c · PDF page 131" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 813.1.c · PDF page 131</div></details>

On [[Card|Cards]]: "This can be played during Closed States on any player's [[Turn|turn]]." ^cr-813-1-c-1

<details class="rule-ref"><summary title="Core rule 813.1.c.1 · PDF page 131" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 813.1.c.1 · PDF page 131</div></details>

On [[Activated Ability|Activated Abilities]]: "This can be activated during Closed States on any player's [[Turn|turn]]." ^cr-813-1-c-2

<details class="rule-ref"><summary title="Core rule 813.1.c.2 · PDF page 131" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 813.1.c.2 · PDF page 131</div></details>

Reaction is formatted as “&#91;Reaction&#93;” on [[Card|cards]], or “&#91;Reaction&#93;&#91;>&#93;” on [[Ability|abilities]]. ^cr-813-1-d

<details class="rule-ref"><summary title="Core rule 813.1.d · PDF page 131" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 813.1.d · PDF page 131</div></details>

The corresponding [[Card|card]] or effect with this [[Keywords|keyword]] is not restricted to Closed States or [[Showdowns]]. This permission is inclusive of all other timings and options available to the [[Ability|ability]] as written, Action's permissions, or by default. ^cr-813-2

<details class="rule-ref"><summary title="Core rule 813.2 · PDF page 131" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 813.2 · PDF page 131</div></details>

Reaction does not alter the function of any instruction of the [[Card]], [[Rune]], or Effect it is on. It is only Permission. ^cr-813-3

<details class="rule-ref"><summary title="Core rule 813.3 · PDF page 131" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 813.3 · PDF page 131</div></details>

Playing [[Unit|Units]] with Reaction still has the inherent restrictions of playing Units without Reaction. It can only be played to the controlling player's [[Base|base]] or a [[Battlefield|battlefield]] they [[Control|control]]. ^cr-813-3-a

<details class="rule-ref"><summary title="Core rule 813.3.a · PDF page 131" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 813.3.a · PDF page 131</div></details>

Some [[Passive Ability|passive abilities]] may grant a [[Card|card]] or [[Ability|ability]] Reaction under certain conditions. The card or ability does not have the Reaction keyword unless and until those circumstances are true. ^cr-813-4

<details class="rule-ref"><summary title="Core rule 813.4 · PDF page 131" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 813.4 · PDF page 131</div></details>

Those conditions [[Might|might]] only be fulfilled while the [[Card|card]] or [[Ability|ability]] is on the [[Chain|chain]]. In such a case, it can still be played or activated at the appropriate timing as long as doing so could fulfill the conditions. ^cr-813-4-a

<details class="rule-ref"><summary title="Core rule 813.4.a · PDF page 132" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 813.4.a · PDF page 132</div></details>

If the [[Chain|chain]] item does not fulfill the conditions by the time step 5: check legality has been reached, the actions taken while playing it are undone and it is returned to the [[Zone|zone]] it was played from if it is a [[Card|card]]. ^cr-813-4-b

<details class="rule-ref"><summary title="Core rule 813.4.b · PDF page 132" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 813.4.b · PDF page 132</div></details>

Reaction is a referencable characteristic. ^cr-813-5

<details class="rule-ref"><summary title="Core rule 813.5 · PDF page 132" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 813.5 · PDF page 132</div></details>

Whether or not a [[Game Object]] has Reaction is a characteristic of that Game Object and may be checked or referenced by other [[Game Effect|Game Effects]]. ^cr-813-5-a

<details class="rule-ref"><summary title="Core rule 813.5.a · PDF page 132" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 813.5.a · PDF page 132</div></details>

Whether or not a [[Spell]] has Reaction is a characteristic of that Spell and may be checked or referenced by other [[Game Effect|Game Effects]]. ^cr-813-5-b

<details class="rule-ref"><summary title="Core rule 813.5.b · PDF page 132" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 813.5.b · PDF page 132</div></details>

Whether or not an [[Ability]] has Reaction is a characteristic of that Ability and may be checked or referenced by other [[Game Effect|Game Effects]]. ^cr-813-5-c

<details class="rule-ref"><summary title="Core rule 813.5.c · PDF page 132" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 813.5.c · PDF page 132</div></details>
