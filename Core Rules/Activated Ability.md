# Activated Ability

[[Start Here|Home]] · [[Concept Index|Find a concept]] · [[Core Rules Index|Core rules]]

<!-- flowchart-links:start -->
**Flowchart:** [[Playing or Activating Abilities Flowchart#Playing or activating abilities|Playing or activating abilities]]
<!-- flowchart-links:end -->

<span title="Core rule 376"></span> ^cr-376

<details class="rule-ref"><summary title="Core rule 376 · PDF page 66" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 376 · PDF page 66</div></details>

Activated Abilities are repeatable effects with a [[Costs|cost]]. They follow a process of going onto the [[Chain|chain]] and resolving, similar to Playing a [[Card]]. ^cr-377

See [[Playing Cards#^cr-349|Playing Cards]] for more information.

<details class="rule-ref"><summary title="Core rule 377 · PDF page 66" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 377 · PDF page 66</div></details>

Activated Abilities are recognized by the presence of a ":" in the text of the [[Card|card]], preceded by a [[Costs|cost]] and succeeded by an effect. ^cr-377-1

**Example:** "&#91;2&#93;: [[Draw]] 1" is an activated ability. The [[Costs|cost]] is 2 [[Energy|energy]]. The effect is to draw 1 [[Card|card]].

<details class="rule-ref"><summary title="Core rule 377.1 · PDF page 66" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 377.1 · PDF page 66</div></details>

[[Card]] text will refer to activating Activated Abilities with the word “use” or “[[Play|play]].” ^cr-377-2

<details class="rule-ref"><summary title="Core rule 377.2 · PDF page 66" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 377.2 · PDF page 66</div></details>

If “using” or “playing” an Activated Ability is part of a trigger condition, that condition is fulfilled when the Activated Ability resolves. ^cr-377-2-a

<details class="rule-ref"><summary title="Core rule 377.2.a · PDF page 66" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 377.2.a · PDF page 66</div></details>

If an Activated Ability has a condition on “using” or “playing” it, that condition must be true in order to activate the [[Ability|ability]] in question. ^cr-377-2-b

**Example:** Ultrasoft Poro reads “&#91;E&#93;: [[Play]] two 1 &#91;M&#93; Bird [[Unit|unit]] [[Token|tokens]] with &#91;[[Deflect]]&#93;. Use this [[Ability|ability]] only while I'm at a [[Battlefield|battlefield]].” In order to activate the ability, Ultrasoft Poro must be located at a battlefield.

<details class="rule-ref"><summary title="Core rule 377.2.b · PDF page 66" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 377.2.b · PDF page 66</div></details>

Activated Abilities use the [[Chain|chain]]. ^cr-377-3

<details class="rule-ref"><summary title="Core rule 377.3 · PDF page 66" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 377.3 · PDF page 66</div></details>

Declare activation of the [[Ability]]. ^cr-377-3-a

<details class="rule-ref"><summary title="Core rule 377.3.a · PDF page 66" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 377.3.a · PDF page 66</div></details>

The [[Ability|ability]] goes on the [[Chain|chain]] but has no [[Card|card]] to represent it, so players need to take note that it is now a [[Closed State]]. ^cr-377-3-a-1

<details class="rule-ref"><summary title="Core rule 377.3.a.1 · PDF page 66" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 377.3.a.1 · PDF page 66</div></details>

Proceed with executing the [[Chain]]. ^cr-377-3-b

<details class="rule-ref"><summary title="Core rule 377.3.b · PDF page 66" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 377.3.b · PDF page 66</div></details>

Follow the steps of “[[Playing or Activating an Ability|Playing or Activating Abilities]]” in [[Playing or Activating an Ability#^cr-399|Playing or Activating an Ability]]. This [[Ability|ability]] will become a [[Pending Chain Item]]. ^cr-377-3-b-1

<details class="rule-ref"><summary title="Core rule 377.3.b.1 · PDF page 66" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 377.3.b.1 · PDF page 66</div></details>

Opponents have an opportunity to respond, as appropriate, as if a [[Card|card]] was played onto the [[Chain|chain]]. ^cr-377-3-b-2

<details class="rule-ref"><summary title="Core rule 377.3.b.2 · PDF page 66" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 377.3.b.2 · PDF page 66</div></details>

If no further action is taken, execute the Activated Ability. ^cr-377-3-b-3

<details class="rule-ref"><summary title="Core rule 377.3.b.3 · PDF page 66" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 377.3.b.3 · PDF page 66</div></details>

The player who controls the source of the Activated Ability decides when and whether to activate the [[Ability|ability]]. ^cr-378

<details class="rule-ref"><summary title="Core rule 378 · PDF page 66" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 378 · PDF page 66</div></details>

If the source of the Activated Ability is uncontrolled, and it isn’t a [[Battlefield]], the owner of the source decides when and whether to activate the [[Ability|ability]]. ^cr-378-1

<details class="rule-ref"><summary title="Core rule 378.1 · PDF page 66" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 378.1 · PDF page 66</div></details>

Some activated abilities specify that one or more players other than the controller or owner of their source can activate them. Those players decide when and whether to activate the [[Ability|ability]]. ^cr-378-2

<details class="rule-ref"><summary title="Core rule 378.2 · PDF page 66" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 378.2 · PDF page 66</div></details>

Activated abilities are present on [[Game Object|Game Objects]] and some [[Spell|Spells]]. ^cr-379

<details class="rule-ref"><summary title="Core rule 379 · PDF page 66" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 379 · PDF page 66</div></details>

Can primarily be activated while on [[Board|the Board]]. ^cr-380

<details class="rule-ref"><summary title="Core rule 380 · PDF page 66" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 380 · PDF page 66</div></details>

All Activated Abilities can only be activated on the appropriate Player's [[Turn]] and during an [[Open State]]. ^cr-381

<details class="rule-ref"><summary title="Core rule 381 · PDF page 66" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 381 · PDF page 66</div></details>

If the source of the Activated Ability is controlled by a player, that is the controller’s [[Main Phase]] during an [[Open State]]. ^cr-381-1

<details class="rule-ref"><summary title="Core rule 381.1 · PDF page 67" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 381.1 · PDF page 67</div></details>

If the source of the Activated Ability is uncontrolled and it isn’t a [[Battlefield]], that is the owner’s [[Main Phase]] during an [[Open State]]. ^cr-381-2

<details class="rule-ref"><summary title="Core rule 381.2 · PDF page 67" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 381.2 · PDF page 67</div></details>

If the Activated Ability specifies that one or more players other than the controller or owner of the source can activate it, that is during the activating player's [[Main Phase]] during an [[Open State]]. ^cr-381-3

<details class="rule-ref"><summary title="Core rule 381.3 · PDF page 67" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 381.3 · PDF page 67</div></details>
