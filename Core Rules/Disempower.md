# Disempower

[[Start Here|Home]] · [[Concept Index|Find a concept]] · [[Core Rules Index|Core rules]]

<span title="Core rule 443"></span> ^cr-443

<details class="rule-ref"><summary title="Core rule 443 · PDF page 97" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 443 · PDF page 97</div></details>

Disempowering is the act of removing the Empowered status from one or more [[Game Object|Game Objects]]. ^cr-443-1

<details class="rule-ref"><summary title="Core rule 443.1 · PDF page 97" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 443.1 · PDF page 97</div></details>

Disempowering affects only [[Card|cards]] that are currently Empowered. ^cr-443-1-a

<details class="rule-ref"><summary title="Core rule 443.1.a · PDF page 97" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 443.1.a · PDF page 97</div></details>

[[Game Effect|Game effects]] that instruct a player to Disempower a [[Card|card]] that is not currently Empowered will do nothing. ^cr-443-1-a-1

<details class="rule-ref"><summary title="Core rule 443.1.a.1 · PDF page 97" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 443.1.a.1 · PDF page 97</div></details>

Disempowering a [[Game Object]] that has multiple Empowered statuses will remove one of those statuses. ^cr-443-1-b

<details class="rule-ref"><summary title="Core rule 443.1.b · PDF page 97" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 443.1.b · PDF page 97</div></details>

Disempowering is a [[Limited Action]]. ^cr-443-2

<details class="rule-ref"><summary title="Core rule 443.2 · PDF page 97" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 443.2 · PDF page 97</div></details>

Players may only Disempower [[Game Object|Game Objects]] when directed to by [[Game Effect|Game Effects]]. ^cr-443-2-a

<details class="rule-ref"><summary title="Core rule 443.2.a · PDF page 97" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 443.2.a · PDF page 97</div></details>
