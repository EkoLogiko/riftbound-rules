<details class="rule-ref"><summary title="Core rule 819 · PDF page 134" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 819 · PDF page 134</div></details>

Quick-Draw is a [[Triggered Ability]] [[Keywords|keyword]]. It is also a Permissive keyword. ^cr-819-1

<details class="rule-ref"><summary title="Core rule 819.1 · PDF page 134" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 819.1 · PDF page 134</div></details>

Quick-Draw is present on [[Gear]] with [[Equip]] [[Ability|abilities]]. ^cr-819-1-a

<details class="rule-ref"><summary title="Core rule 819.1.a · PDF page 134" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 819.1.a · PDF page 134</div></details>

[[Card|Cards]] with Quick-Draw have Reaction inherently. ^cr-819-1-b

<details class="rule-ref"><summary title="Core rule 819.1.b · PDF page 134" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 819.1.b · PDF page 134</div></details>

Quick-Draw allows [[Card|cards]] to be played and [[Attached]] using Reaction timing. ^cr-819-1-c

<details class="rule-ref"><summary title="Core rule 819.1.c · PDF page 134" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 819.1.c · PDF page 134</div></details>

Quick-Draw is functionally short for “&#91;[[Reaction (Keyword)|Reaction]]&#93;” and “When you [[Play|play]] this, [[Attach|attach]] it to a [[Unit]] you [[Control|control]].” ^cr-819-1-d

See [[Attachment#^cr-716|Attachment]] for more information.

<details class="rule-ref"><summary title="Core rule 819.1.d · PDF page 134" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 819.1.d · PDF page 134</div></details>

Multiple instances of Quick-Draw do not trigger separately and have no effect beyond the first. ^cr-819-2

<details class="rule-ref"><summary title="Core rule 819.2 · PDF page 135" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 819.2 · PDF page 135</div></details>

Quick-Draw, and whether or not a [[Gear|gear]] has Quick-Draw, is a characteristic of the Gear and may be checked or referenced by other [[Game Effect|Game Effects]]. ^cr-819-3

<details class="rule-ref"><summary title="Core rule 819.3 · PDF page 135" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 819.3 · PDF page 135</div></details>
