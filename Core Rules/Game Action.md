# Game Action

[[Start Here|Home]] · [[Concept Index|Find a concept]] · [[Core Rules Index|Core rules]]

<span title="Core rule 408"></span> ^cr-408

<details class="rule-ref"><summary title="Core rule 408 · PDF page 77" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 408 · PDF page 77</div></details>

Game Actions are actions players may perform at any given time during the game. ^cr-409

<details class="rule-ref"><summary title="Core rule 409 · PDF page 77" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 409 · PDF page 77</div></details>

A player, unless otherwise specified or prompted, may only perform actions on their [[Turn|turn]]. ^cr-410

<details class="rule-ref"><summary title="Core rule 410 · PDF page 77" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 410 · PDF page 77</div></details>

There are two types of Game Actions: ^cr-411

<details class="rule-ref"><summary title="Core rule 411 · PDF page 77" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 411 · PDF page 77</div></details>

### Discretionary Actions

^cr-411-1

<details class="rule-ref"><summary title="Core rule 411.1 · PDF page 77" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 411.1 · PDF page 77</div></details>

A [[Discretionary Action]] is a Game Action that may be performed at any time during a player's [[Turn|turn]] during a [[Neutral Open State]]. ^cr-411-1-a

See [[Turn States#^cr-307|States of the Turn]] for more information.

<details class="rule-ref"><summary title="Core rule 411.1.a · PDF page 77" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 411.1.a · PDF page 77</div></details>

A player may take any number of [[Discretionary Action|Discretionary Actions]] available to them during their [[Turn|turn]]. ^cr-411-1-b

<details class="rule-ref"><summary title="Core rule 411.1.b · PDF page 77" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 411.1.b · PDF page 77</div></details>

As long as any conditions, if applicable, are met. ^cr-411-1-b-1

<details class="rule-ref"><summary title="Core rule 411.1.b.1 · PDF page 77" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 411.1.b.1 · PDF page 77</div></details>

As long as any [[Costs|costs]], if applicable, are paid. ^cr-411-1-b-2

<details class="rule-ref"><summary title="Core rule 411.1.b.2 · PDF page 77" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 411.1.b.2 · PDF page 77</div></details>

As long as it does not result in any forbidden action being taken or game state being created. ^cr-411-1-b-3

**Example:** A player can't use the [[Standard Move]] [[Discretionary Action|discretionary action]] to [[Move|move]] a [[Unit|unit]] to a [[Battlefield]] that's already occupied by Units controlled by two other players.

<details class="rule-ref"><summary title="Core rule 411.1.b.3 · PDF page 77" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 411.1.b.3 · PDF page 77</div></details>

### Limited Actions

^cr-411-2

<details class="rule-ref"><summary title="Core rule 411.2 · PDF page 77" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 411.2 · PDF page 77</div></details>

A [[Limited Action]] is a game action that a [[Spell|spell]], [[Ability|ability]], or circumstance of [[Turn|the turn]]'s progression causes the player to perform. A player cannot perform these actions at-will. ^cr-411-2-a

<details class="rule-ref"><summary title="Core rule 411.2.a · PDF page 77" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 411.2.a · PDF page 77</div></details>

These actions can only be taken when a player is instructed to do so as the execution of an effect or during their specified occasion during [[Turn|the turn]]. ^cr-411-2-b

**Example:** A player may [[Draw]] during the [[Draw Phase]] on their [[Turn|turn]] or when instructed to do so by a [[Spell|spell]] or [[Ability|ability]]. They can't choose to Draw at any other time.

<details class="rule-ref"><summary title="Core rule 411.2.b · PDF page 77" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 411.2.b · PDF page 77</div></details>
