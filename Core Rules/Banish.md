# Banish

[[Start Here|Home]] · [[Concept Index|Find a concept]] · [[Core Rules Index|Core rules]]

<span title="Core rule 428"></span> ^cr-428

<details class="rule-ref"><summary title="Core rule 428 · PDF page 86" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 428 · PDF page 86</div></details>

Banishing is the action of placing a [[Card|card]] from any other [[Zone|zone]] into [[Banishment]]. See 108.6. Banishment for more information. ^cr-428-1

<details class="rule-ref"><summary title="Core rule 428.1 · PDF page 86" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 428.1 · PDF page 86</div></details>

When a [[Card|card]] is Banished it is placed directly into the [[Banishment]] [[Zone|zone]] from its origin. ^cr-428-2

<details class="rule-ref"><summary title="Core rule 428.2 · PDF page 86" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 428.2 · PDF page 86</div></details>

Banish is not a subset of [[Kill]]. ^cr-428-2-a

<details class="rule-ref"><summary title="Core rule 428.2.a · PDF page 86" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 428.2.a · PDF page 86</div></details>

Banish is not a subset of [[Discard]]. ^cr-428-2-b

<details class="rule-ref"><summary title="Core rule 428.2.b · PDF page 86" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 428.2.b · PDF page 86</div></details>

[[Card|Cards]] and effects can refer to cards that were banished by the same object. ^cr-428-3

<details class="rule-ref"><summary title="Core rule 428.3 · PDF page 86" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 428.3 · PDF page 86</div></details>

Separate instances of an object or effect banishing [[Card|cards]] do not reference other banished cards by objects of the same [[Card Name|name]] or effects originating from cards of the same name. ^cr-428-3-a

**Example:** A [[Spell|spell]] reads "Banish the top [[Card|card]] of your [[Main Deck]]. When you [[Conquer|conquer]] this [[Turn|turn]], [[Draw|draw]] it." This card effect allows you to draw the banished card from [[Banishment|banishment]] if a condition is met. If more than one of these effects is played, each one triggers separately. Each card will be drawn separately. If the turn player passes the turn without playing the card, the card remains in banishment indefinitely. If the same player plays another [[Copy|copy]] of the same spell, banishes another card, and satisfies its condition, they could [[Play|play]] the new banished card, but not the original banished card.

See [[Linked Ability#^cr-394|Linked Abilities]] for more information.

<details class="rule-ref"><summary title="Core rule 428.3.a · PDF page 86-87" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 428.3.a · PDF page 86-87</div></details>

Banishing is a [[Limited Action]]. ^cr-428-4

<details class="rule-ref"><summary title="Core rule 428.4 · PDF page 87" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 428.4 · PDF page 87</div></details>

Players may only Banish [[Card|cards]] or [[Permanent|permanents]] when [[Game Effect|Game Effects]] direct them to do so. ^cr-428-4-a

<details class="rule-ref"><summary title="Core rule 428.4.a · PDF page 87" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 428.4.a · PDF page 87</div></details>

This action is formatted as "Banish &#91;one or more [[Permanent|permanents]] or [[Card|cards]]&#93;." e.g., "Banish a card from your [[Hand|hand]]." e.g., "Banish 2 cards from your [[Trash|trash]]." e.g., "Look at the top 2 cards of your [[Main Deck]]. [[Draw]] one of them and banish the other." ^cr-428-5
