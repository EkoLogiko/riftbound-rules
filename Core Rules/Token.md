# Token

[[Start Here|Home]] · [[Concept Index|Find a concept]] · [[Core Rules Index|Core rules]]

<span title="Core rule 179"></span> ^cr-179

<details class="rule-ref"><summary title="Core rule 179 · PDF page 27" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 179 · PDF page 27</div></details>

Tokens are [[Game Object|Game Objects]] created by [[Spell|spells]] and [[Ability|abilities]] during [[Play|play]]. ^cr-180

<details class="rule-ref"><summary title="Core rule 180 · PDF page 27" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 180 · PDF page 27</div></details>

Tokens can be represented by anything. Printed tokens are included in Riftbound booster packs, but they are not required to [[Play|play]] a token. ^cr-181

<details class="rule-ref"><summary title="Core rule 181 · PDF page 27" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 181 · PDF page 27</div></details>

A token's controller is the controller of the [[Spell|spell]] or [[Ability|ability]] that created it, unless the token's type innately determines [[Control|control]] or that spell or ability specifies that a different player is the token's controller. ^cr-182

<details class="rule-ref"><summary title="Core rule 182 · PDF page 27" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 182 · PDF page 27</div></details>

A token's owner is the player who controlled the effect that created it. ^cr-183

<details class="rule-ref"><summary title="Core rule 183 · PDF page 27" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 183 · PDF page 27</div></details>

The effect that creates a token may specify the conditions or circumstances under which it enters [[Board|the board]]. These stipulations may alter the usual steps for playing a [[Card|card]] if the token is played. ^cr-184

<details class="rule-ref"><summary title="Core rule 184 · PDF page 27" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 184 · PDF page 27</div></details>

The effect may state that the token enters [[Ready|ready]] or [[Exhaust|exhausted]], if that state is contrary to the default for the token's type. ^cr-184-1

<details class="rule-ref"><summary title="Core rule 184.1 · PDF page 27" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 184.1 · PDF page 27</div></details>

The effect may restrict the [[Location|location]] to which the token may be played. ^cr-184-2

<details class="rule-ref"><summary title="Core rule 184.2 · PDF page 27" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 184.2 · PDF page 27</div></details>

The effect may grant [[Temporary|temporary]] [[Ability|abilities]] or modifications to the token. ^cr-184-3

<details class="rule-ref"><summary title="Core rule 184.3 · PDF page 28" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 184.3 · PDF page 28</div></details>

Tokens are not [[Card|cards]]. ^cr-185

<details class="rule-ref"><summary title="Core rule 185 · PDF page 28" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 185 · PDF page 28</div></details>

“Token” is an intrinsic [[Card Category|category]] of [[Game Object|Game Objects]], in the same way “[[Card|card]]” is. ^cr-185-1

<details class="rule-ref"><summary title="Core rule 185.1 · PDF page 28" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 185.1 · PDF page 28</div></details>

Token [[Game Object|Game Objects]] cannot lose their token nature by any means. ^cr-185-1-a

<details class="rule-ref"><summary title="Core rule 185.1.a · PDF page 28" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 185.1.a · PDF page 28</div></details>

[[Card]] [[Game Object|Game Objects]] cannot become tokens by any means. ^cr-185-1-b

<details class="rule-ref"><summary title="Core rule 185.1.b · PDF page 28" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 185.1.b · PDF page 28</div></details>

Tokens have some properties in common with [[Card|cards]]. ^cr-185-2

<details class="rule-ref"><summary title="Core rule 185.2 · PDF page 28" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 185.2 · PDF page 28</div></details>

Tokens can be played by their owner if their [[Card|card]] type is played, following all the applicable steps for playing a card plus any restrictions or modifications from the effect that created the token. ^cr-185-2-a

See [[Playing Cards#^cr-349|Playing Cards]] for more information.

<details class="rule-ref"><summary title="Core rule 185.2.a · PDF page 28" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 185.2.a · PDF page 28</div></details>

Token [[Unit|units]] have a [[Might]]. ^cr-185-2-b

<details class="rule-ref"><summary title="Core rule 185.2.b · PDF page 28" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 185.2.b · PDF page 28</div></details>

Tokens may have one or more tags. ^cr-185-2-c

<details class="rule-ref"><summary title="Core rule 185.2.c · PDF page 28" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 185.2.c · PDF page 28</div></details>

Tokens have a type. They follow all rules for their type unless otherwise specified. ^cr-185-2-d

**Example:** A token [[Unit|unit]] is a unit. It enters [[Exhaust|exhausted]], can take the [[Standard Move|standard move]] action, deals [[Damage|damage]] equal to its [[Might]] [[In Combat|in combat]], is destroyed if it takes damage equal to or greater than its might, can be chosen or otherwise affected by [[Spell|spells]] or [[Ability|abilities]] that choose or affect units, etc.

<details class="rule-ref"><summary title="Core rule 185.2.d · PDF page 28" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 185.2.d · PDF page 28</div></details>

Tokens inherit the [[Recycle|recycle]] destination of their type. ^cr-185-2-e

**Example:** Token [[Rune|runes]] will be recycled to the [[Rune Deck]]. Token [[Unit|units]], [[Gear|gear]], and [[Spell|spells]] will be recycled to the [[Main Deck]]. Token [[Battlefield|battlefields]] and [[Legend|legends]] can’t be recycled.

<details class="rule-ref"><summary title="Core rule 185.2.e · PDF page 28" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 185.2.e · PDF page 28</div></details>

Tokens differ from [[Card|cards]] in some ways. ^cr-185-3

<details class="rule-ref"><summary title="Core rule 185.3 · PDF page 28" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 185.3 · PDF page 28</div></details>

Tokens do not have [[Costs|costs]]. ^cr-185-3-a

<details class="rule-ref"><summary title="Core rule 185.3.a · PDF page 28" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 185.3.a · PDF page 28</div></details>

Although tokens do not have [[Costs|costs]], their cost is treated as being 0 for all purposes. ^cr-185-3-a-1

<details class="rule-ref"><summary title="Core rule 185.3.a.1 · PDF page 28" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 185.3.a.1 · PDF page 28</div></details>

Tokens can have [[Costs|costs]] appended to them via applied Layer effects. ^cr-185-3-a-2

**Example:** Deceiver’s [[Conquer Effect|conquer effect]] creates a 0 &#91;M&#93; Reflection [[Unit|unit]] token and applies a [[Copy|copy]] effect to that token. The copy effect will append all copyable traits, including the [[Costs|cost]] of the unit to be copied. This appends a cost to the Reflection token.

<details class="rule-ref"><summary title="Core rule 185.3.a.2 · PDF page 28" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 185.3.a.2 · PDF page 28</div></details>

Tokens do not have domains. ^cr-185-3-b

<details class="rule-ref"><summary title="Core rule 185.3.b · PDF page 28" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 185.3.b · PDF page 28</div></details>

Tokens can have domains appended to them via applied Layer effects. ^cr-185-3-b-1

**Example:** A [[Card|card]] reads in part “As you [[Play|play]] this, pick a [[Domain|domain]]. All [[Unit|units]] and [[Gear|gear]] are that domain.” If that card is in play, any unit and gear tokens will have the chosen domain appended to them.

<details class="rule-ref"><summary title="Core rule 185.3.b.1 · PDF page 28" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 185.3.b.1 · PDF page 28</div></details>

Tokens are Created on [[Board|the board]] or the [[Chain]] and cannot exist elsewhere. ^cr-186

<details class="rule-ref"><summary title="Core rule 186 · PDF page 29" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 186 · PDF page 29</div></details>

If a token is put into any Non-Board [[Zone]] besides the [[Chain|chain]], it ceases to exist immediately after [[Movement|moving]] to its new zone. ^cr-186-1

<details class="rule-ref"><summary title="Core rule 186.1 · PDF page 29" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 186.1 · PDF page 29</div></details>

The [[Spell|spell]] or [[Ability|ability]] that Creates a token specifies some of its characteristics. It may have other characteristics, as listed below. ^cr-187

<details class="rule-ref"><summary title="Core rule 187 · PDF page 29" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 187 · PDF page 29</div></details>

A 1 &#91;M&#93; Recruit token is a domainless [[Unit|unit]] token with 1 [[Might]] and the Recruit [[Tag|tag]]. ^cr-187-1

<details class="rule-ref"><summary title="Core rule 187.1 · PDF page 29" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 187.1 · PDF page 29</div></details>

A 3 &#91;M&#93; Sprite token with [[Temporary]] is a domainless [[Unit|unit]] token with 3 [[Might]], the Fae [[Tag|tag]], and the Temporary [[Keywords|keyword]]. ^cr-187-2

See [[Temporary#^cr-816|Temporary]] for more information.

<details class="rule-ref"><summary title="Core rule 187.2 · PDF page 29" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 187.2 · PDF page 29</div></details>

A 2 &#91;M&#93; Sand Soldier token is a domainless [[Unit|unit]] token with 2 [[Might]] and the Shurima [[Tag|tag]]. ^cr-187-3

<details class="rule-ref"><summary title="Core rule 187.3 · PDF page 29" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 187.3 · PDF page 29</div></details>

A 3 &#91;M&#93; Mech token is a domainless [[Unit|unit]] token with 3 [[Might]] and the Mech [[Tag|tag]]. ^cr-187-4

<details class="rule-ref"><summary title="Core rule 187.4 · PDF page 29" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 187.4 · PDF page 29</div></details>

A Gold [[Gear|gear]] token is a domainless gear token with “&#91;[[Reaction (Keyword)|Reaction]]&#93;&#91;>&#93; [[Kill]] this, &#91;E&#93;: &#91;Add&#93; &#91;A&#93;.” ^cr-187-5

<details class="rule-ref"><summary title="Core rule 187.5 · PDF page 29" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 187.5 · PDF page 29</div></details>

A 0 &#91;M&#93; Reflection token is a domainless [[Unit|unit]] token with 0 [[Might]]. ^cr-187-6

<details class="rule-ref"><summary title="Core rule 187.6 · PDF page 29" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 187.6 · PDF page 29</div></details>

A 1 &#91;M&#93; Bird token is a domainless [[Unit|unit]] token with 1 [[Might]], the Bird [[Tag|tag]], and the [[Deflect]] [[Keywords|keyword]]. ^cr-187-7

See [[Deflect#^cr-809|Deflect]] for more information.

<details class="rule-ref"><summary title="Core rule 187.7 · PDF page 29" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 187.7 · PDF page 29</div></details>

A Brush [[Battlefield|battlefield]] token is a domainless battlefield token with “Bird, Cat, Dog, Poro, and Ivern [[Unit|units]] here have +1 &#91;M&#93;” and “When you score here, you may replace this with the battlefield it replaced.” ^cr-187-8

<details class="rule-ref"><summary title="Core rule 187.8 · PDF page 29" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 187.8 · PDF page 29</div></details>

The Baron Pit [[Battlefield|battlefield]] token is a domainless battlefield token with “[[Unit|Units]] can [[Move|move]] here from anywhere.” ^cr-187-9

<details class="rule-ref"><summary title="Core rule 187.9 · PDF page 29" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 187.9 · PDF page 29</div></details>

A 1 &#91;M&#93; Tentacle token is a domainless [[Unit|unit]] token with 1 [[Might]] and the Bilgewater [[Tag|tag]]. ^cr-187-10

<details class="rule-ref"><summary title="Core rule 187.10 · PDF page 29" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 187.10 · PDF page 29</div></details>

A 0 &#91;M&#93; Shadow Clone token is a domainless [[Unit|unit]] token with 0 [[Might]] and “When I attack, you may [[Banish|banish]] a unit from your [[Trash|trash]]. If you do, give me &#91;[[Assault]] 4&#93; this [[Turn|turn]].” ^cr-187-11

See [[Assault#^cr-807|Assault]] for more information.

<details class="rule-ref"><summary title="Core rule 187.11 · PDF page 29" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 187.11 · PDF page 29</div></details>

A Bomb [[Gear|gear]] token is a domainless gear token with “&#91;[[Deploy]]&#93;” and “&#91;[[Deathknell]]&#93;&#91;>&#93; [[Deal]] 2 to an [[Enemy|enemy]] [[Unit|unit]] here and [[Kill|kill]] all other Bombs you [[Control|control]] here.” ^cr-187-12

See [[Deploy#^cr-830|Deploy]] for more information.
