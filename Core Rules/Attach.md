# Attach

[[Start Here|Home]] · [[Concept Index|Find a concept]] · [[Core Rules Index|Core rules]]

<span title="Core rule 435"></span> ^cr-435

<details class="rule-ref"><summary title="Core rule 435 · PDF page 91" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 435 · PDF page 91</div></details>

Attaching is the act of linking two [[Card|cards]] on [[Board|the board]] together to combine their effects in some way. This causes one or more cards to become [[Attached]] and at least one card to become a [[Top-most Card|Top-Most Card]]. ^cr-435-1

See [[Attachment#^cr-716|Attachment]] for more information.

<details class="rule-ref"><summary title="Core rule 435.1 · PDF page 91" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 435.1 · PDF page 91</div></details>

Attaching affects two [[Card|cards]] at once. ^cr-435-1-a

<details class="rule-ref"><summary title="Core rule 435.1.a · PDF page 91" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 435.1.a · PDF page 91</div></details>

One [[Card|card]] will be designated as the one being [[Attached]], and thus become Attached. The other will become the [[Top-most Card|Top-Most Card]]. ^cr-435-1-a-1

<details class="rule-ref"><summary title="Core rule 435.1.a.1 · PDF page 91" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 435.1.a.1 · PDF page 91</div></details>

This is represented by physically laying the [[Top-most Card|Top-Most card]] on top of the other or others such that all [[Effect Text|Effect Texts]] and [[Might Bonus|Might Bonuses]] are showing, but nothing else from the [[Card|card]] or cards [[Attached]]. ^cr-435-1-b

<details class="rule-ref"><summary title="Core rule 435.1.b · PDF page 91" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 435.1.b · PDF page 91</div></details>

In the situation where there is more than one [[Card|card]] [[Attached|attached]] to the [[Top-most Card|Top-Most card]], they should be stacked in such a way that all [[Effect Text]] boxes and [[Might Bonus|Might Bonuses]] are readable. The order of the Attached cards has no bearing on the application of effects. ^cr-435-1-b-1

<details class="rule-ref"><summary title="Core rule 435.1.b.1 · PDF page 91" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 435.1.b.1 · PDF page 91</div></details>

The [[Top-most Card|Top-Most card]] has all [[Effect Text]] of all [[Card|cards]] [[Attached]] to it appended to its [[Rules Text]]. ^cr-435-1-c

<details class="rule-ref"><summary title="Core rule 435.1.c · PDF page 91" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 435.1.c · PDF page 91</div></details>

The [[Top-most Card|Top-Most Card]] has its [[Might]] modulated by the [[Might Bonus]] of all [[Card|cards]] [[Attached]] to it. ^cr-435-1-d

<details class="rule-ref"><summary title="Core rule 435.1.d · PDF page 91" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 435.1.d · PDF page 91</div></details>

Attaching one or more [[Card|cards]] will cause those cards’ printed [[Rules Text]] to become [[Inactive]] for as long as they remain [[Attached]]. ^cr-435-1-e

See [[Attachment#^cr-716|Attachment]] for more information.

<details class="rule-ref"><summary title="Core rule 435.1.e · PDF page 91" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 435.1.e · PDF page 91</div></details>

Attaching a [[Card|card]] to a new [[Top-most Card|Top-Most Card]] will cause it to [[Detach]] from the card to which it is currently [[Attached]]. ^cr-435-1-f

<details class="rule-ref"><summary title="Core rule 435.1.f · PDF page 91" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 435.1.f · PDF page 91</div></details>

Attaching a [[Card|card]] to its current [[Top-most Card|Top-Most Card]] will not have any effect. ^cr-435-1-g

<details class="rule-ref"><summary title="Core rule 435.1.g · PDF page 91" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 435.1.g · PDF page 91</div></details>

[[Unit|Units]] cannot be [[Attached]] to other [[Card|cards]]. ^cr-435-1-h

See [[Unit#^cr-140|Units]] for more information.

<details class="rule-ref"><summary title="Core rule 435.1.h · PDF page 91" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 435.1.h · PDF page 91</div></details>

If a [[Unit]] would be [[Attached]], nothing happens. ^cr-435-1-h-1

<details class="rule-ref"><summary title="Core rule 435.1.h.1 · PDF page 92" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 435.1.h.1 · PDF page 92</div></details>

If a non-Unit [[Game Object]] that is [[Attached|attached]] becomes a [[Unit]] through any means, it [[Detach|detaches]] as it becomes a Unit. ^cr-435-1-h-2

<details class="rule-ref"><summary title="Core rule 435.1.h.2 · PDF page 92" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 435.1.h.2 · PDF page 92</div></details>

If a [[Game Effect]] instructs a player to Attach a [[Card|card]] to its current [[Top-most Card|Top-Most Card]], nothing additional happens. ^cr-435-1-i

<details class="rule-ref"><summary title="Core rule 435.1.i · PDF page 92" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 435.1.i · PDF page 92</div></details>

Attaching is a [[Limited Action]]. ^cr-435-2

<details class="rule-ref"><summary title="Core rule 435.2 · PDF page 92" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 435.2 · PDF page 92</div></details>

Players may only Attach [[Card|cards]] when directed to by [[Game Effect|Game Effects]]. ^cr-435-2-a

<details class="rule-ref"><summary title="Core rule 435.2.a · PDF page 92" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 435.2.a · PDF page 92</div></details>

Attaching [[Card|cards]] does not inherently choose or specify a target. However, [[Game Effect|Game Effects]] that Attach cards may do so. ^cr-435-3

<details class="rule-ref"><summary title="Core rule 435.3 · PDF page 92" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 435.3 · PDF page 92</div></details>

When a [[Card|card]] Attaches to a card, its [[Location|location]] becomes the same as the new [[Top-most Card|Top-Most Card]]. ^cr-435-4

<details class="rule-ref"><summary title="Core rule 435.4 · PDF page 92" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 435.4 · PDF page 92</div></details>

This is not a [[Move]]. ^cr-435-4-a

<details class="rule-ref"><summary title="Core rule 435.4.a · PDF page 92" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 435.4.a · PDF page 92</div></details>

Attaching a [[Card|card]] to another card does not modify either card’s state except in making those cards [[Attached]] and the [[Top-most Card|Top-Most Card]], and causing the Attached card to change [[Location|locations]]. ^cr-435-5

**Example:** An [[Exhaust|exhausted]] [[Equipment|equipment]] being [[Attached|attached]] to a [[Unit|unit]] does not [[Ready|ready]] the equipment.

<details class="rule-ref"><summary title="Core rule 435.5 · PDF page 92" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 435.5 · PDF page 92</div></details>
