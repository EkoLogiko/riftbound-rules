<details class="rule-ref"><summary title="Core rule 170 · PDF page 25" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 170 · PDF page 25</div></details>

Battlefields are Owned by a player. ^cr-170-1

<details class="rule-ref"><summary title="Core rule 170.1 · PDF page 25" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 170.1 · PDF page 25</div></details>

Battlefields are not shuffled into Decks at the start of a game. ^cr-170-2

<details class="rule-ref"><summary title="Core rule 170.2 · PDF page 25" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 170.2 · PDF page 25</div></details>

Battlefields are not played during the course of regular [[Play|play]]. ^cr-170-2-a

<details class="rule-ref"><summary title="Core rule 170.2.a · PDF page 25" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 170.2.a · PDF page 25</div></details>

Battlefields are established at the start of a game and remain in place for the duration of regular [[Play|play]]. ^cr-170-2-b

<details class="rule-ref"><summary title="Core rule 170.2.b · PDF page 25" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 170.2.b · PDF page 25</div></details>

Battlefields cannot be [[Kill|Killed]] during the course of regular [[Play|play]]. ^cr-170-3

<details class="rule-ref"><summary title="Core rule 170.3 · PDF page 25" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 170.3 · PDF page 25</div></details>

Battlefields cannot be Moved. ^cr-170-4

<details class="rule-ref"><summary title="Core rule 170.4 · PDF page 25" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 170.4 · PDF page 25</div></details>

Battlefields are [[Location|Locations]]. ^cr-170-5

<details class="rule-ref"><summary title="Core rule 170.5 · PDF page 25" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 170.5 · PDF page 25</div></details>

Battlefields can be Origins of moves. ^cr-170-5-a

<details class="rule-ref"><summary title="Core rule 170.5.a · PDF page 25" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 170.5.a · PDF page 25</div></details>

Battlefields can be Destinations of moves. ^cr-170-5-b

<details class="rule-ref"><summary title="Core rule 170.5.b · PDF page 25" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 170.5.b · PDF page 25</div></details>

Any number of [[Unit|Units]] can be present at a Battlefield. ^cr-170-6

<details class="rule-ref"><summary title="Core rule 170.6 · PDF page 25" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 170.6 · PDF page 25</div></details>

Battlefields can be targeted by [[Spell|spells]] or [[Game Effect|game effects]]. ^cr-170-7

<details class="rule-ref"><summary title="Core rule 170.7 · PDF page 25" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 170.7 · PDF page 25</div></details>

Battlefields can have [[Passive Ability|Passive Abilities]]. ^cr-170-8

See [[Passive Ability#^cr-363|Passive Abilities]] for more information.

<details class="rule-ref"><summary title="Core rule 170.8 · PDF page 25" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 170.8 · PDF page 25</div></details>

Battlefields can have [[Triggered Ability|Triggered Abilities]]. ^cr-170-9

See [[Triggered Ability#^cr-382|Triggered Abilities]] for more information.

<details class="rule-ref"><summary title="Core rule 170.9 · PDF page 25" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 170.9 · PDF page 25</div></details>

Battlefields can have [[Activated Ability|Activated Abilities]]. ^cr-170-10

See [[Activated Ability#^cr-376|Activated Abilities]] for more information.

<details class="rule-ref"><summary title="Core rule 170.10 · PDF page 25" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 170.10 · PDF page 25</div></details>

Battlefields can be referenced in different states in [[Card|card]] text: ^cr-170-11

<details class="rule-ref"><summary title="Core rule 170.11 · PDF page 26" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 170.11 · PDF page 26</div></details>

Battlefields can be “occupied.” This means they have a [[Unit]] present. ^cr-170-11-a

<details class="rule-ref"><summary title="Core rule 170.11.a · PDF page 26" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 170.11.a · PDF page 26</div></details>

Battlefields can be “uncontrolled.” This means no player controls them. ^cr-170-11-b

<details class="rule-ref"><summary title="Core rule 170.11.b · PDF page 26" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 170.11.b · PDF page 26</div></details>

Battlefields can be “open.” This means they are unoccupied and uncontrolled. ^cr-170-11-c

<details class="rule-ref"><summary title="Core rule 170.11.c · PDF page 26" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 170.11.c · PDF page 26</div></details>

Battlefields are not [[Permanent|Permanents]]. ^cr-171

<details class="rule-ref"><summary title="Core rule 171 · PDF page 26" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 171 · PDF page 26</div></details>

The number of Battlefields on [[Board|the Board]] is determined by the Mode of [[Play]]. ^cr-172
