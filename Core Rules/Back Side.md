# Back Side

[[Start Here|Home]] · [[Concept Index|Find a concept]] · [[Core Rules Index|Core rules]]

<span title="Core rule 129"></span> ^cr-129

<details class="rule-ref"><summary title="Core rule 129 · PDF page 9" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 129 · PDF page 9</div></details>

The back side of a [[Card|card]] is the side with the Riftbound logo. ^cr-129-1

<details class="rule-ref"><summary title="Core rule 129.1 · PDF page 9" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 129.1 · PDF page 9</div></details>

There is a [[Unique|unique]] pattern of back side for each of the three categories of [[Card|card]]: [[Main Deck]] cards, [[Rune Deck]] cards, and [[Battlefield|Battlefields]] and [[Champion]] [[Legend|Legends]]. ^cr-129-2

<details class="rule-ref"><summary title="Core rule 129.2 · PDF page 9" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 129.2 · PDF page 9</div></details>

The back side of a [[Card|card]] is presented to conceal information for Private and [[Secret Information|Secret information]] cards. For example, cards in the [[Main Deck]] and cards in [[Hand|hand]] have their back side presented. ^cr-129-3

<details class="rule-ref"><summary title="Core rule 129.3 · PDF page 10" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 129.3 · PDF page 10</div></details>

The term facedown is used to describe the state during regular [[Play|play]] of having a [[Card|card]]'s back side presented on [[Board|the Board]]. A facedown card’s [[Front Side|front side]] is considered [[Private Information]]. ^cr-129-4
