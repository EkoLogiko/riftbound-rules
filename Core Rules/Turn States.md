# Turn States

[[Start Here|Home]] · [[Concept Index|Find a concept]] · [[Core Rules Index|Core rules]]

<span title="Core rule 307"></span> ^cr-307

<details class="rule-ref"><summary title="Core rule 307 · PDF page 35" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 307 · PDF page 35</div></details>

At any given time, [[Turn|the turn]] is in either a [[Neutral State]] or a [[Showdown State]]. ^cr-308

<details class="rule-ref"><summary title="Core rule 308 · PDF page 36" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 308 · PDF page 36</div></details>

If a [[Showdowns|Showdown]] or [[Combat]] is in progress, [[Turn|the turn]] is in a [[Showdown State]]. ^cr-308-1

<details class="rule-ref"><summary title="Core rule 308.1 · PDF page 36" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 308.1 · PDF page 36</div></details>

Only [[Card|cards]] and [[Ability|abilities]] with the Action or Reaction [[Keywords|keywords]] can be played or activated in a [[Showdown State]]. ^cr-308-1-a

<details class="rule-ref"><summary title="Core rule 308.1.a · PDF page 36" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 308.1.a · PDF page 36</div></details>

If no [[Showdowns|Showdown]] or [[Combat]] is in progress, [[Turn|the turn]] is in a [[Neutral State]]. ^cr-308-2

<details class="rule-ref"><summary title="Core rule 308.2 · PDF page 36" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 308.2 · PDF page 36</div></details>

At any given time, [[Turn|the turn]] is in either an [[Open State]] or a [[Closed State]]. ^cr-309

<details class="rule-ref"><summary title="Core rule 309 · PDF page 36" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 309 · PDF page 36</div></details>

If a [[Chain]] exists, [[Turn|the turn]] is in a [[Closed State]]. ^cr-309-1

<details class="rule-ref"><summary title="Core rule 309.1 · PDF page 36" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 309.1 · PDF page 36</div></details>

Only [[Card|cards]] and [[Ability|abilities]] with the [[Reaction (Keyword)|Reaction keyword]] can be played or activated in a [[Closed State]]. ^cr-309-1-a

<details class="rule-ref"><summary title="Core rule 309.1.a · PDF page 36" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 309.1.a · PDF page 36</div></details>

If no [[Chain]] exists, [[Turn|the turn]] is in an [[Open State]]. ^cr-309-2

<details class="rule-ref"><summary title="Core rule 309.2 · PDF page 36" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 309.2 · PDF page 36</div></details>

These descriptions can be combined, such that [[Turn|the turn]] is always in one of these four states: ^cr-310

<details class="rule-ref"><summary title="Core rule 310 · PDF page 36" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 310 · PDF page 36</div></details>

Neutral Open: There is no [[Showdowns|Showdown]] or [[Combat]] in progress and no [[Chain]] exists. ^cr-310-1

<details class="rule-ref"><summary title="Core rule 310.1 · PDF page 36" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 310.1 · PDF page 36</div></details>

By default, [[Card|cards]] can be played and [[Ability|abilities]] activated only when a player has [[Priority|priority]] on their [[Turn|turn]] in a [[Neutral Open State|Neutral Open state]]. ^cr-310-1-a

<details class="rule-ref"><summary title="Core rule 310.1.a · PDF page 36" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 310.1.a · PDF page 36</div></details>

Neutral Closed: There is no [[Showdowns|Showdown]] or [[Combat]] in progress and a [[Chain]] exists. ^cr-310-2

<details class="rule-ref"><summary title="Core rule 310.2 · PDF page 36" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 310.2 · PDF page 36</div></details>

[[Showdowns|Showdown]] Open: A Showdown or [[Combat]] is in progress and no [[Chain]] exists. ^cr-310-3

<details class="rule-ref"><summary title="Core rule 310.3 · PDF page 36" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 310.3 · PDF page 36</div></details>

[[Showdowns|Showdown]] Closed: A Showdown or [[Combat]] is in progress and a [[Chain]] exists. ^cr-310-4
