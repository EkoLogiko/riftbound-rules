# Detach

[[Start Here|Home]] · [[Concept Index|Find a concept]] · [[Core Rules Index|Core rules]]

<span title="Core rule 436"></span> ^cr-436

<details class="rule-ref"><summary title="Core rule 436 · PDF page 92" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 436 · PDF page 92</div></details>

Detaching is the act of unlinking two [[Card|cards]] that are currently linked through the act of [[Attach|Attaching]]. This causes one to cease being [[Attached]], and potentially causes the other to cease being a [[Top-most Card|Top-Most card]]. ^cr-436-1

<details class="rule-ref"><summary title="Core rule 436.1 · PDF page 92" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 436.1 · PDF page 92</div></details>

Detaching affects only [[Card|cards]] that are currently [[Attached]] to another card. ^cr-436-1-a

<details class="rule-ref"><summary title="Core rule 436.1.a · PDF page 92" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 436.1.a · PDF page 92</div></details>

[[Game Effect|Game effects]] that instruct a player to Detach a [[Card|card]] that is currently not [[Attached]] to anything will do nothing. ^cr-436-1-a-1

<details class="rule-ref"><summary title="Core rule 436.1.a.1 · PDF page 92" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 436.1.a.1 · PDF page 92</div></details>

When one or more [[Card|cards]] become Detached, they cease to be in the [[Attached]] state. ^cr-436-1-b

<details class="rule-ref"><summary title="Core rule 436.1.b · PDF page 92" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 436.1.b · PDF page 92</div></details>

To represent this, these [[Card|cards]] should no longer be placed under the card they were previously placed under as [[Top-most Card|Top-Most Card]]. ^cr-436-1-b-1

<details class="rule-ref"><summary title="Core rule 436.1.b.1 · PDF page 92" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 436.1.b.1 · PDF page 92</div></details>

If the [[Top-most Card|Top-Most Card]] no longer has any [[Card|cards]] [[Attached]] to it after this, it is no longer a Top-Most Card. ^cr-436-1-b-2

<details class="rule-ref"><summary title="Core rule 436.1.b.2 · PDF page 92" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 436.1.b.2 · PDF page 92</div></details>

The [[Card|card]] being Detached has its [[Effect Text]] become [[Inactive]] and its [[Rules Text]] cease being Inactive. ^cr-436-1-c

<details class="rule-ref"><summary title="Core rule 436.1.c · PDF page 92" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 436.1.c · PDF page 92</div></details>

The [[Top-most Card|Top-Most Card]] ceases to have the [[Effect Text]] of the [[Card|card]] being Detached appended to its [[Rules Text]]. ^cr-436-1-d

<details class="rule-ref"><summary title="Core rule 436.1.d · PDF page 92" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 436.1.d · PDF page 92</div></details>

The [[Top-most Card|Top-Most Card]] ceases to have its [[Might]] modulated by the [[Might Bonus]] of the [[Card|card]] being Detached. ^cr-436-1-e

<details class="rule-ref"><summary title="Core rule 436.1.e · PDF page 92" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 436.1.e · PDF page 92</div></details>

Detaching is a [[Limited Action]]. ^cr-436-2

<details class="rule-ref"><summary title="Core rule 436.2 · PDF page 92" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 436.2 · PDF page 92</div></details>

Players may only Detach [[Card|cards]] when directed to by [[Game Effect|Game Effects]]. ^cr-436-2-a

<details class="rule-ref"><summary title="Core rule 436.2.a · PDF page 92" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 436.2.a · PDF page 92</div></details>

Detaching [[Card|cards]] does not inherently choose, or specify a target. However, [[Game Effect|Game Effects]] that Detach cards may. ^cr-436-3

<details class="rule-ref"><summary title="Core rule 436.3 · PDF page 92" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 436.3 · PDF page 92</div></details>

When a [[Card|card]] Detaches from a [[Top-most Card|Top-Most Card]], its [[Location|location]] is the same as the Top-Most Card from which it Detached. ^cr-436-4

<details class="rule-ref"><summary title="Core rule 436.4 · PDF page 92" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 436.4 · PDF page 92</div></details>

If the Detached [[Card|card]] was a [[Gear]] and this causes it to become present at a [[Battlefield]], it will be Recalled during the next [[Cleanups|Cleanup]]. ^cr-436-4-a

See [[Cleanups#^cr-318|Cleanups]] for more information.

<details class="rule-ref"><summary title="Core rule 436.4.a · PDF page 93" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 436.4.a · PDF page 93</div></details>

If the [[Attached]] [[Card|card]] was Detached because the [[Top-most Card|Top-Most Card]] changed [[Zone|zones]] from a [[Board|board]] zone to a non-board zone, then the [[Location|location]] that the Attached Card will Detach to is the last location the Top-Most Card was at before changing from a board zone to a non-board zone. ^cr-436-4-b
