# Conceding

[[Start Here|Home]] · [[Concept Index|Find a concept]] · [[Core Rules Index|Core rules]]

<span title="Core rule 649"></span> ^cr-649

<details class="rule-ref"><summary title="Core rule 649 · PDF page 114" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 649 · PDF page 114</div></details>

A player may concede at any time. ^cr-650

<details class="rule-ref"><summary title="Core rule 650 · PDF page 114" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 650 · PDF page 114</div></details>

When a player concedes, they are removed from the game in progress. ^cr-651

<details class="rule-ref"><summary title="Core rule 651 · PDF page 114" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 651 · PDF page 114</div></details>

If only one other player is remaining after a player has conceded, the player remaining Wins. ^cr-651-1

<details class="rule-ref"><summary title="Core rule 651.1 · PDF page 114" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 651.1 · PDF page 114</div></details>

If more than one player remains after a concession, follow the steps for the Removal of a Player. ^cr-651-2

<details class="rule-ref"><summary title="Core rule 651.2 · PDF page 114" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 651.2 · PDF page 114</div></details>

Removal of a player involves them no longer being able to make choices or otherwise influence the game. ^cr-651-3

<details class="rule-ref"><summary title="Core rule 651.3 · PDF page 114" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 651.3 · PDF page 114</div></details>

If the player has Teammates due to the Mode of [[Play]], that player’s Teammates also lose and are removed from the game. ^cr-651-4

<details class="rule-ref"><summary title="Core rule 651.4 · PDF page 115" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 651.4 · PDF page 115</div></details>

If the game continues, follow these steps for Removal of a Player. ^cr-652

<details class="rule-ref"><summary title="Core rule 652 · PDF page 115" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 652 · PDF page 115</div></details>

[[Banish]] all [[Permanent|permanents]], [[Rune|runes]], and facedown [[Card|cards]] they currently [[Control|control]] and all permanents, runes, and facedown cards they own. ^cr-652-1

<details class="rule-ref"><summary title="Core rule 652.1 · PDF page 115" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 652.1 · PDF page 115</div></details>

Remove the [[Battlefield]] they contributed to the game if it is in use. ^cr-652-2

<details class="rule-ref"><summary title="Core rule 652.2 · PDF page 115" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 652.2 · PDF page 115</div></details>

If it was in use, Replace it with a [[Token|token]] [[Battlefield|battlefield]] with no [[Ability|abilities]]. ^cr-652-2-a

<details class="rule-ref"><summary title="Core rule 652.2.a · PDF page 115" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 652.2.a · PDF page 115</div></details>

Any [[Unit|units]] or [[Hidden|hidden]] [[Card|cards]] there do not [[Move|move]] and are otherwise unaffected by this process. ^cr-652-2-b

See [[Replace#^cr-439|Replace]] for more information.

<details class="rule-ref"><summary title="Core rule 652.2.b · PDF page 115" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 652.2.b · PDF page 115</div></details>

If the removed [[Battlefield|battlefield]] was applying any continuous effects, those continuous effects immediately cease, which may cause changes in the characteristics of [[Unit|units]] or [[Hidden|hidden]] [[Card|cards]] there. ^cr-652-2-c

**Example:** A [[Battlefield|battlefield]] reads "[[Unit|Units]] here have +1 &#91;M&#93;." If that battlefield's owner concedes and the battlefield is removed from the game as a result, units there immediately cease to get +1 &#91;M&#93;.

<details class="rule-ref"><summary title="Core rule 652.2.c · PDF page 115" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 652.2.c · PDF page 115</div></details>

Remove all [[Card|cards]] they own from the game. ^cr-652-3

<details class="rule-ref"><summary title="Core rule 652.3 · PDF page 115" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 652.3 · PDF page 115</div></details>

Counter all [[Spell|spells]] and [[Ability|abilities]] of all types controlled by the player that has conceded. ^cr-652-4

<details class="rule-ref"><summary title="Core rule 652.4 · PDF page 115" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 652.4 · PDF page 115</div></details>

Proceed with the game. ^cr-652-5

<details class="rule-ref"><summary title="Core rule 652.5 · PDF page 115" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 652.5 · PDF page 115</div></details>

[[Turn]] ^cr-652-5-a

<details class="rule-ref"><summary title="Core rule 652.5.a · PDF page 115" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 652.5.a · PDF page 115</div></details>

If the removed player was [[Turn|the Turn]] Player, [[Play|play]] proceeds in Turn Order to the next available player in order. ^cr-652-5-a-1

<details class="rule-ref"><summary title="Core rule 652.5.a.1 · PDF page 115" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 652.5.a.1 · PDF page 115</div></details>

[[Focus]] ^cr-652-5-b

<details class="rule-ref"><summary title="Core rule 652.5.b · PDF page 115" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 652.5.b · PDF page 115</div></details>

If the removed player had [[Focus]] in a [[Showdowns|Showdown]], the next Player in order receives Focus. ^cr-652-5-b-1

<details class="rule-ref"><summary title="Core rule 652.5.b.1 · PDF page 115" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 652.5.b.1 · PDF page 115</div></details>

If the player being removed creates a state where all Players have Passed their [[Focus]], the [[Showdowns|Showdown]] ends and [[Play|play]] proceeds as necessary, E.G. [[Combat]] is resolved or a [[Cleanups|Cleanup]] is completed. ^cr-652-5-b-2

<details class="rule-ref"><summary title="Core rule 652.5.b.2 · PDF page 115" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 652.5.b.2 · PDF page 115</div></details>

[[Priority]] ^cr-652-5-c

<details class="rule-ref"><summary title="Core rule 652.5.c · PDF page 115" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 652.5.c · PDF page 115</div></details>

If the removed player had [[Priority]] during a [[Chain]], the next Player in order receives Priority. ^cr-652-5-c-1

<details class="rule-ref"><summary title="Core rule 652.5.c.1 · PDF page 115" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 652.5.c.1 · PDF page 115</div></details>

If the player being removed creates a state where all Players have passed [[Priority]], then the most recent [[Spell|spell]] or [[Ability|ability]] on the [[Chain]] will resolve with Priority being re-established as appropriate for the state after the resolution of that spell or ability. ^cr-652-5-c-2

<details class="rule-ref"><summary title="Core rule 652.5.c.2 · PDF page 115" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 652.5.c.2 · PDF page 115</div></details>
