# Ready

[[Start Here|Home]] · [[Concept Index|Find a concept]] · [[Core Rules Index|Core rules]]

<span title="Core rule 416"></span> ^cr-416

<details class="rule-ref"><summary title="Core rule 416 · PDF page 79" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 416 · PDF page 79</div></details>

Readying is an action that marks a non-spell [[Game Object]] on [[Board|the board]] as available for action. ^cr-416-1

<details class="rule-ref"><summary title="Core rule 416.1 · PDF page 79" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 416.1 · PDF page 79</div></details>

To mark it, rotate the [[Card|card]] 90 degrees opposite of [[Exhaust|Exhausting]], so that it is vertically oriented in front of you. ^cr-416-1-a

<details class="rule-ref"><summary title="Core rule 416.1.a · PDF page 79" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 416.1.a · PDF page 79</div></details>

A [[Unit]] that is already Ready cannot be Readied again. ^cr-416-1-b

<details class="rule-ref"><summary title="Core rule 416.1.b · PDF page 79" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 416.1.b · PDF page 79</div></details>

If a [[Unit]] is instructed to be Readied while it is already Ready, nothing additional happens. ^cr-416-1-c

<details class="rule-ref"><summary title="Core rule 416.1.c · PDF page 79" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 416.1.c · PDF page 79</div></details>

"Ready" is a state for [[Game Object|Game Objects]] on [[Board|the board]] that other [[Game Effect|game effects]] and rules can reference. ^cr-416-2

<details class="rule-ref"><summary title="Core rule 416.2 · PDF page 79" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 416.2 · PDF page 79</div></details>

This is a [[Limited Action]]. ^cr-416-3

<details class="rule-ref"><summary title="Core rule 416.3 · PDF page 79" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 416.3 · PDF page 79</div></details>

A player Readies all non-spell [[Game Object|Game Objects]] they [[Control]] during the Awakening Phase on their [[Turn|turn]]. ^cr-416-3-a

<details class="rule-ref"><summary title="Core rule 416.3.a · PDF page 79" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 416.3.a · PDF page 79</div></details>

Players may also Ready [[Game Object|Game Objects]] on [[Board|the board]] when effects or [[Spell|spells]] instruct them to do so. ^cr-416-3-b

<details class="rule-ref"><summary title="Core rule 416.3.b · PDF page 79" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 416.3.b · PDF page 79</div></details>
