# XP

[[Start Here|Home]] · [[Concept Index|Find a concept]] · [[Core Rules Index|Core rules]]

<span title="Core rule 728"></span> ^cr-728

<details class="rule-ref"><summary title="Core rule 728 · PDF page 120" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 728 · PDF page 120</div></details>

XP is a resource that is accrued, spent, or otherwise modified by Players through the course of [[Play|play]]. ^cr-729

<details class="rule-ref"><summary title="Core rule 729 · PDF page 120" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 729 · PDF page 120</div></details>

The amount of XP that a player has should be marked clearly. ^cr-729-1

<details class="rule-ref"><summary title="Core rule 729.1 · PDF page 120" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 729.1 · PDF page 120</div></details>

XP is a value that can be tracked by [[Counter (Object)|counters]], dice, [[Card|cards]], or any method that clearly displays the specific value of XP that is currently on a Player. ^cr-729-1-a

<details class="rule-ref"><summary title="Core rule 729.1.a · PDF page 120" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 729.1.a · PDF page 120</div></details>

The amount of XP a Player has is [[Public Information]]. ^cr-729-2

<details class="rule-ref"><summary title="Core rule 729.2 · PDF page 120" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 729.2 · PDF page 120</div></details>

XP can be Gained and Spent. ^cr-730

<details class="rule-ref"><summary title="Core rule 730 · PDF page 120" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 730 · PDF page 120</div></details>

To Gain XP, increase the value of XP marked on the Player gaining it. ^cr-730-1

<details class="rule-ref"><summary title="Core rule 730.1 · PDF page 120" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 730.1 · PDF page 120</div></details>

To Spend XP, reduce the value of XP marked on the Player spending it. ^cr-730-2

<details class="rule-ref"><summary title="Core rule 730.2 · PDF page 120" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 730.2 · PDF page 120</div></details>

XP is not a [[Game Object]]. ^cr-731

<details class="rule-ref"><summary title="Core rule 731 · PDF page 120" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 731 · PDF page 120</div></details>

XP cannot be targeted, [[Ready|readied]], or [[Exhaust|exhausted]]. ^cr-731-1

<details class="rule-ref"><summary title="Core rule 731.1 · PDF page 120" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 731.1 · PDF page 120</div></details>

XP is not shared between Allies in Game Modes with Teammates. ^cr-732

<details class="rule-ref"><summary title="Core rule 732 · PDF page 121" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 732 · PDF page 121</div></details>

There is no limit to an amount of XP a player can accrue. ^cr-733

<details class="rule-ref"><summary title="Core rule 733 · PDF page 121" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 733 · PDF page 121</div></details>
