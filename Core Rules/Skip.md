# Skip

[[Start Here|Home]] · [[Concept Index|Find a concept]] · [[Core Rules Index|Core rules]]

<span title="Core rule 444"></span> ^cr-444

<details class="rule-ref"><summary title="Core rule 444 · PDF page 97" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 444 · PDF page 97</div></details>

Skipping an event is the act of replacing that event with nothing. ^cr-444-1

<details class="rule-ref"><summary title="Core rule 444.1 · PDF page 97" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 444.1 · PDF page 97</div></details>

Skip is an action that interacts with events and procedures of [[Turn|the turn]]. ^cr-444-1-a

**Example:** A [[Card|card]] reads in part “Choose an [[Enemy|enemy]] [[Unit|unit]]. Skip the next time that unit would [[Move|move]] this [[Turn|turn]].” This is a [[Replacement Effect|replacement effect]] that replaces the event of a unit [[Movement|moving]] with nothing.

**Example:** A [[Card|card]] reads in part “Skip your [[Draw Phase|Draw phase]].” This is a [[Replacement Effect|replacement effect]] that replaces a player’s Draw Phase with nothing.

**Example:** A [[Card|card]] reads in part “Choose a player. They skip their next point from [[Conquer|conquering]] this [[Turn|turn]].” This is a [[Replacement Effect|replacement effect]] that replaces the 1 point gained when conquering with nothing.

<details class="rule-ref"><summary title="Core rule 444.1.a · PDF page 97" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 444.1.a · PDF page 97</div></details>

An event is the singular moment that results from a [[Game Action]] being performed or from a [[Game Object]] changing state. ^cr-444-1-a-1

See [[Replacement Effect#^cr-367|Replacement Effects]] for more information.

<details class="rule-ref"><summary title="Core rule 444.1.a.1 · PDF page 97" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 444.1.a.1 · PDF page 97</div></details>

Procedures of [[Turn|the turn]] include turns, phases, steps, and substeps. ^cr-444-1-a-2

<details class="rule-ref"><summary title="Core rule 444.1.a.2 · PDF page 97" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 444.1.a.2 · PDF page 97</div></details>

Skip actions are usually formatted as “Skip &#91;event or procedure of [[Turn|the turn]]&#93;.” ^cr-444-1-b

<details class="rule-ref"><summary title="Core rule 444.1.b · PDF page 97" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 444.1.b · PDF page 97</div></details>

When an event or procedure of [[Turn|the turn]] is Skipped, it is replaced with nothing. [[Play]] proceeds accordingly. ^cr-444-2

<details class="rule-ref"><summary title="Core rule 444.2 · PDF page 97" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 444.2 · PDF page 97</div></details>

Anything that triggers on the occurrence of the event or procedure of [[Turn|the turn]] does not trigger. ^cr-444-2-a

<details class="rule-ref"><summary title="Core rule 444.2.a · PDF page 97" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 444.2.a · PDF page 97</div></details>

Skip is a [[Limited Action]]. ^cr-444-3

<details class="rule-ref"><summary title="Core rule 444.3 · PDF page 97" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 444.3 · PDF page 97</div></details>

Players may only Skip events or procedures of [[Turn|the turn]] when directed to by [[Game Effect|Game Effects]]. ^cr-444-3-a

<details class="rule-ref"><summary title="Core rule 444.3.a · PDF page 97" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 444.3.a · PDF page 97</div></details>

Skip is a [[Replacement Effect]]. ^cr-444-4

See [[Replacement Effect#^cr-367|Replacement Effects]] for more information.
