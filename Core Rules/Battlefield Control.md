# Battlefield Control

[[Start Here|Home]] · [[Concept Index|Find a concept]] · [[Core Rules Index|Core rules]]

<span title="Core rule 190"></span> ^cr-190

<details class="rule-ref"><summary title="Core rule 190 · PDF page 29" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 190 · PDF page 29</div></details>

[[Control]] is established over [[Battlefield|Battlefields]] through the course of [[Play|play]]. ^cr-190-1

<details class="rule-ref"><summary title="Core rule 190.1 · PDF page 29" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 190.1 · PDF page 29</div></details>

[[Control]] is a binary state for [[Battlefield|Battlefields]] and an Identifier for players. ^cr-190-2

<details class="rule-ref"><summary title="Core rule 190.2 · PDF page 29" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 190.2 · PDF page 29</div></details>

A [[Battlefield]] is Controlled or Uncontrolled. ^cr-190-2-a

<details class="rule-ref"><summary title="Core rule 190.2.a · PDF page 30" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 190.2.a · PDF page 30</div></details>

A [[Battlefield]] is Controlled by a specific player or Controlled by no one. ^cr-190-2-b

<details class="rule-ref"><summary title="Core rule 190.2.b · PDF page 30" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 190.2.b · PDF page 30</div></details>

[[Control]] can be [[Contested]] through the course of [[Play|play]]. ^cr-190-3

<details class="rule-ref"><summary title="Core rule 190.3 · PDF page 30" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 190.3 · PDF page 30</div></details>

[[Contested]] is a [[Temporary|temporary]] status applied to a [[Battlefield]] when a [[Unit]] controlled by a Player who does not currently [[Control]] that Battlefield Moves or otherwise becomes present there. ^cr-190-3-a

<details class="rule-ref"><summary title="Core rule 190.3.a · PDF page 30" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 190.3.a · PDF page 30</div></details>

[[Unit|Units]] [[Movement|moving]] to or being played to a [[Battlefield|battlefield]] apply [[Contested]] status if that Battlefield is not already Contested and that Unit’s controller does not already [[Control|control]] that battlefield. ^cr-190-3-a-1

<details class="rule-ref"><summary title="Core rule 190.3.a.1 · PDF page 30" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 190.3.a.1 · PDF page 30</div></details>

A [[Unit]] changing controller while located at a [[Battlefield]] will also apply [[Contested]] status to that Battlefield if it isn’t Contested and if the new controller doesn’t [[Control|control]] that Battlefield. ^cr-190-3-a-2

<details class="rule-ref"><summary title="Core rule 190.3.a.2 · PDF page 30" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 190.3.a.2 · PDF page 30</div></details>

Once a [[Showdowns|Showdown]] or [[Combat]] begins at a [[Battlefield]], it remains [[Contested]] until [[Control]] is established or re-established. ^cr-190-3-b

<details class="rule-ref"><summary title="Core rule 190.3.b · PDF page 30" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 190.3.b · PDF page 30</div></details>

If a player who applied [[Contested]] status to a [[Battlefield]] controls no [[Unit|Units]] there and there is no ongoing [[Showdowns|Showdown]] or [[Combat]] at that Battlefield, then Contested status is removed in the following [[Cleanups|Cleanup]]. ^cr-190-3-b-1

<details class="rule-ref"><summary title="Core rule 190.3.b.1 · PDF page 30" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 190.3.b.1 · PDF page 30</div></details>

The state of a [[Battlefield]] being [[Contested]] is used to determine when [[Combat]] should occur and when a Non-Combat [[Showdowns|Showdown]] should occur. ^cr-190-3-c

<details class="rule-ref"><summary title="Core rule 190.3.c · PDF page 30" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 190.3.c · PDF page 30</div></details>

At this time [[Game Effect|Game Effects]] cannot reference this status. ^cr-190-3-d

<details class="rule-ref"><summary title="Core rule 190.3.d · PDF page 30" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 190.3.d · PDF page 30</div></details>

[[Control]] is established by having [[Unit|Units]] at a [[Battlefield]] at the end of a [[Showdowns|Showdown]] or [[Combat]] after applying the [[Contested|contested]] status. ^cr-190-4

<details class="rule-ref"><summary title="Core rule 190.4 · PDF page 30" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 190.4 · PDF page 30</div></details>

If a player controls [[Unit|Units]] at a [[Battlefield]], outside of [[Combat]], they maintain [[Control]] of that Battlefield for as long as they have Units at that Battlefield. ^cr-190-4-a

<details class="rule-ref"><summary title="Core rule 190.4.a · PDF page 30" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 190.4.a · PDF page 30</div></details>

While a [[Combat]] or [[Showdowns|Showdown]] is ongoing at a [[Battlefield]], [[Control]] of that Battlefield cannot change until instructed by steps of the Combat or Showdown. ^cr-190-4-b

<details class="rule-ref"><summary title="Core rule 190.4.b · PDF page 30" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 190.4.b · PDF page 30</div></details>

If a player has no [[Unit|Units]] at a [[Battlefield]] and [[Turn|the turn]] is in an [[Open State|Open state]], they lose [[Control]] of that Battlefield in the following [[Cleanups|cleanup]] unless there is a [[Combat]] or [[Showdowns|Showdown]] ongoing there. ^cr-190-4-c

<details class="rule-ref"><summary title="Core rule 190.4.c · PDF page 30" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 190.4.c · PDF page 30</div></details>

[[Control]] is a constant state. ^cr-190-5

<details class="rule-ref"><summary title="Core rule 190.5 · PDF page 30" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 190.5 · PDF page 30</div></details>

[[Control]] of a [[Battlefield]] determines Control of its [[Ability|Abilities]]. ^cr-190-6

<details class="rule-ref"><summary title="Core rule 190.6 · PDF page 30" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 190.6 · PDF page 30</div></details>

While a [[Battlefield]] is Controlled, its Controller controls its [[Ability|Abilities]] unless that ability indicates another player does. The controlling player takes [[Responsibility|responsibility]] for adding them to the [[Chain]] if applicable, and makes all choices required by them unless otherwise specified. ^cr-190-6-a

<details class="rule-ref"><summary title="Core rule 190.6.a · PDF page 30" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 190.6.a · PDF page 30</div></details>

While a [[Battlefield]] is Uncontrolled, its [[Ability|Abilities]] are also Uncontrolled unless that ability indicates a player controls it. If there is no such indication, [[Turn|the Turn]] Player takes [[Responsibility|responsibility]] for adding them to the [[Chain]] if applicable, makes all choices required by them unless otherwise specified, and is treated as their Controller if any game rule or effect requires one. ^cr-190-6-b

**Example:** The Arena’s Greatest is a [[Battlefield|battlefield]] that reads “At the start of each player's first [[Beginning Phase]], that player gains 1 point.” This [[Ability|ability]] will usually trigger while the battlefield has no controller. If it does, [[Turn|the Turn]] Player goes through the steps of adding the ability to the [[Chain|chain]] and receives [[Priority|priority]] after doing so, exactly as if they controlled the ability.

<details class="rule-ref"><summary title="Core rule 190.6.b · PDF page 31" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 190.6.b · PDF page 31</div></details>

If an [[Ability]] of a [[Battlefield]] indicates that a specific player makes a choice, that player is the Ability’s controller. They take [[Responsibility|responsibility]] for adding it to the [[Chain|chain]] if applicable and make all choices required by the ability. They and only they [[Control|control]] the ability, regardless of who controls the Battlefield. ^cr-190-6-c

**Example:** Abandoned Hall is a [[Battlefield|battlefield]] that reads “When a player plays a [[Spell|spell]], they may give a [[Unit|unit]] they [[Control|control]] here +1 [[Might|might]] this [[Turn|turn]].” The [[Ability|ability]] indicates that the player who played the spell makes the choice, so that player takes [[Responsibility|responsibility]] for putting the ability on the [[Chain|chain]] and makes all choices. They control the [[Triggered Ability|triggered ability]].

<details class="rule-ref"><summary title="Core rule 190.6.c · PDF page 31" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 190.6.c · PDF page 31</div></details>

“You” in a [[Battlefield|battlefield]]’s [[Ability|abilities]] refers to the battlefield’s Controller, as does the implied “you” in [[Instructions|instructions]] that don’t specify a player like “[[Draw|draw]] 1.” If the battlefield has no Controller, “you” refers to no one, and all such instructions are ignored. ^cr-190-6-d
