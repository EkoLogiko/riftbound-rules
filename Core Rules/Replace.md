# Replace

[[Start Here|Home]] · [[Concept Index|Find a concept]] · [[Core Rules Index|Core rules]]

<span title="Core rule 439"></span> ^cr-439

<details class="rule-ref"><summary title="Core rule 439 · PDF page 94" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 439 · PDF page 94</div></details>

Replacing is the act of Creating a [[Token|token]] in the place of another [[Card|card]] or token without playing it while inheriting all effects or statuses of the [[Game Object|game object]] it replaced. ^cr-439-1

<details class="rule-ref"><summary title="Core rule 439.1 · PDF page 94" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 439.1 · PDF page 94</div></details>

The replacing [[Token|token]] is treated as the same [[Game Object]] as the [[Card|card]] or token it replaced for the purposes of [[Game Effect|Game Effects]] that target or reference that game object. ^cr-439-1-a

**Example:** A player with Green Father as their [[Legend|legend]] conquers Navori Fighting Pit. They choose to place the Green Father [[Conquer Effect|conquer effect]] on the [[Chain|chain]] after the Navori Fighting Pit conquer effect. When the Green Father trigger resolves, Navori Fighting Pit is replaced with Brush. Although the Navori Fighting Pit has been replaced, the “here” in its [[Triggered Ability|triggered ability]] still can have its information referenced, because the Brush inherited all statuses and conditions. The [[Unit|unit]] Navori Fighting Pit’s triggered ability has targeted will still be a legal target on resolution.

<details class="rule-ref"><summary title="Core rule 439.1.a · PDF page 94" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 439.1.a · PDF page 94</div></details>

Replacing is a [[Limited Action]]. ^cr-439-2

<details class="rule-ref"><summary title="Core rule 439.2 · PDF page 94" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 439.2 · PDF page 94</div></details>

The player may Replace [[Card|cards]] and [[Token|tokens]] when instructed to do so by other [[Game Effect|game effects]]. ^cr-439-2-a

<details class="rule-ref"><summary title="Core rule 439.2.a · PDF page 94" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 439.2.a · PDF page 94</div></details>

This action, when instructed, is formatted as "Replace &#91;X&#93; with &#91;Y&#93;." ^cr-439-3

<details class="rule-ref"><summary title="Core rule 439.3 · PDF page 94" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 439.3 · PDF page 94</div></details>

The &#91;X&#93; is the target to be Replaced. ^cr-439-3-a

<details class="rule-ref"><summary title="Core rule 439.3.a · PDF page 94" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 439.3.a · PDF page 94</div></details>

The &#91;Y&#93; is the object that will Replace the target. ^cr-439-3-b

<details class="rule-ref"><summary title="Core rule 439.3.b · PDF page 94" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 439.3.b · PDF page 94</div></details>

This will always specify a [[Token]] to create. ^cr-439-3-b-1

<details class="rule-ref"><summary title="Core rule 439.3.b.1 · PDF page 95" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 439.3.b.1 · PDF page 95</div></details>

Replacing is not a subset of Banishing. ^cr-439-4

<details class="rule-ref"><summary title="Core rule 439.4 · PDF page 95" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 439.4 · PDF page 95</div></details>

The [[Card|card]] or [[Token|token]] that is Replaced is placed in [[Banishment]]. ^cr-439-5

<details class="rule-ref"><summary title="Core rule 439.5 · PDF page 95" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 439.5 · PDF page 95</div></details>

While it resides in [[Banishment]], it is considered to have been Replaced and not Banished. ^cr-439-5-a

<details class="rule-ref"><summary title="Core rule 439.5.a · PDF page 95" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 439.5.a · PDF page 95</div></details>

If a [[Token|token]] is Replaced it will stop existing once it begins its occupancy in [[Banishment]]. ^cr-439-6

<details class="rule-ref"><summary title="Core rule 439.6 · PDF page 95" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 439.6 · PDF page 95</div></details>

This does not invalidate the [[Token|token]] created, or the act of Replacement. ^cr-439-6-a

<details class="rule-ref"><summary title="Core rule 439.6.a · PDF page 95" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 439.6.a · PDF page 95</div></details>

[[Token|Tokens]] that have been Created through a Replace action can be instructed to be “Swapped back.” This may also appear as “replace &#91;the token&#93; with the &#91;[[Game Object]]&#93; it replaced.” ^cr-439-7

<details class="rule-ref"><summary title="Core rule 439.7 · PDF page 95" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 439.7 · PDF page 95</div></details>

Swapping Back is an extension of the Replace action. ^cr-439-7-a

<details class="rule-ref"><summary title="Core rule 439.7.a · PDF page 95" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 439.7.a · PDF page 95</div></details>

To [[Swap]] Back, the [[Token|token]] stops existing and the original [[Card|card]] is returned to the space that the token just occupied, inheriting all current effects and statuses. ^cr-439-7-b

<details class="rule-ref"><summary title="Core rule 439.7.b · PDF page 95" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 439.7.b · PDF page 95</div></details>

Any [[Card|card]] that has been Replaced by that [[Token|token]] or any tokens it Replaced is eligible to [[Swap|swap]] back in this way. ^cr-439-7-b-1

<details class="rule-ref"><summary title="Core rule 439.7.b.1 · PDF page 95" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 439.7.b.1 · PDF page 95</div></details>

If there is nothing in [[Banishment]] to [[Swap|swap]] back to then this object can never swap back. ^cr-439-7-c

<details class="rule-ref"><summary title="Core rule 439.7.c · PDF page 95" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 439.7.c · PDF page 95</div></details>
