# Recalls

<span title="Core rule 456"></span> ^cr-456

<details class="rule-ref"><summary title="Core rule 456 · PDF page 99" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 456 · PDF page 99</div></details>

A Recall is when a [[Permanent]] is relocated from anywhere to its [[Base]] without it being a [[Move]]. ^cr-457

<details class="rule-ref"><summary title="Core rule 457 · PDF page 99" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 457 · PDF page 99</div></details>

Recalls are not Moves. ^cr-458

<details class="rule-ref"><summary title="Core rule 458 · PDF page 100" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 458 · PDF page 100</div></details>

They do not cause [[Triggered Ability|Triggered Abilities]] to trigger that are triggered by [[Move]] actions. ^cr-458-1

<details class="rule-ref"><summary title="Core rule 458.1 · PDF page 100" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 458.1 · PDF page 100</div></details>

A Recall causes a [[Permanent]] to change [[Location|locations]]. ^cr-458-2

<details class="rule-ref"><summary title="Core rule 458.2 · PDF page 100" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 458.2 · PDF page 100</div></details>

A Recall cannot be prevented by actions and [[Game Effect|Game Effects]] that restrict or block [[Movement]]. ^cr-458-3

<details class="rule-ref"><summary title="Core rule 458.3 · PDF page 100" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 458.3 · PDF page 100</div></details>

[[Gear]] can be Recalled. ^cr-459

<details class="rule-ref"><summary title="Core rule 459 · PDF page 100" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 459 · PDF page 100</div></details>

When an un-attached non-Unit [[Gear]] without [[Deploy|deploy]] is created or played at a [[Battlefield|battlefield]], or is at a battlefield for any other reason, it is Recalled to its controller's [[Base|base]] during the next [[Cleanups|Cleanup]]. ^cr-459-1

**Example:** An [[Equipment]] is [[Attached|attached]] to a [[Unit|unit]] at a [[Battlefield|battlefield]], so the Equipment is present at that battlefield. If the unit dies, the Equipment will be recalled during the next [[Cleanups|cleanup]].

<details class="rule-ref"><summary title="Core rule 459.1 · PDF page 100" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 459.1 · PDF page 100</div></details>

Recalls do not affect the state of the [[Permanent]] being recalled. ^cr-460

<details class="rule-ref"><summary title="Core rule 460 · PDF page 100" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 460 · PDF page 100</div></details>

Unless otherwise stated by the source of the Recall, [[Damage]] and statuses of a [[Permanent|permanent]] will all remain unaffected by a Recall. ^cr-460-1

<details class="rule-ref"><summary title="Core rule 460.1 · PDF page 100" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 460.1 · PDF page 100</div></details>
