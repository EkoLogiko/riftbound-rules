# Scoring

[[Start Here|Home]] · [[Concept Index|Find a concept]] · [[Core Rules Index|Core rules]]

<span title="Core rule 469"></span> ^cr-469

<details class="rule-ref"><summary title="Core rule 469 · PDF page 105" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 469 · PDF page 105</div></details>

Scoring is the act of a Player seizing or maintaining [[Control|control]] over [[Battlefield|Battlefields]] they have not yet Scored this [[Turn|turn]]. ^cr-470

<details class="rule-ref"><summary title="Core rule 470 · PDF page 105" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 470 · PDF page 105</div></details>

Scoring is a distinct process from Gaining [[Points]]. Scoring may result in a player Gaining Points, but the two are not intrinsically linked. ^cr-470-1

<details class="rule-ref"><summary title="Core rule 470.1 · PDF page 105" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 470.1 · PDF page 105</div></details>

[[Card]] text will refer to the process of Gaining [[Points]] in the following way: “Score X points.” The “score” in this text does not refer to the process of Scoring. ^cr-470-2

<details class="rule-ref"><summary title="Core rule 470.2 · PDF page 105" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 470.2 · PDF page 105</div></details>

[[Card]] text will refer to the process of Scoring using the word “score” without referring to some number of [[Points|points]]. This does refer to the process of Scoring. ^cr-470-3

<details class="rule-ref"><summary title="Core rule 470.3 · PDF page 105" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 470.3 · PDF page 105</div></details>

A player Scores in one of two ways: ^cr-471

<details class="rule-ref"><summary title="Core rule 471 · PDF page 105" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 471 · PDF page 105</div></details>

[[Conquer]]: A player gains [[Control]] of a [[Battlefield]] they did not yet Score this [[Turn|turn]]. ^cr-471-1

<details class="rule-ref"><summary title="Core rule 471.1 · PDF page 105" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 471.1 · PDF page 105</div></details>

In [[Modes of Play]] with teammates, [[Battlefield|Battlefields]] under the [[Control]] of a teammate during the [[Scoring Step|scoring step]] of the [[Beginning Phase]] of a player’s [[Turn|turn]] are also disqualified from being Scored through [[Conquer]] by any means by that player’s team. ^cr-471-1-a

<details class="rule-ref"><summary title="Core rule 471.1.a · PDF page 105" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 471.1.a · PDF page 105</div></details>

A player will gain [[Control|control]] of a [[Battlefield]] after establishing Control. ^cr-471-1-b

<details class="rule-ref"><summary title="Core rule 471.1.b · PDF page 105" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 471.1.b · PDF page 105</div></details>

[[Hold]]: A player maintains [[Control]] of a [[Battlefield]] they did not yet Score this [[Turn|turn]] during their [[Beginning Phase]]. ^cr-471-2

<details class="rule-ref"><summary title="Core rule 471.2 · PDF page 105" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 471.2 · PDF page 105</div></details>

A player may only Score, from either method, once per [[Battlefield]] per [[Turn|turn]]. ^cr-472

<details class="rule-ref"><summary title="Core rule 472 · PDF page 105" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 472 · PDF page 105</div></details>

When a player Scores, two things occur: ^cr-473

<details class="rule-ref"><summary title="Core rule 473 · PDF page 105" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 473 · PDF page 105</div></details>

The player Gains up to one Point, depending on their current score. ^cr-473-1

<details class="rule-ref"><summary title="Core rule 473.1 · PDF page 105" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 473.1 · PDF page 105</div></details>

The Final Point has additional restrictions. ^cr-473-1-a

<details class="rule-ref"><summary title="Core rule 473.1.a · PDF page 105" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 473.1.a · PDF page 105</div></details>

Notably, [[Points|points]] Gained from sources that are not [[Conquer]] are not beholden to these restrictions. ^cr-473-1-a-1

<details class="rule-ref"><summary title="Core rule 473.1.a.1 · PDF page 106" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 473.1.a.1 · PDF page 106</div></details>

When a player tries to Gain a Point through a [[Conquer]], and their current Point Total is 1 point from the [[Victory Score]] of the Mode of [[Play]] or higher, the following occurs: ^cr-473-1-b

<details class="rule-ref"><summary title="Core rule 473.1.b · PDF page 106" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 473.1.b · PDF page 106</div></details>

If the player has Scored every [[Battlefield]] this [[Turn|turn]], that player Gains the Final Point. If the player has not Scored every Battlefield this turn, that player draws a [[Card|card]] instead. ^cr-473-1-b-1

<details class="rule-ref"><summary title="Core rule 473.1.b.1 · PDF page 106" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 473.1.b.1 · PDF page 106</div></details>

Trigger Score [[Ability|abilities]] at the [[Battlefield]] that Scored. ^cr-473-2

<details class="rule-ref"><summary title="Core rule 473.2 · PDF page 106" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 473.2 · PDF page 106</div></details>

[[Conquer]] [[Ability|abilities]] trigger at a [[Battlefield]] that was Conquered. ^cr-473-2-a

<details class="rule-ref"><summary title="Core rule 473.2.a · PDF page 106" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 473.2.a · PDF page 106</div></details>

[[Hold]] [[Ability|abilities]] trigger at a [[Battlefield]] that was Held. ^cr-473-2-b

<details class="rule-ref"><summary title="Core rule 473.2.b · PDF page 106" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 473.2.b · PDF page 106</div></details>

These will only trigger when the [[Battlefield]] is Scored; I.E. These cannot be triggered more than once per [[Turn|turn]] for a player. ^cr-473-2-c

<details class="rule-ref"><summary title="Core rule 473.2.c · PDF page 106" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 473.2.c · PDF page 106</div></details>

When a [[Cleanups|cleanup]] occurs and a player has accrued [[Points]] greater than or equal to the [[Victory Score]] for their Mode of [[Play]], and if they have more points than every opponent, they Win the Game. ^cr-474

<details class="rule-ref"><summary title="Core rule 474 · PDF page 106" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 474 · PDF page 106</div></details>
