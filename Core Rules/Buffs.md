# Buffs

[[Start Here|Home]] · [[Concept Index|Find a concept]] · [[Core Rules Index|Core rules]]

<span title="Core rule 701"></span> ^cr-701

<details class="rule-ref"><summary title="Core rule 701 · PDF page 115" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 701 · PDF page 115</div></details>

Buffs are [[Counter (Object)|counters]] placed on [[Unit|Units]]. ^cr-702

<details class="rule-ref"><summary title="Core rule 702 · PDF page 115" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 702 · PDF page 115</div></details>

Buffs can be tracked with a buff reminder [[Card|card]] from a Riftbound booster pack or with any spare object in your surroundings. ^cr-702-1

<details class="rule-ref"><summary title="Core rule 702.1 · PDF page 116" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 702.1 · PDF page 116</div></details>

Buffs can be added or spent. ^cr-702-2

<details class="rule-ref"><summary title="Core rule 702.2 · PDF page 116" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 702.2 · PDF page 116</div></details>

To Buff a [[Unit]], a player chooses a Unit and then places a buff on it. That Unit is Buffed for as long as the buff remains on it. ^cr-702-2-a

<details class="rule-ref"><summary title="Core rule 702.2.a · PDF page 116" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 702.2.a · PDF page 116</div></details>

Spending a Buff removes a single Buff counter from a [[Unit]]. ^cr-702-2-b

<details class="rule-ref"><summary title="Core rule 702.2.b · PDF page 116" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 702.2.b · PDF page 116</div></details>

A buff cannot be spent from a [[Unit]] that does not have a buff. ^cr-702-2-b-1

<details class="rule-ref"><summary title="Core rule 702.2.b.1 · PDF page 116" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 702.2.b.1 · PDF page 116</div></details>

A player can only spend buffs on [[Unit|units]] they [[Control|control]]. ^cr-702-2-b-2

<details class="rule-ref"><summary title="Core rule 702.2.b.2 · PDF page 116" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 702.2.b.2 · PDF page 116</div></details>

There can only be one Buff on a [[Unit]] at a time. ^cr-702-3

<details class="rule-ref"><summary title="Core rule 702.3 · PDF page 116" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 702.3 · PDF page 116</div></details>

If a Buff is added, or instructed to be added, on a [[Unit]] that already has a Buff, it is not placed instead. ^cr-702-3-a

<details class="rule-ref"><summary title="Core rule 702.3.a · PDF page 116" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 702.3.a · PDF page 116</div></details>

Each Buff individually contributes +1 [[Might]] to a [[Unit]]. ^cr-703

<details class="rule-ref"><summary title="Core rule 703 · PDF page 116" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 703 · PDF page 116</div></details>

Buffs are [[Game Object|Game Objects]] and may be referenced, counted, or affected by other effects as specified. ^cr-704

<details class="rule-ref"><summary title="Core rule 704 · PDF page 116" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 704 · PDF page 116</div></details>

Buffs are [[Counter (Object)|counters]], and thus are not targeted by [[Spell|spells]] and [[Ability|abilities]]. ^cr-704-1

See [[Counter (Object)#^cr-741|Counters]] for more information.

<details class="rule-ref"><summary title="Core rule 704.1 · PDF page 116" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 704.1 · PDF page 116</div></details>

If a [[Unit]] leaves [[Play|play]], remove all Buffs from it. ^cr-705

<details class="rule-ref"><summary title="Core rule 705 · PDF page 116" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 705 · PDF page 116</div></details>

[[Champion|Champions]] do not retain Buffs in the [[Champion Zone]], even if they return there somehow. ^cr-705-1

<details class="rule-ref"><summary title="Core rule 705.1 · PDF page 116" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 705.1 · PDF page 116</div></details>
