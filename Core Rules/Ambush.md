<details class="rule-ref"><summary title="Core rule 822 · PDF page 137" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 822 · PDF page 137</div></details>

Ambush is a [[Passive Ability]] [[Keywords|keyword]]. ^cr-822-1

<details class="rule-ref"><summary title="Core rule 822.1 · PDF page 137" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 822.1 · PDF page 137</div></details>

It is normally present on [[Unit|Units]]. ^cr-822-1-a

<details class="rule-ref"><summary title="Core rule 822.1.a · PDF page 137" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 822.1.a · PDF page 137</div></details>

It is functionally short for "I may be played to a [[Battlefield|battlefield]] where you [[Control|control]] [[Unit|Units]]" and “I have &#91;[[Reaction (Keyword)|Reaction]]&#93; as long as I’m being played to a battlefield where you control Units.” ^cr-822-1-b

<details class="rule-ref"><summary title="Core rule 822.1.b · PDF page 137" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 822.1.b · PDF page 137</div></details>

It is a [[Passive Ability|passive ability]] that adds options to [[Location|locations]] that are valid for a [[Unit]] to be played to during the Make Relevant Choices step of Playing a [[Card]] ^cr-822-1-c

See [[Playing Cards#^cr-349|Playing Cards]] for more information.

<details class="rule-ref"><summary title="Core rule 822.1.c · PDF page 137" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 822.1.c · PDF page 137</div></details>

Ambush can also appear as a verb on a [[Card|card]]. In such a case, the verb is taken to mean “[[Play|play]] with the permissions of the Ambush [[Keywords|keyword]].” ^cr-822-1-d

**Example:** Rengar, Trophy Hunter reads in part “I can &#91;Ambush&#93; to a [[Battlefield|battlefield]] where there are [[Enemy|enemy]] [[Unit|units]], even if you don't have units there.” This [[Ability|ability]] expands the normal permissions of the Ambush [[Keywords|keyword]] to include battlefields where there are enemy units.

**Example:** A [[Card|card]] reads in part “Opponents can only &#91;Ambush&#93; at any time they could [[Play|play]] cards with &#91;[[Action (Keyword)|Action]]&#93;.” This [[Ability|ability]] introduces a restriction to when opponents can play cards with Ambush.

<details class="rule-ref"><summary title="Core rule 822.1.d · PDF page 137" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 822.1.d · PDF page 137</div></details>

Multiple instances of Ambush are redundant. ^cr-822-2

<details class="rule-ref"><summary title="Core rule 822.2 · PDF page 137" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 822.2 · PDF page 137</div></details>

If there are no [[Unit|units]] at the [[Location|location]] chosen before Finalization completes for any reason, then it is no longer a valid location by Ambush’s reasoning and cannot be played there ^cr-822-3

<details class="rule-ref"><summary title="Core rule 822.3 · PDF page 137" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 822.3 · PDF page 137</div></details>

Other effects and permissions may still enable this [[Unit]] to be able to be played to the selected [[Location|location]], but Ambush’s permission will not be valid ^cr-822-3-a

<details class="rule-ref"><summary title="Core rule 822.3.a · PDF page 137" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 822.3.a · PDF page 137</div></details>

Ambush, and whether or not a [[Unit|unit]] has Ambush, is a characteristic of the Unit and may be checked or referenced by other [[Game Effect|Game Effects]]. ^cr-822-4

<details class="rule-ref"><summary title="Core rule 822.4 · PDF page 137" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 822.4 · PDF page 137</div></details>
