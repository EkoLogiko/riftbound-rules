# Delayed Ability

[[Start Here|Home]] · [[Concept Index|Find a concept]] · [[Core Rules Index|Core rules]]

<span title="Core rule 390"></span> ^cr-390

<details class="rule-ref"><summary title="Core rule 390 · PDF page 74" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 390 · PDF page 74</div></details>

Delayed Abilities are a type of [[Ability]] that specifies a window of applicability during which they are active. ^cr-391

<details class="rule-ref"><summary title="Core rule 391 · PDF page 74" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 391 · PDF page 74</div></details>

Delayed Abilities can be any other type of [[Ability]], and contain all of the properties of that type in addition to the properties of Delayed Abilities. ^cr-391-1

<details class="rule-ref"><summary title="Core rule 391.1 · PDF page 74" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 391.1 · PDF page 74</div></details>

[[Delayed Trigger|Delayed Triggers]] are [[Triggered Ability|Triggered Abilities]] that can be recognized by describing a specific time of [[Turn|the turn]], or by structuring a Triggered Ability with a specific frame of time as a restriction. ^cr-391-2

<details class="rule-ref"><summary title="Core rule 391.2 · PDF page 74" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 391.2 · PDF page 74</div></details>

[[Delayed Replacement|Delayed Replacements]] are [[Replacement Effect|Replacement Effects]] that can be recognized by specifying the effect they are replacing at a specific time, or “the &#91;Nth&#93; time” in the description of the effect as it resolves. ^cr-391-3

<details class="rule-ref"><summary title="Core rule 391.3 · PDF page 74" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 391.3 · PDF page 74</div></details>

Some [[Delayed Replacement|Delayed Replacements]] take the form “then [[Recycle|recycle]] it,” or “then [[Banish|banish]] it,” in reference to [[Chain|chain]] items being played by [[Linked Ability|linked abilities]] or [[Instructions|instructions]]. These are short for “if it would leave the chain after becoming a [[Finalized Chain Item|finalized chain item]], and leaving the chain wasn’t instructed by its own execution, perform the specified [[Game Action|game action]] instead.” ^cr-391-3-a

<details class="rule-ref"><summary title="Core rule 391.3.a · PDF page 74" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 391.3.a · PDF page 74</div></details>

[[Delayed Passive Ability|Delayed Passive Abilities]] are [[Passive Ability|Passive Abilities]] that are applicable only during a specified window of time. The time that the Delayed Passive Ability applies will be recognized in the effect that initiates it. ^cr-391-4

<details class="rule-ref"><summary title="Core rule 391.4 · PDF page 74" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 391.4 · PDF page 74</div></details>

[[Delayed Linked Ability|Delayed Linked Abilities]] are [[Linked Ability|Linked Abilities]] that are generated by another [[Ability]] and reference that Ability or [[Game Object|Game Objects]] it affects instead of a window of time. ^cr-391-5

<details class="rule-ref"><summary title="Core rule 391.5 · PDF page 74" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 391.5 · PDF page 74</div></details>

If that [[Ability]] affects a [[Game Object]], the [[Delayed Linked Ability]]’s window will be as long as that Game Object is in an appropriate [[Zone|zone]]. ^cr-391-5-a

<details class="rule-ref"><summary title="Core rule 391.5.a · PDF page 74" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 391.5.a · PDF page 74</div></details>

If the [[Delayed Linked Ability]] references the source of the [[Ability|abilities]], its window will be as long as the source is in an appropriate [[Zone|zone]]. ^cr-391-5-b

<details class="rule-ref"><summary title="Core rule 391.5.b · PDF page 74" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 391.5.b · PDF page 74</div></details>

The appropriate [[Zone|zones]] for these [[Delayed Linked Ability|Delayed Linked Abilities]] will be determined implicitly by the [[Linked Ability]] that generated them. ^cr-391-5-c

<details class="rule-ref"><summary title="Core rule 391.5.c · PDF page 74" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 391.5.c · PDF page 74</div></details>

If the [[Linked Ability]] causes the affected [[Game Object|Game Objects]] to change [[Zone|zone]] to a non-board zone, the appropriate zone for the [[Delayed Linked Ability]] will be the zone the Game Object is moved to. ^cr-391-5-c-1

<details class="rule-ref"><summary title="Core rule 391.5.c.1 · PDF page 74" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 391.5.c.1 · PDF page 74</div></details>

Otherwise, the appropriate [[Zone|zone]] is whatever zone the [[Linked Ability]] triggered or was played from, or whatever zone the affected [[Game Object]] is located in when it is affected. ^cr-391-5-c-2

<details class="rule-ref"><summary title="Core rule 391.5.c.2 · PDF page 74" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 391.5.c.2 · PDF page 74</div></details>

Delayed Abilities will resolve or be active just like the [[Ability|ability]] they augment, but only during the specified time in the effect that created the Delayed Ability. ^cr-392

**Example:** Ravenborn Tome reads “The next [[Spell|spell]] you [[Play|play]] this [[Turn|turn]] deals 1 [[Bonus Damage]].” This is a [[Delayed Passive Ability]] that passively adds 1 Bonus Damage to just the next spell played. The next spell is a specific time, and the 1 Bonus Damage is a [[Passive Ability|passive ability]].

**Example:** Noxian Guillotine reads “Choose a [[Unit|unit]]. [[Kill]] it the next time it takes [[Damage|damage]] this [[Turn|turn]].” When the chosen unit takes damage is the specified time, and killing it is the condition for a Delayed [[Triggered Ability]].

<details class="rule-ref"><summary title="Core rule 392 · PDF page 74" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 392 · PDF page 74</div></details>

Delayed Abilities are not associated with [[Unit|Units]] or [[Gear]]; they are created by other [[Ability|Abilities]] or [[Spell|Spells]]. As such they are executed when their condition and/or specified time occurs regardless of whether the source of the Delayed Ability is still on [[Board|the board]] or not. ^cr-393
