# Dependent Keyword

[[Start Here|Home]] · [[Concept Index|Find a concept]] · [[Core Rules Index|Core rules]]

<span title="Core rule 726"></span> ^cr-726

<details class="rule-ref"><summary title="Core rule 726 · PDF page 119" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 726 · PDF page 119</div></details>

[[Keywords]] can be Dependent Keywords ^cr-727

<details class="rule-ref"><summary title="Core rule 727 · PDF page 119" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 727 · PDF page 119</div></details>

A Dependent Keyword is comprised of both a Condition that it is short for, and an [[Ability|ability]] of some format immediately after the [[Keywords|Keyword]] itself. ^cr-727-1

**Example:** Noxus Hopeful has “&#91;[[Legion]]&#93;&#91;>&#93; I [[Costs|cost]] &#91;2&#93; less.” &#91;Legion&#93; is short for the condition “if you have played another [[Card|card]] this [[Turn|turn]], this card gains &#91;Text&#93;,” while “I cost &#91;2&#93; less” is the dependent [[Ability|ability]].

<details class="rule-ref"><summary title="Core rule 727.1 · PDF page 119" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 727.1 · PDF page 119</div></details>

A Dependent Keyword will always be functionally short for a Condition. ^cr-727-1-a

<details class="rule-ref"><summary title="Core rule 727.1.a · PDF page 119" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 727.1.a · PDF page 119</div></details>

This Condition may also have a determined Duration, Time, or Limitation as part of its definition. ^cr-727-1-a-1

**Example:** [[Legion]] specifies the duration of its condition: “if you have played another [[Card|card]] this [[Turn|turn]].” This turn is the duration.

**Example:** A dependent keyword that is short for “Until you have spent &#91;3&#93; this [[Turn|turn]]” would include a limitation on its condition.

**Example:** A dependent keyword that is short for “After you’ve attacked this [[Turn|turn]]” would include a time after which the condition is active.

<details class="rule-ref"><summary title="Core rule 727.1.a.1 · PDF page 119" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 727.1.a.1 · PDF page 119</div></details>

The Dependent [[Ability]] associated with the Dependent Keyword is [[Inactive]] on the [[Card|card]] with the Dependent Keyword until the Condition is met, when it becomes Active ^cr-727-1-b

<details class="rule-ref"><summary title="Core rule 727.1.b · PDF page 119" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 727.1.b · PDF page 119</div></details>

The Dependent [[Ability]] is present on the [[Card|card]] for the sake of reference or evaluation until the Condition is met ^cr-727-1-b-1

See [[Inactive#^cr-720|Inactive]] for more information.

<details class="rule-ref"><summary title="Core rule 727.1.b.1 · PDF page 120" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 727.1.b.1 · PDF page 120</div></details>

The Dependent [[Ability]] is Active exactly as written while the Condition is true ^cr-727-1-b-2

**Example:** Gustwalker has “&#91;[[Level]] 3&#93;&#91;>&#93; I have +1 &#91;M&#93; and [[Ganking]].” As long as its controller has 3 XP, Gustwalker’s Ganking is active.

<details class="rule-ref"><summary title="Core rule 727.1.b.2 · PDF page 120" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 727.1.b.2 · PDF page 120</div></details>

If an [[Ability|ability]] has multiple Dependent Keywords, all of them must have their Condition met in order for the ability to be active. ^cr-727-1-b-3

**Example:** A [[Unit|unit]] reads “&#91;[[Level]] 11&#93;&#91;>>&#93;&#91;[[Legion]]&#93;&#91;>&#93; When you [[Conquer|conquer]], gain 1 point.” In order for the [[Conquer Effect|conquer effect]] of the unit to be active, its controller must have 11 XP and have finalized a [[Card|card]] other than the unit that [[Turn|turn]].

<details class="rule-ref"><summary title="Core rule 727.1.b.3 · PDF page 120" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 727.1.b.3 · PDF page 120</div></details>

The Dependent [[Ability|Abilities]] of Dependent Keywords can be of any type ^cr-727-1-c

<details class="rule-ref"><summary title="Core rule 727.1.c · PDF page 120" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 727.1.c · PDF page 120</div></details>

[[Triggered Ability|Triggered Abilities]] of Dependent Keywords must be Active for their trigger to be evaluated. ^cr-727-1-c-1

<details class="rule-ref"><summary title="Core rule 727.1.c.1 · PDF page 120" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 727.1.c.1 · PDF page 120</div></details>

If a [[Triggered Ability]] becomes active at the same time as its trigger condition would be fulfilled, it triggers. ^cr-727-1-c-1-a

<details class="rule-ref"><summary title="Core rule 727.1.c.1.a · PDF page 120" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 727.1.c.1.a · PDF page 120</div></details>

If the condition for the Dependent Keyword causes the [[Triggered Ability]] to become [[Inactive]] after it has been added to the [[Chain|chain]] as a [[Pending Chain Item|Pending Item]], that chain item will not be affected and will proceed with being played as normal. ^cr-727-1-c-1-b

<details class="rule-ref"><summary title="Core rule 727.1.c.1.b · PDF page 120" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 727.1.c.1.b · PDF page 120</div></details>

[[Passive Ability|Passive Abilities]] begin applying at the same time the Dependent Keyword becomes true. ^cr-727-1-c-2

<details class="rule-ref"><summary title="Core rule 727.1.c.2 · PDF page 120" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 727.1.c.2 · PDF page 120</div></details>

[[Activated Ability|Activated Abilities]] that become Active from Dependent Keywords can be activated at their associated timing after that [[Ability|ability]] has been granted ^cr-727-1-c-3

<details class="rule-ref"><summary title="Core rule 727.1.c.3 · PDF page 120" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 727.1.c.3 · PDF page 120</div></details>

If the condition for the Dependent Keyword causes the [[Activated Ability]] to become [[Inactive]] after it has been added to the [[Chain|chain]] as a [[Pending Chain Item|Pending Item]], that chain item will not be affected and will proceed with being played as normal. ^cr-727-1-c-3-a

<details class="rule-ref"><summary title="Core rule 727.1.c.3.a · PDF page 120" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 727.1.c.3.a · PDF page 120</div></details>
