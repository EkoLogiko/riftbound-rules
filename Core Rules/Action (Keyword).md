<span title="Core rule 806"></span> ^cr-806

<details class="rule-ref"><summary title="Core rule 806 · PDF page 126" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 806 · PDF page 126</div></details>

Action is a Permissive [[Keywords|keyword]]. ^cr-806-1

<details class="rule-ref"><summary title="Core rule 806.1 · PDF page 126" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 806.1 · PDF page 126</div></details>

It is present on [[Card|Cards]], [[Rune]] [[Ability|Abilities]], [[Legend]] Abilities or [[Permanent]] Abilities. ^cr-806-1-a

<details class="rule-ref"><summary title="Core rule 806.1.a · PDF page 126" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 806.1.a · PDF page 126</div></details>

Action grants the corresponding [[Card|card]] or effect permission to be played or activated during [[Showdowns]], even when it is not the Controlling player's [[Turn|turn]]. ^cr-806-1-b

<details class="rule-ref"><summary title="Core rule 806.1.b · PDF page 126" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 806.1.b · PDF page 126</div></details>

Action is functionally short for the following: ^cr-806-1-c

<details class="rule-ref"><summary title="Core rule 806.1.c · PDF page 126" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 806.1.c · PDF page 126</div></details>

On [[Card|Cards]]: "This can be played during [[Showdowns|showdowns]] on any player's [[Turn|turn]]." ^cr-806-1-c-1

<details class="rule-ref"><summary title="Core rule 806.1.c.1 · PDF page 126" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 806.1.c.1 · PDF page 126</div></details>

On [[Activated Ability|Activated Abilities]]: "This can be activated during [[Showdowns|showdowns]] on any player's [[Turn|turn]]." ^cr-806-1-c-2

<details class="rule-ref"><summary title="Core rule 806.1.c.2 · PDF page 126" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 806.1.c.2 · PDF page 126</div></details>

Action is formatted as “&#91;Action&#93;” on [[Spell|spells]], or “&#91;Action&#93;&#91;>&#93;” on [[Ability|abilities]]. ^cr-806-1-d

<details class="rule-ref"><summary title="Core rule 806.1.d · PDF page 126" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 806.1.d · PDF page 126</div></details>

The [[Card|card]] or effect with this [[Keywords|keyword]] is not restricted to [[Showdowns|showdowns]]. This permission is inclusive of all other timings and options available to the [[Ability|ability]] as written or by default. ^cr-806-2

<details class="rule-ref"><summary title="Core rule 806.2 · PDF page 126" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 806.2 · PDF page 126</div></details>

Action does not alter the function of any instruction of the corresponding [[Card|card]] or effect it is on. It is only permission. ^cr-806-3

**Example:** Playing a [[Unit]] with Action still has the inherent restrictions of playing Units without Action. It can only be played to the controlling player's [[Base|base]] or a [[Battlefield|battlefield]] they [[Control|control]].

<details class="rule-ref"><summary title="Core rule 806.3 · PDF page 126" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 806.3 · PDF page 126</div></details>

Some [[Passive Ability|passive abilities]] may grant a [[Card|card]] or [[Ability|ability]] Action under certain conditions. The card or ability does not have the Action keyword unless and until those circumstances are true. ^cr-806-4

<details class="rule-ref"><summary title="Core rule 806.4 · PDF page 126" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 806.4 · PDF page 126</div></details>

Those conditions [[Might|might]] only be fulfilled while the [[Card|card]] or [[Ability|ability]] is on the [[Chain|chain]]. In such a case, it can still be played or activated at the appropriate timing as long as doing so could fulfill the conditions. ^cr-806-4-a

<details class="rule-ref"><summary title="Core rule 806.4.a · PDF page 126" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 806.4.a · PDF page 126</div></details>

If the [[Chain|chain]] item does not fulfill the conditions by the time step 5: check legality has been reached, the actions taken while playing it are undone and it is returned to the [[Zone|zone]] it was played from if it is a [[Card|card]]. ^cr-806-4-b

<details class="rule-ref"><summary title="Core rule 806.4.b · PDF page 126" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 806.4.b · PDF page 126</div></details>

Action is a referenceable characteristic. ^cr-806-5

<details class="rule-ref"><summary title="Core rule 806.5 · PDF page 126" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 806.5 · PDF page 126</div></details>

Whether or not a [[Game Object]] has Action is a characteristic of that Game Object and may be checked or referenced by other [[Game Effect|Game Effects]]. ^cr-806-5-a

<details class="rule-ref"><summary title="Core rule 806.5.a · PDF page 127" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 806.5.a · PDF page 127</div></details>

Whether or not a [[Spell]] has Action is a characteristic of that Spell and may be checked or referenced by other [[Game Effect|Game Effects]]. ^cr-806-5-b

<details class="rule-ref"><summary title="Core rule 806.5.b · PDF page 127" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 806.5.b · PDF page 127</div></details>

Whether or not an [[Ability]] has Action is a characteristic of that Ability and may be checked or referenced by other [[Game Effect|Game Effects]]. ^cr-806-5-c

<details class="rule-ref"><summary title="Core rule 806.5.c · PDF page 127" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 806.5.c · PDF page 127</div></details>
