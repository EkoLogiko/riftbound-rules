# Effect Text

[[Start Here|Home]] · [[Concept Index|Find a concept]] · [[Core Rules Index|Core rules]]

<span title="Core rule 136"></span> ^cr-136

<details class="rule-ref"><summary title="Core rule 136 · PDF page 16" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 136 · PDF page 16</div></details>

Some [[Card|cards]] have a separate section of text below the [[Rules Text]]. This is referred to as the Effect Text. ^cr-136-1

<details class="rule-ref"><summary title="Core rule 136.1 · PDF page 16" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 136.1 · PDF page 16</div></details>

Effect Text can contain additional [[Ability|Abilities]]. ^cr-136-2

<details class="rule-ref"><summary title="Core rule 136.2 · PDF page 16" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 136.2 · PDF page 16</div></details>

Effect Text can be blank. ^cr-136-2-a

<details class="rule-ref"><summary title="Core rule 136.2.a · PDF page 16" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 136.2.a · PDF page 16</div></details>

Effect Text is [[Inactive|inactive]] unless the [[Card|card]] with the Effect Text is [[Attached]] to another card. ^cr-136-2-b

See [[Attachment#^cr-716|Attachment]] for more information.

See [[Inactive#^cr-720|Inactive]] for more information.

<details class="rule-ref"><summary title="Core rule 136.2.b · PDF page 16" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 136.2.b · PDF page 16</div></details>

The [[Ability|abilities]] in the Effect Text section of a [[Card|card]] are appended to the [[Rules Text]] of the card to which the card with the Effect Text is [[Attached]]. ^cr-136-2-c

<details class="rule-ref"><summary title="Core rule 136.2.c · PDF page 16" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 136.2.c · PDF page 16</div></details>

Effect Text may refer to “this” or to the [[Card Name|name]] of the [[Attached]] [[Game Object|game object]] that appended the Effect Text. Doing so refers to the Attached game object and not the [[Top-most Card|Top-Most Card]], even if the Top-Most Card shares a name with the Attached game object. ^cr-136-2-d

**Example:** Guardian Angel’s effect text reads “If I would die, [[Kill|kill]] Guardian Angel instead. [[Heal]] me, [[Exhaust|exhaust]] me, and recall me.”

**Example:** Brutalizer’s effect text reads “If this was [[Attached|attached]] to me this [[Turn|turn]], I have an additional +2 &#91;M&#93;.” The “this” in the effect text refers to the attached Brutalizer.

<details class="rule-ref"><summary title="Core rule 136.2.d · PDF page 16" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 136.2.d · PDF page 16</div></details>
