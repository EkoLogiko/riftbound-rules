# Movement

[[Start Here|Home]] · [[Concept Index|Find a concept]] · [[Core Rules Index|Core rules]]

<span title="Core rule 447"></span> ^cr-447

<details class="rule-ref"><summary title="Core rule 447 · PDF page 98" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 447 · PDF page 98</div></details>

Moving is a [[Limited Action]]. ^cr-448

<details class="rule-ref"><summary title="Core rule 448 · PDF page 98" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 448 · PDF page 98</div></details>

A [[Permanent]] changing its position from any space on [[Board|the Board]] to another space on the Board is a [[Move]], unless it is caused by a corrective Recall or an [[Attached]] Permanent changing [[Location|locations]] to or with its [[Top-most Card|Top-Most Card]]. ^cr-448-1

See [[Move#^cr-421|Move]] for more information.

<details class="rule-ref"><summary title="Core rule 448.1 · PDF page 98-99" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 448.1 · PDF page 98-99</div></details>

A [[Card|card]] changing game [[Zone|zones]] does not in itself constitute a [[Move]]. ^cr-448-2

<details class="rule-ref"><summary title="Core rule 448.2 · PDF page 99" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 448.2 · PDF page 99</div></details>

Moving is instantaneous. ^cr-448-3

<details class="rule-ref"><summary title="Core rule 448.3 · PDF page 99" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 448.3 · PDF page 99</div></details>

There is no state for [[Permanent|Permanents]] between [[Location|locations]]. ^cr-448-3-a

<details class="rule-ref"><summary title="Core rule 448.3.a · PDF page 99" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 448.3.a · PDF page 99</div></details>

[[Permanent|Permanents]] are either at their Origin before Moving or their Destination after Moving. ^cr-448-3-b

<details class="rule-ref"><summary title="Core rule 448.3.b · PDF page 99" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 448.3.b · PDF page 99</div></details>

Moving does not use the [[Chain]], nor is it able to be Reacted to. ^cr-448-3-c

<details class="rule-ref"><summary title="Core rule 448.3.c · PDF page 99" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 448.3.c · PDF page 99</div></details>

Moving is defined by the Origin and Destination of the [[Permanent]] that is changing [[Location|locations]]. ^cr-449

<details class="rule-ref"><summary title="Core rule 449 · PDF page 99" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 449 · PDF page 99</div></details>

The Origin is where the [[Permanent]] is starting from. ^cr-449-1

<details class="rule-ref"><summary title="Core rule 449.1 · PDF page 99" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 449.1 · PDF page 99</div></details>

The Destination is where the [[Permanent]] is going to. ^cr-449-2

<details class="rule-ref"><summary title="Core rule 449.2 · PDF page 99" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 449.2 · PDF page 99</div></details>

In [[Modes of Play]] with more than two players, [[Battlefield|Battlefields]] with Staged Combats or Combats in Progress are Invalid Destinations for Moves of all kinds (Standard Moves or otherwise) by [[Unit|Units]] controlled by Players not involved in those Combats or who don't already have units at that Battlefield. ^cr-449-2-a

<details class="rule-ref"><summary title="Core rule 449.2.a · PDF page 99" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 449.2.a · PDF page 99</div></details>

In [[Modes of Play]] with teammates, [[Battlefield|Battlefields]] occupied by a player’s teammates are Invalid Destinations for Moves of all kinds (Standard Moves or otherwise) by [[Unit|Units]] that player controls. ^cr-449-2-b

<details class="rule-ref"><summary title="Core rule 449.2.b · PDF page 99" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 449.2.b · PDF page 99</div></details>

If an action would require a [[Move]] that would cause a [[Unit]] to become present in a [[Location]] where it cannot move for any reason, such as a [[Battlefield]] with two players that are not the controller of the Unit performing this Move action are in a [[Combat]] or such a Combat is Staged, it instead [[Recalls]]. ^cr-449-2-c

See [[Recalls#^cr-456|Recalls]] for more information.

<details class="rule-ref"><summary title="Core rule 449.2.c · PDF page 99" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 449.2.c · PDF page 99</div></details>

Players may choose to [[Move|move]] their [[Unit|Units]] with the [[Standard Move]]. ^cr-450

See [[Unit#^cr-144|Unit]] for more information on the [[Standard Move]].

<details class="rule-ref"><summary title="Core rule 450 · PDF page 99" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 450 · PDF page 99</div></details>

[[Spell|Spells]], [[Ability|Abilities]], or other effects may cause a [[Move]] to occur. ^cr-451

<details class="rule-ref"><summary title="Core rule 451 · PDF page 99" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 451 · PDF page 99</div></details>

The source of the [[Move]] will provide details on any restrictions on legality for Destination. ^cr-451-1

<details class="rule-ref"><summary title="Core rule 451.1 · PDF page 99" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 451.1 · PDF page 99</div></details>

[[Unit|Units]] cannot [[Move]] to a [[Battlefield]] that already has units from 2 other players present by any means. ^cr-451-2

<details class="rule-ref"><summary title="Core rule 451.2 · PDF page 99" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 451.2 · PDF page 99</div></details>

The Destination becomes [[Contested]] if it is an Uncontested [[Battlefield]] not controlled by the controller of the [[Unit]] or Units that moved. ^cr-452

<details class="rule-ref"><summary title="Core rule 452 · PDF page 99" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 452 · PDF page 99</div></details>

[[Unit|Units]] may cause a Non-Combat [[Showdowns|Showdown]] when they [[Move]]. ^cr-453

See [[Showdowns#^cr-341|Showdowns]] for more information.

<details class="rule-ref"><summary title="Core rule 453 · PDF page 99" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 453 · PDF page 99</div></details>

[[Unit|Units]] may cause [[Combat]] when they [[Move]]. ^cr-454

See [[Combat#^cr-461|Combat]] for more information.

<details class="rule-ref"><summary title="Core rule 454 · PDF page 99" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 454 · PDF page 99</div></details>

When a [[Move]] action is complete, perform a [[Cleanups|Cleanup]]. ^cr-455

<details class="rule-ref"><summary title="Core rule 455 · PDF page 99" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 455 · PDF page 99</div></details>
