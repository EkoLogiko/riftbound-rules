# Inactive

[[Start Here|Home]] · [[Concept Index|Find a concept]] · [[Core Rules Index|Core rules]]

<span title="Core rule 720"></span> ^cr-720

<details class="rule-ref"><summary title="Core rule 720 · PDF page 118" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 720 · PDF page 118</div></details>

[[Card]] text can occasionally be assigned to be ignored, disregarded, or otherwise rendered as not applicable during the course of [[Play|play]]. This state is referred to as Inactive. ^cr-721

<details class="rule-ref"><summary title="Core rule 721 · PDF page 118" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 721 · PDF page 118</div></details>

Text marked this way is not applied at all while in this state. ^cr-721-1

<details class="rule-ref"><summary title="Core rule 721.1 · PDF page 118" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 721.1 · PDF page 118</div></details>

Inactive [[Ability|Abilities]] do not trigger, do not apply, and cannot be activated. Inactive [[Instructions|instructions]] are not processed. ^cr-721-2

<details class="rule-ref"><summary title="Core rule 721.2 · PDF page 119" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 721.2 · PDF page 119</div></details>

Inactive text is still present on [[Card|cards]]. ^cr-722

<details class="rule-ref"><summary title="Core rule 722 · PDF page 119" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 722 · PDF page 119</div></details>

[[Card|Cards]] with Inactive text still have [[Keywords|keywords]] for the sake of [[Game Effect|Game Effects]] that want to reference or see if a card has a keyword. ^cr-722-1

<details class="rule-ref"><summary title="Core rule 722.1 · PDF page 119" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 722.1 · PDF page 119</div></details>

[[Game Effect|Game Effects]] that parse or interpret text to determine target eligibility may still parse Inactive text for the sake of eligibility. ^cr-722-2

**Example:** Spinning Axe is a [[Gear|gear]] with &#91;[[Temporary]]&#93;. While it’s [[Attached|attached]] and its [[Rules Text|rules text]] is inactive, its &#91;Temporary&#93; [[Ability|ability]] doesn’t trigger. However, a [[Spell|spell]] that reads “Destroy a gear with &#91;Temporary&#93;” could still choose and destroy Spinning Axe.

<details class="rule-ref"><summary title="Core rule 722.2 · PDF page 119" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 722.2 · PDF page 119</div></details>

[[Rules Text]] is never Inactive by default. ^cr-723

<details class="rule-ref"><summary title="Core rule 723 · PDF page 119" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 723 · PDF page 119</div></details>

[[Effect Text]] is Inactive unless the [[Card|card]] with the Effect Text is [[Attached]]. ^cr-724

<details class="rule-ref"><summary title="Core rule 724 · PDF page 119" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 724 · PDF page 119</div></details>

Inactive text can partially cease to be Inactive under specific circumstances and exceptions. ^cr-725

<details class="rule-ref"><summary title="Core rule 725 · PDF page 119" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 725 · PDF page 119</div></details>

If an [[Attached]] [[Card|card]] has a Passive or Replacement [[Ability|ability]] that applies during the process of [[Attach|Attaching]] or a [[Triggered Ability|Triggered ability]] that triggers off of Attaching, that text exists and can be processed as it Attaches. ^cr-725-1

<details class="rule-ref"><summary title="Core rule 725.1 · PDF page 119" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 725.1 · PDF page 119</div></details>

If an [[Attached]] [[Card|card]] has a Passive or Replacement [[Ability|ability]] that applies during the process of [[Detach|Detaching]] or a [[Triggered Ability|Triggered ability]] that triggers off of Detaching, that text exists and can be processed as it Detaches. ^cr-725-2

<details class="rule-ref"><summary title="Core rule 725.2 · PDF page 119" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 725.2 · PDF page 119</div></details>

If an [[Attached]] [[Card|card]] has an [[Equip]] [[Ability|ability]], the [[Weaponmaster]] [[Keywords|keyword]] can reference that Equip ability and any abilities that passively modify that Equip ability. ^cr-725-3

<details class="rule-ref"><summary title="Core rule 725.3 · PDF page 119" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 725.3 · PDF page 119</div></details>

If a Dependent [[Ability]] is a [[Triggered Ability]] whose condition occurs at the same time as the [[Dependent Keyword]]’s condition being fulfilled, that text exists and can be processed as it is fulfilled. ^cr-725-4

<details class="rule-ref"><summary title="Core rule 725.4 · PDF page 119" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 725.4 · PDF page 119</div></details>
