# Combat

<span title="Core rule 461"></span> ^cr-461

<details class="rule-ref"><summary title="Core rule 461 · PDF page 100" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 461 · PDF page 100</div></details>

A Combat occurs when a [[Cleanups|Cleanup]] occurs, there are no items on the [[Chain]], there is a staged Combat at a [[Battlefield]], and no [[Showdowns|Showdown]] or Combat is ongoing at any other Battlefield. ^cr-462

See [[Cleanups#^cr-318|Cleanups]] for more information.

<details class="rule-ref"><summary title="Core rule 462 · PDF page 100" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 462 · PDF page 100</div></details>

If there is an ongoing [[Showdowns|Showdown]] at the [[Battlefield]] where the Combat is staged, that Showdown will become a Combat Showdown and a Combat will be initiated there. ^cr-462-1

<details class="rule-ref"><summary title="Core rule 462.1 · PDF page 100" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 462.1 · PDF page 100</div></details>

Combat is considered Staged if there are [[Unit|units]] controlled by two opposing players at a [[Battlefield]] but the Steps of Combat have not been initiated. ^cr-463

<details class="rule-ref"><summary title="Core rule 463 · PDF page 100" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 463 · PDF page 100</div></details>

If more than one [[Battlefield]] has [[Unit|Units]] controlled by opposing players at it at the same time, [[Turn|the Turn]] Player decides which Combat to resolve first. ^cr-463-1

<details class="rule-ref"><summary title="Core rule 463.1 · PDF page 100" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 463.1 · PDF page 100</div></details>

If Staged Combats stop being Staged before the Steps of Combat are initiated, they are not resolved or executed. ^cr-463-2

<details class="rule-ref"><summary title="Core rule 463.2 · PDF page 100" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 463.2 · PDF page 100</div></details>

If a Combat and [[Showdowns|Showdown]] are staged at the same [[Battlefield]] and [[Turn|the turn]] player initiates the Showdown, it will open as a Combat Showdown. ^cr-463-3

<details class="rule-ref"><summary title="Core rule 463.3 · PDF page 100" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 463.3 · PDF page 100</div></details>

Combat can only occur between [[Unit|Units]] controlled by exactly two players. ^cr-464

<details class="rule-ref"><summary title="Core rule 464 · PDF page 100" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 464 · PDF page 100</div></details>

In [[Modes of Play]] with more than two players, [[Battlefield|Battlefields]] with Staged Combats or Combats in Progress are Invalid Destinations for Moves of all kinds (Standard Moves or otherwise) by [[Unit|Units]] controlled by Players not involved in those Combats or who don't already have Units at that Battlefield. ^cr-464-1

See [[Movement#^cr-449-2-a|Movement]] for more information on Invalid Destinations.

<details class="rule-ref"><summary title="Core rule 464.1 · PDF page 100" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 464.1 · PDF page 100</div></details>

In [[Modes of Play]] with more than two players, [[Battlefield|Battlefields]] with Staged Combats or Combats in Progress are Invalid to be chosen as a [[Location|location]] to [[Play|play]] one or more [[Unit|Units]] by a player not involved in that Combat by any means. ^cr-464-2

<details class="rule-ref"><summary title="Core rule 464.2 · PDF page 100" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 464.2 · PDF page 100</div></details>

If an effect would require a [[Unit]] be played to a [[Battlefield]] with a Staged Combat or a Combat in Progress, where the controller of the played unit is not a participant, instead the Unit is played to its controller's [[Base]]. ^cr-464-2-a

<details class="rule-ref"><summary title="Core rule 464.2.a · PDF page 100" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 464.2.a · PDF page 100</div></details>

Any subsequent reference to "here" in the corresponding effect is reassigned to the Controller's [[Base]], where the [[Unit]] was played. Any further effects that may be invalidated are invalidated as if the effect was mistargeted. ^cr-464-2-b

See [[Process of Playing a Card#^cr-355-6|Targeting]] for more information on Mistargeting.

<details class="rule-ref"><summary title="Core rule 464.2.b · PDF page 100-101" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 464.2.b · PDF page 100-101</div></details>

All choices that would result in a Combat occurring between more than two players simultaneously are invalid and ineligible to be completed. ^cr-464-3
