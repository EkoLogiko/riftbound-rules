# Create

[[Start Here|Home]] · [[Concept Index|Find a concept]] · [[Core Rules Index|Core rules]]

<span title="Core rule 440"></span> ^cr-440

<details class="rule-ref"><summary title="Core rule 440 · PDF page 95" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 440 · PDF page 95</div></details>

Creating is the act of producing a [[Game Object]] that previously did not exist in the game. ^cr-440-1

<details class="rule-ref"><summary title="Core rule 440.1 · PDF page 95" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 440.1 · PDF page 95</div></details>

Effects that Create one or more [[Game Object|Game Objects]] will direct where those Game Objects must go - the Game Objects are Created directly to the [[Zone|zones]] in question. ^cr-440-2

<details class="rule-ref"><summary title="Core rule 440.2 · PDF page 95" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 440.2 · PDF page 95</div></details>

Prior to being Created, these [[Game Object|Game Objects]] did not exist outside of the [[Zone|zone]] they were Created to. After being Created, they may change zones as appropriate for Game Objects of their type. ^cr-440-2-a

<details class="rule-ref"><summary title="Core rule 440.2.a · PDF page 95" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 440.2.a · PDF page 95</div></details>

If a [[Zone|zone]] is not specified by the effect, the [[Game Object]] will be created to the appropriate zone for its type. ^cr-440-2-b

<details class="rule-ref"><summary title="Core rule 440.2.b · PDF page 95" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 440.2.b · PDF page 95</div></details>

[[Permanent|Permanents]] will be Created at any [[Location|location]] on [[Board|the Board]] that they can be played to. ^cr-440-2-b-1

<details class="rule-ref"><summary title="Core rule 440.2.b.1 · PDF page 95" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 440.2.b.1 · PDF page 95</div></details>

[[Spell|Spells]] will be Created on the [[Chain]]. ^cr-440-2-b-2

<details class="rule-ref"><summary title="Core rule 440.2.b.2 · PDF page 95" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 440.2.b.2 · PDF page 95</div></details>

[[Rune|Runes]] will be Created at [[Base|base]]. ^cr-440-2-b-3

<details class="rule-ref"><summary title="Core rule 440.2.b.3 · PDF page 95" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 440.2.b.3 · PDF page 95</div></details>

[[Legend|Legends]] will be Created in the [[Legend Zone]]. ^cr-440-2-b-4

<details class="rule-ref"><summary title="Core rule 440.2.b.4 · PDF page 95" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 440.2.b.4 · PDF page 95</div></details>

[[Battlefield|Battlefields]] will be Created in the [[Battlefield Zone]]. ^cr-440-2-b-5

<details class="rule-ref"><summary title="Core rule 440.2.b.5 · PDF page 95" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 440.2.b.5 · PDF page 95</div></details>

The [[Zone|zone]] a [[Game Object]] is created to can be specified implicitly by the [[Game Action]] being performed. ^cr-440-2-c

**Example:** “[[Play]] a 1 &#91;M&#93; Recruit [[Token|token]]” specifies a [[Zone|zone]] where the token is Created to implicitly, by specifying the token is played and thus created on the [[Chain|chain]].

**Example:** “Create a 1 &#91;M&#93; Recruit [[Token|token]]” does not specify a [[Zone|zone]], so the Recruit token will be created at any [[Location|location]] on [[Board|the board]] that it can be played to.

<details class="rule-ref"><summary title="Core rule 440.2.c · PDF page 95" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 440.2.c · PDF page 95</div></details>

An effect that Creates a [[Game Object]] will specify the state and nature of the Game Object created. ^cr-440-3

<details class="rule-ref"><summary title="Core rule 440.3 · PDF page 95" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 440.3 · PDF page 95</div></details>

If the [[Game Object]] is a [[Token|token]], it will follow the normal rules for tokens. ^cr-440-3-a

See [[Token#^cr-179|Tokens]] for more information.

<details class="rule-ref"><summary title="Core rule 440.3.a · PDF page 96" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 440.3.a · PDF page 96</div></details>

If the effect specifies a [[Game Object]] is Created for a specific duration, it exists while that duration is ongoing, and ceases to exist once that duration ends. ^cr-440-3-b

<details class="rule-ref"><summary title="Core rule 440.3.b · PDF page 96" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 440.3.b · PDF page 96</div></details>

If a Non-Token [[Game Object]] is Created from a finite set of choices made by a [[Linked Ability]] during deck building, only one of those Game Objects may exist in [[Play|play]] at a time. If a player would Create a Game Object that already exists on [[Board|the board]] or on the [[Chain|chain]], that action is Negated. ^cr-440-3-c

<details class="rule-ref"><summary title="Core rule 440.3.c · PDF page 96" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 440.3.c · PDF page 96</div></details>

Unless specified otherwise by the [[Game Effect]] that Creates a [[Game Object]], any such Game Object is owned by the player who Created it. [[Control]] is established as usual for Game Objects of the appropriate type. ^cr-440-4

<details class="rule-ref"><summary title="Core rule 440.4 · PDF page 96" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 440.4 · PDF page 96</div></details>

A Created [[Permanent|permanent]], [[Rune|rune]], [[Legend|legend]], or [[Spell|spell]] is controlled by its owner as it is Created. ^cr-440-4-a

<details class="rule-ref"><summary title="Core rule 440.4.a · PDF page 96" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 440.4.a · PDF page 96</div></details>

A Created [[Battlefield|battlefield]] is uncontrolled as it is Created. ^cr-440-4-b

<details class="rule-ref"><summary title="Core rule 440.4.b · PDF page 96" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 440.4.b · PDF page 96</div></details>

This action, when instructed, is usually formatted as "Create &#91;X&#93; at &#91;Y&#93;" or “Add &#91;X&#93; to &#91;Y&#93;.” ^cr-440-5

<details class="rule-ref"><summary title="Core rule 440.5 · PDF page 96" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 440.5 · PDF page 96</div></details>

Creating is a [[Limited Action]]. ^cr-440-6

<details class="rule-ref"><summary title="Core rule 440.6 · PDF page 96" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 440.6 · PDF page 96</div></details>

Players may only Create [[Game Object|Game Objects]] when directed to by [[Game Effect|Game Effects]]. ^cr-440-6-a

<details class="rule-ref"><summary title="Core rule 440.6.a · PDF page 96" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 440.6.a · PDF page 96</div></details>
