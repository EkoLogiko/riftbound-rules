# Ignoring Effects

[[Start Here|Home]] · [[Concept Index|Find a concept]] · [[Core Rules Index|Core rules]]

<span title="Core rule 764"></span> ^cr-764

<details class="rule-ref"><summary title="Core rule 764 · PDF page 124" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 764 · PDF page 124</div></details>

Some [[Game Effect|Game Effects]] may instruct players to ignore [[Ability|abilities]] while performing a [[Game Action|game action]] or procedure. ^cr-765

<details class="rule-ref"><summary title="Core rule 765 · PDF page 124" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 765 · PDF page 124</div></details>

Any [[Ability|abilities]] ignored in this way are treated as [[Inactive|inactive]] for the purposes of the [[Game Action|game action]] or procedure. ^cr-766

**Example:** A [[Spell|spell]] reads “Ignore [[Deflect]] while paying this spell’s [[Costs|costs]].” Any instances of the Deflect [[Keywords|keyword]] on relevant [[Unit|units]] are treated as [[Inactive|inactive]] while paying the costs of the spell.

**Example:** A [[Unit|unit]] reads “You ignore [[Backline]] while assigning [[Combat|combat]] [[Damage|damage]] here.” While assigning combat damage in the combat damage step with this unit present, any instances of Backline on [[Enemy|enemy]] units is treated as [[Inactive|inactive]]. The unit’s controller can assign damage to any units with Backline as if they didn’t have it.

<details class="rule-ref"><summary title="Core rule 766 · PDF page 124" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 766 · PDF page 124</div></details>

Ignored [[Ability|abilities]] are only treated as [[Inactive|inactive]] for the specific [[Game Action|game action]] or procedure described, and only by the players directed by the ability. ^cr-767

**Example:** A [[Spell|spell]] reads in part “Ignore [[Deflect]] while paying this spell’s [[Costs|costs]].” If another player attempts to [[Play|play]] a spell [[Targeting|targeting]] the same [[Unit|units]] that the above spell does, that other spell will not ignore Deflect.

**Example:** A [[Unit|unit]] reads “You ignore [[Backline]] while assigning [[Combat|combat]] [[Damage|damage]] here.” Any other player assigning combat damage at the same [[Location|location]] as that unit will not be able to ignore Backline.
