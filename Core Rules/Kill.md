# Kill

[[Start Here|Home]] · [[Concept Index|Find a concept]] · [[Core Rules Index|Core rules]]

<span title="Core rule 429"></span> ^cr-429

<details class="rule-ref"><summary title="Core rule 429 · PDF page 87" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 429 · PDF page 87</div></details>

Killing is the action of a [[Permanent]] going to the [[Trash|trash]] from [[Board|the board]]. ^cr-429-1

<details class="rule-ref"><summary title="Core rule 429.1 · PDF page 87" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 429.1 · PDF page 87</div></details>

This can be Active or Passive. ^cr-429-1-a

<details class="rule-ref"><summary title="Core rule 429.1.a · PDF page 87" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 429.1.a · PDF page 87</div></details>

Active Kill is when the action is taken when instructed by a [[Game Effect|game effect]] or as a [[Costs|cost]] for a [[Card|card]] or [[Ability|ability]]. ^cr-429-1-a-1

<details class="rule-ref"><summary title="Core rule 429.1.a.1 · PDF page 87" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 429.1.a.1 · PDF page 87</div></details>

This is referred to as a Kill Instruction. ^cr-429-1-a-1-a

<details class="rule-ref"><summary title="Core rule 429.1.a.1.a · PDF page 87" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 429.1.a.1.a · PDF page 87</div></details>

When a [[Unit|unit]] with a [[Deathknell]] or other [[Ability|ability]] that triggers on its own death is to be put in the [[Trash]] due to a Kill Instruction, it first has any such ability added to the [[Chain|chain]] as a [[Pending Chain Item|Pending Item]]. Note the unit’s [[Location|location]], attributes, and other relevant information to process those abilities when finalized before completing this Kill Instruction. ^cr-429-1-a-1-b

**Example:** Draven, Audacious reads in part “When I die [[In Combat|in combat]], choose an opponent. They gain 1 point.” The [[Ability|ability]] triggers when Draven himself dies, so it will go on the [[Chain|chain]] first when a kill instruction is performed on Draven, before he is put in the [[Trash|trash]].

<details class="rule-ref"><summary title="Core rule 429.1.a.1.b · PDF page 87" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 429.1.a.1.b · PDF page 87</div></details>

Passive Kill is when the action is taken as a result of [[Lethal Damage]] or as a consequence for any other state. ^cr-429-1-a-2

<details class="rule-ref"><summary title="Core rule 429.1.a.2 · PDF page 87" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 429.1.a.2 · PDF page 87</div></details>

When a [[Permanent|permanent]] is killed it is placed directly in the [[Trash|trash]] from its place of origin. ^cr-429-2

<details class="rule-ref"><summary title="Core rule 429.2 · PDF page 87" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 429.2 · PDF page 87</div></details>

It is only considered Killed if its origin was any [[Zone|zone]] on [[Board|the board]]. ^cr-429-2-a

<details class="rule-ref"><summary title="Core rule 429.2.a · PDF page 87" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 429.2.a · PDF page 87</div></details>

This is not a subset of [[Move]]. ^cr-429-2-b

<details class="rule-ref"><summary title="Core rule 429.2.b · PDF page 87" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 429.2.b · PDF page 87</div></details>

Killing is a [[Limited Action]]. ^cr-429-3

<details class="rule-ref"><summary title="Core rule 429.3 · PDF page 87" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 429.3 · PDF page 87</div></details>

Players may only Kill [[Unit|units]] when [[Game Effect|Game Effects]] direct them to do so. ^cr-429-3-a

<details class="rule-ref"><summary title="Core rule 429.3.a · PDF page 87" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 429.3.a · PDF page 87</div></details>

Killing can also be the result of resolving a [[Cleanups|Cleanup]]. ^cr-429-4

<details class="rule-ref"><summary title="Core rule 429.4 · PDF page 87" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 429.4 · PDF page 87</div></details>

Killing can be attributed to one or more [[Game Object|Game Objects]]. ^cr-429-5

<details class="rule-ref"><summary title="Core rule 429.5 · PDF page 87" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 429.5 · PDF page 87</div></details>

The Killed [[Unit]] or [[Gear]] is said to be Killed by that [[Game Object]]. ^cr-429-5-a

<details class="rule-ref"><summary title="Core rule 429.5.a · PDF page 87" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 429.5.a · PDF page 87</div></details>

A [[Spell|spell]] or [[Ability|ability]] that contains a Kill instruction is responsible for Killing the [[Unit]] or [[Gear]]. ^cr-429-5-b

<details class="rule-ref"><summary title="Core rule 429.5.b · PDF page 87" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 429.5.b · PDF page 87</div></details>

When one or more [[Unit|Units]] is killed due to a [[Cleanups|Cleanup]], that kill action is attributed to the [[Spell|spell]] or [[Ability|ability]] that resolved immediately prior to that Cleanup that dealt [[Damage|damage]] to the Unit or Units. ^cr-429-5-c

<details class="rule-ref"><summary title="Core rule 429.5.c · PDF page 88" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 429.5.c · PDF page 88</div></details>

The player responsible for the [[Deal|deal]] action is responsible for the kill action. ^cr-429-5-c-1

<details class="rule-ref"><summary title="Core rule 429.5.c.1 · PDF page 88" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 429.5.c.1 · PDF page 88</div></details>

If the [[Cleanups|Cleanup]] that caused the [[Unit|units]] to be killed was the [[Combat]] Cleanup, the sources of the Combat [[Damage]] are attributed the kill action, and their controller is responsible for the kill action. ^cr-429-5-c-2

<details class="rule-ref"><summary title="Core rule 429.5.c.2 · PDF page 88" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 429.5.c.2 · PDF page 88</div></details>

[[Ability|Abilities]] originating from [[Game Object|Game Objects]] that are attributed Kill Actions are attributed in addition to the Game Object that created them. ^cr-429-5-d

**Example:** There is a [[Spell|spell]] that says “Do this twice: [[Deal]] 3 to a [[Unit|unit]].” Immortal Phoenix is a unit that says “When you kill a unit with a spell, you may pay &#91;1&#93;&#91;C&#93; to [[Play|play]] me from your [[Trash|trash]].” A player plays the spell while Immortal Phoenix is in their trash. The “do this” phrasing means that it has a reflexive [[Triggered Ability|triggered ability]], which places two triggered abilities on the [[Chain|chain]]. As each of those triggered abilities resolve, it deals [[Damage|damage]] to the unit chosen for that [[Ability|ability]]. If one of these abilities deals [[Lethal Damage|lethal damage]] to a unit, both the spell and its ability are considered sources of the damage, and so both the spell and its ability receive attribution for killing the unit. This means that the spell’s controller killed a unit with a spell, so Immortal Phoenix’s ability will trigger.

<details class="rule-ref"><summary title="Core rule 429.5.d · PDF page 88" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 429.5.d · PDF page 88</div></details>

This action is formatted as "Kill &#91;one or more [[Permanent|permanents]]&#93;." e.g., "Kill an [[Enemy|enemy]] [[Unit|unit]]." e.g., "Kill this, &#91;2&#93;: [[Draw]] 1." e.g., "Kill all [[Gear|gear]]." ^cr-429-6
