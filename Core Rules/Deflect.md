<span title="Core rule 809"></span> ^cr-809

<details class="rule-ref"><summary title="Core rule 809 · PDF page 128" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 809 · PDF page 128</div></details>

Deflect is a [[Passive Ability]] [[Keywords|keyword]]. ^cr-809-1

<details class="rule-ref"><summary title="Core rule 809.1 · PDF page 128" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 809.1 · PDF page 128</div></details>

It is normally present on [[Permanent|Permanents]]. ^cr-809-1-a

<details class="rule-ref"><summary title="Core rule 809.1.a · PDF page 128" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 809.1.a · PDF page 128</div></details>

It is formatted as "Deflect &#91;X&#93;". ^cr-809-1-b

<details class="rule-ref"><summary title="Core rule 809.1.b · PDF page 128" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 809.1.b · PDF page 128</div></details>

The X is referenced in the functional text of the [[Ability|ability]]. ^cr-809-1-b-1

<details class="rule-ref"><summary title="Core rule 809.1.b.1 · PDF page 128" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 809.1.b.1 · PDF page 128</div></details>

The X is referred to as the Deflect Value. ^cr-809-1-b-2

<details class="rule-ref"><summary title="Core rule 809.1.b.2 · PDF page 128" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 809.1.b.2 · PDF page 128</div></details>

If X is omitted, it is presumed to be 1. ^cr-809-1-b-3

<details class="rule-ref"><summary title="Core rule 809.1.b.3 · PDF page 128" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 809.1.b.3 · PDF page 128</div></details>

It is functionally short for "[[Spell|Spells]] and [[Ability|abilities]] an opponent controls that target &#91;me/this&#93; [[Costs|cost]] an amount of [[Power]] equal to &#91;Deflect Value&#93; more to [[Play|play]] as an [[Additional Cost|additional cost]] for each time they choose &#91;me/this&#93;." ^cr-809-1-c

<details class="rule-ref"><summary title="Core rule 809.1.c · PDF page 128" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 809.1.c · PDF page 128</div></details>

The [[Power]] used to pay this [[Costs|cost]] may always be of any [[Domain]]. ^cr-809-1-c-1

**Example:** A Fury [[Spell|spell]] targets an Order [[Unit|unit]] with Deflect. The [[Power]] used to pay the Deflect [[Costs|cost]] can be any [[Domain]]; it does not need to match the Domain of the spell or the target.

<details class="rule-ref"><summary title="Core rule 809.1.c.1 · PDF page 128" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 809.1.c.1 · PDF page 128</div></details>

It is an effect that imposes a Mandatory [[Additional Cost]] on [[Spell|Spells]] and [[Ability|Abilities]] that choose the [[Game Object]] that has this ability. ^cr-809-1-d

See [[Playing Cards#^cr-349|Playing Cards]] for more information.

<details class="rule-ref"><summary title="Core rule 809.1.d · PDF page 128" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 809.1.d · PDF page 128</div></details>

If a [[Game Object]] has Deflect, or has been granted Deflect, and is granted Deflect by an additional source, the Deflect Value of all granted Deflect [[Keywords|keywords]] is summed. ^cr-809-2

<details class="rule-ref"><summary title="Core rule 809.2 · PDF page 128" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 809.2 · PDF page 128</div></details>

Deflect, and whether or not a [[Game Object]] has Deflect, is a characteristic of the [[Permanent|permanent]] and may be checked or referenced by other [[Game Effect|Game Effects]]. ^cr-809-3

<details class="rule-ref"><summary title="Core rule 809.3 · PDF page 128" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 809.3 · PDF page 128</div></details>
