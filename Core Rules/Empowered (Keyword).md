# Empowered (Keyword)

[[Start Here|Home]] · [[Concept Index|Find a concept]] · [[Core Rules Index|Core rules]]

<span title="Core rule 828"></span> ^cr-828

<details class="rule-ref"><summary title="Core rule 828 · PDF page 139" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 828 · PDF page 139</div></details>

Empowered is a [[Dependent Keyword]]. ^cr-828-1

<details class="rule-ref"><summary title="Core rule 828.1 · PDF page 139" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 828.1 · PDF page 139</div></details>

It is formatted as “&#91;Empowered&#93;&#91;>&#93; &#91;Text&#93;.” ^cr-828-1-a

<details class="rule-ref"><summary title="Core rule 828.1.a · PDF page 139" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 828.1.a · PDF page 139</div></details>

Starting from the [[Keywords|keyword]] to the end of the clause, the entire statement is the Empowered [[Ability]]. ^cr-828-1-b

<details class="rule-ref"><summary title="Core rule 828.1.b · PDF page 139" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 828.1.b · PDF page 139</div></details>

It is functionally short for “While I have the Empowered status, this [[Card|card]] gains ‘&#91;Text&#93;’.” ^cr-828-1-b-1

<details class="rule-ref"><summary title="Core rule 828.1.b.1 · PDF page 140" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 828.1.b.1 · PDF page 140</div></details>

The &#91;Text&#93; here is the Dependent [[Ability]]. ^cr-828-1-b-2

<details class="rule-ref"><summary title="Core rule 828.1.b.2 · PDF page 140" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 828.1.b.2 · PDF page 140</div></details>

As long as the [[Game Object]] has the Empowered status, then the Dependent [[Ability]] will be active. ^cr-828-1-c

<details class="rule-ref"><summary title="Core rule 828.1.c · PDF page 140" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 828.1.c · PDF page 140</div></details>

If the Dependent [[Ability]] is a [[Triggered Ability]] whose condition is “When I become Empowered,” or a permutation thereof, it will be active and trigger when its source becomes Empowered. ^cr-828-1-d

<details class="rule-ref"><summary title="Core rule 828.1.d · PDF page 140" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 828.1.d · PDF page 140</div></details>

Empowered and whether or not a [[Card|card]] has an Empowered [[Ability]] is a characteristic of the card that may be checked or referenced by other [[Game Effect|Game Effects]]. ^cr-828-2

<details class="rule-ref"><summary title="Core rule 828.2 · PDF page 140" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 828.2 · PDF page 140</div></details>
