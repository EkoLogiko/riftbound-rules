# Predict

[[Start Here|Home]] · [[Concept Index|Find a concept]] · [[Core Rules Index|Core rules]]

<span title="Core rule 437"></span> ^cr-437

<details class="rule-ref"><summary title="Core rule 437 · PDF page 93" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 437 · PDF page 93</div></details>

Predicting a [[Card|card]] is the act of looking at a single card from the top of the [[Main Deck]] and choosing whether or not to [[Recycle]] it. ^cr-437-1

<details class="rule-ref"><summary title="Core rule 437.1 · PDF page 93" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 437.1 · PDF page 93</div></details>

When more than one [[Card|card]] is Predicted, the Predicting player looks at that many cards and Recycles any number of them before putting the rest back on top of their [[Main Deck]] in any order. ^cr-437-1-a

<details class="rule-ref"><summary title="Core rule 437.1.a · PDF page 93" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 437.1.a · PDF page 93</div></details>

Predicting is a [[Limited Action]]. ^cr-437-2

<details class="rule-ref"><summary title="Core rule 437.2 · PDF page 93" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 437.2 · PDF page 93</div></details>

Players may only Predict [[Card|cards]] when instructed to do so by [[Game Effect|game effects]]. ^cr-437-2-a

<details class="rule-ref"><summary title="Core rule 437.2.a · PDF page 93" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 437.2.a · PDF page 93</div></details>

This action, when instructed, is formatted as "Predict X." ^cr-437-3

<details class="rule-ref"><summary title="Core rule 437.3 · PDF page 93" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 437.3 · PDF page 93</div></details>

If omitted, X is presumed to be 1. ^cr-437-3-a

<details class="rule-ref"><summary title="Core rule 437.3.a · PDF page 93" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 437.3.a · PDF page 93</div></details>

If a player attempts to Predict more [[Card|cards]] than are available in their [[Main Deck]], they will Predict as many as possible instead. ^cr-437-4

<details class="rule-ref"><summary title="Core rule 437.4 · PDF page 93" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 437.4 · PDF page 93</div></details>

The Player will not perform a [[Burn Out]] as a result of Predicting with too few [[Card|cards]] in their deck. ^cr-437-4-a

<details class="rule-ref"><summary title="Core rule 437.4.a · PDF page 93" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 437.4.a · PDF page 93</div></details>
