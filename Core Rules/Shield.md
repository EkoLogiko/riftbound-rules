Shield is a [[Passive Ability]] [[Keywords|keyword]]. ^cr-814-1

<details class="rule-ref"><summary title="Core rule 814.1 · PDF page 132" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 814.1 · PDF page 132</div></details>

It is present on [[Unit|Units]]. ^cr-814-1-a

<details class="rule-ref"><summary title="Core rule 814.1.a · PDF page 132" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 814.1.a · PDF page 132</div></details>

Shield is formatted as "Shield &#91;X&#93;". ^cr-814-1-b

<details class="rule-ref"><summary title="Core rule 814.1.b · PDF page 132" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 814.1.b · PDF page 132</div></details>

The X is referenced in the functional text of the [[Ability|ability]]. ^cr-814-1-b-1

<details class="rule-ref"><summary title="Core rule 814.1.b.1 · PDF page 132" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 814.1.b.1 · PDF page 132</div></details>

The X is referred to as the Shield Value. ^cr-814-1-b-2

<details class="rule-ref"><summary title="Core rule 814.1.b.2 · PDF page 132" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 814.1.b.2 · PDF page 132</div></details>

If X is omitted, it is presumed to be 1. ^cr-814-1-b-3

<details class="rule-ref"><summary title="Core rule 814.1.b.3 · PDF page 132" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 814.1.b.3 · PDF page 132</div></details>

It is functionally short for "While I am a [[Defender|defender]], I have +X &#91;M&#93;." ^cr-814-1-c

<details class="rule-ref"><summary title="Core rule 814.1.c · PDF page 132" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 814.1.c · PDF page 132</div></details>

Being a [[Defender|defender]] means the [[Unit]] has gained the Defender designation during [[Combat]]. ^cr-814-1-d

See [[Combat#^cr-461|Combat]] for more information.

<details class="rule-ref"><summary title="Core rule 814.1.d · PDF page 132" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 814.1.d · PDF page 132</div></details>

Shield remains in effect as long as the [[Unit]] maintains the [[Defender]] designation. ^cr-814-1-d-1

<details class="rule-ref"><summary title="Core rule 814.1.d.1 · PDF page 132" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 814.1.d.1 · PDF page 132</div></details>

If a [[Unit]] has Shield, or has been granted Shield, and is granted Shield by an additional source, the Shield Value of all granted Shield [[Keywords|keywords]] is summed. ^cr-814-2

**Example:** Stalwart Poro has Shield. It is chosen as the target of Block, which says "Give a [[Unit|unit]] &#91;Shield 3&#93; and &#91;[[Tank]]&#93; this [[Turn|turn]]." After Block resolves, Stalwart Poro has Shield 4 this turn.

<details class="rule-ref"><summary title="Core rule 814.2 · PDF page 132" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 814.2 · PDF page 132</div></details>

Shield, and whether or not a [[Unit|unit]] has Shield, is a characteristic of the Unit and may be checked or referenced by other [[Game Effect|Game Effects]]. ^cr-814-3
