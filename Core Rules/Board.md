### Facedown Zones

^cr-107-3

<details class="rule-ref"><summary title="Core rule 107.3 · PDF page 4" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 107.3 · PDF page 4</div></details>

Each [[Battlefield]] is associated with a sub-zone called a [[Facedown Zone]], a single logical space that a [[Card|card]] can be put facedown in through various [[Game Effect|Game Effects]]. ^cr-107-3-a

<details class="rule-ref"><summary title="Core rule 107.3.a · PDF page 4" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 107.3.a · PDF page 4</div></details>

Each [[Facedown Zone]] has a maximum occupancy of one [[Card|card]]. ^cr-107-3-b

<details class="rule-ref"><summary title="Core rule 107.3.b · PDF page 4" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 107.3.b · PDF page 4</div></details>

The maximum occupancy of a [[Facedown Zone]] can increase or decrease. ^cr-107-3-b-1

<details class="rule-ref"><summary title="Core rule 107.3.b.1 · PDF page 4" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 107.3.b.1 · PDF page 4</div></details>

If the maximum occupancy of a [[Facedown Zone]] decreases to a number less than the number of [[Card|cards]] currently located there, the controller of that Facedown Zone must put a number of cards equal to the difference in the [[Trash|trash]] from the Facedown Zone. ^cr-107-3-b-2

<details class="rule-ref"><summary title="Core rule 107.3.b.2 · PDF page 4-5" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 107.3.b.2 · PDF page 4-5</div></details>

[[Card|Cards]] can only be placed in or occupy the [[Facedown Zone]] if the controller of the card also controls the associated [[Battlefield]]. ^cr-107-3-c

<details class="rule-ref"><summary title="Core rule 107.3.c · PDF page 5" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 107.3.c · PDF page 5</div></details>

If a player loses [[Control]] of a [[Battlefield]], any [[Card|cards]] in the [[Facedown Zone]] associated with that Battlefield are removed during the next [[Cleanups|Cleanup]]. ^cr-107-3-d

See [[Cleanups#^cr-318|Cleanups]] for more information.

See [[Hide#^cr-422|Hide]] for more information.

<details class="rule-ref"><summary title="Core rule 107.3.d · PDF page 5" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 107.3.d · PDF page 5</div></details>

[[Facedown Zone|Facedown Zones]] are not [[Location|locations]]. ^cr-107-3-e

<details class="rule-ref"><summary title="Core rule 107.3.e · PDF page 5" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 107.3.e · PDF page 5</div></details>

[[Facedown Zone|Facedown Zones]] are Public [[Zone|Zones]], though facedown [[Card|cards]] located there are Private. ^cr-107-3-f

<details class="rule-ref"><summary title="Core rule 107.3.f · PDF page 5" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 107.3.f · PDF page 5</div></details>

### Legend Zone

^cr-107-4

<details class="rule-ref"><summary title="Core rule 107.4 · PDF page 5" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 107.4 · PDF page 5</div></details>

The space for each player's [[Champion Legend]]. ^cr-107-4-a

<details class="rule-ref"><summary title="Core rule 107.4.a · PDF page 5" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 107.4.a · PDF page 5</div></details>

This is not a [[Location|location]]. ^cr-107-4-b

<details class="rule-ref"><summary title="Core rule 107.4.b · PDF page 5" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 107.4.b · PDF page 5</div></details>

The [[Champion Legend]] here is a [[Game Object]]. ^cr-107-4-c

See [[Game Object#^cr-119|Game Objects]] for more information.

<details class="rule-ref"><summary title="Core rule 107.4.c · PDF page 5" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 107.4.c · PDF page 5</div></details>

The [[Champion Legend]] cannot be removed, moved, or displaced from this [[Zone|zone]]. ^cr-107-4-d

<details class="rule-ref"><summary title="Core rule 107.4.d · PDF page 5" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 107.4.d · PDF page 5</div></details>

Some effects may add a [[Legend|legend]] [[Card|card]] or [[Token|token]] to the [[Legend Zone]]. These legends are not [[Champion]] Legends. ^cr-107-4-d-1

<details class="rule-ref"><summary title="Core rule 107.4.d.1 · PDF page 5" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Core rule 107.4.d.1 · PDF page 5</div></details>

Non-Champion [[Legend|legends]] may be removed from the [[Legend Zone]]. They cannot exist in any [[Zone|zone]] other than the Legend Zone or [[Banishment]]. ^cr-107-4-d-2
