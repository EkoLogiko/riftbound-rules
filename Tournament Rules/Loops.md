# Loops

[[Start Here|Home]] · [[Concept Index|Find a concept]] · [[Tournament Rules|Tournament rules]]

<span title="Tournament rule 505"></span> ^tr-505

<details class="rule-ref"><summary title="Tournament rule 505 · PDF page 20" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 505 · PDF page 20</div></details>

Some sequences of actions can be repeated and are shortcutted as a loop. ^tr-505-1

<details class="rule-ref"><summary title="Tournament rule 505.1 · PDF page 20" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 505.1 · PDF page 20</div></details>

Each iteration of a loop must contain identical, non-conditional actions performed on the same set of [[Card|cards]]. To establish a loop, the looping player must be able to say with certainty exactly what each step of the loop will be, not just the outcome. ^tr-505-2

<details class="rule-ref"><summary title="Tournament rule 505.2 · PDF page 20" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 505.2 · PDF page 20</div></details>

Loops must be fully deterministic; they may not rely on probability, decision trees, or conditional actions. Example: ^tr-505-2-a

<details class="rule-ref"><summary title="Tournament rule 505.2.a · PDF page 20" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 505.2.a · PDF page 20</div></details>

Legal Loop: With enough [[Energy]] available, playing Grim Apothecary to a [[Battlefield|battlefield]] then using its trigger to return itself to [[Hand|hand]] 100 times. ^tr-505-2-a-1

<details class="rule-ref"><summary title="Tournament rule 505.2.a.1 · PDF page 20" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 505.2.a.1 · PDF page 20</div></details>

Illegal Loop: A [[Card|card]] reads "[[Recycle]] 3 cards from your [[Trash|trash]]: [[Ready]] a [[Unit|unit]]." A player with enough [[Energy]] available wants to use this to recycle 2 copies of Stupefy from their trash and 1 [[Copy|copy]] of Downstage Dramatics with an additional copy of Dramatics in [[Hand|hand]], planning to [[Play|play]] the Downstage Dramatics from hand, and then play each card as they [[Draw|draw]] it until there are 3 cards in the trash for them to recycle. ^tr-505-2-a-2

<details class="rule-ref"><summary title="Tournament rule 505.2.a.2 · PDF page 20" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 505.2.a.2 · PDF page 20</div></details>

This is a non-deterministic loop because the order you [[Play|play]] the [[Card|cards]] is not guaranteed. If the loop only included copies of the same exact card [[Draw|draw]] [[Spell|spell]], it would be deterministic. ^tr-505-2-a-2-a

<details class="rule-ref"><summary title="Tournament rule 505.2.a.2.a · PDF page 20" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 505.2.a.2.a · PDF page 20</div></details>

Players can manually execute non-deterministic loops, but must do so in a timely fashion. Failure to do so is [[Slow Play]]. See [[Tournament Errors#^tr-703-2|Slow Play]] for more information on Slow Play. ^tr-505-2-b

<details class="rule-ref"><summary title="Tournament rule 505.2.b · PDF page 20" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 505.2.b · PDF page 20</div></details>

To decide how to proceed with a loop, determine how many players are needed to maintain it (who must take actions or make decisions to sustain the loop): ^tr-505-3

<details class="rule-ref"><summary title="Tournament rule 505.3 · PDF page 20" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 505.3 · PDF page 20</div></details>

No players ^tr-505-3-a

<details class="rule-ref"><summary title="Tournament rule 505.3.a · PDF page 20" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 505.3.a · PDF page 20</div></details>

One player ^tr-505-3-b

<details class="rule-ref"><summary title="Tournament rule 505.3.b · PDF page 20" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 505.3.b · PDF page 20</div></details>

Two or more players ^tr-505-3-c

<details class="rule-ref"><summary title="Tournament rule 505.3.c · PDF page 20" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 505.3.c · PDF page 20</div></details>

For each maintaining player (if any), in [[Turn|turn]] order, that player chooses a number of iterations. ^tr-505-4

<details class="rule-ref"><summary title="Tournament rule 505.4 · PDF page 20" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 505.4 · PDF page 20</div></details>

Each other player (if any), in [[Turn|turn]] order, may choose to agree to that number or choose a number of iterations after which they commit to taking action to break the loop or choose not to break the loop. ^tr-505-5

<details class="rule-ref"><summary title="Tournament rule 505.5 · PDF page 20" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 505.5 · PDF page 20</div></details>

If no player chooses to break the loop and there were no maintaining players, the game ends in a [[Draw (Game Result)|draw]]. ^tr-505-6

<details class="rule-ref"><summary title="Tournament rule 505.6 · PDF page 20" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 505.6 · PDF page 20</div></details>

Otherwise, the loop continues until the lowest number of iterations chosen, then that player either gains [[Priority|priority]] (if a maintaining player) or breaks the loop. ^tr-505-7

<details class="rule-ref"><summary title="Tournament rule 505.7 · PDF page 20" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 505.7 · PDF page 20</div></details>

If a player intervenes to break a loop, they may choose to interrupt a partially completed iteration. ^tr-505-8

<details class="rule-ref"><summary title="Tournament rule 505.8 · PDF page 20" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 505.8 · PDF page 20</div></details>

If a sequence of actions is non-deterministic, it may not be [[Shortcuts|shortcut]] and iterations must be performed manually. ^tr-505-9

<details class="rule-ref"><summary title="Tournament rule 505.9 · PDF page 21" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 505.9 · PDF page 21</div></details>

Some loops are maintained by decisions rather than actions. In these cases, apply [[Loops#^tr-505-4|Loops]]-[[Loops#^tr-505-8|Loops]] but with the player making a different decision rather than a different action. ^tr-505-10

<details class="rule-ref"><summary title="Tournament rule 505.10 · PDF page 21" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 505.10 · PDF page 21</div></details>

Judges are the final arbiter of what constitutes a loop, or if choices are available to continue a loop when [[Secret Information|secret information]] is involved. ^tr-505-11

<details class="rule-ref"><summary title="Tournament rule 505.11 · PDF page 21" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 505.11 · PDF page 21</div></details>

Players who try to opt-out of shortcutting or propose incorrect shortcutting to use up time are [[Cheating|cheating]]. See [[Unsporting Conduct#^tr-704-8|Cheating]] for more information about cheating. ^tr-505-12

<details class="rule-ref"><summary title="Tournament rule 505.12 · PDF page 21" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 505.12 · PDF page 21</div></details>

Players cannot use loops to stall. When other actions are available, attempting to perform a loop that doesn’t change the game state is [[Cheating|cheating]]. See [[Unsporting Conduct#^tr-704-8|Cheating]] for more information about cheating. ^tr-505-13

<details class="rule-ref"><summary title="Tournament rule 505.13 · PDF page 21" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 505.13 · PDF page 21</div></details>
