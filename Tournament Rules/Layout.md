# Layout

[[Start Here|Home]] · [[Concept Index|Find a concept]] · [[Tournament Rules|Tournament rules]]

<span title="Tournament rule 508"></span> ^tr-508

<details class="rule-ref"><summary title="Tournament rule 508 · PDF page 22" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 508 · PDF page 22</div></details>

In [[High OPL|high OPL]], players must arrange their [[Card|cards]] according to the following rules, for clarity. ^tr-508-1

<details class="rule-ref"><summary title="Tournament rule 508.1 · PDF page 22" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 508.1 · PDF page 22</div></details>

[[Rune|Runes]] must be closer to the player than nonrunes. ^tr-508-2

<details class="rule-ref"><summary title="Tournament rule 508.2 · PDF page 22" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 508.2 · PDF page 22</div></details>

Nonrunes must be closer to the player’s opponent than the player’s [[Rune|runes]]. ^tr-508-3

<details class="rule-ref"><summary title="Tournament rule 508.3 · PDF page 22" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 508.3 · PDF page 22</div></details>

[[Main Deck]] and [[Trash|trash]] must be together on either the left side or the right side of [[Board|the board]]. ^tr-508-4

<details class="rule-ref"><summary title="Tournament rule 508.4 · PDF page 22" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 508.4 · PDF page 22</div></details>

[[Rune Deck]] should be on the other side (right or left) of [[Board|the board]] from the [[Main Deck]]. ^tr-508-5

<details class="rule-ref"><summary title="Tournament rule 508.5 · PDF page 22" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 508.5 · PDF page 22</div></details>

[[Legend]] must be between nonrunes and [[Chosen Champion]], and both legend and Chosen Champion must be together on either the left side or the right side of [[Board|the board]]. ^tr-508-6

<details class="rule-ref"><summary title="Tournament rule 508.6 · PDF page 23" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 508.6 · PDF page 23</div></details>

Each [[Card|card]] or indicator that [[Attach|attaches]] to another card must be clearly associated with it physically. ^tr-508-7

<details class="rule-ref"><summary title="Tournament rule 508.7 · PDF page 23" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 508.7 · PDF page 23</div></details>

[[Token|Tokens]] must be represented by [[Card|card]] objects that are able to represent [[Ready|ready]] state. They must be understandable and discernible by all players in the game where they are being used. ^tr-508-8

<details class="rule-ref"><summary title="Tournament rule 508.8 · PDF page 23" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 508.8 · PDF page 23</div></details>

[[Buffs]] must be represented by an object that unambiguously represents a buff in game terms. ^tr-508-9

<details class="rule-ref"><summary title="Tournament rule 508.9 · PDF page 23" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 508.9 · PDF page 23</div></details>

[[Ready]] objects must be oriented facing the controller. [[Exhaust|Exhausted]] objects must be oriented at a 90 degree rotation to ready objects, either clockwise or counterclockwise, but all exhausted objects must be rotated consistently. ^tr-508-10

<details class="rule-ref"><summary title="Tournament rule 508.10 · PDF page 23" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 508.10 · PDF page 23</div></details>
