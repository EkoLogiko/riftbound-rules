# Tournament Triggered Abilities

[[Start Here|Home]] · [[Concept Index|Find a concept]] · [[Tournament Rules|Tournament rules]]

<span title="Tournament rule 506"></span> ^tr-506

<details class="rule-ref"><summary title="Tournament rule 506 · PDF page 21" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 506 · PDF page 21</div></details>

[[Accountable Player]]: The player responsible for putting a [[Triggered Ability|triggered ability]] on the [[Chain|chain]], as defined by the core rules. See [[Triggered Ability#^cr-383|Triggered Abilities]] for more information on triggered abilities. ^tr-506-1

<details class="rule-ref"><summary title="Tournament rule 506.1 · PDF page 21" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 506.1 · PDF page 21</div></details>

The [[Accountable Player|accountable player]] for triggers sourced from [[Battlefield|battlefields]] depends on [[Control|control]] of the battlefield and is not automatically the player who brought the battlefield to the game. See [[Battlefield Control#^cr-190-6|Battlefield Control]] For more information on battlefield [[Ability|abilities]]. ^tr-506-1-a

<details class="rule-ref"><summary title="Tournament rule 506.1.a · PDF page 21" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 506.1.a · PDF page 21</div></details>

Players are not required to notify other players of [[Triggered Ability|triggered abilities]] when they are not the [[Accountable Player|accountable player]], but may if they wish. ^tr-506-2

<details class="rule-ref"><summary title="Tournament rule 506.2 · PDF page 21" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 506.2 · PDF page 21</div></details>

At [[Casual OPL|low OPL]], a player is not required to notify other players of [[Triggered Ability|triggered abilities]] when they are not the [[Accountable Player|accountable player]], but it is encouraged for sportsmanship and learning. ^tr-506-2-a

<details class="rule-ref"><summary title="Tournament rule 506.2.a · PDF page 21" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 506.2.a · PDF page 21</div></details>

The [[Accountable Player|accountable player]] must acknowledge their triggers by the time they would have an [[Observable Impact|observable impact]] on the game. If they do not, they are forgotten. ^tr-506-3

<details class="rule-ref"><summary title="Tournament rule 506.3 · PDF page 21" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 506.3 · PDF page 21</div></details>

As part of acknowledging a trigger, the [[Accountable Player|accountable player]] must communicate the trigger to all other players in an understandable and observable way. Examples include verbally announcing the trigger, physically indicating the trigger, or other means of communication understood and agreed upon by all players in the game. ^tr-506-3-a

<details class="rule-ref"><summary title="Tournament rule 506.3.a · PDF page 21" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 506.3.a · PDF page 21</div></details>

A trigger is considered forgotten once its point of [[Observable Impact|observable impact]] has been reached and a new [[Game Action|game action]] is taken without the [[Accountable Player|accountable player]] acknowledging the trigger. ^tr-506-3-b

<details class="rule-ref"><summary title="Tournament rule 506.3.b · PDF page 21" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 506.3.b · PDF page 21</div></details>

Players ruled to be abusing this rule to intentionally forget mandatory triggers that they are the [[Accountable Player|accountable player]] for will be penalized. See [[Game Play Errors#^tr-702-2|Missed Trigger]] for more information about [[Missed Trigger|missed triggers]] as a [[Penalties|penalty]]. ^tr-506-3-c

<details class="rule-ref"><summary title="Tournament rule 506.3.c · PDF page 21" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 506.3.c · PDF page 21</div></details>

For triggers that occur “At the start of each player’s first [[Beginning Phase]]”, the [[Accountable Player|accountable player]] has the full duration of [[Turn|the turn]] in which the trigger occurs to acknowledge the trigger before it's considered forgotten, regardless of its [[Observable Impact|observable impact]]. (Example [[Card|cards]]: Obelisk of [[Power]] and The Arena’s Greatest.) ^tr-506-3-d

<details class="rule-ref"><summary title="Tournament rule 506.3.d · PDF page 21" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 506.3.d · PDF page 21</div></details>

Examples of [[Observable Impact|observable impact]]: ^tr-506-3-e

<details class="rule-ref"><summary title="Tournament rule 506.3.e · PDF page 21" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 506.3.e · PDF page 21</div></details>

The trigger would change a point total. (Example [[Card|card]]: Ahri, Alluring) ^tr-506-3-e-1

<details class="rule-ref"><summary title="Tournament rule 506.3.e.1 · PDF page 21" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 506.3.e.1 · PDF page 21</div></details>

The trigger would change a [[Rune|rune]] total. (Example [[Card|card]]: Startipped Peak) ^tr-506-3-e-2

<details class="rule-ref"><summary title="Tournament rule 506.3.e.2 · PDF page 22" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 506.3.e.2 · PDF page 22</div></details>

The trigger would add a [[Buffs|Buff]] [[Token|token]] to a [[Unit|unit]]. (Example [[Card|card]]: Sett, Brawler) ^tr-506-3-e-3

<details class="rule-ref"><summary title="Tournament rule 506.3.e.3 · PDF page 22" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 506.3.e.3 · PDF page 22</div></details>

The trigger would impact [[Combat|combat]] or other game procedures. A [[Card|card]] that reads “When you [[Play|play]] a [[Spell|spell]], give me +1 [[Might]] this [[Turn|turn]].” does NOT have an immediate [[Observable Impact|observable impact]]. It has an observable impact once it’s Might would be relevant. (Example card: Ravenbloom Student) ^tr-506-3-e-4

<details class="rule-ref"><summary title="Tournament rule 506.3.e.4 · PDF page 22" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 506.3.e.4 · PDF page 22</div></details>

A trigger would cause a player to [[Draw|draw]] or [[Discard|discard]]. (Example [[Card|card]]: Traveling Merchant) ^tr-506-3-e-5

<details class="rule-ref"><summary title="Tournament rule 506.3.e.5 · PDF page 22" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 506.3.e.5 · PDF page 22</div></details>

A trigger would cause a [[Game Object|game object]] to be [[Exhaust|exhausted]] or [[Ready|readied]]. (Example [[Card|card]]: Miss Fortune, Captain) ^tr-506-3-e-6

<details class="rule-ref"><summary title="Tournament rule 506.3.e.6 · PDF page 22" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 506.3.e.6 · PDF page 22</div></details>

A trigger would cause a [[Unit|unit]] to [[Move|move]]. (Example [[Card|card]]: Stealthy Pursuer) ^tr-506-3-e-7

<details class="rule-ref"><summary title="Tournament rule 506.3.e.7 · PDF page 22" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 506.3.e.7 · PDF page 22</div></details>

A player asks for [[Public Information|public information]] that would be impacted by a trigger. ^tr-506-3-e-8

See [[Information#^tr-502|Information]] for more information on [[Public Information|public information]].

<details class="rule-ref"><summary title="Tournament rule 506.3.e.8 · PDF page 22" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 506.3.e.8 · PDF page 22</div></details>

A player would be required to make a choice of whether or not to place an optional trigger on the [[Chain|chain]]. (Example: Overzealous Fan) ^tr-506-3-e-9

<details class="rule-ref"><summary title="Tournament rule 506.3.e.9 · PDF page 22" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 506.3.e.9 · PDF page 22</div></details>

A trigger would require a player to choose something, such as a [[Unit|unit]] or [[Gear|gear]], even if there is only one legal choice. (Example: Abandoned Hall) ^tr-506-3-e-10

<details class="rule-ref"><summary title="Tournament rule 506.3.e.10 · PDF page 22" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 506.3.e.10 · PDF page 22</div></details>

A trigger would cause a player to gain resources, such as XP or floating [[Power]]/[[Energy]]. (Example: Jhin, Murderous Artist) ^tr-506-3-e-11

<details class="rule-ref"><summary title="Tournament rule 506.3.e.11 · PDF page 22" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 506.3.e.11 · PDF page 22</div></details>

A trigger would cause a [[Card|card]] to change [[Zone|zones]], such as a [[Unit|unit]] taking [[Lethal Damage|lethal damage]]. (Non-lethal [[Damage|damage]] is not an [[Observable Impact|observable impact]].) ^tr-506-3-e-12

<details class="rule-ref"><summary title="Tournament rule 506.3.e.12 · PDF page 22" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 506.3.e.12 · PDF page 22</div></details>

A [[Triggered Ability|triggered ability]] that was forgotten never goes on the [[Chain|chain]]. ^tr-506-4

<details class="rule-ref"><summary title="Tournament rule 506.4 · PDF page 22" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 506.4 · PDF page 22</div></details>

A [[Triggered Ability|triggered ability]] that was forgotten is still considered to have triggered for the purpose of non-optional “First time” or similarly restricted triggers. ^tr-506-5
