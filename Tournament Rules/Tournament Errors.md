### Overview

<span title="Tournament rule 703.1"></span> ^tr-703-1

<details class="rule-ref"><summary title="Tournament rule 703.1 · PDF page 42" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 703.1 · PDF page 42</div></details>

A tournament error is caused by actions in or around a tournament match that violate tournament procedure expectations. ^tr-703-1-a

<details class="rule-ref"><summary title="Tournament rule 703.1.a · PDF page 42" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 703.1.a · PDF page 42</div></details>

Repeated tournament error &#91;[[Warning|Warnings]]&#93; can upgrade to &#91;[[Game Loss]]&#93;. ^tr-703-1-b

<details class="rule-ref"><summary title="Tournament rule 703.1.b · PDF page 42" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 703.1.b · PDF page 42</div></details>

If a player commits the same [[Card Category|category]] of tournament error &#91;[[Warning]]&#93; 3 or more times in the same event, the [[Penalties|penalty]] is upgraded to &#91;[[Game Loss]]&#93;. ^tr-703-1-b-1

<details class="rule-ref"><summary title="Tournament rule 703.1.b.1 · PDF page 42" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 703.1.b.1 · PDF page 42</div></details>

At [[Competitive OPL|competitive OPL]], if a player commits a total of 6 or more of any [[Card Category|category]] of tournament error &#91;[[Warning]]&#93; in the same event, the [[Penalties|penalty]] is upgraded to &#91;[[Game Loss]]&#93;. ^tr-703-1-b-2

<details class="rule-ref"><summary title="Tournament rule 703.1.b.2 · PDF page 42" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 703.1.b.2 · PDF page 42</div></details>

At [[Professional OPL|professional OPL]], if a player commits a total of 5 or more of any [[Card Category|category]] of tournament error &#91;[[Warning]]&#93; in the same event, the [[Penalties|penalty]] is upgraded to &#91;[[Game Loss]]&#93;. ^tr-703-1-b-3

<details class="rule-ref"><summary title="Tournament rule 703.1.b.3 · PDF page 42" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 703.1.b.3 · PDF page 42</div></details>

Even if a player has not yet met the threshold to upgrade their [[Penalties|penalties]], a [[Head Judge|head judge]] may initiate a [[Cheating|cheating]] investigation if they feel it is appropriate. See [[Unsporting Conduct#^tr-704-8|Cheating]] for more information about cheating. ^tr-703-1-b-4

<details class="rule-ref"><summary title="Tournament rule 703.1.b.4 · PDF page 42" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 703.1.b.4 · PDF page 42</div></details>

At [[Casual OPL|low OPL]], [[Penalties|penalties]] should generally be less harsh and rewinds may be applied even if the erroring player gains an information advantage. ^tr-703-1-c

<details class="rule-ref"><summary title="Tournament rule 703.1.c · PDF page 42" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 703.1.c · PDF page 42</div></details>

[[Penalties]] that require an opponent of the erroring player to make a choice can be made at random or by a judge if they can’t be avoided by a [[Rewinding|rewind]]. ^tr-703-1-c-1

<details class="rule-ref"><summary title="Tournament rule 703.1.c.1 · PDF page 42" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 703.1.c.1 · PDF page 42</div></details>

[[Slow Play]] &#91;[[Warning]]&#93;: A player is performing their [[Start of Game Procedure|start of game procedure]] or is playing mid-game at an unreasonably slow pace. ^tr-703-2

<details class="rule-ref"><summary title="Tournament rule 703.2 · PDF page 42" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 703.2 · PDF page 42</div></details>

Players must take their turns in a timely manner, appropriate to a judge according to the state of the game at the time, and adhere to time limits specified for the tournament. ^tr-703-2-a

<details class="rule-ref"><summary title="Tournament rule 703.2.a · PDF page 42" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 703.2.a · PDF page 42</div></details>

Players may ask a judge to watch their game for [[Slow Play|slow play]]. ^tr-703-2-b

<details class="rule-ref"><summary title="Tournament rule 703.2.b · PDF page 42" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 703.2.b · PDF page 42</div></details>

Intentionally stalling to gain an advantage is [[Cheating|cheating]]. See [[Unsporting Conduct#^tr-704-8|Cheating]] for more information about cheating. ^tr-703-2-c

<details class="rule-ref"><summary title="Tournament rule 703.2.c · PDF page 42" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 703.2.c · PDF page 42</div></details>

[[Decklist Error]] &#91;[[Game Loss]]&#93;: A player submits a decklist for registration that contains illegal elements. ^tr-703-3

Examples: ^tr-703-3-a

<details class="rule-ref"><summary title="Tournament rule 703.3.a · PDF page 42" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 703.3.a · PDF page 42</div></details>

More or fewer [[Card|cards]] than appropriate [[Deck Size|deck size]]. See [[Deck Size#^tr-402|Deck Size]] for more information about deck size. ^tr-703-3-a-1

[[Card|Cards]] not legal in the format of the tournament. ^tr-703-3-a-2

<details class="rule-ref"><summary title="Tournament rule 703.3.a.2 · PDF page 43" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 703.3.a.2 · PDF page 43</div></details>

More than 3 copies of a [[Main Deck|main deck]] [[Card|card]] between main deck and [[Sideboard|sideboard]]. ^tr-703-3-a-3

<details class="rule-ref"><summary title="Tournament rule 703.3.a.3 · PDF page 43" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 703.3.a.3 · PDF page 43</div></details>

[[Card|Cards]] that do not match the [[Domain|domain]] of the registered [[Legend|legend]]. ^tr-703-3-a-4

<details class="rule-ref"><summary title="Tournament rule 703.3.a.4 · PDF page 43" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 703.3.a.4 · PDF page 43</div></details>

A [[Chosen Champion|chosen champion]] that does not match the identity of the [[Legend|legend]]. ^tr-703-3-a-5

<details class="rule-ref"><summary title="Tournament rule 703.3.a.5 · PDF page 43" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 703.3.a.5 · PDF page 43</div></details>

A player’s decks contain [[Card|cards]] that do not match their registered decklist. ^tr-703-3-a-6

<details class="rule-ref"><summary title="Tournament rule 703.3.a.6 · PDF page 43" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 703.3.a.6 · PDF page 43</div></details>

Remedies: ^tr-703-3-b

<details class="rule-ref"><summary title="Tournament rule 703.3.b · PDF page 43" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 703.3.b · PDF page 43</div></details>

If the player’s registered decklist is illegal, the player must correct their decklist to a legal state making as little change as possible and ensure that their deck matches the newly registered deck. ^tr-703-3-b-1

<details class="rule-ref"><summary title="Tournament rule 703.3.b.1 · PDF page 43" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 703.3.b.1 · PDF page 43</div></details>

If the player’s presented decks do not match their registered decklist but their presented decks are legal, the player must change their registered decklist to match their presented deck. ^tr-703-3-b-2

<details class="rule-ref"><summary title="Tournament rule 703.3.b.2 · PDF page 43" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 703.3.b.2 · PDF page 43</div></details>

If the [[Card|cards]] required to correct a decklist cannot be acquired in a timely manner, the [[Head Judge|head judge]] can issue a [[Proxies and Alters|proxy]]. ^tr-703-3-b-3

<details class="rule-ref"><summary title="Tournament rule 703.3.b.3 · PDF page 43" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 703.3.b.3 · PDF page 43</div></details>

[[Deck Presentation Error]] &#91;[[Warning]]&#93;: A player’s deck’s contents are illegal during presentation to an opponent or during gameplay. ^tr-703-4

<details class="rule-ref"><summary title="Tournament rule 703.4 · PDF page 43" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 703.4 · PDF page 43</div></details>

Examples: ^tr-703-4-a

<details class="rule-ref"><summary title="Tournament rule 703.4.a · PDF page 43" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 703.4.a · PDF page 43</div></details>

A player submits a [[Battlefield|battlefield]] they have already used in the match. ^tr-703-4-a-1

<details class="rule-ref"><summary title="Tournament rule 703.4.a.1 · PDF page 43" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 703.4.a.1 · PDF page 43</div></details>

A player forgets to restore their deck to a pre-sideboard state for the first game of a match. ^tr-703-4-a-2

<details class="rule-ref"><summary title="Tournament rule 703.4.a.2 · PDF page 43" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 703.4.a.2 · PDF page 43</div></details>

A player forgets to take their [[Chosen Champion|chosen champion]] from their [[Main Deck|main deck]] and place it in the [[Champion Zone|chosen champion zone]]. ^tr-703-4-a-3

<details class="rule-ref"><summary title="Tournament rule 703.4.a.3 · PDF page 43" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 703.4.a.3 · PDF page 43</div></details>

A player’s deck is the incorrect [[Deck Size|deck size]]. See [[Deck Size#^tr-402|Deck Size]] for more information about deck size. (Examples: A player misplaced a [[Card|card]], a player forgot to shuffle their banished cards back into their deck between games, a player's deck has an extra card or is missing a card due to an effect like Possession from a previous game.) ^tr-703-4-a-4

<details class="rule-ref"><summary title="Tournament rule 703.4.a.4 · PDF page 43" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 703.4.a.4 · PDF page 43</div></details>

A player has [[Card|cards]] in their deck box with their deck that are not part of the registered contents of their decklist. Promotional cards given out as part of the event, [[Token|tokens]], and damaged cards replaced with official [[Proxies and Alters|proxies]] are allowed to be stored this way and do not warrant this error. ^tr-703-4-a-5

<details class="rule-ref"><summary title="Tournament rule 703.4.a.5 · PDF page 43" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 703.4.a.5 · PDF page 43</div></details>

Remedies when a player forgets to select their [[Chosen Champion]] during [[Setup|setup]]: If the error is caught before the start of the first player’s [[Turn|turn]], restore the deck to its correct state and instruct players to proceed. ^tr-703-4-b

<details class="rule-ref"><summary title="Tournament rule 703.4.b · PDF page 43" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 703.4.b · PDF page 43</div></details>

At [[Casual OPL]], if the error is caught after the start of the first player’s [[Turn|turn]], instruct the erroring player to search the randomized portion of their [[Main Deck|main deck]], their [[Hand|hand]] and [[Sideboard|sideboard]] for a legal [[Chosen Champion|chosen champion]] and place it in their [[Champion Zone|chosen champion zone]], then shuffle the randomized portion of their main deck. If the [[Champion|champion]] came from their hand, instruct them to [[Draw|draw]] a [[Card|card]]. ^tr-703-4-b-1

<details class="rule-ref"><summary title="Tournament rule 703.4.b.1 · PDF page 44" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 703.4.b.1 · PDF page 44</div></details>

If none are found, instruct players to continue playing with the erroring player’s [[Champion Zone|chosen champion zone]] empty. ^tr-703-4-b-1-a

<details class="rule-ref"><summary title="Tournament rule 703.4.b.1.a · PDF page 44" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 703.4.b.1.a · PDF page 44</div></details>

At [[Competitive OPL]], if the error is caught after the start of the first player’s [[Turn|turn]], a judge searches the randomized portion of the erroring player’s [[Main Deck|main deck]] and [[Hand|hand]] for a [[Copy|copy]] of their registered game one [[Chosen Champion|chosen champion]] and [[Move|move]] it to their [[Champion Zone|chosen champion zone]], then shuffle the randomized portion of their main deck. If the [[Champion|champion]] came from their hand, instruct them to [[Draw|draw]] a [[Card|card]]. ^tr-703-4-b-2

<details class="rule-ref"><summary title="Tournament rule 703.4.b.2 · PDF page 44" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 703.4.b.2 · PDF page 44</div></details>

If none are found, instruct players to proceed with the erroring player’s [[Champion Zone|chosen champion zone]] empty. At [[Professional OPL]], if the error is caught after the start of the first player’s [[Turn|turn]], instruct players to proceed with the erroring player’s chosen champion zone empty. ^tr-703-4-b-2-a

<details class="rule-ref"><summary title="Tournament rule 703.4.b.2.a · PDF page 44" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 703.4.b.2.a · PDF page 44</div></details>

Purposely leaving your [[Champion Zone|Chosen Champion zone]] empty during [[Setup|setup]] to gain an advantage is [[Cheating|cheating]]. See [[Unsporting Conduct#^tr-704-8|Cheating]] for more information about cheating. ^tr-703-4-b-3

<details class="rule-ref"><summary title="Tournament rule 703.4.b.3 · PDF page 44" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 703.4.b.3 · PDF page 44</div></details>

Other Remedies: ^tr-703-4-c

<details class="rule-ref"><summary title="Tournament rule 703.4.c · PDF page 44" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 703.4.c · PDF page 44</div></details>

If the error is caught before opening hands have been drawn, restore the deck to its correct state if possible and instruct players to proceed. ^tr-703-4-c-1

<details class="rule-ref"><summary title="Tournament rule 703.4.c.1 · PDF page 44" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 703.4.c.1 · PDF page 44</div></details>

If the error is caught by the erroring player after opening hands have been drawn and it is easily possible, restore the deck to its correct state and instruct players to proceed. For example: ^tr-703-4-c-2

<details class="rule-ref"><summary title="Tournament rule 703.4.c.2 · PDF page 44" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 703.4.c.2 · PDF page 44</div></details>

<details class="rule-ref"><summary title="Tournament rule 703.4.c.2.a · PDF page 44" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 703.4.c.2.a · PDF page 44</div></details>

A judge can restore their deck to the appropriate state by returning [[Card|cards]] to the [[Main Deck|main deck]] and [[Sideboard|sideboard]] as needed. ^tr-703-4-c-2-a-1

<details class="rule-ref"><summary title="Tournament rule 703.4.c.2.a.1 · PDF page 44" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 703.4.c.2.a.1 · PDF page 44</div></details>

If [[Sideboard|sideboard]] [[Card|cards]] are in the player's [[Hand|hand]], they are replaced randomly by [[Main Deck|main deck]] cards that were incorrectly in the sideboard. ^tr-703-4-c-2-a-1-a

<details class="rule-ref"><summary title="Tournament rule 703.4.c.2.a.1.a · PDF page 44" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 703.4.c.2.a.1.a · PDF page 44</div></details>

Shuffle the randomized portion of the [[Main Deck|main deck]] once this process is complete. ^tr-703-4-c-2-a-2

<details class="rule-ref"><summary title="Tournament rule 703.4.c.2.a.2 · PDF page 44" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 703.4.c.2.a.2 · PDF page 44</div></details>

If the error is caught by anyone other than the erroring player after opening hands have been drawn, the [[Penalties|penalty]] is upgraded to &#91;[[Game Loss]]&#93;. ^tr-703-4-c-3

<details class="rule-ref"><summary title="Tournament rule 703.4.c.3 · PDF page 44" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 703.4.c.3 · PDF page 44</div></details>

In either case, if restoring the deck to its correct state is not possible, the [[Penalties|penalty]] is upgraded to &#91;[[Game Loss]]&#93;. ^tr-703-4-c-4

<details class="rule-ref"><summary title="Tournament rule 703.4.c.4 · PDF page 44" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 703.4.c.4 · PDF page 44</div></details>

Example: A player has two total copies of Traveling Merchant on their registered decklist, one in their [[Main Deck]] and one in their [[Sideboard]]. During game one of a match a player [[Draw (Game Result)|draws]] and plays one Traveling Merchant. On a later [[Turn|turn]], they [[Draw|draw]] the second [[Copy|copy]] and realize they forgot to de-sideboard. At this point, since both Traveling Merchants have been drawn, restoring the deck is not possible as there is no easy 1 to 1 [[Swap|swap]] that can be made to restore the correct deck state. ^tr-703-4-c-4-a

<details class="rule-ref"><summary title="Tournament rule 703.4.c.4.a · PDF page 44-45" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 703.4.c.4.a · PDF page 44-45</div></details>

At [[Professional OPL]], extra [[Card|cards]] in a player’s deck box as described in [[Tournament Errors#^tr-703-4-a-5|Tournament Errors]]. upgrades this [[Penalties|penalty]] to &#91;[[Game Loss]]&#93;. ^tr-703-4-c-5

<details class="rule-ref"><summary title="Tournament rule 703.4.c.5 · PDF page 45" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 703.4.c.5 · PDF page 45</div></details>

[[Late to Match]]: A player arrives at their assigned match after the round clock has started. ^tr-703-8

<details class="rule-ref"><summary title="Tournament rule 703.8 · PDF page 46" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 703.8 · PDF page 46</div></details>

If the player arrives within 2 minutes of the round start, the [[Penalties|penalty]] is a &#91;[[Warning]]&#93; and a time extension is issued. ^tr-703-8-a

<details class="rule-ref"><summary title="Tournament rule 703.8.a · PDF page 46" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 703.8.a · PDF page 46</div></details>

If the player arrives within 10 minutes of the round start, the [[Penalties|penalty]] is a &#91;[[Warning]]&#93; and a time extension is issued. At [[High OPL|high OPL]] the penalty is upgraded to &#91;[[Game Loss]]&#93;. ^tr-703-8-b

<details class="rule-ref"><summary title="Tournament rule 703.8.b · PDF page 46" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 703.8.b · PDF page 46</div></details>

If the player arrives after 10 minutes of the round start, the [[Penalties|penalty]] is a &#91;[[Match Loss]]&#93;. ^tr-703-8-c

If a player never arrives for their match, the [[Penalties|penalty]] is a &#91;[[Match Loss]]&#93; and the player is dropped from the tournament unless they report to a judge before the next match begins. ^tr-703-8-d

Players may call a judge before the round clock starts or in between games of a match to request up to a 10 minute time extension in lieu of [[Penalties|penalty]] at the judge’s discretion. (Example: A player requests to use the restroom.) ^tr-703-8-e

<details class="rule-ref"><summary title="Tournament rule 703.8.e · PDF page 46" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 703.8.e · PDF page 46</div></details>

[[Outside Assistance]]: A player receives advice or strategic assistance from an individual outside of the match. ^tr-703-9

<details class="rule-ref"><summary title="Tournament rule 703.9 · PDF page 46" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 703.9 · PDF page 46</div></details>

If the player receiving the advice actively refuses the advice by calling a judge, they receive a &#91;[[Warning]]&#93;. Otherwise, that player receives a &#91;[[Match Loss]]&#93;. This [[Penalties|penalty]] does not apply if the [[Head Judge|head judge]] deems the advice was delivered maliciously. ^tr-703-9-a

<details class="rule-ref"><summary title="Tournament rule 703.9.a · PDF page 46" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 703.9.a · PDF page 46</div></details>

If the player receiving the advice solicited the advice, it is [[Cheating|cheating]]. See [[Unsporting Conduct#^tr-704-8|Cheating]] for more information about cheating. ^tr-703-9-b

<details class="rule-ref"><summary title="Tournament rule 703.9.b · PDF page 46" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 703.9.b · PDF page 46</div></details>

If the [[Spectator|spectator]] giving the [[Outside Assistance|outside assistance]] is also a player in the event, this [[Penalties|penalty]] is also applied to them. ^tr-703-9-c

<details class="rule-ref"><summary title="Tournament rule 703.9.c · PDF page 46" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 703.9.c · PDF page 46</div></details>

[[Spectator|Spectators]] providing advice may be barred from the tournament venue if the advice was given maliciously or knowingly. ^tr-703-9-d

<details class="rule-ref"><summary title="Tournament rule 703.9.d · PDF page 46" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 703.9.d · PDF page 46</div></details>

It is not [[Outside Assistance|outside assistance]] to receive strategic advice from a teammate in the 2v2 format or in other team formats when specified. ^tr-703-9-e

<details class="rule-ref"><summary title="Tournament rule 703.9.e · PDF page 46" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 703.9.e · PDF page 46</div></details>

At a judge’s discretion, a player may receive assistance with the physical logistics of the competition, including [[Game Action|game actions]] such as [[Shuffling|shuffling]] or [[Card|card]] [[Movement|movement]]. This is not considered [[Outside Assistance|outside assistance]]. ^tr-703-9-f

<details class="rule-ref"><summary title="Tournament rule 703.9.f · PDF page 46" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 703.9.f · PDF page 46</div></details>

Playing other formats of Riftbound other than the one designated for the tournament with the appropriate decklist may not be used to determine a winner. ^tr-703-10-b
