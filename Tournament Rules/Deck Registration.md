# Deck Registration

[[Start Here|Home]] · [[Concept Index|Find a concept]] · [[Tournament Rules|Tournament rules]]

<span title="Tournament rule 401"></span> ^tr-401

<details class="rule-ref"><summary title="Tournament rule 401 · PDF page 7" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 401 · PDF page 7</div></details>

Players in competitions are required to register their decks and [[Sideboard|sideboards]] (if applicable to the format) at [[High OPL|high OPL]]. ^tr-401-1

<details class="rule-ref"><summary title="Tournament rule 401.1 · PDF page 7" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 401.1 · PDF page 7</div></details>

The [[Head Judge]] may require deck registration at [[Casual OPL|low OPL]]. ^tr-401-1-a

<details class="rule-ref"><summary title="Tournament rule 401.1.a · PDF page 7" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 401.1.a · PDF page 7</div></details>

Even when a [[Casual OPL|low OPL]] [[Constructed|constructed]] event does not require deck registration, players are expected to use the same deck throughout the event unless given permission by the tournament organizer. ^tr-401-1-b

<details class="rule-ref"><summary title="Tournament rule 401.1.b · PDF page 7" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 401.1.b · PDF page 7</div></details>

A registered decklist must have a complete, unambiguous record of the player’s [[Champion Legend]], [[Battlefield|battlefields]], [[Main Deck]] including [[Chosen Champion]], [[Rune Deck]], and [[Sideboard|sideboard]] (if applicable to the format). ^tr-401-2

<details class="rule-ref"><summary title="Tournament rule 401.2 · PDF page 7" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 401.2 · PDF page 7</div></details>

They must also include registered records of any [[Card|cards]] selected for special additional deckbuilding rules. (Example: The three [[Legend|Legends]] selected for Neeko, Blending In must be registered on a player’s decklist and can’t be changed once they are submitted.) ^tr-401-2-a

<details class="rule-ref"><summary title="Tournament rule 401.2.a · PDF page 8" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 401.2.a · PDF page 8</div></details>

Once a decklist has been registered and delivered to a competition official, it can’t be changed. ^tr-401-3

<details class="rule-ref"><summary title="Tournament rule 401.3 · PDF page 8" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 401.3 · PDF page 8</div></details>

In a [[Constructed|constructed]] event, a player’s deck must be registered prior to the start of the first round of competition. ^tr-401-4

<details class="rule-ref"><summary title="Tournament rule 401.4 · PDF page 8" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 401.4 · PDF page 8</div></details>

Other player’s decklists are normally considered [[Private Information|private information]]. The [[Head Judge|head judge]] of an event may run that event or the final rounds of that event using an open decklist policy. In this case, all players’ decklists will be considered [[Public Information|public information]]. ^tr-401-5

<details class="rule-ref"><summary title="Tournament rule 401.5 · PDF page 8" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 401.5 · PDF page 8</div></details>

In an open decklist competition, each round players are provided with their opponent’s decklist to review at the start of the match and in between games of the match. Players may not review decklists during gameplay. ^tr-401-5-a

<details class="rule-ref"><summary title="Tournament rule 401.5.a · PDF page 8" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 401.5.a · PDF page 8</div></details>

Typically, [[Professional OPL|professional OPL]] competitions should be run with open decklists, but it is ultimately up to the discretion of the [[Head Judge|head judge]] regardless of the event [[Level|level]]. ^tr-401-5-b

<details class="rule-ref"><summary title="Tournament rule 401.5.b · PDF page 8" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 401.5.b · PDF page 8</div></details>
