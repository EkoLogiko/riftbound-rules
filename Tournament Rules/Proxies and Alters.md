# Proxies and Alters

[[Start Here|Home]] · [[Concept Index|Find a concept]] · [[Tournament Rules|Tournament rules]]

<span title="Tournament rule 419"></span> ^tr-419

<details class="rule-ref"><summary title="Tournament rule 419 · PDF page 15" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 419 · PDF page 15</div></details>

A proxy is a stand-in, unofficial version of an actual Riftbound [[Card|card]]. ^tr-419-1

<details class="rule-ref"><summary title="Tournament rule 419.1 · PDF page 15" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 419.1 · PDF page 15</div></details>

Proxies are not allowed at competitions of any [[Organized Play Level|OPL]]. ^tr-419-2

<details class="rule-ref"><summary title="Tournament rule 419.2 · PDF page 15" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 419.2 · PDF page 15</div></details>

The only exception is an official proxy issued by the [[Head Judge|head judge]] at their discretion to replace a [[Card|card]] deemed unusable. ^tr-419-2-a

<details class="rule-ref"><summary title="Tournament rule 419.2.a · PDF page 15" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 419.2.a · PDF page 15</div></details>

An alter is an official Riftbound [[Card|card]] that has been modified in some way. ^tr-419-3

<details class="rule-ref"><summary title="Tournament rule 419.3 · PDF page 15" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 419.3 · PDF page 15</div></details>

Alters are allowed in competition only if the modifications do not: ^tr-419-4

<details class="rule-ref"><summary title="Tournament rule 419.4 · PDF page 15" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 419.4 · PDF page 15</div></details>

Modify or obscure the [[Card Name|card name]], [[Might]]/[[Might Bonus]], or [[Costs|cost]], or make the art unrecognizable. ^tr-419-4-a

<details class="rule-ref"><summary title="Tournament rule 419.4.a · PDF page 15" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 419.4.a · PDF page 15</div></details>

Contain substantial strategic advice. ^tr-419-4-b

<details class="rule-ref"><summary title="Tournament rule 419.4.b · PDF page 15" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 419.4.b · PDF page 15</div></details>

Contain offensive images or text. ^tr-419-4-c

<details class="rule-ref"><summary title="Tournament rule 419.4.c · PDF page 15" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 419.4.c · PDF page 15</div></details>

By judge discretion, alters may not be allowed to be used during matches that are streamed or otherwise broadcast. ^tr-419-5

<details class="rule-ref"><summary title="Tournament rule 419.5 · PDF page 15" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 419.5 · PDF page 15</div></details>

Players using altered [[Card|cards]] are responsible for having official unaltered versions of those cards to use during gameplay that is streamed or otherwise broadcast if instructed by a judge. ^tr-419-5-a

<details class="rule-ref"><summary title="Tournament rule 419.5.a · PDF page 15" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 419.5.a · PDF page 15</div></details>

When instructed, players must replace the altered versions with the official unaltered versions before gameplay begins for a match that is streamed or otherwise broadcast. ^tr-419-5-b

<details class="rule-ref"><summary title="Tournament rule 419.5.b · PDF page 15" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 419.5.b · PDF page 15</div></details>

Alters containing material outside of Riot Games intellectual property may not be permitted during matches that are streamed or otherwise broadcast. ^tr-419-5-c

<details class="rule-ref"><summary title="Tournament rule 419.5.c · PDF page 15" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 419.5.c · PDF page 15</div></details>

The [[Head Judge|head judge]] of a competition is the final decider on whether a [[Card|card]] is acceptable for a competition. ^tr-419-6

<details class="rule-ref"><summary title="Tournament rule 419.6 · PDF page 15" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 419.6 · PDF page 15</div></details>
