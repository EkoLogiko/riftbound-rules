# Shortcuts

[[Start Here|Home]] · [[Concept Index|Find a concept]] · [[Tournament Rules|Tournament rules]]

<span title="Tournament rule 503"></span> ^tr-503

<details class="rule-ref"><summary title="Tournament rule 503 · PDF page 18" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 503 · PDF page 18</div></details>

In competitions, players may take actions that skip parts of the technically precise [[Play|play]] sequence without explicitly announcing that sequence. ^tr-503-1

<details class="rule-ref"><summary title="Tournament rule 503.1 · PDF page 19" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 503.1 · PDF page 19</div></details>

The most common type of shortcut is skipping one or more parts of a [[Turn|turn]], phase, or step to the mutual understanding of all involved players. ^tr-503-2

<details class="rule-ref"><summary title="Tournament rule 503.2 · PDF page 19" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 503.2 · PDF page 19</div></details>

Players may request to use a new shortcut in a game but must be clear about the game state at the start and end of the shortcut. ^tr-503-3

<details class="rule-ref"><summary title="Tournament rule 503.3 · PDF page 19" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 503.3 · PDF page 19</div></details>

Players may interrupt shortcuts by explaining where they want to intervene to take an action. ^tr-503-4

<details class="rule-ref"><summary title="Tournament rule 503.4 · PDF page 19" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 503.4 · PDF page 19</div></details>

Players may interrupt their own shortcuts. ^tr-503-5

<details class="rule-ref"><summary title="Tournament rule 503.5 · PDF page 19" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 503.5 · PDF page 19</div></details>

Players can’t use shortcuts they haven’t previously announced or modify existing shortcuts without announcement. ^tr-503-6

<details class="rule-ref"><summary title="Tournament rule 503.6 · PDF page 19" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 503.6 · PDF page 19</div></details>

Players can’t interrupt a shortcut with the intent to do nothing. ^tr-503-7

<details class="rule-ref"><summary title="Tournament rule 503.7 · PDF page 19" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 503.7 · PDF page 19</div></details>

When resolving [[Spell|spells]] or [[Ability|abilities]], players can’t assume their opponents are using shortcuts without asking. ^tr-503-8

<details class="rule-ref"><summary title="Tournament rule 503.8 · PDF page 19" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 503.8 · PDF page 19</div></details>

The following are common shortcuts for Riftbound competitions: ^tr-503-9

<details class="rule-ref"><summary title="Tournament rule 503.9 · PDF page 19" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 503.9 · PDF page 19</div></details>

When a player channels [[Rune|runes]] or draws a [[Card|card]] at the start of their [[Turn|turn]], it is assumed that they have passed through the [[Beginning Phase]]. ^tr-503-9-a

<details class="rule-ref"><summary title="Tournament rule 503.9.a · PDF page 19" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 503.9.a · PDF page 19</div></details>

When a player places a [[Spell|spell]] or [[Ability|ability]] on the [[Chain|chain]], they are assumed to be passing [[Priority|priority]] unless they explicitly announce they intend to retain it. ^tr-503-9-b

<details class="rule-ref"><summary title="Tournament rule 503.9.b · PDF page 19" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 503.9.b · PDF page 19</div></details>

When a player puts a [[Spell|spell]] or [[Ability|ability]] on the [[Chain|chain]] and announces choices for it that are normally made upon resolution, they must adhere to those choices unless their opponents react. ^tr-503-9-c

<details class="rule-ref"><summary title="Tournament rule 503.9.c · PDF page 19" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 503.9.c · PDF page 19</div></details>

When a player asks about choices normally made upon resolution, they are assumed to be passing [[Priority|priority]] and allowing the [[Spell|spell]] or [[Ability|ability]] to resolve. ^tr-503-9-d

<details class="rule-ref"><summary title="Tournament rule 503.9.d · PDF page 19" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 503.9.d · PDF page 19</div></details>
