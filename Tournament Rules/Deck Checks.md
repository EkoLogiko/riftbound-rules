# Deck Checks

[[Start Here|Home]] · [[Concept Index|Find a concept]] · [[Tournament Rules|Tournament rules]]

<span title="Tournament rule 411"></span> ^tr-411

<details class="rule-ref"><summary title="Tournament rule 411 · PDF page 12" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 411 · PDF page 12</div></details>

At [[High OPL|high OPL]], judges should perform deck checks during the course of the competition. ^tr-411-1

<details class="rule-ref"><summary title="Tournament rule 411.1 · PDF page 12" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 411.1 · PDF page 12</div></details>

When deck checks are performed, at least 10% of all decks, chosen at random, should be checked during the course of the competition. ^tr-411-2

<details class="rule-ref"><summary title="Tournament rule 411.2 · PDF page 12" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 411.2 · PDF page 12</div></details>

Random deck checks should occur at the start of a round, after players have randomized and presented their decks, but before opening hands are drawn and should verify all elements of the registered decks. ^tr-411-3

<details class="rule-ref"><summary title="Tournament rule 411.3 · PDF page 12" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 411.3 · PDF page 12</div></details>

A deck check can be performed after the mulligan procedure is complete as long as [[Play|play]] has not begun and each player’s [[Hand|hand]] is preserved. ^tr-411-3-a

<details class="rule-ref"><summary title="Tournament rule 411.3.a · PDF page 12" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 411.3.a · PDF page 12</div></details>

If a deck check is performed within a match, judges should grant a time extension to that match sufficient to cover the logistical time needed to perform the check. ^tr-411-3-b

<details class="rule-ref"><summary title="Tournament rule 411.3.b · PDF page 12" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 411.3.b · PDF page 12</div></details>
