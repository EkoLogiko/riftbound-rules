# Competition Types

[[Start Here|Home]] · [[Concept Index|Find a concept]] · [[Tournament Rules|Tournament rules]]

Competition Types: Riftbound competitions come in three types. ^tr-201

<details class="rule-ref"><summary title="Tournament rule 201 · PDF page 2" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 201 · PDF page 2</div></details>

[[Premier Competition|Premier]]: A competition that is run by Riot Games or an official [[Competition Organizer|competition organizer]] and has a [[Unique|unique]] [[Card Name|name]] and features. ^tr-201-1

<details class="rule-ref"><summary title="Tournament rule 201.1 · PDF page 2" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 201.1 · PDF page 2</div></details>

[[Qualifier Competition|Qualifier]]: Any competition where rewards include access or advantages for [[Premier Competition|premier]] events. (Premier events can themselves be qualifiers.) ^tr-201-2

<details class="rule-ref"><summary title="Tournament rule 201.2 · PDF page 2" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 201.2 · PDF page 2</div></details>

Local: Any competition that is neither [[Premier Competition|premier]] nor [[Qualifier Competition|qualifier]]. ^tr-201-3
