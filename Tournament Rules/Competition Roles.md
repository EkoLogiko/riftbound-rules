# Competition Roles

[[Start Here|Home]] · [[Concept Index|Find a concept]] · [[Tournament Rules|Tournament rules]]

Competition Roles: Every attendee at a competition has at least one of the following roles. ^tr-204

<details class="rule-ref"><summary title="Tournament rule 204.1 · PDF page 2" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 204.1 · PDF page 2</div></details>

Multiple: Any individual can act in any combination of official roles. ^tr-204-1-a

Judge roles: Roles 4-5 are considered judges for the purpose of this document. ^tr-204-2

<details class="rule-ref"><summary title="Tournament rule 204.2 · PDF page 2" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 204.2 · PDF page 2</div></details>

Judges equally serve as both rules arbiters and ambassadors of a healthy and welcoming environment for all players. ^tr-204-2-a

<details class="rule-ref"><summary title="Tournament rule 204.2.a · PDF page 2" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 204.2.a · PDF page 2</div></details>

[[Competition Organizer]] (CO): The CO is responsible for all competition logistics, including: ^tr-204-3

<details class="rule-ref"><summary title="Tournament rule 204.3 · PDF page 3" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 204.3 · PDF page 3</div></details>

Sanctioning the event by registering it with Riot Games or its official partners. ^tr-204-3-a

<details class="rule-ref"><summary title="Tournament rule 204.3.a · PDF page 3" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 204.3.a · PDF page 3</div></details>

Providing a site for the event (the venue) that meets the competition’s needs, including providing sufficient space and amenities for the expected attendance. ^tr-204-3-b

<details class="rule-ref"><summary title="Tournament rule 204.3.b · PDF page 3" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 204.3.b · PDF page 3</div></details>

Promoting the event before it begins. ^tr-204-3-c

<details class="rule-ref"><summary title="Tournament rule 204.3.c · PDF page 3" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 204.3.c · PDF page 3</div></details>

Staffing the event with the necessary tournament officials and support. ^tr-204-3-d

<details class="rule-ref"><summary title="Tournament rule 204.3.d · PDF page 3" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 204.3.d · PDF page 3</div></details>

Providing all materials necessary to operate the event. ^tr-204-3-e

<details class="rule-ref"><summary title="Tournament rule 204.3.e · PDF page 3" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 204.3.e · PDF page 3</div></details>

Reporting the event results. ^tr-204-3-f

<details class="rule-ref"><summary title="Tournament rule 204.3.f · PDF page 3" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 204.3.f · PDF page 3</div></details>

Maintaining records of the event results (by game and match) for a minimum period of 3 months for the purpose of [[Appeals|appeals]]. See [[Appeals#^tr-413|Appeals]] for more information on appeals. ^tr-204-3-g

<details class="rule-ref"><summary title="Tournament rule 204.3.g · PDF page 3" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 204.3.g · PDF page 3</div></details>

[[Head Judge]]: All sanctioned competitions require a Head Judge. The Head Judge is the final authority on competition rules and regulations, and their responsibilities include: ^tr-204-4

<details class="rule-ref"><summary title="Tournament rule 204.4 · PDF page 3" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 204.4 · PDF page 3</div></details>

Ensuring that rules, procedures and regulations are followed. ^tr-204-4-a

<details class="rule-ref"><summary title="Tournament rule 204.4.a · PDF page 3" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 204.4.a · PDF page 3</div></details>

Ensuring that all game or policy violations are dealt with and any appropriate corrective action taken. ^tr-204-4-b

<details class="rule-ref"><summary title="Tournament rule 204.4.b · PDF page 3" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 204.4.b · PDF page 3</div></details>

Responding to [[Floor Judge|floor judges]] who bring matters to their attention.deck ^tr-204-4-c

<details class="rule-ref"><summary title="Tournament rule 204.4.c · PDF page 3" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 204.4.c · PDF page 3</div></details>

Coordinating and delegating responsibilities to [[Floor Judge|floor judges]] as necessary. ^tr-204-4-d

<details class="rule-ref"><summary title="Tournament rule 204.4.d · PDF page 3" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 204.4.d · PDF page 3</div></details>

Determining corrective action for errors or violations of the [[Scorekeeper|scorekeeper]] or [[Floor Judge|floor judges]]. ^tr-204-4-e

<details class="rule-ref"><summary title="Tournament rule 204.4.e · PDF page 3" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 204.4.e · PDF page 3</div></details>

The [[Head Judge|head judge]] has ultimate discretion if situations arise where the written rules are unclear or inadequate. ^tr-204-4-f

<details class="rule-ref"><summary title="Tournament rule 204.4.f · PDF page 3" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 204.4.f · PDF page 3</div></details>

[[Floor Judge]]: Floor judges respond to players and [[Spectator|spectators]] who have questions about rules and regulations, and/or need judgment on the same, and their responsibilities include: ^tr-204-5

<details class="rule-ref"><summary title="Tournament rule 204.5 · PDF page 3" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 204.5 · PDF page 3</div></details>

Answering questions about rules, interactions among [[Card|cards]], providing Watcher wordings, or derived game state. ^tr-204-5-a

<details class="rule-ref"><summary title="Tournament rule 204.5.a · PDF page 3" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 204.5.a · PDF page 3</div></details>

At [[High OPL|high OPL]], judges may not answer direct questions about the results of [[Game Action|game actions]] a player has not yet taken. In these situations, players must ask questions about the rules. Examples: ^tr-204-5-a-1

<details class="rule-ref"><summary title="Tournament rule 204.5.a.1 · PDF page 3" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 204.5.a.1 · PDF page 3</div></details>

Inappropriate question: “If I attack and [[Conquer|conquer]] this [[Battlefield|battlefield]] with my Tryndamere, Barbarian, will I score the [[Winning|winning]] point?” ^tr-204-5-a-1-a

<details class="rule-ref"><summary title="Tournament rule 204.5.a.1.a · PDF page 3" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 204.5.a.1.a · PDF page 3</div></details>

Appropriate question: “Can point [[Scoring|scoring]] [[Ability|abilities]] like Tryndamere’s score you the [[Winning|winning]] point?” ^tr-204-5-a-1-b

<details class="rule-ref"><summary title="Tournament rule 204.5.a.1.b · PDF page 3" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 204.5.a.1.b · PDF page 3</div></details>

Judges may ask players to rephrase their questions to be appropriate where possible. ^tr-204-5-a-1-c

<details class="rule-ref"><summary title="Tournament rule 204.5.a.1.c · PDF page 3" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 204.5.a.1.c · PDF page 3</div></details>

Provide rulings related to game and policy violations brought to their attention. ^tr-204-5-b

<details class="rule-ref"><summary title="Tournament rule 204.5.b · PDF page 3" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 204.5.b · PDF page 3</div></details>

Intervening in games when they see an error occur to apply the appropriate fixes and [[Penalties|penalties]]. This does not apply to [[Missed Trigger]] errors. See [[Game Play Errors#^tr-702-2|Missed Trigger]] For more information on Missed Trigger errors. ^tr-204-5-c

<details class="rule-ref"><summary title="Tournament rule 204.5.c · PDF page 4" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 204.5.c · PDF page 4</div></details>

Judges should intervene AFTER an error occurs and should not attempt to [[Prevent|prevent]] a player from erroring. This does not apply to proactively intervening in cases of [[Unsporting Conduct]]. ^tr-204-5-c-1

<details class="rule-ref"><summary title="Tournament rule 204.5.c.1 · PDF page 4" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 204.5.c.1 · PDF page 4</div></details>

Assist with translation if able. ^tr-204-5-d

<details class="rule-ref"><summary title="Tournament rule 204.5.d · PDF page 4" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 204.5.d · PDF page 4</div></details>

Assist players in technically precise [[Play|play]] (at [[Casual OPL|low OPL]]). (This should generally not include strategic advice.) ^tr-204-5-e

<details class="rule-ref"><summary title="Tournament rule 204.5.e · PDF page 4" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 204.5.e · PDF page 4</div></details>

[[Scorekeeper]]: All sanctioned competitions require a scorekeeper. Scorekeepers are responsible for correct competition logistics as it relates to games and game records, including: ^tr-204-6

<details class="rule-ref"><summary title="Tournament rule 204.6 · PDF page 4" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 204.6 · PDF page 4</div></details>

Generating each round of the competition and necessary data to proceed with that round (e.g. match pairings). ^tr-204-6-a

<details class="rule-ref"><summary title="Tournament rule 204.6.a · PDF page 4" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 204.6.a · PDF page 4</div></details>

Generating standings in the competition before the last round of the competition (in [[Swiss]] competitions). ^tr-204-6-b

<details class="rule-ref"><summary title="Tournament rule 204.6.b · PDF page 4" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 204.6.b · PDF page 4</div></details>

Generating standings in the competition after the last round of the competition (in [[Swiss]] competitions). ^tr-204-6-c

<details class="rule-ref"><summary title="Tournament rule 204.6.c · PDF page 4" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 204.6.c · PDF page 4</div></details>

Solving scorekeeping problems with a-c above in conjunction with the [[Head Judge]]. ^tr-204-6-d

<details class="rule-ref"><summary title="Tournament rule 204.6.d · PDF page 4" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 204.6.d · PDF page 4</div></details>

Reporting on the competition afterward and including all necessary data. ^tr-204-6-e

<details class="rule-ref"><summary title="Tournament rule 204.6.e · PDF page 4" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 204.6.e · PDF page 4</div></details>

Players have responsibilities, including: ^tr-204-7-b

<details class="rule-ref"><summary title="Tournament rule 204.7.b · PDF page 4" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 204.7.b · PDF page 4</div></details>

Behaving respectfully to all attendees of the competition, including officials and [[Spectator|spectators]]. ^tr-204-7-b-1

<details class="rule-ref"><summary title="Tournament rule 204.7.b.1 · PDF page 4" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 204.7.b.1 · PDF page 4</div></details>

Maintaining clear game state. ^tr-204-7-b-2

<details class="rule-ref"><summary title="Tournament rule 204.7.b.2 · PDF page 4" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 204.7.b.2 · PDF page 4</div></details>

Complying with all processes and procedures of the competition, including announcements and time limits. ^tr-204-7-b-3

<details class="rule-ref"><summary title="Tournament rule 204.7.b.3 · PDF page 4" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 204.7.b.3 · PDF page 4</div></details>

Calling to the attention of a judge any rules or policy violation in their matches. ^tr-204-7-b-4

<details class="rule-ref"><summary title="Tournament rule 204.7.b.4 · PDF page 4" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 204.7.b.4 · PDF page 4</div></details>

<details class="rule-ref"><summary title="Tournament rule 204.7.b.5 · PDF page 4" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 204.7.b.5 · PDF page 4</div></details>

Reporting the result of their competition matches to an official in a timely manner. ^tr-204-7-b-6

<details class="rule-ref"><summary title="Tournament rule 204.7.b.6 · PDF page 4" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 204.7.b.6 · PDF page 4</div></details>

Obeying [[Eligibility|eligibility]] rules. ^tr-204-7-b-7

<details class="rule-ref"><summary title="Tournament rule 204.7.b.7 · PDF page 4" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 204.7.b.7 · PDF page 4</div></details>

Familiarizing themselves with this document and any addenda. ^tr-204-7-b-8

<details class="rule-ref"><summary title="Tournament rule 204.7.b.8 · PDF page 4" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 204.7.b.8 · PDF page 4</div></details>

Presenting themselves physically for the competition for its duration. ^tr-204-7-b-9

<details class="rule-ref"><summary title="Tournament rule 204.7.b.9 · PDF page 4" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 204.7.b.9 · PDF page 4</div></details>

Individual members of a team in a team competition are each individually responsible for the above. ^tr-204-7-d

Violations of the above responsibilities may be subject to [[Penalties|penalties]], suspension, or revocation of that player’s [[Eligibility|eligibility]]. ^tr-204-7-e

Any person present at a competition but not in one of the above roles is a [[Spectator|spectator]]. ^tr-204-8-a

<details class="rule-ref"><summary title="Tournament rule 204.8.a · PDF page 5" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 204.8.a · PDF page 5</div></details>

[[Spectator|Spectators]] have responsibilities, including: ^tr-204-8-c

<details class="rule-ref"><summary title="Tournament rule 204.8.c · PDF page 5" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 204.8.c · PDF page 5</div></details>

Remaining silent during matches and anywhere else in the venue where silence is required. ^tr-204-8-c-1

<details class="rule-ref"><summary title="Tournament rule 204.8.c.1 · PDF page 5" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 204.8.c.1 · PDF page 5</div></details>

At Casual and [[Competitive OPL]], [[Spectator|spectators]] can ask players to pause [[Play|play]] while they alert a judge of a potential issue. ^tr-204-8-c-2

<details class="rule-ref"><summary title="Tournament rule 204.8.c.2 · PDF page 5" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 204.8.c.2 · PDF page 5</div></details>

At [[Professional OPL]], [[Spectator|spectators]] can’t ask players to pause [[Play|play]], but they can still alert a judge of a potential issue. ^tr-204-8-c-3

[[Spectator]] are prohibited from the following: ^tr-204-8-d

<details class="rule-ref"><summary title="Tournament rule 204.8.d · PDF page 5" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 204.8.d · PDF page 5</div></details>

<details class="rule-ref"><summary title="Tournament rule 204.8.d.1 · PDF page 5" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 204.8.d.1 · PDF page 5</div></details>
