### Philosophy

<span title="Tournament rule 701.1"></span> ^tr-701-1

<details class="rule-ref"><summary title="Tournament rule 701.1 · PDF page 32" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 701.1 · PDF page 32</div></details>

Errors are assumed to be committed unintentionally. If the judge believes it was intentional, it is [[Cheating|cheating]]. See [[Unsporting Conduct#^tr-704-8|Cheating]] for more information about cheating. ^tr-701-1-a

<details class="rule-ref"><summary title="Tournament rule 701.1.a · PDF page 32" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 701.1.a · PDF page 32</div></details>

Players attempting to abuse error remedies to receive advantages are [[Cheating|cheating]]. ^tr-701-1-a-1

<details class="rule-ref"><summary title="Tournament rule 701.1.a.1 · PDF page 32" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 701.1.a.1 · PDF page 32</div></details>

Judges are neutral arbiters and enforcers of policy and rules. ^tr-701-1-b

<details class="rule-ref"><summary title="Tournament rule 701.1.b · PDF page 32" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 701.1.b · PDF page 32</div></details>

Judges should not stop errors from occurring. Instead they [[Deal|deal]] with errors that have occurred. ^tr-701-1-c

<details class="rule-ref"><summary title="Tournament rule 701.1.c · PDF page 32" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 701.1.c · PDF page 32</div></details>

Judges should not intervene in games unless: ^tr-701-1-d

<details class="rule-ref"><summary title="Tournament rule 701.1.d · PDF page 32" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 701.1.d · PDF page 32</div></details>

They believe a violation has occurred. ^tr-701-1-d-1

<details class="rule-ref"><summary title="Tournament rule 701.1.d.1 · PDF page 32" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 701.1.d.1 · PDF page 32</div></details>

A player requested assistance. ^tr-701-1-d-2

<details class="rule-ref"><summary title="Tournament rule 701.1.d.2 · PDF page 32" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 701.1.d.2 · PDF page 32</div></details>

They observe a situation related to [[Unsporting Conduct]]. ^tr-701-1-d-3

<details class="rule-ref"><summary title="Tournament rule 701.1.d.3 · PDF page 33" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 701.1.d.3 · PDF page 33</div></details>

Judges should model fair [[Play|play]], sporting conduct, and diplomatic behavior. ^tr-701-1-e

<details class="rule-ref"><summary title="Tournament rule 701.1.e · PDF page 33" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 701.1.e · PDF page 33</div></details>

Judges should not account for a player’s history or skill when determining whether errors occurred. ^tr-701-1-f

<details class="rule-ref"><summary title="Tournament rule 701.1.f · PDF page 33" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 701.1.f · PDF page 33</div></details>

Judges may take into account a player’s history or skill when investigating. ^tr-701-1-g

<details class="rule-ref"><summary title="Tournament rule 701.1.g · PDF page 33" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 701.1.g · PDF page 33</div></details>

[[Penalties]] are designed to educate players on mistakes and encourage them not to make them in the future. ^tr-701-1-h

<details class="rule-ref"><summary title="Tournament rule 701.1.h · PDF page 33" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 701.1.h · PDF page 33</div></details>

[[Penalties]] are also designed to deter other players from similar errors. ^tr-701-1-i

<details class="rule-ref"><summary title="Tournament rule 701.1.i · PDF page 33" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 701.1.i · PDF page 33</div></details>

[[Penalties]] are issued and tracked to help judges understand intent over patterns of behavior. ^tr-701-1-j

<details class="rule-ref"><summary title="Tournament rule 701.1.j · PDF page 33" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 701.1.j · PDF page 33</div></details>

[[Head Judge|Head judges]] and head judges ONLY may issue [[Penalties|penalties]] outside of these guidelines. They have discretion to apply harsher penalties or investigate [[Cheating|cheating]] if needed. See [[Unsporting Conduct#^tr-704-8|Cheating]] for more information about cheating. ^tr-701-1-k

<details class="rule-ref"><summary title="Tournament rule 701.1.k · PDF page 33" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 701.1.k · PDF page 33</div></details>

Judges are human and they make mistakes. ^tr-701-1-l

<details class="rule-ref"><summary title="Tournament rule 701.1.l · PDF page 33" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 701.1.l · PDF page 33</div></details>

If a judge recognizes their own mistakes, they should acknowledge them and correct them if possible. ^tr-701-1-m

<details class="rule-ref"><summary title="Tournament rule 701.1.m · PDF page 33" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 701.1.m · PDF page 33</div></details>

If a competition official makes a mistake and it results in a [[Penalties|penalty]] applied to a player, the [[Head Judge|head judge]] can downgrade the penalty. ^tr-701-1-n

<details class="rule-ref"><summary title="Tournament rule 701.1.n · PDF page 33" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 701.1.n · PDF page 33</div></details>

If a player acts on information given in error by a competition official, the [[Head Judge|head judge]] can [[Rewinding|rewind]] the game to account for it, even if there were no other errors. ^tr-701-1-o

<details class="rule-ref"><summary title="Tournament rule 701.1.o · PDF page 33" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 701.1.o · PDF page 33</div></details>

### Definitions of Penalties

<span title="Tournament rule 701.2"></span> ^tr-701-2

<details class="rule-ref"><summary title="Tournament rule 701.2 · PDF page 33" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 701.2 · PDF page 33</div></details>

[[Warning]]: An indication that an error occurred that provides a record of the error. ^tr-701-2-a

<details class="rule-ref"><summary title="Tournament rule 701.2.a · PDF page 33" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 701.2.a · PDF page 33</div></details>

Time extensions should be granted if the total time to rule and correct is more than 1 minute. ^tr-701-2-a-1

<details class="rule-ref"><summary title="Tournament rule 701.2.a.1 · PDF page 33" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 701.2.a.1 · PDF page 33</div></details>

[[Game Loss]]: A game loss causes the erroring player and any of their teammates to concede the game. If this does not result in a winner, remaining players continue the game. ^tr-701-2-b

<details class="rule-ref"><summary title="Tournament rule 701.2.b · PDF page 33" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 701.2.b · PDF page 33</div></details>

[[Game Loss|Game losses]] are applied immediately if the game is ongoing, or to the player’s next game in the competition if it is not. ^tr-701-2-b-1

<details class="rule-ref"><summary title="Tournament rule 701.2.b.1 · PDF page 33" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 701.2.b.1 · PDF page 33</div></details>

If a player would receive multiple [[Game Loss|game losses]] at the same time, they only receive one. ^tr-701-2-b-2

<details class="rule-ref"><summary title="Tournament rule 701.2.b.2 · PDF page 33" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 701.2.b.2 · PDF page 33</div></details>

If all players in a match receive a [[Game Loss|game loss]] simultaneously, the current game ends in a [[Draw (Game Result)|draw]]. All game losses are recorded but do not affect the match score. ^tr-701-2-b-3

<details class="rule-ref"><summary title="Tournament rule 701.2.b.3 · PDF page 33" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 701.2.b.3 · PDF page 33</div></details>

[[Match Loss]]: A severe [[Penalties|penalty]] that’s issued when the entire match has been compromised by the error. ^tr-701-2-c

<details class="rule-ref"><summary title="Tournament rule 701.2.c · PDF page 33" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 701.2.c · PDF page 33</div></details>

[[Match Loss|Match losses]] are applied to the current match, or to the player’s next match in the competition if their previous match has ended. ^tr-701-2-c-1

<details class="rule-ref"><summary title="Tournament rule 701.2.c.1 · PDF page 34" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 701.2.c.1 · PDF page 34</div></details>

[[Disqualification]]: A [[Penalties|penalty]] issued for errors that [[Damage|damage]] the integrity of the competition or for severe misconduct. ^tr-701-2-d

<details class="rule-ref"><summary title="Tournament rule 701.2.d · PDF page 34" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 701.2.d · PDF page 34</div></details>

[[Disqualification]] causes that player to lose the current match and be dropped from the competition. ^tr-701-2-d-1

<details class="rule-ref"><summary title="Tournament rule 701.2.d.1 · PDF page 34" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 701.2.d.1 · PDF page 34</div></details>

If a player has already physically received prizes from the competition, they keep them, but they will not receive any other prizes after [[Disqualification|disqualification]], even if their placement in the event would otherwise entitle them to prizes. ^tr-701-2-d-2

<details class="rule-ref"><summary title="Tournament rule 701.2.d.2 · PDF page 34" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 701.2.d.2 · PDF page 34</div></details>

When a player is disqualified, they are removed from the competition and from standings. ^tr-701-2-d-3

<details class="rule-ref"><summary title="Tournament rule 701.2.d.3 · PDF page 34" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 701.2.d.3 · PDF page 34</div></details>

Any attendee of a competition can be issued a [[Disqualification|disqualification]], not just players. Being barred from the tournament venue may apply to disqualification at the [[Head Judge|head judge]]’s discretion. ^tr-701-2-d-4

<details class="rule-ref"><summary title="Tournament rule 701.2.d.4 · PDF page 34" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 701.2.d.4 · PDF page 34</div></details>

This [[Penalties|penalty]] can be issued by the [[Head Judge|head judge]] even without conclusive proof if the head judge determines the integrity of the competition has been compromised. ^tr-701-2-d-5

<details class="rule-ref"><summary title="Tournament rule 701.2.d.5 · PDF page 34" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 701.2.d.5 · PDF page 34</div></details>

### Applying Penalties

<span title="Tournament rule 701.3"></span> ^tr-701-3

<details class="rule-ref"><summary title="Tournament rule 701.3 · PDF page 34" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 701.3 · PDF page 34</div></details>

[[Penalties]] of [[Game Loss]] of higher (b-d) should be reported to the [[Head Judge|head judge]]. ^tr-701-3-a

<details class="rule-ref"><summary title="Tournament rule 701.3.a · PDF page 34" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 701.3.a · PDF page 34</div></details>

Judges should explain the error, the procedure to fix it, and the [[Penalties|penalties]] for involved players. ^tr-701-3-b

<details class="rule-ref"><summary title="Tournament rule 701.3.b · PDF page 34" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 701.3.b · PDF page 34</div></details>

Some errors include remedies beyond the scope of the [[Base|base]] [[Penalties|penalty]], to protect competition officials from accusations of bias. ^tr-701-3-c

<details class="rule-ref"><summary title="Tournament rule 701.3.c · PDF page 34" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 701.3.c · PDF page 34</div></details>

If a single error leads to multiple related [[Penalties|penalties]], judges should issue only the one with the most severe penalty. ^tr-701-3-d

<details class="rule-ref"><summary title="Tournament rule 701.3.d · PDF page 34" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 701.3.d · PDF page 34</div></details>

### Shuffling

<span title="Tournament rule 701.4"></span> ^tr-701-4

<details class="rule-ref"><summary title="Tournament rule 701.4 · PDF page 34" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 701.4 · PDF page 34</div></details>

Some remedies require [[Shuffling|shuffling]] the randomized portion of the deck. ^tr-701-4-a

<details class="rule-ref"><summary title="Tournament rule 701.4.a · PDF page 34" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 701.4.a · PDF page 34</div></details>

Many [[Card|cards]] [[Recycle|recycle]] cards to the bottom of a deck. The judge should do what they can using information available from the game state and from the players to determine which portion of the deck is knowable by one or more players, and separate those before [[Shuffling|shuffling]] that deck. ^tr-701-4-b

<details class="rule-ref"><summary title="Tournament rule 701.4.b · PDF page 34" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 701.4.b · PDF page 34</div></details>

If no randomized portion of the deck exists and it is possible, judges may complete remedies without [[Shuffling|shuffling]]. ^tr-701-4-b-1

<details class="rule-ref"><summary title="Tournament rule 701.4.b.1 · PDF page 34" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 701.4.b.1 · PDF page 34</div></details>

If judges can’t confidently determine the full randomized portion of a deck, they may shuffle as much of the deck as needed to perform a remedy. ^tr-701-4-b2

<details class="rule-ref"><summary title="Tournament rule 701.4.b2 · PDF page 34" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 701.4.b2 · PDF page 34</div></details>

Once the deck has been shuffled, any [[Card|cards]] set aside in this way should be returned to their proper [[Location|locations]] in the deck. ^tr-701-4-c

<details class="rule-ref"><summary title="Tournament rule 701.4.c · PDF page 34" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 701.4.c · PDF page 34</div></details>

Shuffles performed by a judge in this way are not considered shuffles in game terms. ^tr-701-4-d

<details class="rule-ref"><summary title="Tournament rule 701.4.d · PDF page 35" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 701.4.d · PDF page 35</div></details>

### Rewinding

<span title="Tournament rule 701.5"></span> ^tr-701-5

<details class="rule-ref"><summary title="Tournament rule 701.5 · PDF page 35" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 701.5 · PDF page 35</div></details>

Some remedies allow [[Rewinding|rewinding]] the game state in extreme circumstances, where leaving the game in its current state is substantially worse than rewinding. ^tr-701-5-a

<details class="rule-ref"><summary title="Tournament rule 701.5.a · PDF page 35" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 701.5.a · PDF page 35</div></details>

Some rewinds are simple; this means [[Rewinding|rewinding]] only the last action completed or one currently in progress. ^tr-701-5-b

<details class="rule-ref"><summary title="Tournament rule 701.5.b · PDF page 35" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 701.5.b · PDF page 35</div></details>

Any judge may perform a simple [[Rewinding|rewind]] of the most recent action of a game. ^tr-701-5-b-1

<details class="rule-ref"><summary title="Tournament rule 701.5.b.1 · PDF page 35" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 701.5.b.1 · PDF page 35</div></details>

When performing a simple [[Rewinding|rewind]] of a player's [[Game Action|game action]], rewind to before the action began, such as before a played [[Card|card]] would be put on the [[Chain|chain]]. The player may then opt not to take the action, or take the action making different decisions. ^tr-701-5-b-2

<details class="rule-ref"><summary title="Tournament rule 701.5.b.2 · PDF page 35" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 701.5.b.2 · PDF page 35</div></details>

When performing a simple [[Rewinding|rewind]], if the action being rewound required the player to [[Recycle|recycle]]/[[Exhaust|exhaust]] [[Rune|runes]] for payment, instruct that player to unrecycle/[[Ready|ready]] those runes. ^tr-701-5-b-3

<details class="rule-ref"><summary title="Tournament rule 701.5.b.3 · PDF page 35" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 701.5.b.3 · PDF page 35</div></details>

For rewinds more complicated than a simple [[Rewinding|rewind]], only the [[Head Judge|head judge]] or designated [[Appeals|appeals]] judges (at [[High OPL|high OPL]]) may authorize rewinding in this way. ^tr-701-5-c

<details class="rule-ref"><summary title="Tournament rule 701.5.c · PDF page 35" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 701.5.c · PDF page 35</div></details>

To [[Rewinding|rewind]]: ^tr-701-5-d

<details class="rule-ref"><summary title="Tournament rule 701.5.d · PDF page 35" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 701.5.d · PDF page 35</div></details>

Each individual action since the time of the error is reversed, starting with the most recent one. ^tr-701-5-d-1

<details class="rule-ref"><summary title="Tournament rule 701.5.d.1 · PDF page 35" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 701.5.d.1 · PDF page 35</div></details>

Every action must be reversed in the correct sequence. ^tr-701-5-d-2

<details class="rule-ref"><summary title="Tournament rule 701.5.d.2 · PDF page 35" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 701.5.d.2 · PDF page 35</div></details>

If the identity of a [[Card|card]] involved in a [[Rewinding|rewind]] is non-public (e.g. a drawn card), a random card is chosen from possible candidates. ^tr-701-5-d-3

<details class="rule-ref"><summary title="Tournament rule 701.5.d.3 · PDF page 35" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 701.5.d.3 · PDF page 35</div></details>

If a player learned the identity of a [[Card|card]] in a deck, but did not [[Draw|draw]] or [[Channel|channel]] it, it should be shuffled into the random part of the deck. ^tr-701-5-d-4

<details class="rule-ref"><summary title="Tournament rule 701.5.d.4 · PDF page 35" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 701.5.d.4 · PDF page 35</div></details>

### Investigations

<span title="Tournament rule 701.6"></span> ^tr-701-6

<details class="rule-ref"><summary title="Tournament rule 701.6 · PDF page 35" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 701.6 · PDF page 35</div></details>

Any [[Penalties|penalty]] that results in [[Disqualification|disqualification]] automatically starts an investigation into that player and patterns of behavior that [[Might|might]] impact their [[Eligibility|eligibility]] in future competitions. ^tr-701-6-a

<details class="rule-ref"><summary title="Tournament rule 701.6.a · PDF page 35" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 701.6.a · PDF page 35</div></details>

[[Investigations]] may also occur at a judge's discretion following the application of a [[Penalties|penalty]] if [[Cheating|cheating]] is suspected. See [[Unsporting Conduct#^tr-704-8|Cheating]] for more information about cheating. ^tr-701-6-b

<details class="rule-ref"><summary title="Tournament rule 701.6.b · PDF page 35" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 701.6.b · PDF page 35</div></details>

The result of an investigation can be suspension of the player from Riftbound competitions. ^tr-701-6-c

<details class="rule-ref"><summary title="Tournament rule 701.6.c · PDF page 35" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 701.6.c · PDF page 35</div></details>

Suspended players may not enter Riftbound competitions. If a suspended player is found to have registered for a competition, the organizer reserves the right to issue a [[Disqualification|disqualification]] at any time. ^tr-701-6-d

<details class="rule-ref"><summary title="Tournament rule 701.6.d · PDF page 35" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 701.6.d · PDF page 35</div></details>
