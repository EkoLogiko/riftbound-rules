# Sleeves

[[Start Here|Home]] · [[Concept Index|Find a concept]] · [[Tournament Rules|Tournament rules]]

<span title="Tournament rule 422"></span> ^tr-422

<details class="rule-ref"><summary title="Tournament rule 422 · PDF page 16" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 422 · PDF page 16</div></details>

Players may use plastic sleeves or other protective devices on their [[Card|cards]]. ^tr-422-1

<details class="rule-ref"><summary title="Tournament rule 422.1 · PDF page 16" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 422.1 · PDF page 16</div></details>

If a player chooses to do this, all such sleeves must be identical and all [[Card|cards]] in a deck must be placed in sleeves in the same manner. Cards in decks must have the same number of [[Layers|layers]] and be the same orientation at all times. ^tr-422-2

<details class="rule-ref"><summary title="Tournament rule 422.2 · PDF page 16" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 422.2 · PDF page 16</div></details>

It’s suggested but not required that players use different sleeves for the different decks (Main, [[Rune]]). ^tr-422-2-a

<details class="rule-ref"><summary title="Tournament rule 422.2.a · PDF page 16" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 422.2.a · PDF page 16</div></details>

Players may use a [[Unique|unique]] sleeve or additional layer to distinguish their [[Chosen Champion]] during game [[Setup|setup]], but must change its sleeve to match their [[Main Deck]] if it would enter a [[Zone|zone]] whose information [[Level|level]] is private or secret during gameplay. See [[Privacy#^cr-128|Privacy]] for information types. ^tr-422-2-b

<details class="rule-ref"><summary title="Tournament rule 422.2.b · PDF page 16" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 422.2.b · PDF page 16</div></details>

Sleeves must have opaque backs. ^tr-422-3

<details class="rule-ref"><summary title="Tournament rule 422.3 · PDF page 16" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 422.3 · PDF page 16</div></details>

During a match, a player may request that a judge inspect an opponent’s sleeves. ^tr-422-4

<details class="rule-ref"><summary title="Tournament rule 422.4 · PDF page 16" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 422.4 · PDF page 16</div></details>

Judges may disallow any specific sleeve or the sleeves generally if they believe they are marked, worn, inappropriate, offensive, or otherwise interfere with [[Shuffling|shuffling]] or [[Play|play]]. ^tr-422-5

<details class="rule-ref"><summary title="Tournament rule 422.5 · PDF page 16" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 422.5 · PDF page 16</div></details>

At [[High OPL|high OPL]], using sleeves for the [[Main Deck]], [[Rune Deck]] and [[Battlefield|Battlefields]] is a requirement. At [[Casual OPL|low OPL]], using sleeves can be required at the discretion of the [[Head Judge|head judge]]. ^tr-422-6

<details class="rule-ref"><summary title="Tournament rule 422.6 · PDF page 16" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 422.6 · PDF page 16</div></details>

At [[High OPL|high OPL]], sleeves must also not: ^tr-422-7

<details class="rule-ref"><summary title="Tournament rule 422.7 · PDF page 16" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 422.7 · PDF page 16</div></details>

Have highly reflective backs. ^tr-422-7-a

<details class="rule-ref"><summary title="Tournament rule 422.7.a · PDF page 16" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 422.7.a · PDF page 16</div></details>

Contain holographic patterns on the front or back. ^tr-422-7-b

<details class="rule-ref"><summary title="Tournament rule 422.7.b · PDF page 16" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 422.7.b · PDF page 16</div></details>
