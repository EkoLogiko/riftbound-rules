### Deck Construction

<span title="Tournament rule 601.1"></span> ^tr-601-1

<details class="rule-ref"><summary title="Tournament rule 601.1 · PDF page 24" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 601.1 · PDF page 24</div></details>

The rules for constructing a Riftbound deck are found in [[Deck Construction#^cr-101|Deck Construction]], except where modified here below for the competition Constructed [[Play|play]] format. ^tr-601-1-a

<details class="rule-ref"><summary title="Tournament rule 601.1.a · PDF page 24" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 601.1.a · PDF page 24</div></details>

In competitions, a player’s [[Main Deck]] must be exactly 40 [[Card|cards]]. ^tr-601-1-b

<details class="rule-ref"><summary title="Tournament rule 601.1.b · PDF page 24" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 601.1.b · PDF page 24</div></details>

In competitions where a [[Sideboard|sideboard]] is allowed: ^tr-601-1-c

<details class="rule-ref"><summary title="Tournament rule 601.1.c · PDF page 24" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 601.1.c · PDF page 24</div></details>

A player’s [[Sideboard|sideboard]] can include 10 or fewer [[Card|cards]]. ^tr-601-1-c-1

<details class="rule-ref"><summary title="Tournament rule 601.1.c.1 · PDF page 24" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 601.1.c.1 · PDF page 24</div></details>

A [[Sideboard|sideboard]] can consist only of valid [[Main Deck]] [[Card|cards]]. ^tr-601-1-c-2

<details class="rule-ref"><summary title="Tournament rule 601.1.c.2 · PDF page 24" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 601.1.c.2 · PDF page 24</div></details>

Limits on copies of named [[Card|cards]] apply to the combination of [[Main Deck|main deck]] and [[Sideboard|sideboard]]. ^tr-601-1-c-3

<details class="rule-ref"><summary title="Tournament rule 601.1.c.3 · PDF page 24" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 601.1.c.3 · PDF page 24</div></details>

A player may change their [[Chosen Champion]] to one from their [[Sideboard|sideboard]] or [[Main Deck|main deck]] that matches their [[Legend]] whenever sideboarding would be allowed. ^tr-601-1-c-4

<details class="rule-ref"><summary title="Tournament rule 601.1.c.4 · PDF page 24" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 601.1.c.4 · PDF page 24</div></details>

See [[Sideboard#^tr-403|Sideboard]] for more information about [[Sideboard|sideboards]]. ^tr-601-1-c-5

<details class="rule-ref"><summary title="Tournament rule 601.1.c.5 · PDF page 24" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 601.1.c.5 · PDF page 24</div></details>

In some competitions, the legal [[Battlefield|battlefields]] are different from the format-legal battlefields. If this is the case, it will be communicated to players via specific event addenda. ^tr-601-1-d

<details class="rule-ref"><summary title="Tournament rule 601.1.d · PDF page 24" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 601.1.d · PDF page 24</div></details>

### Card Legality

<span title="Tournament rule 601.2"></span> ^tr-601-2

<details class="rule-ref"><summary title="Tournament rule 601.2 · PDF page 25" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 601.2 · PDF page 25</div></details>

A [[Card|card]] may only be included in a deck if it is from a set that is legal in that format or it has the same [[Card Name|name]] as a card from a set that is legal in that format. ^tr-601-2-a

<details class="rule-ref"><summary title="Tournament rule 601.2.a · PDF page 25" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 601.2.a · PDF page 25</div></details>

Until set release parity is reached, regional limitations on the legality of [[Card|cards]] will be enforced according to the official product launch date in the region where an event is being held. ^tr-601-2-b

<details class="rule-ref"><summary title="Tournament rule 601.2.b · PDF page 25" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 601.2.b · PDF page 25</div></details>

If an existing [[Card|card]] is reprinted in a new set, but its collector number is not within the normal numbering of that set, it does not affect the card's format legality. ^tr-601-2-c

<details class="rule-ref"><summary title="Tournament rule 601.2.c · PDF page 25" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 601.2.c · PDF page 25</div></details>

Example: A [[Card|card]] with collector number 300/250 is not automatically legal within the standard format of that set. ^tr-601-2-c-1

<details class="rule-ref"><summary title="Tournament rule 601.2.c.1 · PDF page 25" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 601.2.c.1 · PDF page 25</div></details>

If a [[Card|card]] is banned in a specific format, that card may not be included in a deck. ^tr-601-2-d

<details class="rule-ref"><summary title="Tournament rule 601.2.d · PDF page 25" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 601.2.d · PDF page 25</div></details>

Riftbound’s list of [[Card Legality|banned cards]] can be found [here](https://riftbound.leagueoflegends.com/en-us/rules-hub/). ^tr-601-2-d-1

<details class="rule-ref"><summary title="Tournament rule 601.2.d.1 · PDF page 25" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 601.2.d.1 · PDF page 25</div></details>

At [[Casual OPL|low OPL]], if a player is using the exact deck configuration of a preconstructed Riftbound deck product, they are allowed to [[Play|play]] with [[Card|cards]] on the banned list. For example: ^tr-601-2-d-2

<details class="rule-ref"><summary title="Tournament rule 601.2.d.2 · PDF page 25" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 601.2.d.2 · PDF page 25</div></details>

At Nexus Nights, if a player is playing a deck matching the exact contents of the preconstructed Jinx [[Champion]] Deck, they are allowed to use the [[Card Legality|banned cards]] in the deck, such as Fight or Flight, Scrapheap and Reaver’s Row. If the player makes any changes or adds a [[Sideboard|sideboard]], they can no longer include the banned cards. ^tr-601-2-d-2-a

<details class="rule-ref"><summary title="Tournament rule 601.2.d.2.a · PDF page 25" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 601.2.d.2.a · PDF page 25</div></details>
