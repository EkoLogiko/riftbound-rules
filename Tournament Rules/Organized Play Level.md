# Organized Play Level

[[Start Here|Home]] · [[Concept Index|Find a concept]] · [[Tournament Rules|Tournament rules]]

Organized Play Level (OPL): OPL is shorthand that helps communicate expectations to players and judges. ^tr-205

<details class="rule-ref"><summary title="Tournament rule 205 · PDF page 5" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 205 · PDF page 5</div></details>

The purpose of OPL is to define how strictly to treat deviations from rules, policy, and procedures as violations and what [[Penalties|penalty]] those violations warrant. ^tr-205-1

<details class="rule-ref"><summary title="Tournament rule 205.1 · PDF page 5" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 205.1 · PDF page 5</div></details>

Casual (low): Most competitions are casual and are focused on fun and social interaction, not rules enforcement. ^tr-205-2

<details class="rule-ref"><summary title="Tournament rule 205.2 · PDF page 5" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 205.2 · PDF page 5</div></details>

Players are expected to know most of the rules as defined in the Core Rules. ^tr-205-2-a

<details class="rule-ref"><summary title="Tournament rule 205.2.a · PDF page 6" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 205.2.a · PDF page 6</div></details>

Players are responsible for playing according to the rules in the Core Rules and this document, but: ^tr-205-2-b

<details class="rule-ref"><summary title="Tournament rule 205.2.b · PDF page 6" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 205.2.b · PDF page 6</div></details>

The [[Focus|focus]] of judges and competition officials is on education and sportsmanship. ^tr-205-2-b-1

<details class="rule-ref"><summary title="Tournament rule 205.2.b.1 · PDF page 6" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 205.2.b.1 · PDF page 6</div></details>

There is no [[Priority|priority]] placed on technically precise [[Play|play]]. ^tr-205-2-b-2

<details class="rule-ref"><summary title="Tournament rule 205.2.b.2 · PDF page 6" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 205.2.b.2 · PDF page 6</div></details>

Generally, violations at this [[Level|level]] have lower [[Penalties|penalties]] which are covered below in section [[Enforcement and Penalties#^tr-700|Enforcement and Penalties]]. ^tr-205-2-c

<details class="rule-ref"><summary title="Tournament rule 205.2.c · PDF page 6" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 205.2.c · PDF page 6</div></details>

Competitive (high): These competitions have significant rewards, which may include invitations or advantages at the Professional [[Level|level]]. ^tr-205-3

<details class="rule-ref"><summary title="Tournament rule 205.3 · PDF page 6" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 205.3 · PDF page 6</div></details>

Players are expected to know the rules as defined in the Core Rules and this document. ^tr-205-3-a

<details class="rule-ref"><summary title="Tournament rule 205.3.a · PDF page 6" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 205.3.a · PDF page 6</div></details>

All attendees are expected to maintain the integrity of the competition, while recognizing that some players may not be used to playing at the highest and most technically precise [[Level|level]] of [[Play|play]]. ^tr-205-3-b

<details class="rule-ref"><summary title="Tournament rule 205.3.b · PDF page 6" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 205.3.b · PDF page 6</div></details>

Generally, violations at this [[Level|level]] have stricter [[Penalties|penalties]] which are covered below in section [[Enforcement and Penalties#^tr-700|Enforcement and Penalties]]. ^tr-205-3-c

<details class="rule-ref"><summary title="Tournament rule 205.3.c · PDF page 6" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 205.3.c · PDF page 6</div></details>

Professional (high): These competitions have significant rewards and prestige. ^tr-205-4

<details class="rule-ref"><summary title="Tournament rule 205.4 · PDF page 6" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 205.4 · PDF page 6</div></details>

Players are expected to know the rules as defined in the Core Rules and this document completely. ^tr-205-4-a

<details class="rule-ref"><summary title="Tournament rule 205.4.a · PDF page 6" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 205.4.a · PDF page 6</div></details>

All attendees are expected to maintain the integrity of the competition and the highest standard of behavior and technically precise [[Play|play]]. ^tr-205-4-b

<details class="rule-ref"><summary title="Tournament rule 205.4.b · PDF page 6" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 205.4.b · PDF page 6</div></details>

Generally, violations at this [[Level|level]] have the strictest [[Penalties|penalties]] which are covered below in section [[Enforcement and Penalties#^tr-700|Enforcement and Penalties]]. ^tr-205-4-c
