<span title="Tournament rule 603"></span> ^tr-603

<details class="rule-ref"><summary title="Tournament rule 603 · PDF page 31" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 603 · PDF page 31</div></details>

A 2v2 team consists of 2 players who enter a competition together and register together as a team to [[Play|play]] congruently in a single match as described in the Core Rules. ^tr-603-1

<details class="rule-ref"><summary title="Tournament rule 603.1 · PDF page 31" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 603.1 · PDF page 31</div></details>

Each player must provide their individual registration information to enter the competition. ^tr-603-2

<details class="rule-ref"><summary title="Tournament rule 603.2 · PDF page 31" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 603.2 · PDF page 31</div></details>

When registering, teams must specify an ordering for the players on their team for seating purposes by indicating an A player and a B player. ^tr-603-2-a

<details class="rule-ref"><summary title="Tournament rule 603.2.a · PDF page 31" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 603.2.a · PDF page 31</div></details>

If a player drops from a competition, their entire team is dropped. ^tr-603-3

<details class="rule-ref"><summary title="Tournament rule 603.3 · PDF page 31" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 603.3 · PDF page 31</div></details>

If a player is disqualified from a competition, their entire team is disqualified. ^tr-603-4

<details class="rule-ref"><summary title="Tournament rule 603.4 · PDF page 31" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 603.4 · PDF page 31</div></details>

In some competitions, 2v2 teams may provide a team [[Card Name|name]] to be displayed. Tournament officials may disallow a specific name for any reason. ^tr-603-5

<details class="rule-ref"><summary title="Tournament rule 603.5 · PDF page 31" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 603.5 · PDF page 31</div></details>

A 2v2 competition can be either [[Constructed|constructed]] or [[Sealed|sealed]]. In sealed 2v2, the team shares a single product pool of 8 packs. ^tr-603-6

<details class="rule-ref"><summary title="Tournament rule 603.6 · PDF page 31" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 603.6 · PDF page 31</div></details>

During matches, teammates sit next to each other in their registered AB order. The [[Setup Process|setup process]] for a game of Riftbound is defined in the Core Rules, with these additional exceptions for 2v2: ^tr-603-7

<details class="rule-ref"><summary title="Tournament rule 603.7 · PDF page 31" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 603.7 · PDF page 31</div></details>

[[Turn]] order is as follows: ^tr-603-7-a

<details class="rule-ref"><summary title="Tournament rule 603.7.a · PDF page 32" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 603.7.a · PDF page 32</div></details>

The first team’s A player. ^tr-603-7-a-1

<details class="rule-ref"><summary title="Tournament rule 603.7.a.1 · PDF page 32" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 603.7.a.1 · PDF page 32</div></details>

The second team’s A player. ^tr-603-7-a-2

<details class="rule-ref"><summary title="Tournament rule 603.7.a.2 · PDF page 32" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 603.7.a.2 · PDF page 32</div></details>

The first team’s B player. ^tr-603-7-a-3

<details class="rule-ref"><summary title="Tournament rule 603.7.a.3 · PDF page 32" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 603.7.a.3 · PDF page 32</div></details>

The second team’s B player. ^tr-603-7-a-4

<details class="rule-ref"><summary title="Tournament rule 603.7.a.4 · PDF page 32" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 603.7.a.4 · PDF page 32</div></details>

Return to the top of the order. ^tr-603-7-a-5

<details class="rule-ref"><summary title="Tournament rule 603.7.a.5 · PDF page 32" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 603.7.a.5 · PDF page 32</div></details>

A random method is used to decide which team selects the starting player. ^tr-603-7-b

<details class="rule-ref"><summary title="Tournament rule 603.7.b · PDF page 32" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 603.7.b · PDF page 32</div></details>

Once the appropriate step in the core rules process is reached, the team that earned the decision chooses where within the a.1-4 [[Turn|turn]] order [[Play|play]] begins. ^tr-603-7-c

<details class="rule-ref"><summary title="Tournament rule 603.7.c · PDF page 32" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 603.7.c · PDF page 32</div></details>

For games after the first game of a match, the losing team of the previous game gets to choose who plays first. If the previous game was a [[Draw (Game Result)|draw]], [[Turn|the turn]] order from the previous game is maintained. ^tr-603-7-c-1
