# Event and Round Time Limits

[[Start Here|Home]] · [[Concept Index|Find a concept]] · [[Tournament Rules|Tournament rules]]

<span title="Tournament rule 604"></span> ^tr-604

<details class="rule-ref"><summary title="Tournament rule 604 · PDF page 32" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 604 · PDF page 32</div></details>

It’s recommended that players be given 60 minutes for rounds of [[Play|play]] in the [[Swiss]] portion of a competitive event. ^tr-604-1

<details class="rule-ref"><summary title="Tournament rule 604.1 · PDF page 32" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 604.1 · PDF page 32</div></details>

It is strongly recommended that [[Playoff|single elimination]] matches use untimed rounds so players can [[Play|play]] their games to a natural conclusion. If single elimination rounds must be timed, see [[End of Match Procedure#^tr-408-4|End of Match Procedure]] for an altered [[End of Match Procedure|End of Match procedure]]. ^tr-604-2

<details class="rule-ref"><summary title="Tournament rule 604.2 · PDF page 32" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 604.2 · PDF page 32</div></details>

Players are still expected to [[Play|play]] at a reasonable pace. See [[Tournament Errors#^tr-703-2|Slow Play]] the [[Slow Play]] [[Penalties|penalty]]. ^tr-604-2-a
