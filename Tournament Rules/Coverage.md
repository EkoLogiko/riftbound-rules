<details class="rule-ref"><summary title="Tournament rule 418 · PDF page 14" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 418 · PDF page 14</div></details>

Some competitions at [[High OPL|high OPL]] use video capture of matches. ^tr-418-1

<details class="rule-ref"><summary title="Tournament rule 418.1 · PDF page 14" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 418.1 · PDF page 14</div></details>

Certain events or portions of events may require players to appear on camera. ^tr-418-2

<details class="rule-ref"><summary title="Tournament rule 418.2 · PDF page 14" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 418.2 · PDF page 14</div></details>

[[Spectator|Spectators]] and players who are on camera during matches are responsible for behaving respectfully toward all participants. ^tr-418-3

<details class="rule-ref"><summary title="Tournament rule 418.3 · PDF page 14" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 418.3 · PDF page 14</div></details>

[[Spectator|Spectators]] are permitted to record matches using video capture, provided they do so without interfering with the match. ^tr-418-4

<details class="rule-ref"><summary title="Tournament rule 418.4 · PDF page 14" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 418.4 · PDF page 14</div></details>

At [[Professional OPL]], the [[Head Judge|head judge]] may consult video capture to help make rulings during a match. ^tr-418-5

<details class="rule-ref"><summary title="Tournament rule 418.5 · PDF page 15" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 418.5 · PDF page 15</div></details>

Judges should never honor a player's request to consult video capture. ^tr-418-6

<details class="rule-ref"><summary title="Tournament rule 418.6 · PDF page 15" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 418.6 · PDF page 15</div></details>
