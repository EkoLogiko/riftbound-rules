### Overview

<span title="Tournament rule 702.1"></span> ^tr-702-1

<details class="rule-ref"><summary title="Tournament rule 702.1 · PDF page 36" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 702.1 · PDF page 36</div></details>

A game [[Play|play]] error is caused by incorrect and inaccurate play of the game that violates the Core Rules. ^tr-702-1-a

<details class="rule-ref"><summary title="Tournament rule 702.1.a · PDF page 36" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 702.1.a · PDF page 36</div></details>

Except for [[Game Play Errors#^tr-702-17|Failure to Maintain Game State]], repeated game [[Play|play]] error &#91;[[Warning|Warnings]]&#93; can upgrade to &#91;[[Game Loss]]&#93;. ^tr-702-1-b

<details class="rule-ref"><summary title="Tournament rule 702.1.b · PDF page 36" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 702.1.b · PDF page 36</div></details>

If a player commits the same exact [[Card Category|category]] of game [[Play|play]] error &#91;[[Warning]]&#93; 3 or more times in the same event, the [[Penalties|penalty]] is upgraded to &#91;[[Game Loss]]&#93;. ^tr-702-1-b-1

<details class="rule-ref"><summary title="Tournament rule 702.1.b.1 · PDF page 36" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 702.1.b.1 · PDF page 36</div></details>

At [[Competitive OPL|competitive OPL]], if a player commits a total of 6 or more of any [[Card Category|category]] of game [[Play|play]] error &#91;[[Warning]]&#93; in the same event, the [[Penalties|penalty]] is upgraded to &#91;[[Game Loss]]&#93;. ^tr-702-1-b-2

<details class="rule-ref"><summary title="Tournament rule 702.1.b.2 · PDF page 36" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 702.1.b.2 · PDF page 36</div></details>

At [[Professional OPL|professional OPL]], if a player commits a total of 5 or more of any [[Card Category|category]] of game [[Play|play]] error &#91;[[Warning]]&#93; in the same event, the [[Penalties|penalty]] is upgraded to &#91;[[Game Loss]]&#93;. ^tr-702-1-b-3

<details class="rule-ref"><summary title="Tournament rule 702.1.b.3 · PDF page 36" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 702.1.b.3 · PDF page 36</div></details>

Even if a player has not yet met the threshold to upgrade their [[Penalties|penalties]], a [[Head Judge|head judge]] may initiate a [[Cheating|cheating]] investigation if they feel it is appropriate. See [[Unsporting Conduct#^tr-704-8|Cheating]] for more information about cheating. ^tr-702-1-b-4

<details class="rule-ref"><summary title="Tournament rule 702.1.b.4 · PDF page 36" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 702.1.b.4 · PDF page 36</div></details>

At [[Casual OPL|low OPL]], [[Penalties|penalties]] should generally be less harsh and rewinds may be applied even if the erroring player gains an information advantage. ^tr-702-1-c

<details class="rule-ref"><summary title="Tournament rule 702.1.c · PDF page 36" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 702.1.c · PDF page 36</div></details>

At [[Casual OPL|low OPL]], [[Penalties|penalties]] that require an opponent of the erroring player to make a choice are made at random by a judge when they can’t be avoided by a [[Rewinding|rewind]]. ^tr-702-1-c-1

<details class="rule-ref"><summary title="Tournament rule 702.1.c.1 · PDF page 36" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 702.1.c.1 · PDF page 36</div></details>

Certain [[Penalties|penalties]], such as [[Forgetting to Draw Cards]], that would usually be disadvantageous to the erroring player can upgrade in severity if they occur in a situation where the error is obviously advantageous for them. ^tr-702-1-d

<details class="rule-ref"><summary title="Tournament rule 702.1.d · PDF page 36" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 702.1.d · PDF page 36</div></details>

Judges should only upgrade these [[Penalties|penalties]] when the advantage is obvious. If it is ambiguous, judges should not upgrade. ^tr-702-1-d-1

<details class="rule-ref"><summary title="Tournament rule 702.1.d.1 · PDF page 36" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 702.1.d.1 · PDF page 36</div></details>

Certain [[Penalties|penalties]], such as [[Channeling Too Few Runes]], refer to a “full [[Round Cycle|round cycle]]”. A full round cycle completes when the player whose [[Turn|turn]] the error occurred on begins their next turn. ^tr-702-1-e

<details class="rule-ref"><summary title="Tournament rule 702.1.e · PDF page 36" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 702.1.e · PDF page 36</div></details>

[[Missed Trigger]] &#91;No [[Penalties|Penalty]]&#93;: The [[Accountable Player|accountable player]] for a [[Triggered Ability|triggered ability]] doesn’t demonstrate awareness of the trigger before the first time it would have an [[Observable Impact|observable impact]] on the game. ^tr-702-2

<details class="rule-ref"><summary title="Tournament rule 702.2 · PDF page 36" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 702.2 · PDF page 36</div></details>

See [[Tournament Triggered Abilities#^tr-506|Tournament Triggered Abilities]] for definition of [[Triggered Ability|triggered abilities]]. ^tr-702-2-a

<details class="rule-ref"><summary title="Tournament rule 702.2.a · PDF page 36" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 702.2.a · PDF page 36</div></details>

After the initial point at which a [[Triggered Ability|triggered ability]] is missed, any further errors related to that trigger are considered a [[General Error]] instead. See [[Game Play Errors#^tr-702-16|General Error]] for more information about General Errors. ^tr-702-2-b

<details class="rule-ref"><summary title="Tournament rule 702.2.b · PDF page 36" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 702.2.b · PDF page 36</div></details>

Players may not attempt to cause [[Triggered Ability|triggered abilities]] where an opponent is the [[Accountable Player|accountable player]] to be missed by taking [[Game Action|game actions]] or otherwise prematurely advancing the game, including through otherwise acceptable [[Shortcuts|shortcuts]]. ^tr-702-2-c

<details class="rule-ref"><summary title="Tournament rule 702.2.c · PDF page 36" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 702.2.c · PDF page 36</div></details>

A [[Triggered Ability|triggered ability]] is considered to have triggered even if it was subsequently missed. Effects that count or restrict the number of times that [[Ability|ability]] can trigger will count the missed one. ^tr-702-2-d

<details class="rule-ref"><summary title="Tournament rule 702.2.d · PDF page 37" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 702.2.d · PDF page 37</div></details>

If a mandatory trigger is missed by its [[Accountable Player|accountable player]] and missing that trigger is advantageous for them, this [[Penalties|penalty]] is a &#91;[[Warning]]&#93; instead. ^tr-702-2-e

<details class="rule-ref"><summary title="Tournament rule 702.2.e · PDF page 37" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 702.2.e · PDF page 37</div></details>

Remedies: ^tr-702-2-f

<details class="rule-ref"><summary title="Tournament rule 702.2.f · PDF page 37" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 702.2.f · PDF page 37</div></details>

If the trigger was missed during a previous [[Turn|turn]], instruct the players to continue playing. ^tr-702-2-f-1

<details class="rule-ref"><summary title="Tournament rule 702.2.f.1 · PDF page 37" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 702.2.f.1 · PDF page 37</div></details>

Otherwise, the next opponent in [[Turn|turn]] order of the player who missed the trigger chooses whether to resolve the trigger immediately or miss it altogether. ^tr-702-2-f-2

<details class="rule-ref"><summary title="Tournament rule 702.2.f.2 · PDF page 37" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 702.2.f.2 · PDF page 37</div></details>

[[Forgetting to Score a Point]] &#91;No [[Penalties|Penalty]]&#93;: A player is entitled to a point from [[Conquer|conquering]] or [[Hold|holding]] a [[Battlefield|battlefield]] but fails to track it. ^tr-702-3

<details class="rule-ref"><summary title="Tournament rule 702.3 · PDF page 37" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 702.3 · PDF page 37</div></details>

This does not apply to [[Points|points]] that would be scored from [[Card|card]] triggers such as Ahri, Alluring. ^tr-702-3-a

<details class="rule-ref"><summary title="Tournament rule 702.3.a · PDF page 37" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 702.3.a · PDF page 37</div></details>

Remedies: ^tr-702-3-b

<details class="rule-ref"><summary title="Tournament rule 702.3.b · PDF page 37" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 702.3.b · PDF page 37</div></details>

If the correct score can be determined and no more than a full [[Round Cycle|round cycle]] has passed, increment the appropriate player’s score to that total. ^tr-702-3-b-1

<details class="rule-ref"><summary title="Tournament rule 702.3.b.1 · PDF page 37" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 702.3.b.1 · PDF page 37</div></details>

Otherwise, instruct the players to continue playing. ^tr-702-3-b-2

<details class="rule-ref"><summary title="Tournament rule 702.3.b.2 · PDF page 37" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 702.3.b.2 · PDF page 37</div></details>

[[Forgetting to Draw Cards]] &#91;No [[Penalties|Penalty]]&#93;: A player is obligated to [[Draw|draw]] a [[Card|card]], either as part of their [[Draw Phase|draw phase]] or instruction from a card, but fails to do so. ^tr-702-4

<details class="rule-ref"><summary title="Tournament rule 702.4 · PDF page 37" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 702.4 · PDF page 37</div></details>

Remedies: ^tr-702-4-a

<details class="rule-ref"><summary title="Tournament rule 702.4.a · PDF page 37" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 702.4.a · PDF page 37</div></details>

If the missed draws can be determined and no more than a full [[Round Cycle|round cycle]] has passed, the appropriate player draws the missing [[Card|cards]]. ^tr-702-4-a-1

<details class="rule-ref"><summary title="Tournament rule 702.4.a.1 · PDF page 37" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 702.4.a.1 · PDF page 37</div></details>

Otherwise, instruct the players to continue playing. ^tr-702-4-a-2

<details class="rule-ref"><summary title="Tournament rule 702.4.a.2 · PDF page 37" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 702.4.a.2 · PDF page 37</div></details>

If forgetting to [[Draw|draw]] was advantageous to the erroring player (example: the player is near burning out), this [[Penalties|penalty]] is a &#91;[[Warning]]&#93; instead. ^tr-702-4-b

<details class="rule-ref"><summary title="Tournament rule 702.4.b · PDF page 37" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 702.4.b · PDF page 37</div></details>

[[Looking at Extra Cards]] &#91;[[Warning]]&#93;: While taking a [[Game Action|game action]] that allows a player to look at [[Card|cards]] from a deck, they look at more cards than they are entitled to. ^tr-702-5

<details class="rule-ref"><summary title="Tournament rule 702.5 · PDF page 37" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 702.5 · PDF page 37</div></details>

[[Card|Cards]] being looked at from [[Secret Information|secret information]] such as a deck are added to a [[Private Information|private information]] group while they are being looked at. ^tr-702-5-a

<details class="rule-ref"><summary title="Tournament rule 702.5.a · PDF page 37" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 702.5.a · PDF page 37</div></details>

Once extra [[Card|cards]] being looked at have touched a new private or secret group from their original source, they become part of that group. If the extra cards have not touched a new group, this is instead a [[Looking at Secret Information]] error. See [[Game Play Errors#^tr-702-10|Looking at Secret Information]] for more on Looking at Secret Information errors. ^tr-702-5-b

<details class="rule-ref"><summary title="Tournament rule 702.5.b · PDF page 37" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 702.5.b · PDF page 37</div></details>

For example, if a player plays a Stacked Deck and adds a fourth [[Card|card]] to the private set of cards they are looking at, it is [[Looking at Extra Cards]]. If they correctly look at the top three, but knock the top card of their [[Main Deck]] over without adding it to the private group, it is [[Looking at Secret Information]]. ^tr-702-5-b-1

<details class="rule-ref"><summary title="Tournament rule 702.5.b.1 · PDF page 37-38" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 702.5.b.1 · PDF page 37-38</div></details>

Remedies: ^tr-702-5-c

<details class="rule-ref"><summary title="Tournament rule 702.5.c · PDF page 38" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 702.5.c · PDF page 38</div></details>

If the error is caught while the erroring player is looking at the extra [[Card|cards]], the next opponent in [[Turn|turn]] order of the erroring player looks at the private group and chooses the appropriate number of extra cards to shuffle back into the randomized portion of the appropriate deck. ^tr-702-5-c-1

<details class="rule-ref"><summary title="Tournament rule 702.5.c.1 · PDF page 38" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 702.5.c.1 · PDF page 38</div></details>

If one or more of the [[Card|cards]] has already been added to a new group of cards, the next opponent in [[Turn|turn]] order of the erroring player looks at that group and chooses the appropriate number of cards to return to the original group of cards being looked at. Then perform [[Game Play Errors#^tr-702-5-c-1|Game Play Errors]] ^tr-702-5-c-1-a

<details class="rule-ref"><summary title="Tournament rule 702.5.c.1.a · PDF page 38" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 702.5.c.1.a · PDF page 38</div></details>

If the error is caught at a later stage in the game, instruct players to continue playing. ^tr-702-5-c-2

<details class="rule-ref"><summary title="Tournament rule 702.5.c.2 · PDF page 38" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 702.5.c.2 · PDF page 38</div></details>

[[Channeling Too Many Runes]] &#91;[[Warning]]&#93;: A player channels a number of [[Rune|runes]] greater than they are entitled to under the Core Rules as the result of a [[Limited Action|limited action]]. ^tr-702-6

<details class="rule-ref"><summary title="Tournament rule 702.6 · PDF page 38" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 702.6 · PDF page 38</div></details>

Errors of this sort are generally public, and all players are expected to be mindful of game state. ^tr-702-6-a

<details class="rule-ref"><summary title="Tournament rule 702.6.a · PDF page 38" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 702.6.a · PDF page 38</div></details>

Remedies: ^tr-702-6-b

<details class="rule-ref"><summary title="Tournament rule 702.6.b · PDF page 38" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 702.6.b · PDF page 38</div></details>

If the additional [[Rune|runes]] have been used to pay for actions, [[Rewinding|rewind]] if possible. If rewinding is not possible, this is a [[General Error]] instead. See [[Game Play Errors#^tr-702-16|General Error]] for more information about General Errors. ^tr-702-6-b-1

<details class="rule-ref"><summary title="Tournament rule 702.6.b.1 · PDF page 38" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 702.6.b.1 · PDF page 38</div></details>

If the additional [[Rune|runes]] are caught and no more than a full [[Round Cycle|round cycle]] has passed, shuffle them appropriately into the [[Rune Deck|rune deck]]. ^tr-702-6-b-2

<details class="rule-ref"><summary title="Tournament rule 702.6.b.2 · PDF page 38" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 702.6.b.2 · PDF page 38</div></details>

If the specific [[Rune|runes]] can’t be identified, shuffle random runes instead. ^tr-702-6-b-2-a

<details class="rule-ref"><summary title="Tournament rule 702.6.b.2.a · PDF page 38" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 702.6.b.2.a · PDF page 38</div></details>

Otherwise, instruct the players to continue playing. ^tr-702-6-b-3

<details class="rule-ref"><summary title="Tournament rule 702.6.b.3 · PDF page 38" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 702.6.b.3 · PDF page 38</div></details>

[[Channeling Too Few Runes]] &#91;No [[Penalties|Penalty]]&#93;: A player channels a number of [[Rune|runes]] less than what they are entitled to under the Core Rules as the result of a [[Limited Action|limited action]]. ^tr-702-7

<details class="rule-ref"><summary title="Tournament rule 702.7 · PDF page 38" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 702.7 · PDF page 38</div></details>

<details class="rule-ref"><summary title="Tournament rule 702.8.b.1 · PDF page 39" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 702.8.b.1 · PDF page 39</div></details>

[[Looking at Secret Information]] &#91;[[Warning]]&#93;: A player looks at information that is not available to any player. See [[Privacy#^cr-128|Privacy]] for information types. ^tr-702-10

<details class="rule-ref"><summary title="Tournament rule 702.10 · PDF page 39" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 702.10 · PDF page 39</div></details>

Players should not be penalized via a remedy for errors their opponents make. ^tr-702-10-a

Example: If one of your opponents inappropriately flips over the top [[Card|card]] of their deck, you do not receive a [[Penalties|penalty]] if you see it.

<details class="rule-ref"><summary title="Tournament rule 702.10.a · PDF page 39" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 702.10.a · PDF page 39</div></details>

Remedies: ^tr-702-10-b

<details class="rule-ref"><summary title="Tournament rule 702.10.b · PDF page 39" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 702.10.b · PDF page 39</div></details>
