# End of Match Procedure

[[Start Here|Home]] · [[Concept Index|Find a concept]] · [[Tournament Rules|Tournament rules]]

<span title="Tournament rule 408"></span> ^tr-408

<details class="rule-ref"><summary title="Tournament rule 408 · PDF page 11" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 408 · PDF page 11</div></details>

A match is complete once a match result is recorded by players or a tournament official. ^tr-408-1

<details class="rule-ref"><summary title="Tournament rule 408.1 · PDF page 11" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 408.1 · PDF page 11</div></details>

If the time limit for a competition round is reached before a winner is determined, the player whose [[Turn|turn]] it is finishes their turn. ^tr-408-2

<details class="rule-ref"><summary title="Tournament rule 408.2 · PDF page 11" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 408.2 · PDF page 11</div></details>

After that player’s [[Turn|turn]] is complete, three [[Additional Turns|additional turns]] are played, and then the match ends. ^tr-408-2-a

<details class="rule-ref"><summary title="Tournament rule 408.2.a · PDF page 11" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 408.2.a · PDF page 11</div></details>

If the game is incomplete at the end of the [[Additional Turns|additional turns]], a player is declared the winner of the game if they have a point lead of two or more. If no player has a point lead of two or more, the game is a [[Draw (Game Result)|draw]]. ^tr-408-2-b

<details class="rule-ref"><summary title="Tournament rule 408.2.b · PDF page 11" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 408.2.b · PDF page 11</div></details>

[[Additional Turns|Additional turns]] are untimed, but at [[Professional OPL|professional OPL]] a judge must be present to ensure a reasonable pace of [[Play|play]]. ^tr-408-2-c

<details class="rule-ref"><summary title="Tournament rule 408.2.c · PDF page 11" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 408.2.c · PDF page 11</div></details>

If the players are between games when the round time ends, no new game is started. ^tr-408-2-d

<details class="rule-ref"><summary title="Tournament rule 408.2.d · PDF page 11" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 408.2.d · PDF page 11</div></details>

The winner of a match is the first player who reaches the appropriate game win score. ^tr-408-3

<details class="rule-ref"><summary title="Tournament rule 408.3 · PDF page 11" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 408.3 · PDF page 11</div></details>

If neither player has reached that score by the end of the end of match procedure, the player with more game wins wins the match. ^tr-408-3-a

<details class="rule-ref"><summary title="Tournament rule 408.3.a · PDF page 11" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 408.3.a · PDF page 11</div></details>

If players are tied on game wins, the match is a [[Draw (Game Result)|draw]]. ^tr-408-3-b

<details class="rule-ref"><summary title="Tournament rule 408.3.b · PDF page 11" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 408.3.b · PDF page 11</div></details>

[[Playoff|Single elimination]] matches use untimed rounds so players can [[Play|play]] their games to a natural conclusion. In the event that single elimination rounds must use a timer, the following altered End of Match Procedure can be used to determine a winner if time runs out: ^tr-408-4

<details class="rule-ref"><summary title="Tournament rule 408.4 · PDF page 11" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 408.4 · PDF page 11</div></details>

When time is reached before a winner is determined, if players are in-between games, if a player has more game wins in the match they win the match. If game wins are tied, proceed to [[End of Match Procedure#^tr-408-4-d|End of Match Procedure]]. ^tr-408-4-a

<details class="rule-ref"><summary title="Tournament rule 408.4.a · PDF page 11" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 408.4.a · PDF page 11</div></details>

When time is reached before a winner is determined, if players are in the middle of a game, the player whose [[Turn|turn]] it is finishes their turn. ^tr-408-4-b

<details class="rule-ref"><summary title="Tournament rule 408.4.b · PDF page 11" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 408.4.b · PDF page 11</div></details>

After that player’s [[Turn|turn]] is complete, three [[Additional Turns|additional turns]] are played. At the conclusion of those additional turns: ^tr-408-4-c

<details class="rule-ref"><summary title="Tournament rule 408.4.c · PDF page 11" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 408.4.c · PDF page 11</div></details>

If a player has the most [[Points|points]] in the current game, they win that game. Then, if a player has more game wins in the match, they win the match. If the game score is tied, proceed to [[End of Match Procedure#^tr-408-4-d|End of Match Procedure]]. ^tr-408-4-c-1

<details class="rule-ref"><summary title="Tournament rule 408.4.c.1 · PDF page 11" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 408.4.c.1 · PDF page 11</div></details>

If the point score of the current game is tied, but a player has the most game wins in the match, that player wins the match. ^tr-408-4-c-2

<details class="rule-ref"><summary title="Tournament rule 408.4.c.2 · PDF page 11" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 408.4.c.2 · PDF page 11</div></details>

If the point score of the current game is tied and the game score of the match is tied, players continue to [[Play|play]] until the next point is scored. The player who scores that point wins the match. This does not remove normal [[Scoring|scoring]] restrictions if the next point is the Final Point. See [[Scoring#^cr-473-1-a|Scoring]] for Final Point details. ^tr-408-4-c-3

<details class="rule-ref"><summary title="Tournament rule 408.4.c.3 · PDF page 11" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 408.4.c.3 · PDF page 11</div></details>

If the game score is tied and a new game needs to be started, players start the new game and act as though time immediately runs out, beginning the process of [[End of Match Procedure#^tr-408-4-a|End of Match Procedure]]., except with five [[Additional Turns|additional turns]] following the first player's [[Turn|turn]] before [[Movement|moving]] into sudden death [[Scoring|scoring]] as described in [[End of Match Procedure#^tr-408-4-c-3|End of Match Procedure]]. if the point score is tied at the end of those turns. ^tr-408-4-d
