# Display

[[Start Here|Home]] · [[Concept Index|Find a concept]] · [[Tournament Rules|Tournament rules]]

<span title="Tournament rule 424"></span> ^tr-424

<details class="rule-ref"><summary title="Tournament rule 424 · PDF page 17" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 424 · PDF page 17</div></details>

During a match, the [[Start of Match Procedure|start of match procedure]], and other relevant times during a competition, players must keep [[Card|cards]] above the vertical [[Level|level]] of the playing surface. ^tr-424-1

<details class="rule-ref"><summary title="Tournament rule 424.1 · PDF page 17" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 424.1 · PDF page 17</div></details>

Players are responsible for making reasonable effort to [[Prevent|prevent]] [[Secret Information|secret information]] from being [[Reveal|revealed]] accidentally. See [[Privacy#^cr-128|Privacy]] for information types. ^tr-424-2

<details class="rule-ref"><summary title="Tournament rule 424.2 · PDF page 17" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 424.2 · PDF page 17</div></details>

Players may [[Reveal|reveal]] [[Private Information|private information]] unless specifically prohibited by the Core Rules. ^tr-424-3

<details class="rule-ref"><summary title="Tournament rule 424.3 · PDF page 17" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 424.3 · PDF page 17</div></details>

At [[High OPL|high OPL]], players don’t need to inform opponents of accidentally [[Reveal|revealed]] [[Private Information|private information]]. ^tr-424-4
