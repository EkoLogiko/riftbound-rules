# Deck Size

[[Start Here|Home]] · [[Concept Index|Find a concept]] · [[Tournament Rules|Tournament rules]]

In a [[Constructed|constructed]] event, players must use a [[Main Deck]] of exactly 40 [[Card|cards]] (including a [[Chosen Champion|chosen champion]]), 1 [[Legend]], 12 [[Rune|runes]], and exactly 3 [[Battlefield|battlefields]] each with a [[Unique|unique]] [[Card Name|name]]. ^tr-402-1

<details class="rule-ref"><summary title="Tournament rule 402.1 · PDF page 8" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 402.1 · PDF page 8</div></details>
