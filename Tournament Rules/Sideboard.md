<span title="Tournament rule 403"></span> ^tr-403

<details class="rule-ref"><summary title="Tournament rule 403 · PDF page 8" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 403 · PDF page 8</div></details>

In certain competitions, players may have a group of additional [[Card|cards]] (outside of their starting configuration) called a sideboard. See [[Competition Formats#^tr-600|Competition Formats]] for more information on sideboards based on [[Competition Formats|competition formats]]. ^tr-403-1

<details class="rule-ref"><summary title="Tournament rule 403.1 · PDF page 8" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 403.1 · PDF page 8</div></details>

Sideboard size and contents are dictated by the [[Competition Formats|competition format]]. ^tr-403-2

<details class="rule-ref"><summary title="Tournament rule 403.2 · PDF page 8" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 403.2 · PDF page 8</div></details>

Limits on copies of named [[Card|cards]] as defined by [[Competition Formats|competition format]] apply to the combination of [[Main Deck]] and sideboard. ^tr-403-3

<details class="rule-ref"><summary title="Tournament rule 403.3 · PDF page 8" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 403.3 · PDF page 8</div></details>

Players may use sideboard [[Card|cards]] to modify their deck in between games of a match. In [[Constructed|constructed]], sideboard cards must be exchanged 1 for 1 with [[Main Deck]] cards. ^tr-403-4

<details class="rule-ref"><summary title="Tournament rule 403.4 · PDF page 8" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 403.4 · PDF page 8</div></details>

During that time, a player may change their [[Chosen Champion]] to one from their sideboard or [[Main Deck]] that meets the deckbuilding rules of the [[Competition Formats|competition format]]. ^tr-403-4-a

<details class="rule-ref"><summary title="Tournament rule 403.4.a · PDF page 8" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 403.4.a · PDF page 8</div></details>

In [[Constructed|constructed]] formats, a player may not change their [[Rune|Runes]], [[Legend]], or [[Battlefield|Battlefields]] at any point after [[Deck Registration|deck registration]]. ^tr-403-4-b

<details class="rule-ref"><summary title="Tournament rule 403.4.b · PDF page 8" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 403.4.b · PDF page 8</div></details>

After the sideboarding process, a player’s [[Main Deck]] must meet [[Deck Size|deck size]] [[Requirements|requirements]] dictated by the [[Competition Formats|competition format]]. ^tr-403-4-c

<details class="rule-ref"><summary title="Tournament rule 403.4.c · PDF page 8" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 403.4.c · PDF page 8</div></details>

Players may not use sideboard [[Card|cards]] in the first game of a match. ^tr-403-5

<details class="rule-ref"><summary title="Tournament rule 403.5 · PDF page 8" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 403.5 · PDF page 8</div></details>

Players may count the [[Card|cards]] in their opponents’ sideboards at any time. ^tr-403-6

<details class="rule-ref"><summary title="Tournament rule 403.6 · PDF page 8" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 403.6 · PDF page 8</div></details>

A player may look at their own sideboard at any time, but must keep it distinguishable from other [[Card|cards]]. ^tr-403-7

<details class="rule-ref"><summary title="Tournament rule 403.7 · PDF page 9" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 403.7 · PDF page 9</div></details>

A player’s deck and sideboard must be returned to their registered states before the first game of the next match. ^tr-403-8

<details class="rule-ref"><summary title="Tournament rule 403.8 · PDF page 9" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 403.8 · PDF page 9</div></details>

If a match completely skips the first game due to a [[Penalties|penalty]], neither player may sideboard for the following game. ^tr-403-9

<details class="rule-ref"><summary title="Tournament rule 403.9 · PDF page 9" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 403.9 · PDF page 9</div></details>

If a game ends in a [[Draw (Game Result)|draw]], neither player may sideboard for the following game. ^tr-403-10

<details class="rule-ref"><summary title="Tournament rule 403.10 · PDF page 9" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 403.10 · PDF page 9</div></details>

If a game restarts due to an in-game effect or due to corrective action by judges, the state of each player’s deck and sideboard must remain the same in the restarted game. ^tr-403-11

<details class="rule-ref"><summary title="Tournament rule 403.11 · PDF page 9" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 403.11 · PDF page 9</div></details>
