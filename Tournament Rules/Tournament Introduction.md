# Tournament Introduction

[[Start Here|Home]] · [[Concept Index|Find a concept]] · [[Tournament Rules|Tournament rules]]

<span title="Tournament rule 100"></span> ^tr-100

<details class="rule-ref"><summary title="Tournament rule 100 · PDF page 1" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 100 · PDF page 1</div></details>

Purpose: This document provides the frameworks and structures for Riftbound competitions by defining rules, responsibilities and procedures to be followed in all Riftbound competitions. ^tr-101

<details class="rule-ref"><summary title="Tournament rule 101 · PDF page 1" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 101 · PDF page 1</div></details>

Consistency: All Riftbound competitions must be run consistently regardless of their organizer or [[Location|location]] to ensure equal treatment of players and interchangeability of events no matter the region or [[Level|level]]. ^tr-102

<details class="rule-ref"><summary title="Tournament rule 102 · PDF page 1" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 102 · PDF page 1</div></details>

### Responsibility

<span title="Tournament rule 103"></span> ^tr-103

<details class="rule-ref"><summary title="Tournament rule 103 · PDF page 1" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 103 · PDF page 1</div></details>

Attendees: All competitors AND all competition officials are expected to be responsible for following the rules as written and in the spirit in which they were written. This includes respecting all people at competitions. ^tr-103-1

<details class="rule-ref"><summary title="Tournament rule 103.1 · PDF page 1" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 103.1 · PDF page 1</div></details>

[[Spectator|Spectators]]: Spectators have their own set of responsibilities and expectations. See [[Competition Roles#^tr-204-8|Spectator]] for more information on spectators. ^tr-103-2

<details class="rule-ref"><summary title="Tournament rule 103.2 · PDF page 1" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 103.2 · PDF page 1</div></details>

[[Penalties]]: Individuals who violate the frameworks and structures in this document are subject to penalties at the appropriate [[Organized Play Level]] (OPL). See [[Organized Play Level#^tr-205|Organized Play Level]] for more information on Organized Play Levels. ^tr-103-3

### Precedence

<span title="Tournament rule 104"></span> ^tr-104

<details class="rule-ref"><summary title="Tournament rule 104 · PDF page 1" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 104 · PDF page 1</div></details>

vs. Core Rules: In some cases, information in this document may contradict, or provide information not contained in, the Riftbound Core Rules. In all such cases, this document takes precedence for competitions. ^tr-104-1
