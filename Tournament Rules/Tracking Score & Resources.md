# Tracking Score & Resources

[[Start Here|Home]] · [[Concept Index|Find a concept]] · [[Tournament Rules|Tournament rules]]

<span title="Tournament rule 415"></span> ^tr-415

<details class="rule-ref"><summary title="Tournament rule 415 · PDF page 13" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 415 · PDF page 13</div></details>

All players within a game are responsible for tracking all players’ scores throughout the game. ^tr-415-1

<details class="rule-ref"><summary title="Tournament rule 415.1 · PDF page 13" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 415.1 · PDF page 13</div></details>

Changes to score should be announced and acknowledged by all players. ^tr-415-2

<details class="rule-ref"><summary title="Tournament rule 415.2 · PDF page 13" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 415.2 · PDF page 13</div></details>

Scores must be tracked, displayed, and updated legibly in writing. ^tr-415-3

<details class="rule-ref"><summary title="Tournament rule 415.3 · PDF page 13" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 415.3 · PDF page 13</div></details>

At [[Casual OPL|low OPL]], an electronic device, dice, or similar methods can be used to track score. ^tr-415-3-a

<details class="rule-ref"><summary title="Tournament rule 415.3.a · PDF page 14" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 415.3.a · PDF page 14</div></details>

If any player notices a score discrepancy, they must immediately make all players aware of it. If it can’t be resolved easily by the players, a judge must be called. ^tr-415-3-b

<details class="rule-ref"><summary title="Tournament rule 415.3.b · PDF page 14" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 415.3.b · PDF page 14</div></details>

Players must track their own resources such as XP and unspent [[Energy]]/[[Power]] they have floating. They are not required to be written down, but they must be represented in a way that is clear and understandable to all players, such as with dice or [[Counter (Object)|counters]]. ^tr-415-4

<details class="rule-ref"><summary title="Tournament rule 415.4 · PDF page 14" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 415.4 · PDF page 14</div></details>

Resources being immediately spent need to be communicated, but do not need to be tracked in this way. ^tr-415-4-a

<details class="rule-ref"><summary title="Tournament rule 415.4.a · PDF page 14" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 415.4.a · PDF page 14</div></details>

If any player notices a resource discrepancy, they must immediately make all players aware of it. If it can’t be resolved easily by the players, a judge must be called. ^tr-415-4-b

<details class="rule-ref"><summary title="Tournament rule 415.4.b · PDF page 14" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 415.4.b · PDF page 14</div></details>
