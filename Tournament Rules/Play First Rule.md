<details class="rule-ref"><summary title="Tournament rule 407 · PDF page 10" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 407 · PDF page 10</div></details>

For the first game of a match, a designated player decides whether they wish to [[Play|play]] first or last. ^tr-407-1

<details class="rule-ref"><summary title="Tournament rule 407.1 · PDF page 10" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 407.1 · PDF page 10</div></details>

Any random method that is agreed upon by all players in the current game may be used to determine the designated player. ^tr-407-2

<details class="rule-ref"><summary title="Tournament rule 407.2 · PDF page 10" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 407.2 · PDF page 10</div></details>

At [[High OPL|high OPL]], during [[Playoff|playoff]] matches that occur following the end of [[Swiss|Swiss rounds]], the higher ranked player from the Swiss rounds is automatically the designated player for the first game of each match. ^tr-407-2-a

<details class="rule-ref"><summary title="Tournament rule 407.2.a · PDF page 10" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 407.2.a · PDF page 10</div></details>

The player is designated and the choice of playing first is made during the [[Start of Game Procedure|Start of Game procedure]]. See [[Setup Process#^cr-115|Determine turn order]]. ^tr-407-3

<details class="rule-ref"><summary title="Tournament rule 407.3 · PDF page 10" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 407.3 · PDF page 10</div></details>

For games after the first game of a match, the loser of the previous game gets to choose if they [[Play|play]] first or last. If the previous game was a [[Draw (Game Result)|draw]], the starting play from the previous game is maintained. ^tr-407-4

<details class="rule-ref"><summary title="Tournament rule 407.4 · PDF page 10" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 407.4 · PDF page 10</div></details>

For alterations to this rule for 2v2, see [[2v2 (Tournament)#^tr-603-7|2v2 (Tournament)]]. ^tr-407-5
