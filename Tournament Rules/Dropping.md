# Dropping

[[Start Here|Home]] · [[Concept Index|Find a concept]] · [[Tournament Rules|Tournament rules]]

<span title="Tournament rule 414"></span> ^tr-414

<details class="rule-ref"><summary title="Tournament rule 414 · PDF page 13" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 414 · PDF page 13</div></details>

Players may drop from a competition at any time. ^tr-414-1

<details class="rule-ref"><summary title="Tournament rule 414.1 · PDF page 13" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 414.1 · PDF page 13</div></details>

If a player drops before the competition begins, they never participated in the competition. ^tr-414-2

<details class="rule-ref"><summary title="Tournament rule 414.2 · PDF page 13" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 414.2 · PDF page 13</div></details>

Players who wish to drop must inform the [[Scorekeeper|scorekeeper]] before pairings for the next round of the competition are generated. ^tr-414-3

<details class="rule-ref"><summary title="Tournament rule 414.3 · PDF page 13" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 414.3 · PDF page 13</div></details>

If a player doesn’t show up for their match, they are automatically dropped from the competition unless they report to the [[Scorekeeper|scorekeeper]]. ^tr-414-4

<details class="rule-ref"><summary title="Tournament rule 414.4 · PDF page 13" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 414.4 · PDF page 13</div></details>

Players who drop from [[Limited|limited]] format tournaments own the [[Card|cards]] that they correctly have in their possession at the time of dropping, including unopened packs. ^tr-414-5

<details class="rule-ref"><summary title="Tournament rule 414.5 · PDF page 13" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 414.5 · PDF page 13</div></details>

If a player drops from a competition after a top placement cut has been made, no player is advanced in replacement. The highest ranked remaining player receives a bye if the drop happens before pairings. ^tr-414-6

<details class="rule-ref"><summary title="Tournament rule 414.6 · PDF page 13" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 414.6 · PDF page 13</div></details>

Players who have dropped may re-enter the competition before the start of the following round at the discretion of the [[Head Judge|head judge]]. ^tr-414-7

<details class="rule-ref"><summary title="Tournament rule 414.7 · PDF page 13" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 414.7 · PDF page 13</div></details>

Players can’t re-enter a competition if they missed a portion where a [[Deck Construction|deck construction]] activity was required. ^tr-414-8

<details class="rule-ref"><summary title="Tournament rule 414.8 · PDF page 13" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 414.8 · PDF page 13</div></details>

Players can’t re-enter a competition after a top placement cut. ^tr-414-9

<details class="rule-ref"><summary title="Tournament rule 414.9 · PDF page 13" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 414.9 · PDF page 13</div></details>
