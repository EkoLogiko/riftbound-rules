# Requirements

[[Start Here|Home]] · [[Concept Index|Find a concept]] · [[Tournament Rules|Tournament rules]]

<span title="Tournament rule 501"></span> ^tr-501

<details class="rule-ref"><summary title="Tournament rule 501 · PDF page 17" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 501 · PDF page 17</div></details>

Players are required to communicate honestly about the state of the game with their opponents. ^tr-501-1

<details class="rule-ref"><summary title="Tournament rule 501.1 · PDF page 17" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 501.1 · PDF page 17</div></details>

Players are required to communicate honestly and completely with tournament officials. ^tr-501-2

<details class="rule-ref"><summary title="Tournament rule 501.2 · PDF page 17" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 501.2 · PDF page 17</div></details>

Players are not required to assist their opponents in [[Playing the Game|playing the game]]. ^tr-501-3

<details class="rule-ref"><summary title="Tournament rule 501.3 · PDF page 17" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 501.3 · PDF page 17</div></details>

Players are required to treat other players, tournament officials, and [[Spectator|spectators]] with respect. ^tr-501-4

<details class="rule-ref"><summary title="Tournament rule 501.4 · PDF page 17" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 501.4 · PDF page 17</div></details>

In team events, communication between teammates is allowed and encouraged, but it must be done in a reasonably timely manner. See [[Tournament Errors#^tr-703-2|Slow Play]] for more information on [[Slow Play]]. ^tr-501-5
