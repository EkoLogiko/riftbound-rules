# Concessions and Intentional Draws

[[Start Here|Home]] · [[Concept Index|Find a concept]] · [[Tournament Rules|Tournament rules]]

<span title="Tournament rule 410"></span> ^tr-410

<details class="rule-ref"><summary title="Tournament rule 410 · PDF page 12" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 410 · PDF page 12</div></details>

At any time before a game is completed, any player may concede that game or all players may mutually agree to [[Draw (Game Result)|draw]] it. ^tr-410-1

<details class="rule-ref"><summary title="Tournament rule 410.1 · PDF page 12" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 410.1 · PDF page 12</div></details>

At any time before a match is completed, any player may concede that match or all players may mutually agree to [[Draw (Game Result)|draw]] it. ^tr-410-2

<details class="rule-ref"><summary title="Tournament rule 410.2 · PDF page 12" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 410.2 · PDF page 12</div></details>

Players can’t agree to concessions or draws in exchange for anything. See [[Unsporting Conduct#^tr-704-5|Bribery]] for more information on [[Bribery|bribery]]. ^tr-410-3

<details class="rule-ref"><summary title="Tournament rule 410.3 · PDF page 12" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 410.3 · PDF page 12</div></details>

Players can’t scout other match results before deciding to concede or [[Draw (Game Result)|draw]] their match and need to remain in their seats while their match is in progress. Violating this policy is considered an [[Unsporting Minor|unsporting minor]] [[Penalties|penalty]]. (See [[Unsporting Conduct#^tr-704-2|Unsporting Minor]] for Unsporting Minor penalties.) ^tr-410-4

<details class="rule-ref"><summary title="Tournament rule 410.4 · PDF page 12" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 410.4 · PDF page 12</div></details>

If a player refuses to [[Play|play]], tournament officials should treat that as [[Conceding|conceding]] the match. ^tr-410-5
