# Tiebreakers

[[Start Here|Home]] · [[Concept Index|Find a concept]] · [[Tournament Rules|Tournament rules]]

<span title="Tournament rule 409"></span> ^tr-409

<details class="rule-ref"><summary title="Tournament rule 409 · PDF page 12" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 409 · PDF page 12</div></details>

In the course of determining standings, the [[Scorekeeper|scorekeeper]] [[Might|might]] need to distinguish between two players with equal match records. ^tr-409-1

<details class="rule-ref"><summary title="Tournament rule 409.1 · PDF page 12" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 409.1 · PDF page 12</div></details>

In these cases, the following tiebreakers should be applied in order: ^tr-409-2

<details class="rule-ref"><summary title="Tournament rule 409.2 · PDF page 12" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 409.2 · PDF page 12</div></details>

The player with higher opponents’ mean (average) match win percentage. ^tr-409-2-a

<details class="rule-ref"><summary title="Tournament rule 409.2.a · PDF page 12" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 409.2.a · PDF page 12</div></details>

The player with higher game win percentage. ^tr-409-2-b

<details class="rule-ref"><summary title="Tournament rule 409.2.b · PDF page 12" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 409.2.b · PDF page 12</div></details>

The player with higher opponents’ mean (average) game win percentage. ^tr-409-2-c

<details class="rule-ref"><summary title="Tournament rule 409.2.c · PDF page 12" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 409.2.c · PDF page 12</div></details>

If after all tiebreakers are applied, two players are still of equal standing in the competition, the [[Scorekeeper|scorekeeper]] should use a random method to break the [[Tie|tie]]. ^tr-409-3

<details class="rule-ref"><summary title="Tournament rule 409.3 · PDF page 12" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 409.3 · PDF page 12</div></details>
