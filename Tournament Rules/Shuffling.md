<span title="Tournament rule 421"></span> ^tr-421

<details class="rule-ref"><summary title="Tournament rule 421 · PDF page 15" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 421 · PDF page 15</div></details>

Decks must be made random at the start of each game, and whenever an instruction from [[Card|cards]] or tournament officials require it. ^tr-421-1

<details class="rule-ref"><summary title="Tournament rule 421.1 · PDF page 15" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 421.1 · PDF page 15</div></details>

Random is defined as a state where no player could have any information about the order or position of [[Card|cards]] in any part of the deck. ^tr-421-2

<details class="rule-ref"><summary title="Tournament rule 421.2 · PDF page 15" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 421.2 · PDF page 15</div></details>

Shuffling by methodically placing [[Card|cards]] into distinct piles (informally known as “pile shuffling”) may be used as a method to count the deck, but can’t solely be used to make a deck random. ^tr-421-3

<details class="rule-ref"><summary title="Tournament rule 421.3 · PDF page 16" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 421.3 · PDF page 16</div></details>

When a deck is made random, it is presented to the player’s opponent. This signals that the player believes their deck is legal and random. ^tr-421-4

<details class="rule-ref"><summary title="Tournament rule 421.4 · PDF page 16" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 421.4 · PDF page 16</div></details>

Players must notify a judge if they believe their opponents’ deck has not been made sufficiently random. See [[Tournament Errors#^tr-703-7|Insufficient Randomization]] for more information on [[Insufficient Randomization|insufficient randomization]]. ^tr-421-5

<details class="rule-ref"><summary title="Tournament rule 421.5 · PDF page 16" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 421.5 · PDF page 16</div></details>

Players may shuffle their opponents’ decks additionally. ^tr-421-6

<details class="rule-ref"><summary title="Tournament rule 421.6 · PDF page 16" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 421.6 · PDF page 16</div></details>

Players must take care not to [[Damage|damage]] [[Card|cards]] or [[Sleeves|sleeves]] through this process of shuffling, nor cause cards or sleeves to become marked. ^tr-421-7

<details class="rule-ref"><summary title="Tournament rule 421.7 · PDF page 16" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 421.7 · PDF page 16</div></details>

When two or more [[Card|cards]] are recycled to the player’s [[Main Deck]] as part of a single action, the above procedures 1-7 should be followed for that group of cards to properly randomize them before recycling them. ^tr-421-8
