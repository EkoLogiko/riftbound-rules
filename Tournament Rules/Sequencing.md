# Sequencing

[[Start Here|Home]] · [[Concept Index|Find a concept]] · [[Tournament Rules|Tournament rules]]

<span title="Tournament rule 504"></span> ^tr-504

<details class="rule-ref"><summary title="Tournament rule 504 · PDF page 19" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 504 · PDF page 19</div></details>

Complex series of [[Game Action|game actions]] are sometimes shortcutted into out-of-order sequences, which are technically incorrect or imprecise, but arrive at the correct legal and understood game state. ^tr-504-1

<details class="rule-ref"><summary title="Tournament rule 504.1 · PDF page 19" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 504.1 · PDF page 19</div></details>

Example: Drawing a [[Card|card]] before channeling [[Rune|runes]]. ^tr-504-1-a

<details class="rule-ref"><summary title="Tournament rule 504.1.a · PDF page 19" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 504.1.a · PDF page 19</div></details>

Players may ask their opponents to do these actions, or a subset of these actions, in the correct order so that they can react at the appropriate time. ^tr-504-2

<details class="rule-ref"><summary title="Tournament rule 504.2 · PDF page 19" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 504.2 · PDF page 19</div></details>

Players can’t [[Shortcuts|shortcut]] out-of-order in a way that gives them information prematurely that [[Might|might]] affect decisions later in that sequence. ^tr-504-3

<details class="rule-ref"><summary title="Tournament rule 504.3 · PDF page 19" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 504.3 · PDF page 19</div></details>

When something is recycled, it must be immediately put on the bottom of the appropriate deck. ^tr-504-4

<details class="rule-ref"><summary title="Tournament rule 504.4 · PDF page 19" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 504.4 · PDF page 19</div></details>

Example: A player may not keep their recycled [[Rune|runes]] facedown on [[Board|the board]] to track [[Energy]]. ^tr-504-4-a

<details class="rule-ref"><summary title="Tournament rule 504.4.a · PDF page 19" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 504.4.a · PDF page 19</div></details>

Failure to [[Recycle|recycle]] in this way is a [[Communication Violation]]. See [[Tournament Errors#^tr-703-5|Communication Violation]] for more information on Communication Violations. ^tr-504-4-b

<details class="rule-ref"><summary title="Tournament rule 504.4.b · PDF page 20" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 504.4.b · PDF page 20</div></details>
