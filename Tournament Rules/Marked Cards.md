# Marked Cards

[[Start Here|Home]] · [[Concept Index|Find a concept]] · [[Tournament Rules|Tournament rules]]

<span title="Tournament rule 423"></span> ^tr-423

<details class="rule-ref"><summary title="Tournament rule 423 · PDF page 16" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 423 · PDF page 16</div></details>

Players are responsible during competitions to make sure their [[Card|cards]] and/or [[Sleeves|sleeves]] are not marked. ^tr-423-1

<details class="rule-ref"><summary title="Tournament rule 423.1 · PDF page 16" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 423.1 · PDF page 16</div></details>

Marked is defined as bearing something that makes it possible to identify the [[Card|card]] without seeing its face. ^tr-423-2

<details class="rule-ref"><summary title="Tournament rule 423.2 · PDF page 17" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 423.2 · PDF page 17</div></details>

If [[Card|cards]] are sleeved, they should be inspected for marking while in the [[Sleeves|sleeves]]. ^tr-423-3

<details class="rule-ref"><summary title="Tournament rule 423.3 · PDF page 17" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 423.3 · PDF page 17</div></details>

Judges may ask players to remove [[Sleeves|sleeves]] or replace any specific sleeve at any time during a competition. ^tr-423-4

<details class="rule-ref"><summary title="Tournament rule 423.4 · PDF page 17" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 423.4 · PDF page 17</div></details>
