# Match

[[Start Here|Home]] · [[Concept Index|Find a concept]] · [[Tournament Rules|Tournament rules]]

<span title="Tournament rule 404"></span> ^tr-404

<details class="rule-ref"><summary title="Tournament rule 404 · PDF page 9" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 404 · PDF page 9</div></details>

A match of Riftbound consists of a series of games that are played until one side has won a predetermined number of games. ^tr-404-1

<details class="rule-ref"><summary title="Tournament rule 404.1 · PDF page 9" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 404.1 · PDF page 9</div></details>

Most matches of Riftbound are “best of 3,” meaning the predetermined number of games to win is 2. ^tr-404-2

<details class="rule-ref"><summary title="Tournament rule 404.2 · PDF page 9" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 404.2 · PDF page 9</div></details>

Games that end in a [[Draw|draw]] do not count toward this goal. ^tr-404-3

<details class="rule-ref"><summary title="Tournament rule 404.3 · PDF page 9" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 404.3 · PDF page 9</div></details>

If the competition round ends (due to time limits) prior to any side achieving the goal, the winner of the match is the one who has won the most games. ^tr-404-4

<details class="rule-ref"><summary title="Tournament rule 404.4 · PDF page 9" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 404.4 · PDF page 9</div></details>

If all sides have equal game wins, the match is a [[Draw (Game Result)|draw]]. ^tr-404-5

<details class="rule-ref"><summary title="Tournament rule 404.5 · PDF page 9" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 404.5 · PDF page 9</div></details>
