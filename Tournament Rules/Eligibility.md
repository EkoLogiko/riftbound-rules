# Eligibility

[[Start Here|Home]] · [[Concept Index|Find a concept]] · [[Tournament Rules|Tournament rules]]

<span title="Tournament rule 300"></span> ^tr-300

<details class="rule-ref"><summary title="Tournament rule 300 · PDF page 6" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 300 · PDF page 6</div></details>

Anyone is eligible to participate as a player in Riftbound competitions, unless the player is: ^tr-301

<details class="rule-ref"><summary title="Tournament rule 301 · PDF page 6" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 301 · PDF page 6</div></details>

Suspended. ^tr-301-1

<details class="rule-ref"><summary title="Tournament rule 301.1 · PDF page 6" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 301.1 · PDF page 6</div></details>

A competition official in that same competition, unless the competition explicitly allows it (non-premier competitions only). ^tr-301-2

<details class="rule-ref"><summary title="Tournament rule 301.2 · PDF page 6" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 301.2 · PDF page 6</div></details>

Specifically prohibited by Riot or official partner policy. ^tr-301-3

<details class="rule-ref"><summary title="Tournament rule 301.3 · PDF page 6" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 301.3 · PDF page 6</div></details>

Under 13 years of age and do not have a parent’s or guardian’s permission. ^tr-301-4

<details class="rule-ref"><summary title="Tournament rule 301.4 · PDF page 6" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 301.4 · PDF page 6</div></details>

Prohibited by law, the rules or policy of the [[Competition Organizer]], or by the venue’s rules or policy. ^tr-301-5

<details class="rule-ref"><summary title="Tournament rule 301.5 · PDF page 6" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 301.5 · PDF page 6</div></details>

Restricted by competition addenda regarding age, as long as those restrictions are messaged ahead of time (at [[Casual OPL|low OPL]]). ^tr-301-6

<details class="rule-ref"><summary title="Tournament rule 301.6 · PDF page 7" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 301.6 · PDF page 7</div></details>

Anyone is eligible to participate as a competition official, unless the player is: ^tr-302

<details class="rule-ref"><summary title="Tournament rule 302 · PDF page 7" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 302 · PDF page 7</div></details>

Suspended. ^tr-302-1

<details class="rule-ref"><summary title="Tournament rule 302.1 · PDF page 7" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 302.1 · PDF page 7</div></details>

A player in that same competition, unless the competition explicitly allows it (non-premier competitions only). ^tr-302-2

<details class="rule-ref"><summary title="Tournament rule 302.2 · PDF page 7" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 302.2 · PDF page 7</div></details>

If a competition official for an event participates in that event, it must be run at [[Casual OPL]]. ^tr-303

<details class="rule-ref"><summary title="Tournament rule 303 · PDF page 7" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 303 · PDF page 7</div></details>

Owners of organizations that run [[Premier Competition|premier competitions]] may not [[Play|play]] in those competitions, even if otherwise allowed. ^tr-304

<details class="rule-ref"><summary title="Tournament rule 304 · PDF page 7" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 304 · PDF page 7</div></details>

Some competitions have additional criteria regarding eligibility for players or competition officials (for example, invitation-only competitions). ^tr-305

<details class="rule-ref"><summary title="Tournament rule 305 · PDF page 7" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 305 · PDF page 7</div></details>

Employees of Riot and their families are subject to additional restrictions. ^tr-306

<details class="rule-ref"><summary title="Tournament rule 306 · PDF page 7" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 306 · PDF page 7</div></details>

Family is defined here as any person living with or related to the relevant employee, but not themselves an employee. ^tr-306-1

<details class="rule-ref"><summary title="Tournament rule 306.1 · PDF page 7" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 306.1 · PDF page 7</div></details>

All employees and their family are allowed to participate in [[Local Competition|local competitions]]. ^tr-306-2

<details class="rule-ref"><summary title="Tournament rule 306.2 · PDF page 7" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 306.2 · PDF page 7</div></details>

If the reward is product or cash, the employee or family member may claim that part of the reward. ^tr-306-2-a

<details class="rule-ref"><summary title="Tournament rule 306.2.a · PDF page 7" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 306.2.a · PDF page 7</div></details>

Employees must declare themselves to the [[Competition Organizer|CO]]. ^tr-306-3

<details class="rule-ref"><summary title="Tournament rule 306.3 · PDF page 7" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 306.3 · PDF page 7</div></details>

The [[Competition Organizer|CO]] may decline to allow Riot employees to participate in the competition for any reason; if so, they must abide by this decision. ^tr-306-4

<details class="rule-ref"><summary title="Tournament rule 306.4 · PDF page 7" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 306.4 · PDF page 7</div></details>

No Riot employee is allowed to [[Play|play]] in [[Premier Competition|premier]] or [[Qualifier Competition|qualifier]] competitions. ^tr-306-5

<details class="rule-ref"><summary title="Tournament rule 306.5 · PDF page 7" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 306.5 · PDF page 7</div></details>

Families of employees are allowed to [[Play|play]] in [[Premier Competition|premier]] or [[Qualifier Competition|qualifier]] competitions, if they are otherwise eligible to compete. ^tr-306-6

<details class="rule-ref"><summary title="Tournament rule 306.6 · PDF page 7" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 306.6 · PDF page 7</div></details>
