# Information

[[Start Here|Home]] · [[Concept Index|Find a concept]] · [[Tournament Rules|Tournament rules]]

<span title="Tournament rule 502"></span> ^tr-502

<details class="rule-ref"><summary title="Tournament rule 502 · PDF page 17" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 502 · PDF page 17</div></details>

[[Card|Cards]] have a [[Level|level]] of [[Privacy|privacy]] as specified in [[Privacy#^cr-128|Privacy]]. These apply to levels of information accessible to the players as well. ^tr-502-1

<details class="rule-ref"><summary title="Tournament rule 502.1 · PDF page 17" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 502.1 · PDF page 17</div></details>

In addition to these levels of information, some information is derived. ^tr-502-2

<details class="rule-ref"><summary title="Tournament rule 502.2 · PDF page 17" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 502.2 · PDF page 17</div></details>

[[Derived Information|Derived information]] is a combination of [[Public Information|public information]] and a player’s own skill or calculation. ^tr-502-2-a

<details class="rule-ref"><summary title="Tournament rule 502.2.a · PDF page 17" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 502.2.a · PDF page 17</div></details>

Players are not required to assist opponents in determining [[Derived Information|derived information]]. ^tr-502-2-b

<details class="rule-ref"><summary title="Tournament rule 502.2.b · PDF page 17" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 502.2.b · PDF page 17</div></details>

Like [[Card|cards]], other relevant information about the game state can be public, derived, private, or secret. ^tr-502-3

<details class="rule-ref"><summary title="Tournament rule 502.3 · PDF page 17" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 502.3 · PDF page 17</div></details>

The additional relevant [[Public Information|public information]] includes: ^tr-502-4

<details class="rule-ref"><summary title="Tournament rule 502.4 · PDF page 18" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 502.4 · PDF page 18</div></details>

The current [[Turn Player|turn player]], phase, step, state of [[Turn|the turn]], and who has [[Priority and Focus|priority and focus]]. ^tr-502-4-a

<details class="rule-ref"><summary title="Tournament rule 502.4.a · PDF page 18" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 502.4.a · PDF page 18</div></details>

If the [[End of Match Procedure|end of match procedure]] has entered [[Additional Turns|additional turns]] and where in the additional turns players are. Players must announce and acknowledge additional turns as they occur. (See [[End of Match Procedure#^tr-408|End of Match Procedure]] for more information on End of Match Procedure.) ^tr-502-4-b

<details class="rule-ref"><summary title="Tournament rule 502.4.b · PDF page 18" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 502.4.b · PDF page 18</div></details>

[[Rune Pool|Rune Pools]] and the number and quantity of resources in them. ^tr-502-4-c

<details class="rule-ref"><summary title="Tournament rule 502.4.c · PDF page 18" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 502.4.c · PDF page 18</div></details>

All players’ current scores. ^tr-502-4-d

<details class="rule-ref"><summary title="Tournament rule 502.4.d · PDF page 18" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 502.4.d · PDF page 18</div></details>

A [[Permanent|permanent]]’s current state, as distinct from its printed ones. ^tr-502-4-e

<details class="rule-ref"><summary title="Tournament rule 502.4.e · PDF page 18" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 502.4.e · PDF page 18</div></details>

[[Spell|Spells]] and [[Ability|abilities]] on the [[Chain]], their order, and [[Play|play]] choices made for them. ^tr-502-4-f

<details class="rule-ref"><summary title="Tournament rule 502.4.f · PDF page 18" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 502.4.f · PDF page 18</div></details>

[[Spell|Spells]] and [[Ability|abilities]] that resolved previously in [[Turn|the turn]], and the sources of them are themselves public. ^tr-502-4-g

<details class="rule-ref"><summary title="Tournament rule 502.4.g · PDF page 18" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 502.4.g · PDF page 18</div></details>

The additional relevant [[Derived Information|derived information]] includes: ^tr-502-5

<details class="rule-ref"><summary title="Tournament rule 502.5 · PDF page 18" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 502.5 · PDF page 18</div></details>

Which public [[Card|cards]] have been recycled. ^tr-502-5-a

<details class="rule-ref"><summary title="Tournament rule 502.5.a · PDF page 18" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 502.5.a · PDF page 18</div></details>

The order of [[Rune|runes]] in a [[Rune Deck]]. ^tr-502-5-b

<details class="rule-ref"><summary title="Tournament rule 502.5.b · PDF page 18" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 502.5.b · PDF page 18</div></details>

Consequences of actions that [[Might|might]] happen in the future, such as a [[Unit|unit]] receiving a [[Might Bonus|Might bonus]] from the [[Shield]] [[Ability|ability]] if a player attacks. ^tr-502-5-c

<details class="rule-ref"><summary title="Tournament rule 502.5.c · PDF page 18" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 502.5.c · PDF page 18</div></details>

Players must acknowledge changes to [[Public Information|public information]] that result from their [[Card|cards]] and effects as those effects would have an [[Observable Impact|observable impact]] on the game. See [[Tournament Triggered Abilities#^tr-506-3-e|Tournament Triggered Abilities]] for examples of observable impact. ^tr-502-6

<details class="rule-ref"><summary title="Tournament rule 502.6 · PDF page 18" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 502.6 · PDF page 18</div></details>

As part of acknowledging changes to [[Public Information|public information]], the [[Accountable Player|accountable player]] must communicate the change to all other players in an understandable and observable way. Examples include verbally announcing the change, physically indicating the change, or other means of communication understood and agreed upon by all players in the game. ^tr-502-6-a

<details class="rule-ref"><summary title="Tournament rule 502.6.a · PDF page 18" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 502.6.a · PDF page 18</div></details>

Players must answer honestly any questions regarding [[Public Information|public information]]. ^tr-502-7

<details class="rule-ref"><summary title="Tournament rule 502.7 · PDF page 18" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 502.7 · PDF page 18</div></details>

Players must not represent public or [[Derived Information|derived information]] incorrectly. ^tr-502-8

<details class="rule-ref"><summary title="Tournament rule 502.8 · PDF page 18" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 502.8 · PDF page 18</div></details>

Players must point out discrepancies between announced and recorded [[Public Information|public information]]. ^tr-502-9

<details class="rule-ref"><summary title="Tournament rule 502.9 · PDF page 18" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 502.9 · PDF page 18</div></details>

Judges are encouraged to help players determine [[Public Information|public information]], but not [[Derived Information|derived information]]. ^tr-502-10

<details class="rule-ref"><summary title="Tournament rule 502.10 · PDF page 18" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 502.10 · PDF page 18</div></details>

Players are not required to share [[Private Information|private information]], and may bluff in regards to their private information. ^tr-502-11

<details class="rule-ref"><summary title="Tournament rule 502.11 · PDF page 18" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 502.11 · PDF page 18</div></details>

In 2v2, teammates may share [[Private Information|Private information]], including directly showing each other the [[Card|cards]] in their [[Hand|hand]] as defined by [[2v2 (Magma Chamber)#^cr-491-8-f|2v2 (Magma Chamber)]] in the Core Rules. ^tr-502-12

<details class="rule-ref"><summary title="Tournament rule 502.12 · PDF page 18" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 502.12 · PDF page 18</div></details>
