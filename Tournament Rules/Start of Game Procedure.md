<span title="Tournament rule 406"></span> ^tr-406

<details class="rule-ref"><summary title="Tournament rule 406 · PDF page 9" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 406 · PDF page 9</div></details>

The [[Setup Process|setup process]] for a game of Riftbound is defined in the Core Rules. See [[Setup Process#^cr-110|Setup Process]]. Additionally: ^tr-406-1

<details class="rule-ref"><summary title="Tournament rule 406.1 · PDF page 9" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 406.1 · PDF page 9</div></details>

In competitions where [[Sideboard|sideboards]] are allowed, players may exchange [[Card|cards]] from their [[Main Deck|main deck]] and their sideboard after each game of a match. See [[Sideboard#^tr-403|Sideboard]] for more information on sideboards. ^tr-406-1-a

<details class="rule-ref"><summary title="Tournament rule 406.1.a · PDF page 9" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 406.1.a · PDF page 9</div></details>

If a game ends in a [[Draw (Game Result)|draw]], players must use the same [[Battlefield|battlefields]] for the following game. ^tr-406-1-b

<details class="rule-ref"><summary title="Tournament rule 406.1.b · PDF page 9" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 406.1.b · PDF page 9</div></details>

If a game ends due to a [[Game Loss|game loss]] [[Penalties|penalty]] after players have selected and [[Reveal|revealed]] their [[Battlefield|battlefields]], players must use different battlefields for any following games in the match. ^tr-406-1-c

<details class="rule-ref"><summary title="Tournament rule 406.1.c · PDF page 9" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 406.1.c · PDF page 9</div></details>

Each player must shuffle their [[Main Deck]] and their [[Rune Deck]]. See [[Shuffling#^tr-421|Shuffling]] for more information on [[Shuffling|shuffling]]. ^tr-406-1-d

<details class="rule-ref"><summary title="Tournament rule 406.1.d · PDF page 9" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 406.1.d · PDF page 9</div></details>

Each player must present their [[Main Deck]], [[Rune Deck]], and [[Sideboard|sideboard]] (if applicable to the format) to their opponents. ^tr-406-1-e

<details class="rule-ref"><summary title="Tournament rule 406.1.e · PDF page 9" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 406.1.e · PDF page 9</div></details>

Each player may shuffle the [[Main Deck]] and [[Rune Deck]] of each of their opponents. ^tr-406-1-f

<details class="rule-ref"><summary title="Tournament rule 406.1.f · PDF page 10" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 406.1.f · PDF page 10</div></details>

In team competitions, each player may shuffle the [[Main Deck]] and [[Rune Deck]] of one of their team’s opponents. ^tr-406-1-f-1

<details class="rule-ref"><summary title="Tournament rule 406.1.f.1 · PDF page 10" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 406.1.f.1 · PDF page 10</div></details>

At [[Professional OPL]], this is required. ^tr-406-1-f-2

<details class="rule-ref"><summary title="Tournament rule 406.1.f.2 · PDF page 10" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 406.1.f.2 · PDF page 10</div></details>

A player may request a judge shuffle their deck in lieu of an opponent, to be honored at judge discretion. ^tr-406-1-f-3

<details class="rule-ref"><summary title="Tournament rule 406.1.f.3 · PDF page 10" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 406.1.f.3 · PDF page 10</div></details>

For the first game of a match, start of game procedures may be performed as soon as both players reach their assigned seat, even before the start of the round clock. Gameplay must wait for the round clock to begin. ^tr-406-1-g

<details class="rule-ref"><summary title="Tournament rule 406.1.g · PDF page 10" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 406.1.g · PDF page 10</div></details>

For competitions run using a “best of 1” format instead of a “best of 3” format, the [[Head Judge|head judge]] may opt to use the altered initial [[Setup Process|setup process]] listed below to closer mirror the “best of 3” experience: ^tr-406-1-h

<details class="rule-ref"><summary title="Tournament rule 406.1.h · PDF page 10" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 406.1.h · PDF page 10</div></details>

Each player separates their [[Champion Legend]] and places it in the [[Legend Zone]]. ^tr-406-1-h-1

<details class="rule-ref"><summary title="Tournament rule 406.1.h.1 · PDF page 10" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 406.1.h.1 · PDF page 10</div></details>

Each player randomly selects one of their three [[Battlefield|Battlefields]], and places it into the [[Battlefield Zone]]. ^tr-406-1-h-2

<details class="rule-ref"><summary title="Tournament rule 406.1.h.2 · PDF page 10" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 406.1.h.2 · PDF page 10</div></details>

Players use the [[Play First Rule]] listed below to determine the designated player. See [[Play First Rule#^tr-407|Play First Rule]] for more information on the Play First Rule. ^tr-406-1-h-3

<details class="rule-ref"><summary title="Tournament rule 406.1.h.3 · PDF page 10" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 406.1.h.3 · PDF page 10</div></details>

The designated player chooses if they would like to go first or last. ^tr-406-1-h-4

<details class="rule-ref"><summary title="Tournament rule 406.1.h.4 · PDF page 10" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 406.1.h.4 · PDF page 10</div></details>

Players then have the opportunity to [[Sideboard|sideboard]] as if they were in between games of a “best of 3” match. See [[Sideboard#^tr-403|Sideboard]] for more information on sideboards. ^tr-406-1-h-5

<details class="rule-ref"><summary title="Tournament rule 406.1.h.5 · PDF page 10" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 406.1.h.5 · PDF page 10</div></details>

After [[Sideboard|sideboarding]] is complete, each player separates their [[Chosen Champion]] and places it in the [[Champion Zone]]. ^tr-406-1-h-6

<details class="rule-ref"><summary title="Tournament rule 406.1.h.6 · PDF page 10" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 406.1.h.6 · PDF page 10</div></details>

Players perform [[Shuffling|shuffling]] steps [[Start of Game Procedure#^tr-406-1-d|deck shuffling]]-[[Start of Game Procedure#^tr-406-1-f-3|the judge shuffle option]] listed above, then proceed to [[Setup Process#^cr-110|Setup Process]]. ^tr-406-1-h-7

<details class="rule-ref"><summary title="Tournament rule 406.1.h.7 · PDF page 10" aria-label="Show source rule">ⓘ</summary><div class="rule-tooltip">Tournament rule 406.1.h.7 · PDF page 10</div></details>
